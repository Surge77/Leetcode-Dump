# 1235. Maximum Profit in Job Scheduling

**🔗 Link:** [LeetCode 1235](https://leetcode.com/problems/maximum-profit-in-job-scheduling/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Each job runs from `startTime[i]` to `endTime[i]` and pays `profit[i]`. Pick a set of jobs whose time ranges do not overlap, where a job may start exactly when another ends, and return the largest total profit.

* **Example:** `startTime = [1,2,3,3], endTime = [3,4,5,6], profit = [50,10,40,70]` → `120`
* **Constraints:** `1 ≤ n ≤ 5·10^4`, `1 ≤ startTime[i] < endTime[i] ≤ 10^9`, `1 ≤ profit[i] ≤ 10^4`

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Sort jobs by end time. For job `i`, either skip it or take it plus the best answer among jobs that end at or before its start (found by binary search).
* **Core Concept:** Weighted interval scheduling = DP + binary search
* **When to Use This Pattern?** Choose non-overlapping intervals/events/meetings to maximise total value.
* **Mistakes to Avoid:**
  * Greedy by profit or by earliest end — works only when all weights are equal.
  * Wrong boundary: a job ending at time `X` *does* allow a job starting at `X` → use `bisect_right`.

## 🔹 Optimization Path

* **Brute Force:** O(2ⁿ · n log n) — try every subset, sort it and check overlaps (hopeless for `n` up to 5·10⁴).
* **Optimized Solution:** O(n log n) — sort + one binary search per job.
* **Further Improvements Possible?** No for comparison-based input.

## 🔹 Solution Breakdown

* **Optimal Approach:** `dp[i]` = best profit using the first `i` jobs (sorted by end). `dp[i] = max(dp[i-1], dp[j] + profit_i)`, where `j` = number of jobs with `end <= start_i`.
* **Why This Works?** Sorted by end, the jobs compatible with job `i` form a prefix — so "the best before `i` starts" is a single earlier DP value.
* **Edge Cases Considered:**
  * Back-to-back jobs (`end == next start`).
  * One job dominating many small ones.
  * All jobs overlapping (answer = max profit).

## 🔹 Pattern Recognition

* **Belongs To:** DP + Binary Search (weighted interval scheduling)
* **Common Problems Using This:**
  * 2008. Maximum Earnings From Taxi

## 🔹 Tricks & Patterns Used

* **Sort by end time** so compatible jobs form a prefix.
* **`bisect_right(ends, start)`** counts jobs finishing at or before `start`.

## 🔹 Alternative Data Structures

* Top-down version: sort by start, `f(i) = max(f(i+1), profit_i + f(next index with start >= end_i))`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n log n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def jobScheduling(self, startTime: List[int], endTime: List[int], profit: List[int]) -> int:
        n = len(startTime)
        best = 0
        for mask in range(1 << n):  # every subset of jobs
            picked = [i for i in range(n) if mask >> i & 1]
            spans = sorted((startTime[i], endTime[i]) for i in picked)
            if all(spans[k][1] <= spans[k + 1][0] for k in range(len(spans) - 1)):
                best = max(best, sum(profit[i] for i in picked))
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from bisect import bisect_right
from typing import List


class Solution:
    def jobScheduling(self, startTime: List[int], endTime: List[int], profit: List[int]) -> int:
        jobs = sorted(zip(endTime, startTime, profit))
        ends = [e for e, _, _ in jobs]
        dp = [0] * (len(jobs) + 1)  # dp[i]: best profit using the first i jobs
        for i, (end, start, gain) in enumerate(jobs, 1):
            j = bisect_right(ends, start, 0, i - 1)  # jobs that end <= start
            dp[i] = max(dp[i - 1], dp[j] + gain)
        return dp[-1]
```
