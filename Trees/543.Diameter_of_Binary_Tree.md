# 543. Diameter of Binary Tree

**🔗 Link:** [LeetCode 543](https://leetcode.com/problems/diameter-of-binary-tree/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Return the diameter of a binary tree: the number of edges on the longest path between any two nodes. The path may or may not pass through the root.

* **Example:** `root = [1,2,3,4,5]` → `3`
* **Constraints:** `1 ≤ nodes ≤ 10^4`, `-100 ≤ Node.val ≤ 100`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Post-order heights.** Every path has one highest node where it bends; through node `v` the longest path has `height(v.left) + height(v.right)` edges (heights counted in nodes). Compute heights bottom-up once and take the maximum of that sum over all nodes.
* **Core Concept:** a subtree answer (height) is returned upwards while a global answer (best bend) is updated on the way
* **When to Use This Pattern?** "Longest / best path anywhere in the tree" where the path need not pass through the root — diameter, max path sum, longest univalue path.
* **Mistakes to Avoid:**
  * Returning `height(root.left) + height(root.right)`: the diameter may not pass through the root (a deep left subtree with a short right one).
  * Counting nodes instead of edges: the answer is the number of **edges**.
  * Recursing on a 10⁴-node path: Python's default limit is 1000. Iterate over a BFS order backwards instead.

## 🔹 Optimization Path

* **Brute Force:** for every node, measure both child heights from scratch — O(n·h), O(n²) on a path.
* **Optimized Solution:** one bottom-up pass storing each height once — O(n).
* **Further Improvements Possible?** No; every node must be seen.

## 🔹 Solution Breakdown

* **Optimal Approach:** collect nodes in BFS order (parents before children); walk it backwards so both children are done before their parent; `height[v] = 1 + max(left, right)` and `best = max(best, left + right)`.
* **Why This Works?** The highest node of any path splits it into a downward path into the left subtree and one into the right subtree; each is longest when it reaches the deepest leaf, i.e. has `height(child)` edges counting the edge from `v`.
* **Edge Cases Considered:**
  * Single node → 0.
  * Skewed tree (a path) → `n − 1`, handled without recursion.

## 🔹 Tricks & Patterns Used

* **BFS order reversed = post-order:** gives children-before-parents without recursion.
* **`{None: 0}` sentinel:** missing children read height 0 with no branching.

## 🔹 Alternative Data Structures

* Recursive DFS returning the height and updating a `nonlocal best` — shortest to write, but needs a raised recursion limit for deep trees.
* Explicit stack with a "visited" flag for a true post-order.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n) for the order and the height map

## 🔹 Code Snippet (Brute Force)

```python
from collections import deque
from typing import Optional


class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        def height(node: Optional[TreeNode]) -> int:
            levels, queue = 0, deque([node] if node else [])
            while queue:
                levels += 1
                for _ in range(len(queue)):
                    cur = queue.popleft()
                    queue.extend(child for child in (cur.left, cur.right) if child)
            return levels

        best, stack = 0, [root]
        while stack:
            node = stack.pop()
            if node:
                best = max(best, height(node.left) + height(node.right))  # longest path bending at `node`
                stack += [node.left, node.right]
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        order = [root]
        for node in order:  # BFS: parents appear before their children
            order += [child for child in (node.left, node.right) if child]
        height, best = {None: 0}, 0
        for node in reversed(order):  # children before parents
            left, right = height[node.left], height[node.right]
            best = max(best, left + right)
            height[node] = 1 + max(left, right)
        return best
```
