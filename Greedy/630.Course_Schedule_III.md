# 🔹 Problem Name: 630. Course Schedule III (Greedy + Max-Heap, Hard)

**🔗 Link:** [LeetCode 630](https://leetcode.com/problems/course-schedule-iii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Sort by deadline. Take each course; if the total time now exceeds its deadline, drop the **longest** course taken so far (max-heap).
* **Core Concept:** Greedy scheduling with regret (exchange argument)
* **When to Use This Pattern?** Maximise the number of jobs done before deadlines; "take now, undo the worst choice if it breaks a constraint".
* **Mistakes to Avoid:**
  * Sorting by duration — deadlines decide feasibility.
  * Dropping the current course instead of the longest one.

## 🔹 Optimization Path

* **Brute Force:** Try every subset — O(2ⁿ · n log n).
* **DP:** `dp[time]` knapsack over sorted courses — O(n · maxDay), too slow for 10⁴ × 10⁴.
* **Optimized Solution:** O(n log n) greedy + heap.

## 🔹 Solution Breakdown

* **Optimal Approach:** `time += d`, push `-d`; if `time > lastDay`, `time += heappop(heap)` (removes the largest duration).
* **Why This Works?** Processing by deadline (earliest-deadline-first is optimal for a fixed set), the heap always holds a maximum-size feasible set with the smallest possible total time; swapping out the longest course keeps the count and minimises time.
* **Edge Cases Considered:**
  * A course longer than its own deadline (dropped immediately).
  * All courses fit.

* **"Regret" greedy:** commit, then undo the most expensive commitment when a constraint breaks.
* **Max-heap via negated values.**

## 🔹 Code Snippet (Optimized)

```python
import heapq
from typing import List


class Solution:
    def scheduleCourse(self, courses: List[List[int]]) -> int:
        courses.sort(key=lambda c: c[1])  # earliest deadline first
        taken = []  # max-heap of durations (negated)
        time = 0
        for duration, last_day in courses:
            time += duration
            heapq.heappush(taken, -duration)
            if time > last_day:
                time += heapq.heappop(taken)  # drop the longest course so far
        return len(taken)
```
