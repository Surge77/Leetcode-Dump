# 🔹 Problem Name: 746. Min Cost Climbing Stairs (1D DP, Easy)

**🔗 Link:** [LeetCode 746](https://leetcode.com/problems/min-cost-climbing-stairs/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Fibonacci-style min DP.** `reach[i]` = cheapest way to stand on step `i` (steps `0` and `1` are free starts). `reach[i] = min(reach[i-1] + cost[i-1], reach[i-2] + cost[i-2])`; the top is step `n`. Only the last two values are needed.
* **Core Concept:** the cheapest way to a position comes from one of the two positions that can jump to it
* **When to Use This Pattern?** "Reach the end moving 1 or 2 steps, minimise / count something" — climbing stairs (70), house robber (198), decode ways (91).
* **Mistakes to Avoid:**
  * The top is **beyond** the last step (index `n`), not `n − 1`.
  * Paying for the step you land on instead of the step you leave — the cost is paid when you step **off** `i`.
  * Recursion without memo — O(2ⁿ) for `n ≤ 1000` (and deep).

## 🔹 Optimization Path

* **Brute Force:** recursion trying both jumps from every step — O(2ⁿ).
* **Optimized Solution:** two rolling variables — O(n) time, O(1) space.
* **Further Improvements Possible?** No; every cost must be read.

## 🔹 Solution Breakdown

* **Optimal Approach:** `two_back, one_back = 0, 0` (`reach[0]`, `reach[1]`); for `i` in `2..n`: `two_back, one_back = one_back, min(one_back + cost[i-1], two_back + cost[i-2])`; return `one_back`.
* **Why This Works?** The last move onto step `i` came from `i − 1` or `i − 2`, paying that step's cost; the cheapest route to that predecessor is independent of what happens after it (optimal substructure).
* **Edge Cases Considered:**
  * `n = 2` → `min(cost[0], cost[1])`.
  * Zero costs.

## 🔹 Pattern Recognition

* **Belongs To:** 1D DP — Fibonacci-style
* **Common Problems Using This:**
  * 70. Climbing Stairs (in this repo)

## 🔹 Tricks & Patterns Used

* **Free start on step 0 or 1:** both start values are 0, which avoids a `min` of two separate runs.
* **Rolling variables** — the recurrence looks only two back.

## 🔹 Alternative Data Structures

* In-place on `cost`: `cost[i] += min(cost[i-1], cost[i-2])` ("cost to leave step `i`"), answer `min(cost[-1], cost[-2])` — O(1) extra, but mutates the input.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        def reach(step: int) -> int:
            if step <= 1:
                return 0
            return min(reach(step - 1) + cost[step - 1], reach(step - 2) + cost[step - 2])

        return reach(len(cost))
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def minCostClimbingStairs(self, cost: List[int]) -> int:
        two_back = one_back = 0  # starting on step 0 or 1 is free
        for i in range(2, len(cost) + 1):
            two_back, one_back = one_back, min(one_back + cost[i - 1], two_back + cost[i - 2])
        return one_back
```
