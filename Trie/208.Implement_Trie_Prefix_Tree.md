# 🔹 Problem Name: 208. Implement Trie (Prefix Tree) (Trie, Medium)

**🔗 Link:** [LeetCode 208](https://leetcode.com/problems/implement-trie-prefix-tree/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Each node maps a character to a child node and has an `is_end` flag. Insert/search/prefix all walk the word character by character.
* **Core Concept:** Trie (prefix tree)
* **When to Use This Pattern?** Many prefix queries, autocomplete, word dictionaries with wildcards, XOR maximisation over bits (binary trie).
* **Mistakes to Avoid:**
  * Treating "path exists" as "word exists" — `search` must check `is_end`.
  * Sharing a mutable default (e.g., `children={}` in `__init__` signature).

## 🔹 Optimization Path

* **Brute Force:** List of words; prefix check scans all words — O(N · L) per query.
* **Optimized Solution:** O(L) per operation.
* **Further Improvements Possible?** Fixed arrays of size 26 per node — faster, more memory.

## 🔹 Solution Breakdown

* **Optimal Approach:** `insert`: create missing children, mark the last node. `search`: walk, then check `is_end`. `startsWith`: walk only.
* **Why This Works?** Words sharing a prefix share the same path, so a prefix query visits exactly `len(prefix)` nodes regardless of dictionary size.
* **Edge Cases Considered:**
  * A word that is a prefix of another (`"app"` vs `"apple"`).
  * Searching before any insert.

## 🔹 Tricks & Patterns Used

* **`__slots__`** cuts per-node memory in Python.
* A shared `_walk` helper avoids duplicating the traversal.

## 🔹 Alternative Data Structures

* Hash set of all prefixes — O(L²) per insert, O(L) per query (the string must be hashed), and much more memory than a trie.

## 🔹 Complexity Analysis

* **Time Complexity:** O(L) per operation
* **Space Complexity:** O(total characters inserted)

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class TrieNode:
    __slots__ = ("children", "is_end")

    def __init__(self):
        self.children = {}
        self.is_end = False


class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for ch in word:
            node = node.children.setdefault(ch, TrieNode())
        node.is_end = True

    def _walk(self, s: str) -> Optional[TrieNode]:
        node = self.root
        for ch in s:
            node = node.children.get(ch)
            if node is None:
                return None
        return node

    def search(self, word: str) -> bool:
        node = self._walk(word)
        return node is not None and node.is_end

    def startsWith(self, prefix: str) -> bool:
        return self._walk(prefix) is not None
```
