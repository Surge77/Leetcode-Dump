# 🔹 Problem Name: 847. Shortest Path Visiting All Nodes (BFS + Bitmask, Hard)

**🔗 Link:** [LeetCode 847](https://leetcode.com/problems/shortest-path-visiting-all-nodes/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** BFS where a state is `(current node, set of visited nodes)`. Start from **every** node at once; the first state whose mask is full gives the answer.
* **Core Concept:** BFS on an expanded state space (node × bitmask)
* **When to Use This Pattern?** "Visit all / collect all K special things" with `n` or `K ≤ 12–16` — a TSP-flavoured problem on unweighted edges.
* **Mistakes to Avoid:**
  * Marking only nodes as visited — you may revisit a node later with a different mask.
  * Starting BFS from node 0 only — the walk may start anywhere.

## 🔹 Optimization Path

* **Brute Force:** O(n! · n) — every visiting order with shortest-path distances.
* **Optimized Solution:** O(2ⁿ · n²) — each of the `n · 2ⁿ` states scans its neighbours.
* **Further Improvements Possible?** Weighted edges → precompute all-pairs distances, then Held–Karp DP `dp[mask][v]`.

## 🔹 Solution Breakdown

* **Optimal Approach:** Queue all `(v, 1 << v)`; expand to `(u, mask | 1 << u)` for each neighbour `u`; stop at `mask == full`.
* **Why This Works?** Every edge costs 1, so BFS reaches each state with its minimum number of steps; the first full-mask state is the optimum.
* **Edge Cases Considered:**
  * One node → 0.
  * Star graph (must come back through the centre).

## 🔹 Pattern Recognition

* **Belongs To:** Bitmask + BFS (state-space search)
* **Common Problems Using This:**
  * 864. Shortest Path to Get All Keys
  * 943. Find the Shortest Superstring (Held–Karp)

## 🔹 Tricks & Patterns Used

* **Multi-source BFS** for "start anywhere".
* **State = (position, mask)** — add the mask to the visited key.

## 🔹 Alternative Data Structures

* `seen` as a 2D list `[n][1<<n]` of booleans is faster than a set of tuples.

## 🔹 Complexity Analysis

* **Time Complexity:** O(2ⁿ · n²)
* **Space Complexity:** O(2ⁿ · n)

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def shortestPathLength(self, graph: List[List[int]]) -> int:
        n = len(graph)
        full = (1 << n) - 1
        seen = [[False] * (1 << n) for _ in range(n)]
        q = deque()
        for v in range(n):  # the walk may start at any node
            seen[v][1 << v] = True
            q.append((v, 1 << v))
        steps = 0
        while q:
            for _ in range(len(q)):
                v, mask = q.popleft()
                if mask == full:
                    return steps
                for u in graph[v]:
                    nxt = mask | 1 << u
                    if not seen[u][nxt]:
                        seen[u][nxt] = True
                        q.append((u, nxt))
            steps += 1
        return -1
```
