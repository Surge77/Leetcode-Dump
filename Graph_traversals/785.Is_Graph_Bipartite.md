# 🔹 Problem Name: 785. Is Graph Bipartite? (Graph Colouring, Medium)

**🔗 Link:** [LeetCode 785](https://leetcode.com/problems/is-graph-bipartite/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** BFS from every uncoloured node, giving neighbours the opposite colour. An edge between two same-coloured nodes means "not bipartite".
* **Core Concept:** 2-colouring / bipartite check
* **When to Use This Pattern?** Split people/tasks into two groups with conflicts across groups only; detect odd cycles.
* **Mistakes to Avoid:**
  * Starting BFS only from node 0 — the graph may be disconnected.
  * Treating "visited" and "colour" separately — one array with `-1` = unvisited does both.

## 🔹 Optimization Path

* **Brute Force:** Try all 2ⁿ colourings.
* **Optimized Solution:** O(V + E) BFS/DFS colouring.
* **Further Improvements Possible?** Union-Find also works: every node's neighbours must share a set that excludes the node.

## 🔹 Solution Breakdown

* **Optimal Approach:** `colour[v] = -1` initially; for each uncoloured start, colour 0 and BFS; neighbour uncoloured → `1 - colour[u]`; neighbour same colour → False.
* **Why This Works?** A graph is bipartite iff it has no odd cycle. BFS colouring is forced along every path, so a conflict appears exactly when some cycle has odd length.
* **Edge Cases Considered:**
  * Isolated nodes.
  * Several components.

## 🔹 Tricks & Patterns Used

* **`1 - colour`** flips between the two sides.
* **Outer loop over all nodes** for disconnected graphs.

## 🔹 Alternative Data Structures

* Union-Find: union all neighbours of `u` together; conflict if `u` ends up in their set.

## 🔹 Complexity Analysis

* **Time Complexity:** O(V + E)
* **Space Complexity:** O(V)

## 🔹 Code Snippet (Brute Force)

```python
from itertools import product
from typing import List


class Solution:
    def isBipartite(self, graph: List[List[int]]) -> bool:
        n = len(graph)
        for colour in product((0, 1), repeat=n):  # every possible 2-colouring
            if all(colour[u] != colour[v] for u in range(n) for v in graph[u]):
                return True
        return False
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def isBipartite(self, graph: List[List[int]]) -> bool:
        colour = [-1] * len(graph)  # -1 = not visited yet
        for start in range(len(graph)):
            if colour[start] != -1:
                continue
            colour[start] = 0
            q = deque([start])
            while q:
                u = q.popleft()
                for v in graph[u]:
                    if colour[v] == -1:
                        colour[v] = 1 - colour[u]
                        q.append(v)
                    elif colour[v] == colour[u]:
                        return False  # odd cycle
        return True
```
