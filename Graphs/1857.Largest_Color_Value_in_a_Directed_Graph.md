# 1857. Largest Color Value in a Directed Graph

**🔗 Link:** [LeetCode 1857](https://leetcode.com/problems/largest-color-value-in-a-directed-graph/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Each node of a directed graph has a lowercase-letter colour. The colour value of a path is how many times its most frequent colour appears along it. Return the largest colour value over all paths, or `-1` if the graph contains a cycle (making path lengths unbounded).

* **Example:** `colors = "abaca", edges = [[0,1],[0,2],[2,3],[3,4]]` → `3`
* **Constraints:** `1 ≤ n ≤ 10^5`, `0 ≤ m ≤ 10^5`, `colors` is lowercase English letters

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Process nodes in topological order. `cnt[v][c]` = the most nodes of colour `c` on any path ending at `v`. Push counts along edges; if the topological sort does not cover every node, there is a cycle → `-1`.
* **Core Concept:** DP on a DAG in topological order
* **When to Use This Pattern?** "Best path in a directed graph" where the value is a count/sum along the path and cycles make the answer undefined.
* **Mistakes to Avoid:**
  * DFS from every node without memo — exponential.
  * Adding the node's own colour once per incoming edge instead of exactly once when the node is popped (after all predecessors have merged in, before propagating to successors).
  * Missing the cycle check.

## 🔹 Optimization Path

* **Brute Force:** Enumerate all paths — exponential.
* **Optimized Solution:** O((V + E) · 26).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Kahn's BFS; when `u` is popped, `cnt[u][colour(u)] += 1`, update the answer, then for each `u → v`: `cnt[v][c] = max(cnt[v][c], cnt[u][c])` for all 26 colours.
* **Why This Works?** In topological order all predecessors of `v` are finished before `v` is popped, so `cnt[v]` already holds the best over every incoming path.
* **Edge Cases Considered:**
  * Self-loop → -1.
  * Isolated nodes → answer at least 1.

* **Kahn's algorithm doubles as cycle detection** (`processed < n`).
* **Small alphabet (26)** → keep one counter per colour per node.

## 🔹 Code Snippet (Brute Force)

```python
from collections import Counter
from typing import List


class Solution:
    def largestPathValue(self, colors: str, edges: List[List[int]]) -> int:
        n = len(colors)
        adj = [[] for _ in range(n)]
        for u, v in edges:
            adj[u].append(v)

        state = [0] * n  # 0 = unvisited, 1 = on the DFS stack, 2 = done

        def has_cycle(u):
            state[u] = 1
            for v in adj[u]:
                if state[v] == 1 or (state[v] == 0 and has_cycle(v)):
                    return True
            state[u] = 2
            return False

        if any(state[u] == 0 and has_cycle(u) for u in range(n)):
            return -1

        best = 0
        count = Counter()

        def walk(u):  # enumerate every path starting at u (finite: the graph is a DAG)
            nonlocal best
            count[colors[u]] += 1
            best = max(best, count[colors[u]])
            for v in adj[u]:
                walk(v)
            count[colors[u]] -= 1

        for u in range(n):
            walk(u)
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def largestPathValue(self, colors: str, edges: List[List[int]]) -> int:
        n = len(colors)
        adj = [[] for _ in range(n)]
        indeg = [0] * n
        for u, v in edges:
            adj[u].append(v)
            indeg[v] += 1

        cnt = [[0] * 26 for _ in range(n)]  # best count of each colour on paths ending here
        q = deque(v for v in range(n) if indeg[v] == 0)
        processed = best = 0
        while q:
            u = q.popleft()
            processed += 1
            cu = cnt[u]
            cu[ord(colors[u]) - 97] += 1  # count u itself
            best = max(best, max(cu))
            for v in adj[u]:
                cv = cnt[v]
                for c in range(26):
                    if cu[c] > cv[c]:
                        cv[c] = cu[c]
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)
        return best if processed == n else -1  # unprocessed nodes => cycle
```
