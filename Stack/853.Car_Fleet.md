# 🔹 Problem Name: 853. Car Fleet (Monotonic Stack, Medium)

**🔗 Link:** [LeetCode 853](https://leetcode.com/problems/car-fleet/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Cars start at distinct positions on a one-lane road and all drive toward the same `target` mile at their own constant speeds. A car cannot overtake; if it catches the car ahead it slows to that car's speed and they travel together as a fleet (catching up exactly at the target also counts). Return how many fleets arrive at the target.

* **Example:** `target = 12, position = [10,8,0,5,3], speed = [2,4,1,1,3]` → `3`
* **Constraints:** `1 ≤ n ≤ 10⁵`, `0 < target ≤ 10⁶`, `0 ≤ position[i] < target` with all positions distinct, `0 < speed[i] ≤ 10⁶`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Sort by position, closest to the target first, and compare arrival times.** Car `i` alone would arrive at `(target − position[i]) / speed[i]`. Walking from the front car backwards, a car that would arrive no later than the fleet ahead of it catches up and joins it; a car that would arrive strictly later starts a new fleet. The fleet times form an increasing stack — only its top matters.
* **Core Concept:** cars cannot pass, so a fleet arrives at the time of its slowest (front-most limiting) car; a car joins iff its solo time ≤ the time of the fleet in front
* **When to Use This Pattern?** Objects that merge when one catches another on a one-way track; "count groups after collapsing" after sorting by position.
* **Mistakes to Avoid:**
  * Sorting by speed or by time instead of by position.
  * Using `<` instead of `≤`: catching up exactly at the target still counts as one fleet.
  * Comparing against the car directly ahead rather than the fleet ahead (a slow fleet absorbs many cars).

## 🔹 Optimization Path

* **Brute Force:** car `i` heads its own fleet iff every car in front of it has a strictly smaller solo time — O(n²) pair checks.
* **Optimized Solution:** sort + one backward scan keeping the slowest time so far — O(n log n).
* **Further Improvements Possible?** Positions are `< target ≤ 10⁶`, so bucketing by position gives O(n + target) without a comparison sort.

## 🔹 Solution Breakdown

* **Optimal Approach:** sort pairs by position descending; `fleets = 0, slowest = 0`; for each time `t`: if `t > slowest`, `fleets += 1` and `slowest = t`.
* **Why This Works?** Process cars from front to back. The fleet directly ahead arrives at `slowest` (the maximum solo time seen, since faster cars behind it were absorbed). If `t ≤ slowest` the car reaches that fleet's position by the target and is then held back; if `t > slowest` it never catches anything and becomes the new slowest front.
* **Edge Cases Considered:**
  * One car → 1.
  * Two cars meeting exactly at the target → 1 fleet.
  * Floating-point times are safe: two distinct times `a/b ≠ c/d` with `b, d ≤ 10⁶` differ by a relative ≥ 10⁻¹², far above double precision, and equal fractions round to the same double.

## 🔹 Tricks & Patterns Used

* **Sort by position, sweep from the front** — then every decision depends only on what is ahead.
* **Stack collapses to one variable** because only the top fleet time is compared.

## 🔹 Alternative Data Structures

* Explicit stack of fleet times (push if larger than top) — `len(stack)` is the answer; identical logic.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n log n), `n ≤ 10⁵`
* **Space Complexity:** O(n) for the sorted pairs

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def carFleet(self, target: int, position: List[int], speed: List[int]) -> int:
        n = len(position)
        fleets = 0
        for i in range(n):
            # exact comparison of (target - p_j) / s_j < (target - p_i) / s_i by cross-multiplying
            if all((target - position[j]) * speed[i] < (target - position[i]) * speed[j]
                   for j in range(n) if position[j] > position[i]):
                fleets += 1
        return fleets
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def carFleet(self, target: int, position: List[int], speed: List[int]) -> int:
        fleets, slowest = 0, 0.0
        for pos, spd in sorted(zip(position, speed), reverse=True):
            arrival = (target - pos) / spd
            if arrival > slowest:  # cannot catch the fleet ahead before the target
                fleets += 1
                slowest = arrival
        return fleets
```
