# 🔹 Problem Name: 66. Plus One (Digit Arithmetic, Easy)

**🔗 Link:** [LeetCode 66](https://leetcode.com/problems/plus-one/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Carry from the right.** Walk from the last digit: a digit below 9 just increments and you are done; a 9 becomes 0 and the carry moves left. If every digit was 9, the answer is `1` followed by zeros.
* **Core Concept:** a carry propagates only through a suffix of 9s
* **When to Use This Pattern?** Incrementing/adding to numbers stored as digit arrays, linked lists or strings.
* **Mistakes to Avoid:**
  * Forgetting the all-9s case (`[9, 9] → [1, 0, 0]`) — the array grows by one.
  * Joining into an `int` in a language without big integers — up to 100 digits overflows 64-bit.

## 🔹 Optimization Path

* **Brute Force:** join the digits into an integer, add 1, split it back into digits — O(n) here, but it relies on arbitrary-precision integers and converts the whole number twice.
* **Optimized Solution:** in-place carry from the right, stopping at the first non-9 — O(n) worst case, O(1) when the last digit is not 9.
* **Further Improvements Possible?** No; the all-9s case must write `n + 1` digits.

## 🔹 Solution Breakdown

* **Optimal Approach:** for `i` from `n − 1` down to 0: if `digits[i] < 9`, increment and return; else set it to 0. After the loop, return `[1] + digits`.
* **Why This Works?** Adding 1 changes a digit only if every digit to its right overflowed, i.e. was 9. The first non-9 from the right absorbs the carry and nothing to its left changes.
* **Edge Cases Considered:**
  * `[0]` → `[1]` (the only input with a leading zero).
  * All 9s → length grows by one.

## 🔹 Tricks & Patterns Used

* **Early exit on the first non-9:** the expected work is O(1) for random digits.
* **All-9s shortcut:** after zeroing everything, the answer is just `[1] + [0] * n`.

## 🔹 Alternative Data Structures

* Reversed digit list (least significant first) so the overflow digit is an `append` instead of a prepend.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n) worst case
* **Space Complexity:** O(1) extra (O(n) only for the grown all-9s output)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def plusOne(self, digits: List[int]) -> List[int]:
        value = int("".join(map(str, digits))) + 1
        return [int(ch) for ch in str(value)]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def plusOne(self, digits: List[int]) -> List[int]:
        for i in range(len(digits) - 1, -1, -1):
            if digits[i] < 9:
                digits[i] += 1
                return digits
            digits[i] = 0
        return [1] + digits
```
