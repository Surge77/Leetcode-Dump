# 🔹 Infosys SP / DSE — Technical Interview Prep

After the online test, shortlisted candidates face a technical interview and then HR. Public 2025–2026 reports describe the technical round as:

* **2 DSA problems** (Easy–Medium), solved live on a shared screen → practise with the 🔄 notes in [INDEX.md](../INDEX.md), out loud, using the [mock interview protocol](Mock_Interview.md).
* **OOP** concepts with code → [OOP.md](OOP.md)
* **DBMS + SQL queries** → [SQL.md](SQL.md) (every query verified) and [DBMS_and_OS.md](DBMS_and_OS.md)
* **OS basics** (occasionally) → [DBMS_and_OS.md](DBMS_and_OS.md#-operating-systems)
* **Your resume and projects**, plus scenario questions

> Sourced from unofficial guides and candidate reports — the exact mix varies by interviewer and drive.

## 🔹 Talking About a Project (2-minute structure)

1. **Problem:** who has it and why it matters (one sentence).
2. **What you built:** the main components and *your* part.
3. **One hard decision:** the alternatives you considered and why you chose yours.
4. **Proof it works:** tests, metrics, users, a demo.
5. **What you would change next.**

Prepare one project you can go deep on: expect "why this database?", "what happens when X fails?", "how would it scale to 10× users?".

## 🔹 Live-Coding Habits

* Restate the problem and confirm the input/output format before coding.
* Say the brute force and its complexity first, then optimise.
* Walk through a small example and one edge case (empty input, single element, duplicates) before declaring it done.
* Name variables clearly — interviewers read your code while you type.
