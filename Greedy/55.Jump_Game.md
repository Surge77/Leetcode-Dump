# 🔹 Problem Name: 55. Jump Game (Greedy, Medium)

**🔗 Link:** [LeetCode 55](https://leetcode.com/problems/jump-game/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Track the farthest index reachable so far. If the scan reaches an index beyond it, you are stuck.
* **Core Concept:** Greedy reachability
* **When to Use This Pattern?** "Can you reach the end?" with jump lengths — interval coverage in disguise.
* **Mistakes to Avoid:**
  * DFS/backtracking — exponential.
  * Forgetting `[0]` (single element) is already at the end → True.

## 🔹 Optimization Path

* **Brute Force:** Recursion over every jump — exponential.
* **DP:** `reach[i]` from all earlier `j` — O(n²).
* **Optimized Solution:** O(n) greedy.

## 🔹 Solution Breakdown

* **Optimal Approach:** `far = 0`; for each `i`: if `i > far` return False; `far = max(far, i + nums[i])`.
* **Why This Works?** Every index `≤ far` is reachable (you can stop anywhere along a jump), so the reachable set is always a prefix `[0, far]`.
* **Edge Cases Considered:**
  * Zero at index 0 with length > 1 → False.
  * Zeros that can be jumped over.

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def canJump(self, nums: List[int]) -> bool:
        far = 0  # farthest reachable index so far
        for i, jump in enumerate(nums):
            if i > far:
                return False
            far = max(far, i + jump)
        return True
```
