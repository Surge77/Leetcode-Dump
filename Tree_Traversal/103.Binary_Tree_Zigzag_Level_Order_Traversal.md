# 🔹 Problem Name: 103. Binary Tree Zigzag Level Order Traversal (Tree BFS, Medium)

**🔗 Link:** [LeetCode 103](https://leetcode.com/problems/binary-tree-zigzag-level-order-traversal/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Level-order BFS plus a direction flag.** Traverse exactly as in 102 — children always enqueued left then right — but on every other level write the `i`-th popped value at index `size − 1 − i` instead of `i`.
* **Core Concept:** the *visiting* order stays left-to-right; only the *writing* order alternates
* **When to Use This Pattern?** Level-wise output with a per-level twist — alternating direction, reversing odd levels, spiral order of a tree.
* **Mistakes to Avoid:**
  * Swapping the order children are enqueued on odd levels — the queue then stops holding the next level left to right and later levels come out scrambled. (Only the two-stack method may flip the push order.)
  * Off-by-one on the direction: depth 0 (the root) is left-to-right, depth 1 is right-to-left.

## 🔹 Optimization Path

* **Brute Force:** for each depth `d`, a fresh DFS collects the nodes at depth `d`; reverse the odd depths — O(n·h).
* **Optimized Solution:** one BFS, each value placed straight at its final index — O(n) time, O(w) space.
* **Further Improvements Possible?** No for time. Two stacks (current level / next level) with alternating push order are an equal O(n) alternative without index arithmetic.

## 🔹 Solution Breakdown

* **Optimal Approach:** per level: `size = len(queue)`, `level = [0] * size`; the `i`-th popped node goes to `level[i]`, or `level[size − 1 − i]` on reversed levels; flip the flag after each level.
* **Why This Works?** The queue holds each level left to right (102's invariant), and mapping position `i` to `size − 1 − i` is exactly the reversal, done while filling.
* **Edge Cases Considered:**
  * Empty tree → `[]`.
  * A level with one node reads the same in both directions.

## 🔹 Tricks & Patterns Used

* **Choose the write position, not the visit order:** `level[size - 1 - i if is_reversed else i]`.
* **`deque.appendleft`** on reversed levels is an equivalent way to build the level backwards.

## 🔹 Alternative Data Structures

* Two stacks: pop from the current one and push children onto the next — left then right on even levels, right then left on odd ones; LIFO order does the reversing.
* Plain level-order lists, then `level.reverse()` on odd levels — same O(n), one extra pass per odd level.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(w) for the queue, plus O(n) for the output

## 🔹 Code Snippet (Brute Force)

```python
from typing import List, Optional


class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        result = []
        target = 0
        while True:
            level = []
            stack = [(root, 0)] if root else []
            while stack:
                node, depth = stack.pop()
                if depth == target:
                    level.append(node.val)
                    continue  # nothing below this node is at the target depth
                for child in (node.right, node.left):  # left is popped first: left-to-right order
                    if child:
                        stack.append((child, depth + 1))
            if not level:
                return result
            result.append(level[::-1] if target % 2 else level)
            target += 1
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List, Optional


class Solution:
    def zigzagLevelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        result = []
        queue = deque([root] if root else [])
        is_reversed = False
        while queue:
            size = len(queue)
            level = [0] * size
            for i in range(size):
                node = queue.popleft()
                level[size - 1 - i if is_reversed else i] = node.val
                if node.left:
                    queue.append(node.left)  # the queue itself always stays left-to-right
                if node.right:
                    queue.append(node.right)
            result.append(level)
            is_reversed = not is_reversed
        return result
```
