# 🔹 Problem Name: 1614. Maximum Nesting Depth of the Parentheses (Balance Counter, Easy)

**🔗 Link:** [LeetCode 1614](https://leetcode.com/problems/maximum-nesting-depth-of-the-parentheses/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

The string is a valid parentheses expression that may also contain digits and the operators `+ - * /`. Return its nesting depth, i.e. the largest number of parentheses open at the same time.

* **Example:** `s = "(1+(2*3)+((8)/4))+1"` → `3`
* **Constraints:** `1 ≤ s.length ≤ 100`; characters are digits, `+`, `-`, `*`, `/`, `(`, `)`; the parentheses are guaranteed valid

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Running depth.** `'('` increments the depth, `')'` decrements it, every other character is ignored; the answer is the largest depth reached.
* **Core Concept:** the nesting depth at a position is (`'('` so far) − (`')'` so far)
* **When to Use This Pattern?** Any single-bracket-type question on a valid string: depth, primitive splits (1021), balance fixes (921, 1249).
* **Mistakes to Avoid:**
  * Taking the max after `')'` instead of after `'('` — depth only peaks right after an opening bracket.
  * Using a stack of characters when only its height is needed.

## 🔹 Optimization Path

* **Brute Force:** for every position, recount `'('` and `')'` in the prefix — O(n²).
* **Optimized Solution:** one pass with a counter — O(n).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `depth += 1` on `'('` and update `best = max(best, depth)`; `depth -= 1` on `')'`.
* **Why This Works?** The input is a valid parentheses string (VPS), so the prefix balance never goes negative and equals the number of currently open brackets — which is precisely the nesting depth of the characters at that point.
* **Edge Cases Considered:**
  * No parentheses (`"1+2"`) → 0.
  * Digits and operators between brackets do not change the depth.

## 🔹 Alternative Data Structures

* Stack of `'('` — `max(len(stack))` gives the same answer with O(n) extra space.
* Prefix-sum array of `+1/−1`, then `max` — same idea, materialised.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n), `n ≤ 100`
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def maxDepth(self, s: str) -> int:
        return max((s[:i + 1].count("(") - s[:i + 1].count(")") for i in range(len(s))), default=0)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def maxDepth(self, s: str) -> int:
        depth = best = 0
        for ch in s:
            if ch == "(":
                depth += 1
                best = max(best, depth)
            elif ch == ")":
                depth -= 1
        return best
```
