# 189. Rotate Array

**🔗 Link:** [LeetCode 189 Rotate Array](https://leetcode.com/problems/rotate-array/description/)

**🟢 Status:** ✅ Solved


## 🔹 Problem Statement

Rotate an integer array to the right by `k` positions, where `k` is non-negative. The change must be made on `nums` itself; the function returns nothing.

* **Example:** `nums = [1,2,3,4,5,6,7], k = 3` → `[5,6,7,1,2,3,4]`
* **Constraints:** `1 ≤ nums.length ≤ 10^5`; `−2^31 ≤ nums[i] ≤ 2^31 − 1`; `0 ≤ k ≤ 10^5`

* **When to Use This Pattern?**

* **Mistakes to Avoid:**

## 🔹 Optimization Path

* **Brute Force:**
  * Shift one by one for `k` times → `O(n * k)`
* **Optimized Solution:**
  * Reverse 3 parts → `O(n)` time, `O(1)` space
* **Further Improvements Possible?**
  Not really. This is the optimal space-time tradeoff unless you're allowed extra memory.

---

## 🔹 Solution Breakdown

* **Optimal Approach:**
  Reverse the whole array, then reverse the first `k` elements, then the remaining `n-k`.
* **Why This Works?**
  Reversing is a cheap way to rotate in-place. Think of rotating as just rearranging in reverse-order bursts.
* **Edge Cases Considered:**
  * `k > len(nums)` (handled by `k % n`)
  * `k = 0` (no rotation)
  * Single-element array (`k % 1 == 0`, nothing to do); an empty array never occurs since `nums.length ≥ 1`

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        for _ in range(k % len(nums)):
            last = nums[-1]
            for i in range(len(nums) - 1, 0, -1):
                nums[i] = nums[i - 1]
            nums[0] = last
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List

class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        """
        Rotates the array to the right by k steps in-place.
        Time: O(n), Space: O(1)
        """
        k = k % len(nums)

        # Step 1: Reverse entire array
        l, r = 0, len(nums) - 1
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l, r = l + 1, r - 1

        # Step 2: Reverse first k elements
        l, r = 0, k - 1
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l, r = l + 1, r - 1

        # Step 3: Reverse the rest
        l, r = k, len(nums) - 1
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l, r = l + 1, r - 1

```
