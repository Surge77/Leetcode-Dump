# 🔹 Problem Name: 494. Target Sum (Dynamic Programming, Medium)

**🔗 Link:** [LeetCode 494](https://leetcode.com/problems/target-sum/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Let `P` = sum of numbers given `+`, `N` = sum given `-`. Then `P - N = target` and `P + N = total`, so `P = (total + target) / 2`. Count subsets with sum `P`.
* **Core Concept:** Algebraic reduction → 0/1 knapsack counting
* **When to Use This Pattern?** Assigning `+`/`-` (or two groups) to every element with a target difference.
* **Mistakes to Avoid:**
  * Missing the checks `|target| > total` or `(total + target)` odd → 0 ways.
  * Forgetting zeros: each `0` doubles the count (the DP handles this automatically).

## 🔹 Optimization Path

* **Brute Force:** O(2ⁿ) — try every sign assignment.
* **Middle Ground:** DP over (index, running sum) with a dict — O(n · total).
* **Optimized Solution:** O(n · P) counting knapsack in a 1D array.

## 🔹 Solution Breakdown

* **Optimal Approach:** `ways[s]` = number of subsets with sum `s`; for each `x`, `ways[s] += ways[s - x]` going downwards.
* **Why This Works?** Each sign assignment corresponds to exactly one subset (the `+` group), and the algebra fixes that group's sum to `P`.
* **Edge Cases Considered:**
  * Negative target (symmetric).
  * Zeros in the array.
  * Target unreachable.

## 🔹 Pattern Recognition

* **Belongs To:** DP — 0/1 Knapsack (counting)

## 🔹 Tricks & Patterns Used

* **Turn signs into a subset**: two equations, two unknowns.
* **Backward loop** keeps it 0/1.

## 🔹 Alternative Data Structures

* `Counter` of running sums (dict DP) avoids the algebra and handles negative sums directly.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · P)
* **Space Complexity:** O(P)

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def findTargetSumWays(self, nums: List[int], target: int) -> int:
        total = sum(nums)
        if abs(target) > total or (total + target) % 2:
            return 0
        goal = (total + target) // 2  # required sum of the '+' group
        ways = [1] + [0] * goal  # ways[s]: subsets with sum s
        for x in nums:
            for s in range(goal, x - 1, -1):  # backwards => each number used once
                ways[s] += ways[s - x]
        return ways[goal]
```
