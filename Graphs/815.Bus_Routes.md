# 815. Bus Routes

**🔗 Link:** [LeetCode 815](https://leetcode.com/problems/bus-routes/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Each entry of `routes` is a bus that loops forever through its listed stops. Starting at stop `source` (not on any bus) and travelling only by bus, return the fewest buses you must ride to reach stop `target`, or `-1` if it cannot be done. Changing buses is possible at any stop shared by two routes.

* **Example:** `routes = [[1,2,7],[3,6,7]], source = 1, target = 6` → `2`
* **Constraints:** `1 ≤ routes.length ≤ 500`, `sum(routes[i].length) ≤ 10^5`, stops in one route are distinct, `0 ≤ routes[i][j], source, target < 10^6`

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **BFS where a level = one more bus taken.** Map each stop to the routes serving it. Start with all routes through `source`; for each route popped, every unseen route sharing any of its stops is one more bus away. Return the level at which a route containing `target` is reached.
* **Core Concept:** the graph's nodes are **routes**, not stops — you pay per bus, not per stop, so BFS over routes counts exactly the cost
* **When to Use This Pattern?** Shortest path where cost is per "line / ticket / transfer" instead of per edge between stops.
* **Mistakes to Avoid:**
  * BFS over individual stops with cost 1 per hop counts stops, not buses.
  * Not marking routes (or stops) as visited: each stop's route list gets rescanned for every route that contains it and the search blows up.
  * `source == target` → `0` buses, before any search.

## 🔹 Optimization Path

* **Brute Force:** build a route-to-route graph by testing every pair of routes for a shared stop (set intersection), then BFS — O(R² · L).
* **Optimized Solution:** stop → routes map, expanding each stop at most once — O(total stops).
* **Further Improvements Possible?** No; the input size is Σ|routes[i]| ≤ 10⁵.

## 🔹 Solution Breakdown

* **Optimal Approach:** `stop_routes[stop]` = routes through it. BFS queue holds routes with their bus count. For a route, iterate its stops; if a stop is unseen, mark it and enqueue every unvisited route in `stop_routes[stop]` with `buses + 1`. Stop when a dequeued route contains `target`.
* **Why This Works?** BFS visits routes in increasing number of buses; each stop is expanded once (all its routes are enqueued the first time it is seen), so the work is O(total stops) while still reaching each route with its minimal bus count.
* **Edge Cases Considered:**
  * `source == target` → `0`.
  * `source` or `target` served by no route → `-1`.
  * A stop shared by many routes — the stop-level `seen` set makes sure its route list is scanned only once (stops within one route are distinct by the constraints).

## 🔹 Tricks & Patterns Used

* **Inverted index (`stop → routes`)** to jump between routes without comparing pairs.
* **Two visited sets** (routes and stops) so every stop and route is expanded once.

## 🔹 Alternative Data Structures

* Bipartite graph stops ⇄ routes, with 0/1-weight BFS (boarding costs 1, riding is free) — same complexity.

## 🔹 Complexity Analysis

* **Time Complexity:** O(S) with `S = Σ len(routes[i])`
* **Space Complexity:** O(S)

## 🔹 Code Snippet (Brute Force)

```python
from collections import deque
from typing import List


class Solution:
    def numBusesToDestination(self, routes: List[List[int]], source: int, target: int) -> int:
        if source == target:
            return 0
        stops = [set(route) for route in routes]
        count = len(routes)
        neighbours = [[j for j in range(count) if j != i and stops[i] & stops[j]]
                      for i in range(count)]  # compares every pair of routes
        queue = deque((i, 1) for i in range(count) if source in stops[i])
        visited = {i for i, _ in queue}
        while queue:
            route, buses = queue.popleft()
            if target in stops[route]:
                return buses
            for other in neighbours[route]:
                if other not in visited:
                    visited.add(other)
                    queue.append((other, buses + 1))
        return -1
```

## 🔹 Code Snippet (Optimized)

```python
from collections import defaultdict, deque
from typing import List


class Solution:
    def numBusesToDestination(self, routes: List[List[int]], source: int, target: int) -> int:
        if source == target:
            return 0
        stop_routes = defaultdict(list)
        for i, route in enumerate(routes):
            for stop in route:
                stop_routes[stop].append(i)

        queue = deque((i, 1) for i in stop_routes[source])
        seen_routes = set(i for i, _ in queue)
        seen_stops = {source}
        while queue:
            route, buses = queue.popleft()
            for stop in routes[route]:
                if stop == target:
                    return buses
                if stop in seen_stops:  # its routes were already enqueued
                    continue
                seen_stops.add(stop)
                for other in stop_routes[stop]:
                    if other not in seen_routes:
                        seen_routes.add(other)
                        queue.append((other, buses + 1))
        return -1
```
