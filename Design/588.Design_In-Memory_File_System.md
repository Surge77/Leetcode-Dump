## 🔹 Problem Statement

Implement an in-memory file system with `ls(path)` (list a directory's entries in lexicographic order, or just the file's own name if the path is a file), `mkdir(path)` (create a directory, including missing parents), `addContentToFile(filePath, content)` (create the file if needed, otherwise append) and `readContentFromFile(filePath)`. *(premium — paraphrased from memory, not checked against the official page)*

* **Example:** `ls("/"), mkdir("/a/b/c"), addContentToFile("/a/b/c/d","hello"), ls("/"), readContentFromFile("/a/b/c/d")` → `[], null, null, ["a"], "hello"`
* **Constraints:** absolute paths of at most `100` characters, lowercase names, valid arguments, at most `300` calls

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Trie of path components.** Each node has `children` (name → node) and `content` (`None` for a directory, a string for a file). Every operation splits the path on `/` and walks the trie.
* **Core Concept:** a file system is a tree, so a trie keyed by directory/file names gives O(path length) lookups and keeps each directory's children together
* **When to Use This Pattern?** Hierarchical namespaces: file systems, URL routers, package paths, autocomplete.
* **Mistakes to Avoid:**
  * `ls` on a **file** returns just that file's name (`[name]`), not its content.
  * `ls` output must be sorted lexicographically.
  * `addContentToFile` **appends** to existing content and creates the file (and missing parent directories) when absent.
  * Splitting `"/"` gives empty parts — skip them so the root maps to the root node.

## 🔹 Optimization Path

* **Brute Force:** one flat dict of full path → content plus a set of directories; `ls` scans every entry to find those whose parent is the path — O(N) per `ls` for N total entries.
* **Optimized Solution:** trie — `ls` touches only that directory's children, O(path + k log k) for k entries.
* **Further Improvements Possible?** Keep each directory's names in a sorted container to avoid re-sorting (`sortedcontainers` is not in the standard library, so sort on demand).

## 🔹 Solution Breakdown

* **Optimal Approach:** `_walk(path)` descends, creating missing nodes. `ls`: if the node is a file return `[last name]`, else `sorted(children)`. `mkdir`: `_walk`. `addContentToFile`: `_walk`, then `content = (content or "") + text`. `readContentFromFile`: `_walk(path).content`.
* **Why This Works?** Path components uniquely identify a node, and a node is a file exactly when `content is not None`, so one structure serves both kinds of entries.
* **Edge Cases Considered:**
  * `ls("/")` on an empty system → `[]`.
  * `mkdir` on an already existing directory — no change.
  * `ls` on a file path returns the single file name.

## 🔹 Tricks & Patterns Used

* **One node type for files and directories:** `content is None` means directory.
* **Create-on-walk:** the same descent implements `mkdir` and the implicit parent creation of `addContentToFile`.

## 🔹 Alternative Data Structures

* Nested dicts (`{"a": {"b": {...}}}`) with a special key for file content — same idea, less explicit.
* Flat dict of full paths — simple, but `ls` becomes a scan.

## 🔹 Complexity Analysis

* **Time Complexity:** `mkdir` / `read` / `add`: O(L) for path length L (plus content length for `add`); `ls`: O(L + k log k)
* **Space Complexity:** O(total path components + total content)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class FileSystem:
    def __init__(self):
        self.dirs = {"/"}
        self.files = {}  # full path -> content

    @staticmethod
    def _parent(path: str) -> str:
        return path.rsplit("/", 1)[0] or "/"

    def ls(self, path: str) -> List[str]:
        if path in self.files:
            return [path.split("/")[-1]]
        names = [entry.split("/")[-1] for entry in list(self.dirs) + list(self.files)
                 if entry != "/" and self._parent(entry) == path]
        return sorted(names)

    def mkdir(self, path: str) -> None:
        current = ""
        for part in path.split("/")[1:]:
            current += "/" + part
            self.dirs.add(current)

    def addContentToFile(self, filePath: str, content: str) -> None:
        parent = self._parent(filePath)
        if parent != "/":
            self.mkdir(parent)
        self.files[filePath] = self.files.get(filePath, "") + content

    def readContentFromFile(self, filePath: str) -> str:
        return self.files[filePath]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Node:
    def __init__(self):
        self.children = {}
        self.content = None  # None marks a directory; a string marks a file


class FileSystem:
    def __init__(self):
        self.root = Node()

    def _walk(self, path: str) -> Node:
        node = self.root
        for part in path.split("/"):
            if part:  # the leading "/" (and the root path) yields empty parts
                node = node.children.setdefault(part, Node())
        return node

    def ls(self, path: str) -> List[str]:
        node = self._walk(path)
        if node.content is not None:
            return [path.split("/")[-1]]
        return sorted(node.children)

    def mkdir(self, path: str) -> None:
        self._walk(path)

    def addContentToFile(self, filePath: str, content: str) -> None:
        node = self._walk(filePath)
        node.content = (node.content or "") + content

    def readContentFromFile(self, filePath: str) -> str:
        return self._walk(filePath).content
```
