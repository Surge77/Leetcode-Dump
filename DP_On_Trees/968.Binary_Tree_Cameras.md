# 🔹 Problem Name: 968. Binary Tree Cameras (Tree DP / Greedy, Hard)

**🔗 Link:** [LeetCode 968](https://leetcode.com/problems/binary-tree-cameras/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Post-order with three states per node: `NOT_COVERED`, `HAS_CAMERA`, `COVERED`. A node gets a camera only when a child is uncovered — cameras are pushed as high as possible.
* **Core Concept:** Greedy on trees, justified by tree DP
* **When to Use This Pattern?** Minimum dominating set / covering problems on trees (guards, servers, hospitals within distance 1).
* **Mistakes to Avoid:**
  * Putting cameras on leaves — a leaf camera covers 2 nodes, its parent's camera covers up to 4.
  * Forgetting the root: if it ends `NOT_COVERED`, add one more camera.
  * Treating `None` children as uncovered — treat them as `COVERED`.

## 🔹 Optimization Path

* **Brute Force:** O(2ⁿ · n) — every camera subset.
* **Optimized Solution:** O(n) — one post-order pass.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:**
  * any child `NOT_COVERED` → place a camera here (`HAS_CAMERA`)
  * else any child `HAS_CAMERA` → `COVERED`
  * else → `NOT_COVERED` (let the parent cover it)
* **Why This Works?** An uncovered leaf must be covered by itself or its parent; the parent covers a superset of what the leaf would cover, so choosing the parent is never worse (exchange argument). Applying this bottom-up is optimal.
* **Edge Cases Considered:**
  * Single node → 1.
  * Chain of nodes.

## 🔹 Tricks & Patterns Used

* **Small state enum per node** returned bottom-up.
* **Iterative post-order** — safe for deep trees in Python.

## 🔹 Alternative Data Structures

* Pure DP: each node returns `(min cameras if it has a camera, if covered by a child, if covered by its parent)`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional

NOT_COVERED, HAS_CAMERA, COVERED = 0, 1, 2


class Solution:
    def minCameraCover(self, root: Optional["TreeNode"]) -> int:
        order, stack = [], [root]
        while stack:  # pre-order; reversed => children before parents
            node = stack.pop()
            order.append(node)
            if node.left:
                stack.append(node.left)
            if node.right:
                stack.append(node.right)

        state = {None: COVERED}  # missing children never need a camera
        cameras = 0
        for node in reversed(order):
            left, right = state[node.left], state[node.right]
            if left == NOT_COVERED or right == NOT_COVERED:
                cameras += 1
                state[node] = HAS_CAMERA
            elif left == HAS_CAMERA or right == HAS_CAMERA:
                state[node] = COVERED
            else:
                state[node] = NOT_COVERED
        return cameras + (state[root] == NOT_COVERED)
```
