# 🔹 Problem Name: 354. Russian Doll Envelopes (Dynamic Programming + Binary Search, Hard)

**🔗 Link:** [LeetCode 354](https://leetcode.com/problems/russian-doll-envelopes/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Sort by width ascending and, for equal widths, height **descending**; then the answer is the LIS of the heights.
* **Core Concept:** 2D LIS reduced to 1D LIS by a clever sort
* **When to Use This Pattern?** Chains where *both* dimensions must strictly increase (boxes, envelopes, people stacking).
* **Mistakes to Avoid:**
  * Sorting equal widths by height ascending — then `[3,4]` → `[3,5]` would be counted as nesting.
  * O(n²) DP — times out for n = 10⁵.

## 🔹 Optimization Path

* **Brute Force:** O(n²) DP after sorting.
* **Optimized Solution:** O(n log n) — sort + patience-sorting LIS on heights.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `sort(key=(w, -h))`, then LIS (strict, `bisect_left`) over `h`.
* **Why This Works?** After sorting, any increasing subsequence of heights has strictly increasing widths too: equal widths appear in decreasing height order, so two of them can never both be in a strictly increasing height sequence.
* **Edge Cases Considered:**
  * Duplicate envelopes.
  * All same width → answer 1.

## 🔹 Tricks & Patterns Used

* **Tie-break sort to kill a dimension:** descending second key removes same-width chains.

## 🔹 Alternative Data Structures

* Fenwick tree over compressed heights with "max over prefix" (process same-width groups together).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n log n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
from bisect import bisect_left
from typing import List


class Solution:
    def maxEnvelopes(self, envelopes: List[List[int]]) -> int:
        # width ascending; equal widths by height descending so they cannot chain
        envelopes.sort(key=lambda e: (e[0], -e[1]))
        tails = []
        for _, h in envelopes:
            i = bisect_left(tails, h)
            if i == len(tails):
                tails.append(h)
            else:
                tails[i] = h
        return len(tails)
```
