# 🔹 Problem Name: 239. Sliding Window Maximum (Monotonic Deque, Hard)

**🔗 Link:** [LeetCode 239](https://leetcode.com/problems/sliding-window-maximum/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Keep a deque of indices whose values are decreasing. Drop from the back anything smaller than the new value (it can never be a maximum again); drop from the front indices that left the window.
* **Core Concept:** Monotonic deque
* **When to Use This Pattern?** Max/min of every window of size k; DP transitions `dp[i] = max(dp[i-k..i-1]) + …` (e.g., 1696 Jump Game VI).
* **Mistakes to Avoid:**
  * A heap without removing expired indices → wrong answers.
  * Storing values instead of indices (you cannot tell when they expire).

## 🔹 Optimization Path

* **Brute Force:** O(n · k).
* **Heap:** O(n log n) with lazy deletion.
* **Optimized Solution:** O(n) — each index enters and leaves the deque once.

## 🔹 Solution Breakdown

* **Optimal Approach:** For each `i`: pop back while `nums[back] <= nums[i]`; push `i`; pop front if `front <= i - k`; once `i >= k - 1`, record `nums[front]`.
* **Why This Works?** An element smaller than a newer element can never be the maximum of any later window, so discarding it loses nothing; the front is always the largest remaining candidate.
* **Edge Cases Considered:**
  * `k = 1` → the array itself.
  * `k = n` → one maximum.
  * Negative numbers, duplicates.

## 🔹 Pattern Recognition

* **Belongs To:** Sliding Window / Monotonic Queue
* **Common Problems Using This:**
  * 1696. Jump Game VI

## 🔹 Tricks & Patterns Used

* **Monotonic deque** = sliding-window max in amortised O(1).

## 🔹 Alternative Data Structures

* **Sparse table:** O(n log n) build, O(1) range-max for arbitrary (not just sliding) windows.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(k)

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        dq = deque()  # indices, values decreasing from front to back
        result = []
        for i, x in enumerate(nums):
            while dq and nums[dq[-1]] <= x:
                dq.pop()  # dominated: can never be a window max again
            dq.append(i)
            if dq[0] <= i - k:
                dq.popleft()  # left the window
            if i >= k - 1:
                result.append(nums[dq[0]])
        return result
```
