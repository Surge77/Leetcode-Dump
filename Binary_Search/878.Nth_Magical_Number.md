# 878. Nth Magical Number

**🔗 Link:** [LeetCode 878](https://leetcode.com/problems/nth-magical-number/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

A positive integer is magical if it is divisible by `a` or by `b`. Given `n`, `a` and `b`, return the `n`-th magical number in increasing order, taken modulo `10^9 + 7` because it can be huge.

* **Example:** `n = 1, a = 2, b = 3` → `2`
* **Constraints:** `1 ≤ n ≤ 10^9`; `2 ≤ a, b ≤ 4 * 10^4`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** `count(x) = x//a + x//b - x//lcm(a, b)` numbers `≤ x` are magical. Binary search the smallest `x` with `count(x) ≥ n`, then return it mod 10⁹+7.
* **Core Concept:** Binary search on the answer + inclusion–exclusion
* **When to Use This Pattern?** "n-th number divisible by any of …" with `n` up to 10⁹ (two divisors here, three in 1201).
* **Mistakes to Avoid:**
  * Taking the modulo before the binary search finishes — the search needs the true value.
  * Upper bound too small: `n · min(a, b)` is always enough.

## 🔹 Optimization Path

* **Brute Force:** Test `x = 1, 2, 3, …` until the n-th magical number — O(n · min(a, b)) steps, since the answer can be that large.
* **Optimized Solution:** O(log(n · min(a, b))).
* **Further Improvements Possible?** Arithmetic on one LCM period gives O(1) after O(lcm) work — not better here.

## 🔹 Solution Breakdown

* **Optimal Approach:** `lo = 1`, `hi = n · min(a, b)`; standard "first x with count(x) ≥ n".
* **Why This Works?** Multiples of both `a` and `b` are exactly the multiples of their LCM, which the two single terms count twice. `count` rises by one exactly at each magical number, so the first `x` reaching `n` is the n-th one.
* **Edge Cases Considered:**
  * `a == b`.
  * One divides the other.

## 🔹 Code Snippet (Brute Force)

```python
MOD = 10**9 + 7


class Solution:
    def nthMagicalNumber(self, n: int, a: int, b: int) -> int:
        count, x = 0, 0
        while count < n:
            x += 1
            if x % a == 0 or x % b == 0:
                count += 1
        return x % MOD
```

## 🔹 Code Snippet (Optimized)

```python
from math import lcm

MOD = 10**9 + 7


class Solution:
    def nthMagicalNumber(self, n: int, a: int, b: int) -> int:
        both = lcm(a, b)

        def count(x: int) -> int:  # magical numbers <= x
            return x // a + x // b - x // both

        lo, hi = 1, n * min(a, b)
        while lo < hi:
            mid = (lo + hi) // 2
            if count(mid) >= n:
                hi = mid
            else:
                lo = mid + 1
        return lo % MOD
```
