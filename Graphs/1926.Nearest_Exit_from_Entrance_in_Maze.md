# 1926. Nearest Exit from Entrance in Maze

**🔗 Link:** [LeetCode 1926](https://leetcode.com/problems/nearest-exit-from-entrance-in-maze/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You are given a maze of open cells `'.'` and walls `'+'`, plus the starting cell `entrance`. Each step moves one cell up, down, left or right onto an open cell. An exit is any open cell on the border of the maze, except the entrance itself. Return the fewest steps from the entrance to the nearest exit, or `-1` if none is reachable.

* **Example:** `maze = [["+","+",".","+"],[".",".",".","+"],["+","+","+","."]], entrance = [1,2]` → `1`
* **Constraints:** `1 ≤ m, n ≤ 100`, each cell is `'.'` or `'+'`, the entrance is always an empty cell

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **BFS from the entrance.** Walk over `'.'` cells in 4 directions; the first reached cell on the border (other than the entrance itself) is the nearest exit, and its BFS level is the answer. `-1` if none.
* **Core Concept:** BFS layers = number of steps, so the first border cell found is the closest
* **When to Use This Pattern?** Shortest path in a grid maze where the goal is "any cell with a property".
* **Mistakes to Avoid:**
  * Counting the entrance as an exit: it is on the border, but the problem excludes it.
  * Testing "is exit" only on dequeue vs. on enqueue — both are fine, but forgetting the entrance exclusion is not.
  * DFS: not guaranteed shortest.

## 🔹 Optimization Path

* **Brute Force:** repeatedly relax distances over the whole grid until stable — O((m·n)²) worst case.
* **Optimized Solution:** BFS — O(m · n).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** mark the entrance as a wall/visited, queue `(r, c, 0)`. For each neighbour that is in bounds and `'.'`: if it lies on the border return `steps + 1`; otherwise mark and enqueue.
* **Why This Works?** Neighbours of the dequeued cell are at distance `steps + 1` and BFS dequeues in order of distance, so the first border hit is the minimum. Marking the entrance visited ensures it is never reported as an exit.
* **Edge Cases Considered:**
  * Entrance enclosed by walls → `-1`.
  * `1 × n` / `m × 1` mazes where almost every cell is a border cell.
  * Entrance itself on the border with no other reachable border cell → `-1`.

## 🔹 Tricks & Patterns Used

* **Border test:** `r in (0, rows − 1) or c in (0, cols − 1)`.
* **Seed the visited set with the entrance** (the code below does this); alternatively overwrite visited cells with `'+'`, copying the maze first if the input must stay intact.

## 🔹 Alternative Data Structures

* Visited set instead of mutating the maze.
* Bidirectional search is not worthwhile: the goal is a set of cells, not one.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n)
* **Space Complexity:** O(m · n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def nearestExit(self, maze: List[List[str]], entrance: List[int]) -> int:
        rows, cols = len(maze), len(maze[0])
        INF = float("inf")
        dist = [[INF] * cols for _ in range(rows)]
        dist[entrance[0]][entrance[1]] = 0
        changed = True
        while changed:  # relax every open cell until no distance improves
            changed = False
            for r in range(rows):
                for c in range(cols):
                    if maze[r][c] != ".":
                        continue
                    for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                        nr, nc = r + dr, c + dc
                        if 0 <= nr < rows and 0 <= nc < cols and dist[nr][nc] + 1 < dist[r][c]:
                            dist[r][c] = dist[nr][nc] + 1
                            changed = True
        best = min((dist[r][c] for r in range(rows) for c in range(cols)
                    if (r in (0, rows - 1) or c in (0, cols - 1)) and [r, c] != entrance),
                   default=INF)
        return -1 if best == INF else best
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def nearestExit(self, maze: List[List[str]], entrance: List[int]) -> int:
        rows, cols = len(maze), len(maze[0])
        start = (entrance[0], entrance[1])
        seen = {start}  # the entrance is visited from the start, so it can never count as an exit
        queue = deque([(start[0], start[1], 0)])
        while queue:
            r, c, steps = queue.popleft()
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols and maze[nr][nc] == "." and (nr, nc) not in seen:
                    if nr in (0, rows - 1) or nc in (0, cols - 1):
                        return steps + 1
                    seen.add((nr, nc))
                    queue.append((nr, nc, steps + 1))
        return -1
```
