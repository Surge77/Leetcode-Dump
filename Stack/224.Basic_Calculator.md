# 🔹 Problem Name: 224. Basic Calculator (Stack, Hard)

**🔗 Link:** [LeetCode 224](https://leetcode.com/problems/basic-calculator/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Running sum + stack of (result, sign) per parenthesis.** With only `+`, `-` and parentheses, the value is a signed sum of numbers. Keep `result`, the pending `sign` and the number being read. On `(` push `(result, sign)` and start a fresh sum; on `)` finish the inner sum and fold it back: `result = saved_result + saved_sign * inner`.
* **Core Concept:** a parenthesis is a sub-expression whose value gets multiplied by the sign in front of it — save the outer state, compute, restore
* **When to Use This Pattern?** Evaluating infix expressions with nesting: calculators (224/227/772), decoding nested strings (394), any "suspend, compute inner, resume" parse.
* **Mistakes to Avoid:**
  * Unary minus: `"-(2+3)"` and `"(-1)"` are valid. Starting each level with `result = 0` makes `-x` just `0 - x`.
  * Multi-digit numbers — accumulate `num = num * 10 + d`.
  * Forgetting to add the last number after the loop.
  * Recursive descent on `"((((…))))"` with up to 3·10⁵ characters → recursion error.

## 🔹 Optimization Path

* **Brute Force:** repeatedly find the innermost `( … )`, evaluate that flat signed sum and splice the number back into the string — O(n²) for deep nesting.
* **Optimized Solution:** one left-to-right pass with an explicit stack — O(n).
* **Further Improvements Possible?** No; O(n) is optimal. (Shunting-yard to RPN also works but is longer.)

## 🔹 Solution Breakdown

* **Optimal Approach:** digit → extend `num`; `+`/`-` → `result += sign * num`, reset `num`, set `sign`; `(` → push `(result, sign)`, reset both; `)` → `result += sign * num`, then `result = prev + prev_sign * result`; spaces ignored.
* **Why This Works?** Inside one level the value is `Σ signᵢ · numᵢ`. A whole parenthesised group behaves like one number whose sign is the one in front of `(` — exactly what the saved `sign` applies on `)`.
* **Edge Cases Considered:**
  * Leading unary minus `"-2+1"` → −1.
  * Spaces anywhere, e.g. `" 2-1 + 2 "` → 3.
  * Deep nesting — the stack is a list, no recursion.

## 🔹 Tricks & Patterns Used

* **Fold signs into numbers:** with no `*`/`/`, subtraction is addition of a negated term, so one accumulator suffices.
* **Stack frame = (partial result, sign before the group).**

## 🔹 Alternative Data Structures

* Recursive descent parser — clearest, but needs `sys.setrecursionlimit` for 3·10⁵ nested parentheses.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n), `n = len(s) ≤ 3·10⁵`
* **Space Complexity:** O(depth of nesting) ≤ O(n)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def calculate(self, s: str) -> int:
        def flat(expr: str) -> int:
            total, sign, i = 0, 1, 0
            while i < len(expr):
                ch = expr[i]
                if ch == "-":
                    sign = -sign  # splicing a negative value can create "--5" or "+-5"
                    i += 1
                elif ch == "+":
                    i += 1
                else:
                    j = i
                    while j < len(expr) and expr[j].isdigit():
                        j += 1
                    total += sign * int(expr[i:j])
                    sign, i = 1, j
            return total

        s = s.replace(" ", "")
        while "(" in s:
            close = s.index(")")
            open_ = s.rindex("(", 0, close)  # the "(" closest to the first ")" is innermost
            s = s[:open_] + str(flat(s[open_ + 1:close])) + s[close + 1:]
        return flat(s)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def calculate(self, s: str) -> int:
        result, sign, num = 0, 1, 0
        stack = []
        for ch in s:
            if ch.isdigit():
                num = num * 10 + int(ch)
            elif ch in "+-":
                result += sign * num
                num, sign = 0, (1 if ch == "+" else -1)
            elif ch == "(":
                stack.append((result, sign))
                result, sign = 0, 1  # a fresh level makes a unary "-" read as 0 - x
            elif ch == ")":
                result += sign * num
                num = 0
                prev, prev_sign = stack.pop()
                result = prev + prev_sign * result
        return result + sign * num
```
