# 🔹 Problem Name: 930. Binary Subarrays With Sum (Sliding Window, Medium)

**🔗 Link:** [LeetCode 930](https://leetcode.com/problems/binary-subarrays-with-sum/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given a binary array `nums` and an integer `goal`, count the non-empty contiguous subarrays whose elements add up to exactly `goal`.

* **Example:** `nums = [1,0,1,0,1]`, `goal = 2` → `4`
* **Constraints:** `1 ≤ nums.length ≤ 3·10^4`, `nums[i]` is 0 or 1, `0 ≤ goal ≤ nums.length`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **"At most" trick.** Count subarrays with sum `≤ goal` using a sliding window, then subtract the count with sum `≤ goal − 1`. What remains are exactly the subarrays with sum `== goal`.
* **Core Concept:** "exactly K" is not monotone in the window, but "at most K" is — so `exact(K) = atMost(K) − atMost(K − 1)`
* **When to Use This Pattern?** Counting subarrays where some non-negative quantity (sum of 0/1s, number of odd values, number of distinct values) equals exactly `K`.
* **Mistakes to Avoid:**
  * A single window for "sum == goal" misses subarrays: zeros let the left edge move without changing the sum, so several starts are valid at once.
  * `atMost(-1)` must return 0 (goal can be 0) — guard it, or the window shrinks past `right`.

## 🔹 Optimization Path

* **Brute Force:** fix every start, extend the end while adding — O(n²), about 4.5·10⁸ steps at `n = 3·10⁴`: too slow in Python.
* **Optimized Solution:** two "at most" sliding windows — O(n) time, O(1) space.
* **Further Improvements Possible?** Prefix sum + hashmap of prefix counts (as in 560) is also O(n), but needs O(n) space.

## 🔹 Solution Breakdown

* **Optimal Approach:** `atMost(k)`: grow `right`, add `nums[right]`; while the window sum exceeds `k`, drop `nums[left]` and advance `left`. Every subarray ending at `right` and starting in `[left, right]` has sum `≤ k`, so add `right − left + 1`.
* **Why This Works?** All values are ≥ 0, so shrinking from the left never increases the sum: the smallest valid `left` for each `right` only moves forward, and every start to its right is valid too. Subarrays with sum `≤ goal` minus those with sum `≤ goal − 1` are exactly those with sum `== goal`.
* **Edge Cases Considered:**
  * `goal = 0`: counts the all-zero runs; `[0,0,0,0,0]` gives 15.
  * `goal` larger than the total sum: both counts are `n(n+1)/2`, answer 0.

## 🔹 Pattern Recognition

* **Belongs To:** Sliding Window — counting with "at most K"

## 🔹 Tricks & Patterns Used

* **`exact(K) = atMost(K) − atMost(K − 1)`:** turns a non-monotone condition into two monotone windows.
* **`right − left + 1`:** counts every valid subarray ending at `right` in one step.

## 🔹 Alternative Data Structures

* Hashmap `prefix → count`: answer += `count[prefix − goal]` while scanning. Works for any integers, uses O(n) space.
* Positions of the ones: for each block of `goal` consecutive ones, multiply the zero-gaps on each side.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n) — each pointer moves at most `n` times per call
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def numSubarraysWithSum(self, nums: List[int], goal: int) -> int:
        count = 0
        for start in range(len(nums)):
            total = 0
            for end in range(start, len(nums)):
                total += nums[end]
                if total == goal:
                    count += 1
        return count
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def numSubarraysWithSum(self, nums: List[int], goal: int) -> int:
        def at_most(k: int) -> int:
            if k < 0:
                return 0  # no subarray of non-negative values sums below 0
            left = total = count = 0
            for right, value in enumerate(nums):
                total += value
                while total > k:
                    total -= nums[left]
                    left += 1
                count += right - left + 1
            return count

        return at_most(goal) - at_most(goal - 1)
```
