# 1008. Construct Binary Search Tree from Preorder Traversal

**🔗 Link:** [LeetCode 1008](https://leetcode.com/problems/construct-binary-search-tree-from-preorder-traversal/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You get the preorder traversal of a binary search tree as an array of distinct integers. Rebuild the tree and return its root. A valid BST is guaranteed to exist for every input.

* **Example:** `preorder = [8,5,1,7,10,12]` → `[8,5,10,1,7,null,12]`
* **Constraints:** `1 ≤ preorder.length ≤ 100`, `1 ≤ preorder[i] ≤ 1000`, all values unique

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Upper-bound recursion.** Consume `preorder` left to right with a shared index. `build(bound)` creates a node from the next value only if it is below `bound`; its left subtree is `build(node.val)` and its right subtree is `build(bound)`. Each value is read once.
* **Core Concept:** in preorder of a BST, a node's left subtree is the run of following values smaller than it, the right subtree is the rest below the ancestor's bound
* **When to Use This Pattern?** Rebuilding or validating a BST from a traversal (449 serialize BST, 255 verify preorder sequence), or any "consume a stream while values fit a range" recursion.
* **Mistakes to Avoid:**
  * Inserting values one by one — correct but O(n²) on sorted input.
  * Splitting with a linear scan for the first larger value at every node — also O(n²) worst case.
  * Adding a lower-bound check as well — unnecessary: preorder order already guarantees it, so only the upper bound decides when a subtree ends.

## 🔹 Optimization Path

* **Brute Force:** insert each value into a BST starting from the first — O(n²) worst case (sorted input builds a path).
* **Better:** sort a copy to get inorder, then use the preorder+inorder construction (105) — O(n log n).
* **Optimized Solution:** bound recursion — O(n).
* **Further Improvements Possible?** A monotonic stack also gives O(n) without recursion; time is optimal.

## 🔹 Solution Breakdown

* **Optimal Approach:** `i = 0`; `build(bound)`: if `i == n` or `preorder[i] > bound` return `None`; make the node, `i += 1`, `left = build(node.val)`, `right = build(bound)`. Call `build(inf)`.
* **Why This Works?** Preorder lists a node, then all of its left subtree (values < node), then all of its right subtree (values between node and the nearest ancestor bound). `build(node.val)` therefore consumes exactly the left subtree and stops at the first larger value; `build(bound)` consumes the right subtree and stops at the first value that belongs further up.
* **Edge Cases Considered:**
  * One value → single node.
  * Strictly increasing / decreasing input → a path of depth `n ≤ 100`, well within the recursion limit.

## 🔹 Tricks & Patterns Used

* **Shared index + bound:** the recursion never searches; the bound tells it when to stop.
* **Monotonic stack variant:** for each value, pop while the stack top is smaller (the last popped is the parent, attach as right child); otherwise attach as left child of the top.

## 🔹 Alternative Data Structures

* Monotonic decreasing stack — O(n), iterative.
* Sort for inorder + hash map of positions, then 105's algorithm — O(n log n).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n) — each value is consumed once and each `build` call that returns `None` is charged to its parent
* **Space Complexity:** O(h) recursion, at most `n = 100`

## 🔹 Code Snippet (Brute Force)

```python
from typing import List, Optional


class Solution:
    def bstFromPreorder(self, preorder: List[int]) -> Optional[TreeNode]:
        root = TreeNode(preorder[0])
        for val in preorder[1:]:
            node = root
            while True:
                side = "left" if val < node.val else "right"
                child = getattr(node, side)
                if child is None:
                    setattr(node, side, TreeNode(val))  # inserting in preorder order reproduces the shape
                    break
                node = child
        return root
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List, Optional


class Solution:
    def bstFromPreorder(self, preorder: List[int]) -> Optional[TreeNode]:
        i = 0

        def build(bound: float) -> Optional[TreeNode]:
            nonlocal i
            if i == len(preorder) or preorder[i] > bound:
                return None  # this value belongs to an ancestor's right subtree
            node = TreeNode(preorder[i])
            i += 1
            node.left = build(node.val)
            node.right = build(bound)
            return node

        return build(float("inf"))  # depth <= len(preorder) <= 100, safe to recurse
```
