# 🔹 Problem Name: 201. Bitwise AND of Numbers Range (Bit Manipulation, Medium)

**🔗 Link:** [LeetCode 201](https://leetcode.com/problems/bitwise-and-of-numbers-range/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Common binary prefix.** The AND of every number in `[left, right]` is the longest common prefix of `left` and `right` in binary, followed by zeros. Shift both right until they are equal, then shift the result back.
* **Core Concept:** below the first bit where `left` and `right` differ, the range crosses a point `…0111 → …1000`, so every lower bit is 0 in at least one number
* **When to Use This Pattern?** Bitwise aggregates over a contiguous integer range — AND/OR of a range, "which bits stay set when counting from `a` to `b`".
* **Mistakes to Avoid:**
  * Looping from `left` to `right`: up to 2³¹ iterations.
  * Assuming the answer is `left & right` — `5 & 7 = 5`, but `5 & 6 & 7 = 4`.

## 🔹 Optimization Path

* **Brute Force:** AND every number in the range, stopping early at 0 — O(right − left) in the worst case.
* **Optimized Solution:** strip differing low bits — O(log right) ≤ 31 steps.
* **Further Improvements Possible?** Brian Kernighan variant: `while right > left: right &= right - 1` — same bound, often fewer steps.

## 🔹 Solution Breakdown

* **Optimal Approach:** `while left != right: left >>= 1; right >>= 1; shift += 1`; return `left << shift`.
* **Why This Works?** Let bit `k` be the highest bit where `left` and `right` differ (`left` has 0, `right` has 1). The range contains `P·2^(k+1) + 2^k − 1` and `P·2^(k+1) + 2^k` (with `P` the shared prefix), which disagree on every bit `≤ k`, so those bits AND to 0. Bits above `k` are the same in `left` and `right` and therefore in every number between them.
* **Edge Cases Considered:**
  * `left == right` → the number itself.
  * `left = 0` → 0.
  * `left = 1, right = 2³¹ − 1` → 0.

## 🔹 Tricks & Patterns Used

* **`n & (n − 1)`** clears the lowest set bit.
* **Shift until equal** finds the common binary prefix.

## 🔹 Alternative Data Structures

* `left.bit_length()`-based mask: `shift = (left ^ right).bit_length()`, answer `left >> shift << shift` — O(1) with built-ins.

## 🔹 Complexity Analysis

* **Time Complexity:** O(log right) — at most 31 iterations
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def rangeBitwiseAnd(self, left: int, right: int) -> int:
        result = left
        for num in range(left + 1, right + 1):
            result &= num
            if result == 0:
                break
        return result
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def rangeBitwiseAnd(self, left: int, right: int) -> int:
        shift = 0
        # below the highest differing bit, the range passes ...0111 -> ...1000, zeroing everything
        while left != right:
            left >>= 1
            right >>= 1
            shift += 1
        return left << shift
```
