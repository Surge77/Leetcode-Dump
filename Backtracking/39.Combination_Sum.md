# 🔹 Problem Name: 39. Combination Sum (Backtracking, Medium)

**🔗 Link:** [LeetCode 39](https://leetcode.com/problems/combination-sum/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Backtracking with a start index.** Sort the distinct candidates. `dfs(start, remain)` tries every candidate `candidates[i]` with `i ≥ start`, recursing with the **same** `i` (a number may be reused) and `remain − candidates[i]`. Stop the loop as soon as a candidate exceeds `remain` — every later one is bigger.
* **Core Concept:** generate each multiset exactly once by only ever picking candidates in non-decreasing index order
* **When to Use This Pattern?** "List all combinations (not permutations) that sum to / satisfy X", with or without reuse — the start index is what kills duplicate orderings.
* **Mistakes to Avoid:**
  * Looping from 0 at every level: `[2,2,3]`, `[2,3,2]`, `[3,2,2]` all get generated and must be deduplicated.
  * Recursing with `i + 1`: that forbids reuse (that is problem 40).
  * Appending `path` itself instead of a copy — every result ends up as the same (empty) list.

## 🔹 Optimization Path

* **Brute Force:** enumerate every **ordered** sequence that sums to `target`, sort each one and dedupe with a set — the number of orderings is exponentially larger than the number of answers.
* **Optimized Solution:** start-index backtracking with sorted break — each multiset is produced once and dead branches stop early.
* **Further Improvements Possible?** A DP table "which sums are reachable from candidates[i:]" prunes branches that can never hit `target`; not needed for `target ≤ 40`.

## 🔹 Solution Breakdown

* **Optimal Approach:** `path` holds the current multiset; on `remain == 0` record `path[:]`; for `i` in `start..`: if `c > remain` break, else push, `dfs(i, remain − c)`, pop.
* **Why This Works?** Any multiset written in non-decreasing order of index is reached by exactly one path of the recursion, and the recursion only builds such sequences — so the output is complete and duplicate-free. All candidates are ≥ 2 (positive), so `remain` strictly decreases and depth is at most `target / min(candidates)`.
* **Edge Cases Considered:**
  * No combination (`[2]`, target `1`) → `[]`.
  * A single candidate equal to `target` → `[[target]]`.

## 🔹 Tricks & Patterns Used

* **Start index = combination, not permutation.**
* **Sort + break:** once `candidates[i] > remain`, the rest of the loop cannot succeed.
* **Shared `path` with push/pop** instead of `path + [c]` copies on every call.

## 🔹 Alternative Data Structures

* DP over sums where `dp[s]` is the list of combinations for `s`, built candidate by candidate (unbounded knapsack order avoids duplicates) — more memory, same output.

## 🔹 Complexity Analysis

* **Time Complexity:** O(N^(T/M + 1)) worst case, `N` candidates, `T` target, `M` smallest candidate (the depth is at most `T/M`); copying results adds O(answers × T/M). LeetCode guarantees fewer than 150 answers.
* **Space Complexity:** O(T/M) recursion depth and path, excluding the output.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        found = set()

        def dfs(remain: int, seq: List[int]) -> None:
            if remain == 0:
                found.add(tuple(sorted(seq)))
                return
            for c in candidates:
                if c <= remain:
                    dfs(remain - c, seq + [c])

        dfs(target, [])
        return [list(combo) for combo in found]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates = sorted(candidates)
        result, path = [], []

        def dfs(start: int, remain: int) -> None:
            if remain == 0:
                result.append(path[:])
                return
            for i in range(start, len(candidates)):
                c = candidates[i]
                if c > remain:
                    break
                path.append(c)
                dfs(i, remain - c)  # same i: a candidate may be used again
                path.pop()

        dfs(0, target)
        return result
```
