# 827. Making A Large Island

**🔗 Link:** [LeetCode 827](https://leetcode.com/problems/making-a-large-island/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You are given an `n × n` binary grid where an island is a 4-directionally connected group of `1`s. You may change at most one `0` into a `1`. Return the size of the largest island you can end up with.

* **Example:** `grid = [[1,0],[0,1]]` → `3`
* **Constraints:** `1 ≤ n ≤ 500`, each cell is `0` or `1`

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Label islands once, then score every water cell.** Pass 1: flood-fill each island, writing its id into `label` and its area into `sizes[id]`. Pass 2: for each `0`, the island created by flipping it has area `1 + Σ sizes` of the **distinct** island ids among its 4 neighbours. The answer is the best such value, or the largest island when there is no `0`.
* **Core Concept:** precompute component sizes so a "what if I add this cell" query costs O(1)
* **When to Use This Pattern?** "Change one cell / add one edge, maximise the component" — the joined component is the new cell plus whatever components it touches.
* **Mistakes to Avoid:**
  * Adding the same island twice when it touches the flipped cell from two sides — collect neighbour ids in a **set**.
  * Forgetting the all-land grid: there is nothing to flip, the answer is `n²`, not `n² + 1`.
  * Re-flooding the grid for every `0`: O(n⁴) = 6·10¹⁰ steps at `n = 500`.
  * Recursive DFS: an island can have 250 000 cells.

## 🔹 Optimization Path

* **Brute Force:** for every `0`, flip it, recompute the largest island by flood fill, flip it back — O(n⁴).
* **Optimized Solution:** component labeling + one neighbour lookup per water cell — O(n²).
* **Further Improvements Possible?** No; every cell must be read.

## 🔹 Solution Breakdown

* **Optimal Approach:** `sizes = [0]` so id 0 means water; ids start at 1. Iterative DFS per unlabeled land cell. Then `best = max(sizes)` and, for every water cell, `best = max(best, 1 + sum(sizes[i] for i in {neighbour ids}))`.
* **Why This Works?** Flipping a cell only merges the islands adjacent to it; no other island changes. The new island's area is therefore that cell plus each touching island counted once, and every island area is known from pass 1.
* **Edge Cases Considered:**
  * All water → `1`.
  * All land → `n²`.
  * `n = 1` → `1` either way.

## 🔹 Tricks & Patterns Used

* **Sentinel id 0 with `sizes[0] = 0`:** water neighbours add nothing, no special case.
* **Separate `label` matrix:** the input grid stays unchanged.

## 🔹 Alternative Data Structures

* Union-Find over cells with component sizes: union all land, then for each `0` sum sizes of distinct neighbour roots — same O(n²·α).
* Overwrite the grid with ids `≥ 2` instead of a `label` matrix to save memory (mutates the input).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n²)
* **Space Complexity:** O(n²) for `label` and the stack

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def largestIsland(self, grid: List[List[int]]) -> int:
        n = len(grid)

        def biggest() -> int:
            seen, best = set(), 0
            for r in range(n):
                for c in range(n):
                    if grid[r][c] != 1 or (r, c) in seen:
                        continue
                    seen.add((r, c))
                    stack, area = [(r, c)], 0
                    while stack:
                        i, j = stack.pop()
                        area += 1
                        for x, y in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
                            if 0 <= x < n and 0 <= y < n and grid[x][y] == 1 and (x, y) not in seen:
                                seen.add((x, y))
                                stack.append((x, y))
                    best = max(best, area)
            return best

        best = biggest()  # an all-land grid has no zero to flip
        for r in range(n):
            for c in range(n):
                if grid[r][c] == 0:
                    grid[r][c] = 1
                    best = max(best, biggest())
                    grid[r][c] = 0
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def largestIsland(self, grid: List[List[int]]) -> int:
        n = len(grid)
        label = [[0] * n for _ in range(n)]
        sizes = [0]  # ids start at 1 so label 0 can stand for water
        for r in range(n):
            for c in range(n):
                if grid[r][c] != 1 or label[r][c]:
                    continue
                island = len(sizes)
                label[r][c] = island
                stack, area = [(r, c)], 0
                while stack:
                    i, j = stack.pop()
                    area += 1
                    for x, y in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
                        if 0 <= x < n and 0 <= y < n and grid[x][y] == 1 and not label[x][y]:
                            label[x][y] = island
                            stack.append((x, y))
                sizes.append(area)

        best = max(sizes)  # an all-land grid has no zero to flip
        for r in range(n):
            for c in range(n):
                if grid[r][c] == 0:
                    touching = {label[x][y] for x, y in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1))
                                if 0 <= x < n and 0 <= y < n}  # a set, so an island touching twice counts once
                    best = max(best, 1 + sum(sizes[i] for i in touching))
        return best
```
