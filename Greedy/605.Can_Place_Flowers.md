# 605. Can Place Flowers

**🔗 Link:** [LeetCode 605](https://leetcode.com/problems/can-place-flowers/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

A flowerbed is an array of 0 (empty) and 1 (planted) with no two flowers adjacent. Decide whether `n` more flowers can be planted in empty plots without ever putting two flowers next to each other.

* **Example:** `flowerbed = [1,0,0,0,1], n = 1` → `true`
* **Constraints:** `1 ≤ flowerbed.length ≤ 2 · 10^4`, `flowerbed[i]` is 0 or 1, the given bed has no adjacent flowers, `0 ≤ n ≤ flowerbed.length`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Plant as early as possible.** Scan left to right; plant at `i` whenever `i` and both neighbours are empty (out-of-range neighbours count as empty). Count plantings and compare with `n`.
* **Core Concept:** planting at the leftmost legal slot never reduces what the rest of the bed can hold
* **When to Use This Pattern?** Maximum number of non-adjacent picks on a line (seating, scheduling with conflicts only between neighbours).
* **Mistakes to Avoid:**
  * Checking `flowerbed[i + 1]` without bounds handling at the ends — pad with zeros instead.
  * Not updating the bed after planting, so the next cell sees a stale neighbour.
  * Dividing runs of zeros by 2 without the `k − 1` correction.

## 🔹 Optimization Path

* **Brute Force:** recursively decide plant / skip at every position and take the maximum — exponential without memoisation.
* **Optimized Solution:** greedy single pass — O(m) with `m = len(flowerbed)`.
* **Further Improvements Possible?** Early exit once the count reaches `n`; otherwise optimal.

## 🔹 Solution Breakdown

* **Optimal Approach:** copy the bed with a `0` on each end; for each real position, if left, itself and right are all `0`, set it to `1` and count it.
* **Why This Works?** In a maximal run of `k` zeros between flowers the greedy places at the first allowed cell, then every other cell — the maximum possible `⌊(k − 1) / 2⌋` (a run touching one end of the bed holds `⌊k / 2⌋`, an all-zero bed `⌈k / 2⌉`; the padding handles both). Exchange argument: any solution can shift its leftmost plant to the leftmost legal cell without breaking others.
* **Edge Cases Considered:**
  * `n = 0` → always `True`.
  * `[0]`, `n = 1` → `True`; `[1]`, `n = 1` → `False`.
  * `[1, 0, 0, 0, 1]`: `n = 1` → `True`, `n = 2` → `False`.

## 🔹 Tricks & Patterns Used

* **Zero padding** to remove boundary special cases.
* **Mutating the working copy** so later cells see the new flower.

## 🔹 Alternative Data Structures

* Run-length: for every run of `k` zeros add `(k − 1) // 2` (with one extra zero added at each bed end).

## 🔹 Complexity Analysis

* **Time Complexity:** O(m)
* **Space Complexity:** O(m) for the padded copy (O(1) if the input may be modified)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def canPlaceFlowers(self, flowerbed: List[int], n: int) -> bool:
        m = len(flowerbed)

        def free(i: int) -> bool:
            return (flowerbed[i] == 0
                    and (i == 0 or flowerbed[i - 1] == 0)
                    and (i == m - 1 or flowerbed[i + 1] == 0))

        def most(i: int) -> int:
            if i >= m:
                return 0
            skip = most(i + 1)
            # planting at i blocks i + 1, so continue from i + 2
            return max(skip, 1 + most(i + 2)) if free(i) else skip

        return most(0) >= n
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def canPlaceFlowers(self, flowerbed: List[int], n: int) -> bool:
        bed = [0] + flowerbed + [0]  # virtual empty plots beyond both ends
        planted = 0
        for i in range(1, len(bed) - 1):
            if bed[i - 1] == bed[i] == bed[i + 1] == 0:
                bed[i] = 1
                planted += 1
        return planted >= n
```
