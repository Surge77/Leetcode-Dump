# 🔹 Problem Name: 131. Palindrome Partitioning (Backtracking, Medium)

**🔗 Link:** [LeetCode 131](https://leetcode.com/problems/palindrome-partitioning/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given a string, cut it into consecutive pieces so that every piece reads the same forwards and backwards. Return every possible way to do this.

* **Example:** `s = "aab"` → `[["a","a","b"],["aa","b"]]`
* **Constraints:** `1 ≤ s.length ≤ 16`, lowercase English letters only

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Backtracking over cut positions + palindrome table.** Precompute `pal[i][j]` ("is `s[i..j]` a palindrome") in O(n²). `dfs(start)` tries every `end ≥ start` with `pal[start][end]`, appends `s[start:end+1]`, recurses from `end + 1`, pops.
* **Core Concept:** only extend the partition with pieces that are already valid, so every leaf of the recursion is an answer
* **When to Use This Pattern?** "Split a string into pieces that each satisfy P, list all splits" — Word Break II, Restore IP Addresses, palindrome partitioning.
* **Mistakes to Avoid:**
  * Checking `piece == piece[::-1]` on every call — O(n) per check, repeated for the same substrings many times.
  * Building the table in the wrong order: `pal[i][j]` depends on `pal[i + 1][j − 1]`, so `i` must go from `n − 1` down.

## 🔹 Optimization Path

* **Brute Force:** each of the `n − 1` gaps is cut or not → 2ⁿ⁻¹ partitions; keep those whose pieces are all palindromes — O(2ⁿ · n) regardless of the input.
* **Optimized Solution:** backtracking that only follows palindromic prefixes, with O(1) checks — O(n · 2ⁿ) in the worst case (`"aaa…a"`, where every partition is valid), far less on typical strings.
* **Further Improvements Possible?** The output itself can have 2ⁿ⁻¹ partitions of total length n each, so O(n · 2ⁿ) is optimal in the worst case.

## 🔹 Solution Breakdown

* **Optimal Approach:** `pal[i][j] = s[i] == s[j] and (j − i < 2 or pal[i + 1][j − 1])`; then backtrack with a shared `path`.
* **Why This Works?** Every valid partition is a sequence of palindromic pieces whose boundaries increase; the DFS chooses the first piece among all palindromic prefixes, then recursively partitions the rest, so it enumerates every valid partition exactly once and nothing else.
* **Edge Cases Considered:**
  * Single character → `[[s]]`.
  * All equal characters (`n = 16`) → 2¹⁵ = 32768 partitions.

## 🔹 Tricks & Patterns Used

* **Interval palindrome DP** `pal[i][j]` built from shorter intervals.
* **Push / recurse / pop** on a shared path, copying only at leaves.

## 🔹 Alternative Data Structures

* Expand-around-centre to fill `pal` (O(n²) too, no dependency order to get wrong).
* Memoise `partitions(start)` as a list of lists — trades memory for avoiding recomputation of suffix partitions.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · 2ⁿ) worst case for `n ≤ 16`, plus O(n²) for the table.
* **Space Complexity:** O(n²) for the table, O(n) recursion depth, excluding the output.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def partition(self, s: str) -> List[List[str]]:
        n = len(s)
        result = []
        for mask in range(1 << (n - 1)):
            pieces, start = [], 0
            for gap in range(n - 1):
                if mask >> gap & 1:
                    pieces.append(s[start:gap + 1])
                    start = gap + 1
            pieces.append(s[start:])
            if all(p == p[::-1] for p in pieces):
                result.append(pieces)
        return result
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def partition(self, s: str) -> List[List[str]]:
        n = len(s)
        pal = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):  # pal[i][j] needs pal[i + 1][j - 1] first
            for j in range(i, n):
                pal[i][j] = s[i] == s[j] and (j - i < 2 or pal[i + 1][j - 1])

        result, path = [], []

        def dfs(start: int) -> None:
            if start == n:
                result.append(path[:])
                return
            for end in range(start, n):
                if pal[start][end]:
                    path.append(s[start:end + 1])
                    dfs(end + 1)
                    path.pop()

        dfs(0)
        return result
```
