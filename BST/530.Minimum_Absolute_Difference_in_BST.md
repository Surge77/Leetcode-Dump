# 🔹 Problem Name: 530. Minimum Absolute Difference in BST (BST Inorder Traversal, Easy)

**🔗 Link:** [LeetCode 530](https://leetcode.com/problems/minimum-absolute-difference-in-bst/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given the root of a BST, return the smallest absolute difference between the values of any two different nodes.

* **Example:** `root = [4,2,6,1,3]` → `1`
* **Constraints:** `2 ≤ nodes ≤ 10^4`, `0 ≤ Node.val ≤ 10^5`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Inorder = sorted.** Walk the BST inorder keeping the previous value; the answer is the smallest `cur − prev`. In a sorted list the closest pair is always adjacent.
* **Core Concept:** minimum gap of a sorted sequence is between neighbours
* **When to Use This Pattern?** "Minimum difference / closest pair" over a BST or any data you can visit in sorted order (783 is the same problem).
* **Mistakes to Avoid:**
  * Comparing each node only with its parent and children — the closest value can be far away in the tree (e.g. the root and the rightmost node of its left subtree).
  * Recursive inorder on a 10⁴-node path: recursion limit.
  * Initialising `prev` to `0` or `-1` — values start at 0, so a sentinel can create a fake small gap; use `None`.

## 🔹 Optimization Path

* **Brute Force:** collect all values, compare every pair — O(n²).
* **Better:** collect, sort, scan neighbours — O(n log n).
* **Optimized Solution:** iterative inorder with `prev` — O(n) time, O(h) space.
* **Further Improvements Possible?** Morris traversal for O(1) space; time is optimal.

## 🔹 Solution Breakdown

* **Optimal Approach:** stack-based inorder; at each visited node, if `prev` exists update `best = min(best, node.val − prev)`, then `prev = node.val`.
* **Why This Works?** For sorted `a₁ < a₂ < … < aₙ` and `i < j`, `aⱼ − aᵢ ≥ aᵢ₊₁ − aᵢ`, so some adjacent pair is at least as close as any pair.
* **Edge Cases Considered:**
  * Two nodes (minimum `n = 2`) — exactly one gap.
  * Equal values (if a tree ever held duplicates) — they are adjacent in inorder, giving gap 0 correctly.

## 🔹 Tricks & Patterns Used

* **Iterative inorder template:** push left spine, pop, visit, move right.
* **Predecessor value instead of a list:** O(h) memory instead of O(n).

## 🔹 Alternative Data Structures

* Morris traversal — O(1) extra space.
* For a plain binary tree (not BST): collect and sort.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(h) for the stack

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def getMinimumDifference(self, root: Optional[TreeNode]) -> int:
        vals, stack = [], [root]
        while stack:
            node = stack.pop()
            if node:
                vals.append(node.val)
                stack += [node.left, node.right]
        return min(abs(vals[i] - vals[j]) for i in range(len(vals)) for j in range(i + 1, len(vals)))
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def getMinimumDifference(self, root: Optional[TreeNode]) -> int:
        best, prev = float("inf"), None
        stack, cur = [], root
        while stack or cur:
            while cur:
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()
            if prev is not None:
                best = min(best, cur.val - prev)  # inorder is ascending, so no abs needed
            prev = cur.val
            cur = cur.right
        return best
```
