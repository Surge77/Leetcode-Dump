# 🔹 Problem Name: 72. Edit Distance (Dynamic Programming, Medium)

**🔗 Link:** [LeetCode 72](https://leetcode.com/problems/edit-distance/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given two words, return the fewest single-character operations needed to turn `word1` into `word2`. The allowed operations are inserting a character, deleting a character, and replacing a character.

* **Example:** `word1 = "horse", word2 = "ros"` → `3`
* **Constraints:** `0 ≤ word1.length, word2.length ≤ 500`; lowercase English letters only.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** `dp[i][j]` = edits to turn `a[:i]` into `b[:j]`. Equal last characters → `dp[i-1][j-1]`; else `1 + min(delete, insert, replace)`.
* **Core Concept:** 2D DP on two strings (Levenshtein distance)
* **When to Use This Pattern?** Minimum operations to transform one sequence into another; spell-checkers, DNA alignment.
* **Mistakes to Avoid:**
  * Wrong base cases: `dp[i][0] = i` (delete everything), `dp[0][j] = j` (insert everything).
  * Mixing up which neighbour is insert vs delete (it doesn't change the answer, but explain it right in the interview).

## 🔹 Optimization Path

* **Brute Force:** O(3^(n+m)) — recursion without memo.
* **Optimized Solution:** O(n · m) time, O(m) space.
* **Further Improvements Possible?** If only "is distance ≤ k?" is asked, restrict to a diagonal band: O(n · k).

## 🔹 Solution Breakdown

* **Optimal Approach:**
  * delete `a[i-1]` → `prev[j] + 1`
  * insert `b[j-1]` → `cur[j-1] + 1`
  * replace → `prev[j-1] + 1`
* **Why This Works?** In an optimal edit script the last characters are either matched, replaced, or one of them is deleted/inserted — those cases are exhaustive.
* **Edge Cases Considered:**
  * One string empty → length of the other.
  * Identical strings → 0.

## 🔹 Pattern Recognition

* **Belongs To:** DP — two-string grid

## 🔹 Tricks & Patterns Used

* **Rolling rows**, with `cur[0] = i` as the base for each row.

## 🔹 Alternative Data Structures

* Top-down `lru_cache` version is shorter to write but needs `sys.setrecursionlimit` for 500-char strings.

* **Time Complexity:** O(n · m)
* **Space Complexity:** O(m)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        def dist(i, j):  # plain recursion, no memo
            if i == len(word1):
                return len(word2) - j
            if j == len(word2):
                return len(word1) - i
            if word1[i] == word2[j]:
                return dist(i + 1, j + 1)
            return 1 + min(dist(i + 1, j),  # delete
                           dist(i, j + 1),  # insert
                           dist(i + 1, j + 1))  # replace

        return dist(0, 0)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m = len(word2)
        prev = list(range(m + 1))  # word1 empty: insert j characters
        for i, ch in enumerate(word1, 1):
            cur = [i] + [0] * m  # word2 empty: delete i characters
            for j in range(1, m + 1):
                if ch == word2[j - 1]:
                    cur[j] = prev[j - 1]
                else:
                    cur[j] = 1 + min(prev[j],  # delete
                                     cur[j - 1],  # insert
                                     prev[j - 1])  # replace
            prev = cur
        return prev[m]
```
