# 🔹 Problem Name: 409. Longest Palindrome (Hash Map Counting, Easy)

**🔗 Link:** [LeetCode 409](https://leetcode.com/problems/longest-palindrome/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Count letters.** A palindrome is made of mirrored pairs plus at most one unpaired centre. Every letter contributes `count // 2 * 2` characters, and if any letter has an odd count, one extra character can sit in the middle.
* **Core Concept:** build the length from letter frequencies, never the string itself
* **When to Use This Pattern?** "Longest palindrome you can *form* from these characters" (rearrangement allowed) — as opposed to finding a palindromic *substring*.
* **Mistakes to Avoid:**
  * Adding `+1` per odd letter — only **one** centre is allowed, so the bonus is at most `+1`.
  * Treating `A` and `a` as the same letter — the problem is case-sensitive.
  * Confusing this with 5 / 516, where the characters must keep their order.

## 🔹 Optimization Path

* **Brute Force:** repeatedly take a character and search the rest of the list for a partner — O(n²).
* **Optimized Solution:** one pass of counting, then add up the pairs — O(n).
* **Further Improvements Possible?** No, every character must be read once. The alphabet is 52 letters, so the table is constant size.

## 🔹 Solution Breakdown

* **Optimal Approach:** count each letter, add `c - (c % 2)` for each count, then add `1` if the total is shorter than `len(s)` (some character was left over, so it can be the centre).
* **Why This Works?** Pairs are the only thing a palindrome needs on both sides, so every pair of equal letters can be used. A leftover letter exists exactly when some count is odd, and one of those can go in the middle.
* **Edge Cases Considered:**
  * All letters distinct → answer is `1`.
  * All counts even → no centre, answer is `len(s)`.
  * A count of 3 contributes one pair, and the spare letter is a centre candidate.

## 🔹 Tricks & Patterns Used

* **Pairs plus one centre:** `sum(c // 2 * 2)` and `+1 if any c is odd`.
* **Shortcut for the centre check:** `total < len(s)` replaces a second pass looking for odd counts.

## 🔹 Alternative Data Structures

* A set that toggles membership: add a letter when absent, remove it and add `2` when present. At the end, a non-empty set means a centre exists.
* An array of 128 counters indexed by `ord(ch)`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(σ) with σ = 52 letters, so O(1)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def longestPalindrome(self, s: str) -> int:
        chars = list(s)
        length = 0
        has_centre = False
        while chars:
            ch = chars.pop()
            if ch in chars:
                chars.remove(ch)
                length += 2
            else:
                has_centre = True
        return length + (1 if has_centre else 0)
```

## 🔹 Code Snippet (Optimized)

```python
from collections import Counter


class Solution:
    def longestPalindrome(self, s: str) -> int:
        paired = sum(c - (c % 2) for c in Counter(s).values())
        # any leftover letter can be the single centre of the palindrome
        return paired + 1 if paired < len(s) else paired
```
