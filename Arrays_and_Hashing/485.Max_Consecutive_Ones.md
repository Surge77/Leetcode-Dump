# 485. Max Consecutive Ones

**🔗 Link:** [LeetCode 485](https://leetcode.com/problems/max-consecutive-ones/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given a binary array, return the length of the longest run of consecutive `1`s.

* **Example:** `nums = [1,1,0,1,1,1]` → `3`
* **Constraints:** `1 ≤ nums.length ≤ 10⁵`, each `nums[i]` is `0` or `1`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **One pass with a running streak.** Add 1 to `streak` on a 1, reset it to 0 on a 0, and keep the best streak seen so far.
* **Core Concept:** the length of the run ending at `i` depends only on the run ending at `i − 1`, so one counter replaces re-scanning from every start
* **When to Use This Pattern?** Longest run of consecutive elements that satisfy a per-element condition; the base case of the sliding-window variants that allow `k` flips.
* **Mistakes to Avoid:**
  * Updating `best` only when a 0 appears — misses a run that reaches the end (`[1, 1]`).
  * Reaching for a sliding window: with no flips allowed the window restarts at every 0, so a plain counter is enough.

## 🔹 Optimization Path

* **Brute Force:** from every start index, extend while the values are 1 — O(n²) on an all-ones array.
* **Optimized Solution:** running counter — O(n) time, O(1) space.
* **Further Improvements Possible?** No; every element must be read.

## 🔹 Solution Breakdown

* **Optimal Approach:** `streak = streak + 1 if x == 1 else 0`, then `best = max(best, streak)` at every step.
* **Why This Works?** After index `i`, `streak` is exactly the length of the run of 1s ending at `i` (0 if `nums[i] = 0`). Every run ends somewhere, so the maximum over all `i` is the longest run.
* **Edge Cases Considered:**
  * All zeros → 0; all ones → `n`.
  * The longest run touching the last index.

## 🔹 Tricks & Patterns Used

* **Reset-on-break counter:** the DP `run[i] = run[i − 1] + 1` (or 0) kept in one variable.

## 🔹 Alternative Data Structures

* `itertools.groupby(nums)` and take the longest group of 1s — O(n), but builds a list per group.
* Join to a string and split on `"0"` — O(n) with extra string allocations.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        best = 0
        for start in range(len(nums)):
            end = start
            while end < len(nums) and nums[end] == 1:
                end += 1
            best = max(best, end - start)
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        best = streak = 0
        for x in nums:
            streak = streak + 1 if x == 1 else 0
            best = max(best, streak)  # checked every step so a run that ends the array still counts
        return best
```
