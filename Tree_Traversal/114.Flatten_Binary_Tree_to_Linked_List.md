# 🔹 Problem Name: 114. Flatten Binary Tree to Linked List (Morris Traversal, Medium)

**🔗 Link:** [LeetCode 114](https://leetcode.com/problems/flatten-binary-tree-to-linked-list/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Flatten a binary tree in place into a "linked list" made of the same `TreeNode`s: every `right` pointer points to the next node, every `left` pointer is `null`, and the order is the tree's preorder. The follow-up asks for O(1) extra space.

* **Example:** `root = [1,2,5,3,4,null,6]` → `[1,null,2,null,3,null,4,null,5,null,6]`
* **Constraints:** the number of nodes is in `[0, 2000]`; `-100 ≤ Node.val ≤ 100`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Splice each left subtree in, in place.** Walk down the `right` pointers. At a node with a left subtree, find that subtree's rightmost node `tail`, hang the node's current right subtree on `tail.right`, move the left subtree into `right`, and clear `left`. Then step right and repeat.
* **Core Concept:** in preorder, a node's right subtree comes right after the left subtree's rightmost node — the same predecessor link Morris traversal uses
* **When to Use This Pattern?** Restructuring a tree in place with O(1) extra memory — Morris inorder/preorder traversal, tree to linked list, threading predecessor pointers.
* **Mistakes to Avoid:**
  * Forgetting `node.left = None` — the result must be a right-only chain.
  * Overwriting `node.right` before attaching the old right subtree to `tail`.
  * Creating new nodes: the task is in place, so re-link the existing ones.

## 🔹 Optimization Path

* **Brute Force:** preorder into a list of nodes, then re-link `node.left = None`, `node.right = next node` — O(n) time, O(n) extra space.
* **Optimized Solution:** splice in place — O(n) time, O(1) extra space (the follow-up).
* **Further Improvements Possible?** No for time. Reverse postorder (right, left, root) with a `prev` pointer is another O(n) answer but needs O(h) stack.

## 🔹 Solution Breakdown

* **Optimal Approach:** `node = root`; while `node`: if `node.left`: walk `tail` from `node.left` down its right pointers; `tail.right = node.right`; `node.right = node.left`; `node.left = None`. Then `node = node.right`.
* **Why This Works?** Each splice keeps the preorder sequence intact: the left subtree now follows `node` directly, and the old right subtree hangs on `tail`, the last node reached by right pointers, so it comes after the whole left subtree. If `tail` has a left child of its own, that part gets spliced in before it when the walk reaches `tail`. When the walk ends no node has a left child, so the right pointers spell out the preorder.
* **Edge Cases Considered:**
  * Empty tree or a single node — nothing to do.
  * Already a right-only chain — no splices.
  * Left-only chain — every step splices a one-node left subtree.

## 🔹 Tricks & Patterns Used

* **Rightmost node of the left subtree = the node just before the right subtree in preorder:** link it, and the right subtree is already in its final position.
* **Reverse postorder with `prev`:** visiting right, left, root and setting `node.right = prev; node.left = None; prev = node` builds the list from its tail.

## 🔹 Alternative Data Structures

* Explicit-stack preorder: pop a node, push right then left, set `prev.right = node`, `prev.left = None` — O(n) time, O(h) space.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n) — a `tail` walk only passes nodes on the right edge of some left subtree, and each node is on at most one such edge
* **Space Complexity:** O(1) extra

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        """
        Do not return anything, modify root in-place instead.
        """
        order = []
        stack = [root] if root else []
        while stack:
            node = stack.pop()
            order.append(node)
            if node.right:
                stack.append(node.right)
            if node.left:
                stack.append(node.left)  # popped first: preorder visits left before right
        for node, nxt in zip(order, order[1:] + [None]):
            node.left = None
            node.right = nxt
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        """
        Do not return anything, modify root in-place instead.
        """
        node = root
        while node:
            if node.left:
                tail = node.left
                while tail.right:
                    tail = tail.right
                tail.right = node.right  # the old right subtree follows the whole left subtree
                node.right = node.left
                node.left = None
            node = node.right
```
