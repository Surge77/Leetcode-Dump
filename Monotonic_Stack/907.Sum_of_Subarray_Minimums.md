# 🔹 Problem Name: 907. Sum of Subarray Minimums (Monotonic Stack + Contribution, Medium)

**🔗 Link:** [LeetCode 907](https://leetcode.com/problems/sum-of-subarray-minimums/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Count each element's **contribution**: `arr[i]` is the minimum of `left · right` subarrays, where `left` = distance to the previous smaller element and `right` = distance to the next smaller-or-equal element.
* **Core Concept:** Contribution technique + monotonic stack, modulo 10⁹+7
* **When to Use This Pattern?** "Sum over all subarrays of min/max/range" — never enumerate subarrays; count how many times each element is the answer.
* **Mistakes to Avoid:**
  * Using strict `<` on both sides — subarrays with equal minimums get counted twice. Use `<` on one side and `<=` on the other.
  * Forgetting the modulo.

## 🔹 Optimization Path

* **Brute Force:** O(n²) — extend each start with a running minimum.
* **Optimized Solution:** O(n) — each index pushed/popped once.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** One pass with a stack and a `0` sentinel: when index `j` pops index `m` (because `arr[j] <= arr[m]`), `m`'s right boundary is `j` and its left boundary is the new stack top; add `arr[m] · (m - left) · (j - m)`.
* **Why This Works?** Every subarray has exactly one "owner" of its minimum under the tie-break (the rightmost minimum: equal values may sit to its left, never to its right), so summing contributions counts each subarray exactly once.
* **Edge Cases Considered:**
  * All equal values.
  * Strictly increasing / decreasing arrays.

## 🔹 Tricks & Patterns Used

* **Asymmetric tie-break** (`<` vs `<=`) removes double counting.
* **Modulo Arithmetic** on the running total.

## 🔹 Alternative Data Structures

* DP: `dp[i] = dp[prev_smaller(i)] + arr[i] · (i - prev_smaller(i))`, answer `Σ dp[i]`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List

MOD = 10**9 + 7


class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        total = 0
        for i in range(len(arr)):
            lowest = arr[i]
            for j in range(i, len(arr)):
                lowest = min(lowest, arr[j])
                total += lowest
        return total % MOD
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List

MOD = 10**9 + 7


class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        a = arr + [0]  # sentinel pops everything at the end (values are >= 1)
        stack = []  # indices with strictly increasing values
        total = 0
        for j, x in enumerate(a):
            while stack and a[stack[-1]] >= x:  # j is m's next smaller-or-equal
                m = stack.pop()
                left = stack[-1] if stack else -1  # m's previous strictly smaller
                total += a[m] * (m - left) * (j - m)
            stack.append(j)
        return total % MOD
```
