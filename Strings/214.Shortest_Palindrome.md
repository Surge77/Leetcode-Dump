# 214. Shortest Palindrome

**🔗 Link:** [LeetCode 214](https://leetcode.com/problems/shortest-palindrome/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You may add characters only at the front of string `s`. Return the shortest palindrome that can be produced this way.

* **Example:** `s = "aacecaaa"` → `"aaacecaaa"`
* **Constraints:** `0 ≤ s.length ≤ 5 · 10⁴`; lowercase letters only

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Only characters can be added in front, so keep the **longest palindromic prefix** of `s` and prepend the reverse of the rest. That prefix length = last value of the prefix function of `s + '#' + reversed(s)`.
* **Core Concept:** KMP prefix function on a combined string
* **When to Use This Pattern?** Longest prefix that is also a suffix of something else — palindromic prefixes, overlaps between strings, rotations.
* **Mistakes to Avoid:**
  * Checking every prefix for being a palindrome — O(n²).
  * Forgetting the separator `#` — without it the border can run past `s`.

## 🔹 Optimization Path

* **Brute Force:** For each prefix length from `n` down, test palindrome — O(n²).
* **Optimized Solution:** O(n) with the prefix function.
* **Further Improvements Possible?** Manacher's algorithm also finds it in O(n).

## 🔹 Solution Breakdown

* **Optimal Approach:** `combined = s + '#' + s[::-1]`; `L = pi[-1]`; answer `s[L:][::-1] + s`.
* **Why This Works?** A prefix of `s` that equals a suffix of `reversed(s)` reads the same reversed — it is a palindrome. The prefix function returns the longest such border.
* **Edge Cases Considered:**
  * Empty string.
  * Already a palindrome → unchanged.
  * No repeated characters → reverse of `s[1:]` + `s`.

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def shortestPalindrome(self, s: str) -> str:
        for end in range(len(s), 0, -1):
            prefix = s[:end]
            if prefix == prefix[::-1]:
                return s[end:][::-1] + s
        return s
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def shortestPalindrome(self, s: str) -> str:
        combined = s + "#" + s[::-1]
        pi = [0] * len(combined)
        k = 0
        for i in range(1, len(combined)):
            while k and combined[i] != combined[k]:
                k = pi[k - 1]
            if combined[i] == combined[k]:
                k += 1
            pi[i] = k
        keep = pi[-1] if s else 0  # longest palindromic prefix of s
        return s[keep:][::-1] + s
```
