# 727. Minimum Window Subsequence

## 🔹 Problem Statement

Given strings `s1` and `s2`, return the shortest contiguous substring of `s1` that contains `s2` as a subsequence (characters in order, gaps allowed). If none exists return `""`; if several shortest windows tie, return the one that starts left-most. *(premium — paraphrased from memory, not checked against the official page)*

* **Example:** `s1 = "abcdebdde"`, `s2 = "bde"` → `"bcde"`
* **Constraints:** `1 ≤ s1.length ≤ 2·10^4`, `1 ≤ s2.length ≤ 100`, lowercase English letters

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **DP over the end of the window.** Scan `s1` left to right. `start[j]` = the **largest** index `st` such that `s2[:j]` is a subsequence of `s1[st..i]` (or −1). When `s1[i] == s2[j - 1]`, extend: `start[j] = start[j - 1]` (`start[1] = i`). After each `i`, `start[m]` is the latest start of a window ending at or before `i` that contains `s2`; a new window ending at `i` with start `start[m]` is the shortest one ending at `i`.
* **Core Concept:** for each end, the best window is the one with the latest possible start — keep that per prefix of `s2`
* **When to Use This Pattern?** "Shortest substring that contains `t` **as a subsequence**" (order matters, gaps allowed). If order did not matter it would be 76's counting window.
* **Mistakes to Avoid:**
  * Using the 76 counting window — counts ignore order.
  * Updating `j` in increasing order: `s1[i]` would be reused for two consecutive characters of `s2` (e.g. `s2 = "bb"`). Go from `m` down to 1.
  * Ties: return the **left-most** shortest window — only replace the best on a strictly shorter length.

## 🔹 Optimization Path

* **Brute Force:** for every start with `s1[st] == s2[0]`, greedily match `s2` forward to find the earliest end — O(n²) worst case.
* **Optimized Solution:** the `start[]` DP — O(n · m), and only the positions of `s1[i]` inside `s2` are touched, so typically much less.
* **Further Improvements Possible?** Forward scan to find an end, then backward scan to tighten the start, then resume from `start + 1` — fast in practice but O(n²) in the worst case; the DP bound O(n · m) = 2·10⁶ is guaranteed.

## 🔹 Solution Breakdown

* **Optimal Approach:** `positions[c]` = indices `j` (1-based, descending) with `s2[j - 1] == c`. For each `i`: for `j` in `positions[s1[i]]`: `start[j] = i if j == 1 else start[j - 1]`. If `s1[i] == s2[-1]` and `start[m] != -1` and `i - start[m] + 1 < best_len`, record the window.
* **Why This Works?** Greedy-latest is optimal: if `s2[:j]` fits in `s1[st..i]` with some `st`, then it fits with the largest such `st`, and a later start can only make the window shorter. Matching `s2[j - 1]` to `s1[i]` turns the best start for `s2[:j - 1]` ending before `i` into the best start for `s2[:j]` ending at `i`. Ends are scanned left to right and only strictly shorter windows replace the best, so ties keep the left-most.
* **Edge Cases Considered:**
  * No window → `""`.
  * `s2` longer than `s1` → `""`.
  * Repeated letters in `s2` (`"bb"`) — descending `j` prevents one character serving twice.

## 🔹 Tricks & Patterns Used

* **Descending inner loop** (like 0/1 knapsack): each `s1[i]` is used at most once per `s2`-prefix update.
* **Only touch the matching positions:** precompute where each character occurs in `s2`.

## 🔹 Alternative Data Structures

* `next[i][c]` jump table (next occurrence of `c` at or after `i`) — from each start, jump through `s2` in O(m); O(n · m) total with 26 · n memory.
* Full 2-D DP `dp[i][j]` = latest start — same recurrence, O(n · m) memory.

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def minWindow(self, s1: str, s2: str) -> str:
        best = ""
        for st in range(len(s1)):
            if s1[st] != s2[0]:
                continue
            j = 0
            for end in range(st, len(s1)):
                if s1[end] == s2[j]:
                    j += 1
                    if j == len(s2):
                        if not best or end - st + 1 < len(best):
                            best = s1[st:end + 1]
                        break
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from collections import defaultdict


class Solution:
    def minWindow(self, s1: str, s2: str) -> str:
        m = len(s2)
        positions = defaultdict(list)
        for j in range(m, 0, -1):  # descending so s1[i] never serves two consecutive s2 letters
            positions[s2[j - 1]].append(j)
        start = [-1] * (m + 1)
        best_start, best_len = -1, len(s1) + 1
        for i, c in enumerate(s1):
            for j in positions.get(c, ()):
                start[j] = i if j == 1 else start[j - 1]
            if c == s2[-1] and start[m] != -1 and i - start[m] + 1 < best_len:
                best_start, best_len = start[m], i - start[m] + 1
        return "" if best_start == -1 else s1[best_start:best_start + best_len]
```
