# 🔹 Problem Name: 151. Reverse Words in a String (Two Pointers, Medium)

**🔗 Link:** [LeetCode 151](https://leetcode.com/problems/reverse-words-in-a-string/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Squeeze, reverse everything, reverse each word.** A read/write pointer pass drops leading, trailing and repeated spaces. Reversing the whole character array puts the words in the right order but spells each one backwards; reversing every word again fixes the spelling.
* **Core Concept:** reversing a sequence and then each block inside it reverses the order of the blocks while keeping every block intact
* **When to Use This Pattern?** Reordering blocks of a sequence in place — reverse words, rotate an array by `k` (reverse all, then both parts), swap two adjacent segments with O(1) extra space.
* **Mistakes to Avoid:**
  * `s.split(" ")` — splitting on one space keeps empty strings for repeated spaces; plain `s.split()` drops them.
  * Building the answer with `result = word + " " + result` — every prepend copies the whole string, O(n²).

## 🔹 Optimization Path

* **Brute Force:** scan words left to right and prepend each to the answer string — O(n²) character copies.
* **Optimized Solution:** squeeze + reverse all + reverse each word — O(n) time, O(1) extra on a mutable character array (the follow-up).
* **Further Improvements Possible?** Not asymptotically. In Python, `" ".join(reversed(s.split()))` is the idiomatic O(n) one-liner.

## 🔹 Solution Breakdown

* **Optimal Approach:** `chars = list(s)`; copy non-space characters forward and a single space only right after a word, drop a trailing space, cut the list; reverse `chars`; then reverse each maximal run of non-spaces.
* **Why This Works?** Reversing the whole string moves the `k`-th word from the front to the `k`-th position from the back but also flips its letters; reversing each word undoes only the letter flip. The write pointer never passes the read pointer, so compaction never overwrites an unread character, and it leaves exactly one space between words.
* **Edge Cases Considered:**
  * Leading / trailing spaces and runs of spaces between words.
  * A single word, or a single character (at least one word is guaranteed).

## 🔹 Tricks & Patterns Used

* **Reverse all, then reverse each block:** block order flips, block contents stay.
* **Read/write pointers:** `write ≤ read` always, so compacting in place is safe.

## 🔹 Alternative Data Structures

* `s.split()` + `reversed` + `" ".join` — O(n) extra space, the simplest Python answer.
* A stack of words, or a deque with `appendleft` — O(n) extra space.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n) in Python because `str` is immutable; O(1) extra on a mutable character array

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        result, word = "", ""
        for ch in s + " ":  # the extra space flushes the last word
            if ch != " ":
                word += ch
            elif word:
                result = word if not result else word + " " + result
                word = ""
        return result
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        chars = list(s)  # Python strings are immutable; a list stands in for a mutable char array

        def reverse(lo: int, hi: int) -> None:
            while lo < hi:
                chars[lo], chars[hi] = chars[hi], chars[lo]
                lo, hi = lo + 1, hi - 1

        write = 0
        for read in range(len(chars)):
            if chars[read] != " ":
                chars[write] = chars[read]
                write += 1
            elif write > 0 and chars[write - 1] != " ":  # one space, and only right after a word
                chars[write] = " "
                write += 1
        if chars[write - 1] == " ":  # at least one word is guaranteed, so write > 0
            write -= 1
        del chars[write:]

        reverse(0, len(chars) - 1)
        start = 0
        for end in range(len(chars) + 1):
            if end == len(chars) or chars[end] == " ":
                reverse(start, end - 1)
                start = end + 1
        return "".join(chars)
```
