# 🔹 Problem Name: 1318. Minimum Flips to Make a OR b Equal to c (Bit Manipulation, Medium)

**🔗 Link:** [LeetCode 1318](https://leetcode.com/problems/minimum-flips-to-make-a-or-b-equal-to-c/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Decide each bit independently.** For bit position `k` with bits `x, y` of `a, b` and target `z` of `c`:
  * `z = 1`: need `x | y = 1`; if both are 0, flip one → 1 flip.
  * `z = 0`: need both 0; every set bit among `x, y` costs one flip → 0, 1 or 2 flips.
  * The whole thing in word-parallel form: `diff = (a | b) ^ c`; answer = `popcount(diff) + popcount(a & b & diff)` (the second term pays the extra flip where both `a` and `b` have a 1 that must become 0).
* **Core Concept:** bitwise operations act on all bit positions at once, so per-bit logic becomes a few word operations
* **When to Use This Pattern?** "Make `f(a, b) == c`" where `f` is bitwise — every bit is independent.
* **Mistakes to Avoid:**
  * Counting only one flip when `c`'s bit is 0 and both `a`, `b` have 1.
  * Flipping a bit of `a` when `c`'s bit is already satisfied.

## 🔹 Optimization Path

* **Brute Force:** loop over the 31 bit positions, extract the three bits and apply the case table — O(log max).
* **Optimized Solution:** `(a | b) ^ c` and `a & b & diff` with `bin(...).count("1")` — O(1) word operations.
* **Further Improvements Possible?** Only constant-factor (`int.bit_count()` on Python 3.10+; kept `bin().count` for older judges).

## 🔹 Solution Breakdown

* **Optimal Approach:** `diff = (a | b) ^ c` marks every bit where `a | b` disagrees with `c`. Each marked bit costs 1 flip, except where `c` is 0 and both `a`, `b` are 1 — those cost 2, which `a & b & diff` counts once more.
* **Why This Works?** A mismatching bit has `c = 1, a|b = 0` (flip either one) or `c = 0, a|b = 1` (zero out every set bit among `a`, `b`). The `a & b` mask is non-zero only in the latter case with two ones, so no other position is double-counted.
* **Edge Cases Considered:**
  * `a = b = c` → `0`.
  * `c = 0` with `a = b = 2^k` → 2 flips for that bit.
  * Values up to 10⁹ fit in 30 bits.

* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def minFlips(self, a: int, b: int, c: int) -> int:
        flips = 0
        for bit in range(31):
            x, y, z = (a >> bit) & 1, (b >> bit) & 1, (c >> bit) & 1
            if z == 1:
                flips += 1 if x == 0 and y == 0 else 0
            else:
                flips += x + y  # every set bit has to be cleared
        return flips
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def minFlips(self, a: int, b: int, c: int) -> int:
        diff = (a | b) ^ c
        # where c is 0 and both a and b are 1, one mismatch costs two flips
        return bin(diff).count("1") + bin(a & b & diff).count("1")
```
