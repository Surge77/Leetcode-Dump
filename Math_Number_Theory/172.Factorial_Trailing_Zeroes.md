# 🔹 Problem Name: 172. Factorial Trailing Zeroes (Number Theory, Medium)

**🔗 Link:** [LeetCode 172](https://leetcode.com/problems/factorial-trailing-zeroes/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Legendre's formula for p = 5.** Each trailing zero is a factor 10 = 2·5, and `n!` always has more 2s than 5s, so the answer is the exponent of 5 in `n!`: `⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + …`.
* **Core Concept:** count prime factors of a factorial without computing it
* **When to Use This Pattern?** Exponent of a prime in `n!`, trailing zeros in any base, "smallest `n` whose factorial has ≥ k zeros" (binary search on top of this count).
* **Mistakes to Avoid:**
  * Counting only multiples of 5 (`n // 5`): 25 contributes two 5s, 125 three.
  * Computing `n!` — fine in Python for `n ≤ 10⁴`, impossible in fixed-width types and slow in general.
  * Writing `5 ** k <= n` with a growing power in languages with overflow; dividing `n` by 5 repeatedly avoids it.

## 🔹 Optimization Path

* **Brute Force:** compute `n!` with big integers and strip trailing zeros — n big-integer multiplications on a number of O(n log n) bits, roughly O(n² log n) bit operations.
* **Optimized Solution:** `while n: n //= 5; count += n` — O(log₅ n), the follow-up's logarithmic bound.
* **Further Improvements Possible?** No; O(log n) is already the size of the input.

## 🔹 Solution Breakdown

* **Optimal Approach:** repeatedly divide `n` by 5 and add each quotient.
* **Why This Works?** `⌊n/5^k⌋` counts the numbers in `1..n` divisible by `5^k`. A number with exactly `e` factors of 5 is counted once in each of the first `e` terms, so the sum is the total exponent of 5. Since `⌊⌊n/5⌋/5⌋ = ⌊n/25⌋`, repeated division yields each term in turn. 2s outnumber 5s (every second number is even), so every 5 pairs with a 2.
* **Edge Cases Considered:**
  * `n = 0` → `0! = 1` → 0.
  * `n = 4` → 0; `n = 25` → 6 (5, 10, 15, 20 give one each, 25 gives two).

## 🔹 Tricks & Patterns Used

* **Legendre:** `ν_p(n!) = Σ ⌊n/p^k⌋`.
* **Limiting factor:** zeros in base `b` = min over primes of `b` of `ν_p(n!) / exponent of p in b`.

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def trailingZeroes(self, n: int) -> int:
        fact = 1
        for k in range(2, n + 1):
            fact *= k
        zeros = 0
        while fact % 10 == 0:
            fact //= 10
            zeros += 1
        return zeros
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def trailingZeroes(self, n: int) -> int:
        count = 0
        while n:
            n //= 5  # after k divisions n == floor(original / 5^k)
            count += n
        return count
```
