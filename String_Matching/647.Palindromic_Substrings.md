# 🔹 Problem Name: 647. Palindromic Substrings (Manacher's Algorithm, Medium)

**🔗 Link:** [LeetCode 647](https://leetcode.com/problems/palindromic-substrings/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Insert `#` between characters so every palindrome has odd length in the new string `t`. Manacher computes `p[i]` = palindrome radius around each centre in O(n); centre `i` contributes `(p[i] + 1) // 2` palindromes of `s`.
* **Core Concept:** Manacher's algorithm
* **When to Use This Pattern?** Longest palindromic substring or counting palindromes when O(n²) is too slow (n ≥ 10⁵).
* **Mistakes to Avoid:**
  * Handling odd and even centres with separate code — the `#` transform unifies them.
  * Counting `p[i]` instead of `(p[i] + 1) // 2` (radius in `t` ≠ number of palindromes in `s`).

## 🔹 Optimization Path

* **Brute Force:** O(n³) — check every substring.
* **Expand around centre:** O(n²) — accepted for n ≤ 1000.
* **Optimized Solution:** O(n) Manacher.

## 🔹 Solution Breakdown

* **Optimal Approach:** Keep the palindrome `[center - right, right]` reaching furthest right. For `i < right`, start from the mirror's radius `p[2·center - i]` (capped by `right - i`), then expand.
* **Why This Works?** Inside a palindrome, the neighbourhood of `i` mirrors that of `2·center - i`, so its radius is known up to the boundary; `right` only moves forward, so total expansion work is O(n).
* **Edge Cases Considered:**
  * Single character → 1.
  * All equal characters → `n(n+1)/2`.

## 🔹 Tricks & Patterns Used

* **Separator transform** `"#a#b#a#"` makes every centre a character of `t`.
* **Mirror reuse** — the same amortisation idea as the Z-function.

## 🔹 Alternative Data Structures

* Expand around each of the `2n - 1` centres — simpler, O(n²).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        t = "#" + "#".join(s) + "#"  # every palindrome of t has odd length
        n = len(t)
        p = [0] * n  # p[i]: palindrome radius around t[i]
        center = right = 0
        for i in range(n):
            if i < right:
                p[i] = min(right - i, p[2 * center - i])  # mirror inside the known palindrome
            while i - p[i] - 1 >= 0 and i + p[i] + 1 < n and t[i - p[i] - 1] == t[i + p[i] + 1]:
                p[i] += 1
            if i + p[i] > right:
                center, right = i, i + p[i]
        return sum((radius + 1) // 2 for radius in p)
```
