# 🔹 Problem Name: 1277. Count Square Submatrices with All Ones (Grid DP, Medium)

**🔗 Link:** [LeetCode 1277](https://leetcode.com/problems/count-square-submatrices-with-all-ones/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Largest-square DP.** `side[i][j]` = side of the largest all-ones square whose bottom-right corner is `(i, j)`. For a `1` cell, `side[i][j] = 1 + min(side[i−1][j], side[i][j−1], side[i−1][j−1])`. A corner with `side = s` is the corner of exactly `s` squares (sizes 1..s), so the answer is the sum of all `side` values.
* **Core Concept:** the same DP as Maximal Square (221) — sum it instead of maxing it
* **When to Use This Pattern?** Squares/regions of uniform cells anchored at a corner; "count" or "largest" square of ones.
* **Mistakes to Avoid:**
  * Counting only the largest square per corner — a size-`s` corner also anchors every smaller square.
  * Using `min` of only two neighbours — the diagonal is needed to close the square.

## 🔹 Optimization Path

* **Brute Force:** for each corner, grow the square while the new border row and column are all ones — O(m·n·min(m,n)²) worst case.
* **Optimized Solution:** DP — O(m·n).
* **Further Improvements Possible?** O(n) memory with a rolling row; time is optimal.

## 🔹 Solution Breakdown

* **Optimal Approach:** one pass top-left to bottom-right with a padded row of zeros; add every `side` to the total.
* **Why This Works?** A square of side `s` ending at `(i, j)` exists iff squares of side `s − 1` end at the top, left and top-left neighbours (the three overlap to cover everything except the corner cell itself). So the largest side is one more than the smallest of the three.
* **Edge Cases Considered:**
  * All zeros → 0.
  * Single row or column → number of ones.

## 🔹 Pattern Recognition

* **Belongs To:** DP on grids — corner-anchored squares
* **Common Problems Using This:**

## 🔹 Tricks & Patterns Used

* **"Largest at corner" gives "count at corner"** — the sizes form the range 1..s.
* **Padding** (`prev` row and left value start at 0) removes border checks.

## 🔹 Alternative Data Structures

* 2-D prefix sums: check any square in O(1) — O(m·n·min(m,n)) total; slower than the DP but useful when cells are weighted.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m·n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def countSquares(self, matrix: List[List[int]]) -> int:
        m, n = len(matrix), len(matrix[0])
        total = 0
        for top in range(m):
            for left in range(n):
                size = 1
                while top + size <= m and left + size <= n and all(
                        matrix[r][c] for r in range(top, top + size) for c in range(left, left + size)):
                    total += 1
                    size += 1
        return total
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def countSquares(self, matrix: List[List[int]]) -> int:
        n = len(matrix[0])
        prev = [0] * (n + 1)
        total = 0
        for row in matrix:
            cur = [0] * (n + 1)
            for j, cell in enumerate(row, 1):
                if cell:
                    cur[j] = 1 + min(prev[j], cur[j - 1], prev[j - 1])
                    total += cur[j]  # a corner with side s anchors squares of sizes 1..s
            prev = cur
        return total
```
