# 🔹 Problem Name: 327. Count of Range Sum (Prefix Sum + Fenwick Tree, Hard)

**🔗 Link:** [LeetCode 327](https://leetcode.com/problems/count-of-range-sum/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** With prefix sums `P`, a subarray `(i, j]` qualifies iff `P[j] - upper ≤ P[i] ≤ P[j] - lower`. For each `j`, count earlier prefix values inside that window with a Fenwick tree.
* **Core Concept:** Prefix sums + Fenwick tree range counting
* **When to Use This Pattern?** Counting subarrays whose sum lies in a range (negatives allowed — so sliding window does not work).
* **Mistakes to Avoid:**
  * Sliding window — it needs non-negative numbers.
  * Forgetting the empty prefix `P[0] = 0` (subarrays starting at index 0).

## 🔹 Optimization Path

* **Brute Force:** O(n²) — every subarray.
* **Optimized Solution:** O(n log n) — Fenwick over compressed prefix values (or merge sort).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Compress all `P` values. Insert `P[0]`. For `j = 1..n`: count stored values in `[P[j] - upper, P[j] - lower]` = `prefix(bisect_right(hi)) - prefix(bisect_left(lo))`; then insert `P[j]`.
* **Why This Works?** Each subarray sum is `P[j] - P[i]` for a unique pair `i < j`, and the inequality on the sum is the same as a window on `P[i]`.
* **Edge Cases Considered:**
  * `lower == upper`.
  * All negative numbers.
  * Single element.

## 🔹 Tricks & Patterns Used

* **Turn "subarray sum in a range" into "earlier prefix in a range".**
* **`bisect_left` / `bisect_right`** give the rank bounds of the window.

## 🔹 Alternative Data Structures

* Merge sort on the prefix array, counting with two pointers during each merge.
* `SortedList` (from `sortedcontainers`) — not available in most exam portals.

* **Time Complexity:** O(n log n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
from bisect import bisect_left, bisect_right
from itertools import accumulate
from typing import List


class Solution:
    def countRangeSum(self, nums: List[int], lower: int, upper: int) -> int:
        prefix_sums = [0] + list(accumulate(nums))
        vals = sorted(set(prefix_sums))
        tree = [0] * (len(vals) + 1)

        def add(i: int) -> None:
            while i < len(tree):
                tree[i] += 1
                i += i & -i

        def count_upto(i: int) -> int:  # how many stored values have rank <= i
            total = 0
            while i > 0:
                total += tree[i]
                i -= i & -i
            return total

        result = 0
        add(bisect_left(vals, 0) + 1)  # empty prefix P[0] = 0
        for p in prefix_sums[1:]:
            lo, hi = p - upper, p - lower  # window for earlier prefix values
            result += count_upto(bisect_right(vals, hi)) - count_upto(bisect_left(vals, lo))
            add(bisect_left(vals, p) + 1)
        return result
```
