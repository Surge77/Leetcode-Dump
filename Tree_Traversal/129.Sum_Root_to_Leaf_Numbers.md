# 🔹 Problem Name: 129. Sum Root to Leaf Numbers (Tree DFS, Medium)

**🔗 Link:** [LeetCode 129](https://leetcode.com/problems/sum-root-to-leaf-numbers/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Carry the number down the path.** Stepping from a node to its child turns the number `x` into `10·x + child.val`. At a leaf the carried number is that path's number; add it to the total. Iterative DFS over `(node, number_so_far)` pairs.
* **Core Concept:** top-down state — each node receives what its ancestors spelled, so no path has to be stored
* **When to Use This Pattern?** Any root-to-leaf quantity that depends only on the ancestors: path sums, path strings, binary numbers on paths (1022), "does some path satisfy X".
* **Mistakes to Avoid:**
  * Counting at `None` children (`if not node: return number`): every leaf is counted twice and a one-child node adds a fake path — `[1, 2]` gives 25 instead of 12.
  * Treating a one-child node as a leaf: only nodes with **no** children end a path.

## 🔹 Optimization Path

* **Brute Force:** collect every root-to-leaf path as a list of digits (copying the path at each node), then `int("".join(path))` per leaf — O(n·h) time and space.
* **Optimized Solution:** carry `10·x + val` — O(n) time, O(h) space.
* **Further Improvements Possible?** No: every node must be read, and the stack is O(h) with `h ≤ 10` here.

## 🔹 Solution Breakdown

* **Optimal Approach:** stack starts with `(root, 0)`. Pop `(node, number)`, set `number = 10·number + node.val`; a leaf adds `number` to the total, otherwise each child is pushed with `number`.
* **Why This Works?** Appending a decimal digit is "shift one place left and add": `10·x + d`. A node's number depends only on its ancestors, so passing it down reaches every node exactly once, and each leaf closes exactly one root-to-leaf path.
* **Edge Cases Considered:**
  * Single node → its own value.
  * Zeros anywhere, including the root: `0 → 1` spells `01 = 1`; the arithmetic ignores leading zeros for free.
  * Depth ≤ 10, so a number has at most 10 digits; LeetCode guarantees the total fits in 32 bits.

## 🔹 Tricks & Patterns Used

* **Digit append:** `x = base·x + d` — also how integers are parsed and how rolling hashes extend.
* **`(node, state)` stack entries:** an iterative DFS carries per-path state without any undo step.

## 🔹 Alternative Data Structures

* Recursive `dfs(node, x)` — safe here because the depth is at most 10.
* BFS queue of `(node, number)` pairs — same O(n) time, O(w) memory.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(h), `h ≤ 10`

## 🔹 Code Snippet (Brute Force)

```python
from typing import List, Optional


class Solution:
    def sumNumbers(self, root: Optional[TreeNode]) -> int:
        paths: List[List[str]] = []

        def collect(node: TreeNode, digits: List[str]) -> None:
            digits = digits + [str(node.val)]  # a copy, so sibling branches never share one list
            if not node.left and not node.right:
                paths.append(digits)
            for child in (node.left, node.right):
                if child:
                    collect(child, digits)

        collect(root, [])
        return sum(int("".join(digits)) for digits in paths)
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def sumNumbers(self, root: Optional[TreeNode]) -> int:
        total, stack = 0, [(root, 0)]
        while stack:
            node, number = stack.pop()
            number = number * 10 + node.val  # appending a digit shifts the rest one place left
            if not node.left and not node.right:
                total += number
            for child in (node.left, node.right):
                if child:
                    stack.append((child, number))
        return total
```
