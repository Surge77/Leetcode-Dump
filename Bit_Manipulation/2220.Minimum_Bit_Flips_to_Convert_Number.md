# 2220. Minimum Bit Flips to Convert Number

**🔗 Link:** [LeetCode 2220](https://leetcode.com/problems/minimum-bit-flips-to-convert-number/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

A flip changes one bit of a number from 0 to 1 or 1 to 0 (leading zeros may also be flipped). Given `start` and `goal`, return the fewest flips that turn `start` into `goal`.

* **Example:** `start = 10, goal = 7` → `3`
* **Constraints:** `0 ≤ start, goal ≤ 10^9`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Popcount of XOR.** `start ^ goal` has a 1 exactly where the two numbers differ; each such bit needs one flip and no other bit needs any. Count the set bits with Brian Kernighan's loop (`x &= x − 1`).
* **Core Concept:** this is the Hamming distance between `start` and `goal`
* **When to Use This Pattern?** "How many bits differ / how many flips to turn A into B" — 461. Hamming Distance, 477. Total Hamming Distance, 1318. Minimum Flips to Make a OR b Equal to c.
* **Mistakes to Avoid:**
  * Comparing binary strings of different lengths without padding.
  * Thinking flips interact — each bit is independent, so the minimum is just the count of differing bits.

## 🔹 Optimization Path

* **Brute Force:** compare the two numbers bit by bit over all 30 positions — O(30).
* **Optimized Solution:** XOR, then Kernighan's loop — O(number of differing bits).
* **Further Improvements Possible?** `(start ^ goal).bit_count()` (Python 3.10+) does the count in C.

## 🔹 Solution Breakdown

* **Optimal Approach:** `x = start ^ goal`; count iterations of `x &= x − 1` until `x == 0`.
* **Why This Works?** XOR is 1 exactly on differing bits. `x & (x − 1)` removes one set bit per iteration, so the loop runs once per differing bit.
* **Edge Cases Considered:**
  * `start == goal` → 0.
  * One of them 0 → popcount of the other.

## 🔹 Code Snippet (Brute Force)

```python
BITS = 30


class Solution:
    def minBitFlips(self, start: int, goal: int) -> int:
        return sum(((start >> i) & 1) != ((goal >> i) & 1) for i in range(BITS))
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def minBitFlips(self, start: int, goal: int) -> int:
        diff = start ^ goal  # 1 exactly where a flip is needed
        flips = 0
        while diff:
            diff &= diff - 1
            flips += 1
        return flips
```
