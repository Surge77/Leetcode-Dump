# 🔹 Problem Name: 160. Intersection of Two Linked Lists (Two Pointers, Easy)

**🔗 Link:** [LeetCode 160](https://leetcode.com/problems/intersection-of-two-linked-lists/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given the heads of two singly linked lists, return the node where they merge into a shared tail, or null if they never meet. Intersection means the same node object (same reference), not equal values. There are no cycles, and both lists must keep their structure.

* **Example:** `intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3` → `Intersected at '8'`
* **Constraints:** `1 ≤ m, n ≤ 3·10^4` (list lengths); `1 ≤ Node.val ≤ 10^5`. Follow-up: `O(m + n)` time with `O(1)` memory.

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Switch heads.** Pointer `p` walks A then B, pointer `q` walks B then A. Both cover `lenA + lenB` nodes, so they line up on the shared tail and meet at the first common node — or both reach `None` together when there is none.
* **Core Concept:** equalise path lengths by concatenating the two lists in opposite orders
* **When to Use This Pattern?** Two singly linked chains that may merge (Y shape); also "lowest common ancestor with parent pointers" (1650), which is the same problem on parent chains.
* **Mistakes to Avoid:**
  * Comparing values instead of nodes — `[4,1,8,4,5]` and `[5,6,1,8,4,5]` share value `1` but the intersection is the node `8`.
  * Switching to the other head when the pointer *is* `None` vs. when its `next` is `None`: switching only after reaching `None` is what lets the no-intersection case end with both pointers at `None`.
  * Modifying the lists — the problem requires the original structure afterwards.

## 🔹 Optimization Path

* **Brute Force:** put every node of A into a set, return the first node of B found in it — O(m + n) time, O(m) space.
* **Optimized Solution:** two pointers switching heads — O(m + n) time, O(1) space (the follow-up).
* **Further Improvements Possible?** Equivalent alternative: compute both lengths, advance the longer list by the difference, then walk together.

## 🔹 Solution Breakdown

* **Optimal Approach:** `p = p.next if p else headB` and `q = q.next if q else headA` until `p is q`.
* **Why This Works?** Let A = `x` private nodes + `z` shared, B = `y` private + `z` shared. Counting the jump through `None` as one move, `p` reaches the first shared node after `x + z + 1 + y` moves, and `q` after `y + z + 1 + x` moves — the same number. If `z = 0`, both land on `None` after `x + y + 1` moves and the loop ends with `None`.
* **Edge Cases Considered:**
  * Intersection at the head of one list (`skip = 0`).
  * Same list passed twice → returns the head immediately.
  * No intersection → `None` after `m + n + 1` moves.

## 🔹 Tricks & Patterns Used

* **Path concatenation:** A+B and B+A have equal length and identical suffixes.
* **`None` as a real step:** treating the end of a list as one position makes the "no intersection" case terminate naturally.

## 🔹 Alternative Data Structures

* Hash set of nodes from one list — simplest, O(m) memory.
* Length difference — same complexity, two extra passes but easier to explain.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m + n)
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        in_a = set()
        node = headA
        while node:
            in_a.add(node)
            node = node.next
        node = headB
        while node:
            if node in in_a:
                return node
            node = node.next
        return None
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        p, q = headA, headB
        while p is not q:
            # both walk lenA + lenB, so they reach the shared tail (or None) together
            p = p.next if p else headB
            q = q.next if q else headA
        return p
```
