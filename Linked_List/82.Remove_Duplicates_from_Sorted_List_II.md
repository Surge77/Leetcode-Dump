# 🔹 Problem Name: 82. Remove Duplicates from Sorted List II (Linked List Dummy Node, Medium)

**🔗 Link:** [LeetCode 82](https://leetcode.com/problems/remove-duplicates-from-sorted-list-ii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Dummy head + skip whole runs.** Because the list is sorted, equal values form one contiguous run. Keep `prev`, the last node known to survive (a dummy at first). At `curr`: if `curr.next` has the same value, skip the entire run and link `prev.next` to the first node after it — but do **not** advance `prev`, since that next node may start another duplicate run. Otherwise `curr` survives: move `prev` to it.
* **Core Concept:** sorted ⇒ duplicates are adjacent; a dummy head lets you delete the original head
* **When to Use This Pattern?** Deleting nodes by a rule that may remove the head, or deleting runs of equal elements from a sorted sequence.
* **Mistakes to Avoid:**
  * Keeping one copy of each duplicate — that is problem 83; here every node with a repeated value goes.
  * Advancing `prev` right after removing a run: `[1,1,2,2]` would keep a `2`.
  * Special-casing the head instead of using a dummy (`[1,1,1,2,3]` → `[2,3]` removes it).

## 🔹 Optimization Path

* **Brute Force:** count every value with a hash map, then relink only the nodes whose value occurs once — O(n) time, O(n) extra space, and ignores that the list is sorted.
* **Optimized Solution:** one pass with `prev` / `curr` — O(n) time, O(1) extra space.
* **Further Improvements Possible?** No; every node must be looked at.

## 🔹 Solution Breakdown

* **Optimal Approach:** `dummy → head`, `prev = dummy`, `curr = head`; if `curr.next and curr.next.val == curr.val`, advance `curr` past all nodes with that value and set `prev.next = curr`; else `prev = curr`, `curr = curr.next`.
* **Why This Works?** Invariant: the list from `dummy` up to `prev` contains exactly the distinct-valued nodes seen so far, and `prev.next` is the first unprocessed node. A run is either length 1 (keep, extend the prefix) or longer (drop, prefix unchanged).
* **Edge Cases Considered:**
  * Empty list → `None`.
  * Everything duplicated (`[1,1,2,2]`) → `None`.
  * A duplicate run at the head or the tail.

## 🔹 Tricks & Patterns Used

* **Dummy head:** deleting the first node is no longer a special case.
* **Lagging pointer:** `prev` moves only past nodes that are confirmed to stay.

## 🔹 Code Snippet (Brute Force)

```python
from collections import Counter
from typing import Optional


class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        counts = Counter()
        node = head
        while node:
            counts[node.val] += 1
            node = node.next
        dummy = tail = ListNode()
        node = head
        while node:
            if counts[node.val] == 1:
                tail.next = node
                tail = node
            node = node.next
        tail.next = None  # the old successor may be a deleted node
        return dummy.next
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        prev, curr = dummy, head
        while curr:
            if curr.next and curr.next.val == curr.val:
                dup = curr.val
                while curr and curr.val == dup:
                    curr = curr.next
                prev.next = curr  # prev stays: curr may begin another run
            else:
                prev = curr
                curr = curr.next
        return dummy.next
```
