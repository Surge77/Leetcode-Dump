# 🔹 Problem Name: 1358. Number of Substrings Containing All Three Characters (Sliding Window, Medium)

**🔗 Link:** [LeetCode 1358](https://leetcode.com/problems/number-of-substrings-containing-all-three-characters/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Last-seen positions.** For each end index `i`, a substring `s[j..i]` contains `a`, `b` and `c` iff `j ≤ min(last[a], last[b], last[c])`. So `min(last) + 1` substrings end at `i`.
* **Core Concept:** once a window is valid, extending it to the left keeps it valid — count all those starts at once
* **When to Use This Pattern?** "Count substrings that contain at least …" — validity is monotone in the start index, so count the valid starts per end.
* **Mistakes to Avoid:**
  * Counting only minimal windows: every start to the left of a valid one is also valid.
  * Initialising `last` to 0 instead of −1: a missing letter would then count a substring.

## 🔹 Optimization Path

* **Brute Force:** every start, extend until all three letters appear, then add `n − end` — O(n²) worst case (e.g. `"aaaa…abc"`), 2.5·10⁹ at `n = 5·10⁴`.
* **Optimized Solution:** track the last index of each letter — O(n), O(1) space.
* **Further Improvements Possible?** The standard sliding window (shrink while the window still holds all three, add `left` each step) is the same O(n).

## 🔹 Solution Breakdown

* **Optimal Approach:** `last = [-1, -1, -1]`; for each `i`, set `last[s[i]] = i`, then add `min(last) + 1`.
* **Why This Works?** `s[j..i]` holds every letter iff each letter occurs at some index in `[j, i]`, i.e. its last occurrence up to `i` is `≥ j`. The tightest letter is the one seen longest ago, so the valid starts are `0 … min(last)`: `min(last) + 1` of them (0 while a letter is still unseen).
* **Edge Cases Considered:**
  * `"abc"`: only the whole string, answer 1.
  * A letter that never appears: `min(last)` stays −1 and every term is 0.

## 🔹 Tricks & Patterns Used

* **Last occurrence array:** turns "does the window contain X" into a comparison of indices.
* **Count starts, not windows:** every valid `j` for a fixed `i` adds 1, summed as `min(last) + 1`.

## 🔹 Alternative Data Structures

* Counter of size 3 with two pointers: shrink while all counts are positive, then add `left` (the number of starts that were valid).

* **Time Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        n = len(s)
        count = 0
        for start in range(n):
            seen = set()
            for end in range(start, n):
                seen.add(s[end])
                if len(seen) == 3:
                    count += n - end  # every longer end also contains all three
                    break
        return count
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        last = [-1, -1, -1]  # -1 = not seen yet, so it contributes no starts
        count = 0
        for i, ch in enumerate(s):
            last[ord(ch) - ord("a")] = i
            count += min(last) + 1
        return count
```
