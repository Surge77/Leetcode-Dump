# 🔹 Problem Name: 653. Two Sum IV - Input is a BST (BST Hash Set, Easy)

**🔗 Link:** [LeetCode 653](https://leetcode.com/problems/two-sum-iv-input-is-a-bst/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Two Sum with a seen-set.** Traverse the tree in any order; for each value `v`, if `k − v` was already seen return `True`, else add `v`. Alternative that uses the BST order: two iterators (ascending and descending inorder) moving towards each other like two pointers.
* **Core Concept:** complement lookup in O(1) — the classic Two Sum, just over tree nodes
* **When to Use This Pattern?** "Do two elements sum to `k`" over any collection you can enumerate; two-pointer variant when the data is sorted (sorted array, BST inorder).
* **Mistakes to Avoid:**
  * Pairing a node with itself (`v + v == k`) — check the set *before* inserting `v`.
  * Searching the BST for `k − v` from the root without excluding the current node — same self-pair bug.
  * Recursive DFS on a 10⁴-node path: recursion limit.

## 🔹 Optimization Path

* **Brute Force:** collect the values, test every pair — O(n²).
* **Optimized Solution:** hash set during traversal — O(n) time, O(n) space.
* **Further Improvements Possible?** Two BST iterators (forward/backward inorder stacks) give O(n) time with O(h) space.

## 🔹 Solution Breakdown

* **Optimal Approach:** iterative DFS with a stack; for each popped node test `k − node.val in seen`, then add `node.val`.
* **Why This Works?** For any valid pair `(a, b)`, whichever is visited second finds the other already in `seen`. Checking before inserting guarantees the two values come from different nodes.
* **Edge Cases Considered:**
  * Single node → `False`.
  * Negative values and negative `k` — set lookup does not care.

## 🔹 Tricks & Patterns Used

* **Check-then-insert** to exclude self-pairs.
* **BST iterators as two pointers:** a stack of the left spine yields ascending order, a stack of the right spine yields descending order.

## 🔹 Alternative Data Structures

* Inorder into a sorted list + two pointers — O(n) time and space, uses the BST property.
* For each node, binary search `k − v` in the BST — O(n·h).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def findTarget(self, root: Optional[TreeNode], k: int) -> bool:
        vals, stack = [], [root]
        while stack:
            node = stack.pop()
            if node:
                vals.append(node.val)
                stack += [node.left, node.right]
        return any(vals[i] + vals[j] == k for i in range(len(vals)) for j in range(i + 1, len(vals)))
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def findTarget(self, root: Optional[TreeNode], k: int) -> bool:
        seen = set()
        stack = [root]
        while stack:
            node = stack.pop()
            if node is None:
                continue
            if k - node.val in seen:
                return True
            seen.add(node.val)  # after the check, so a node never pairs with itself
            stack += [node.left, node.right]
        return False
```
