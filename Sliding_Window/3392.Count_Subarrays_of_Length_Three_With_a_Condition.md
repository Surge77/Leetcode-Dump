## 🔹 Solution Breakdown (FPT Style)

**First Principles Thinking:**

* You don't **assume** fancy structures like prefix sums, sliding windows, or anything.
* **You go from scratch**:
  * Every element (except the first and last) has two neighbors.
  * Check: Is the **sum** of the left and right neighbors exactly **half** of the middle value?
* Division by 2 can produce fractions (and is slower), so instead of: `nums[i-1] + nums[i+1] == nums[i] / 2` you rearrange it to: `2 * (nums[i-1] + nums[i+1]) == nums[i]` to **avoid division**.

**Summary**: You stick to raw CPU-efficient operations — addition and multiplication only.

**No extra space. No libraries. Just brain + array.**

## 🔹 Tricks & Patterns Used

* **Avoid Division Trick**: Instead of `b + c == a / 2` (a = middle), check `2 * (b + c) == a`.
* **Boundary Protection**: Start loop at index `1`, end at `n-2`, so neighbors exist.

## 🔹 Code Snippet (Optimized)

```java

class Solution {
    public int countSubarrays(int[] nums) {
        int count = 0;

        // Traverse from the second element to the second-last element
        for (int i = 1; i <= nums.length - 2; ++i) {

            // Sum of immediate neighbors
            int sum = nums[i - 1] + nums[i + 1];

            // Using multiplication instead of division for speed
            if (2 * sum == nums[i]) {
                count++;
            }
        }

        return count;
    }
}

```

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        count = 0
        for i in range(len(nums) - 2):
            first, middle, third = nums[i:i + 3]
            if first + third == middle / 2:
                count += 1
        return count
```

## 🔹 Code Snippet (Python)

```python
from typing import List


class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        # first + third == middle / 2  <=>  2 * (first + third) == middle (no float division)
        return sum(1 for i in range(len(nums) - 2) if 2 * (nums[i] + nums[i + 2]) == nums[i + 1])
```
