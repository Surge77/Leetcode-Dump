# 🔹 Problem Name: 337. House Robber III (DP on Trees, Medium)

**🔗 Link:** [LeetCode 337](https://leetcode.com/problems/house-robber-iii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** For every node return a pair `(rob this node, skip this node)`. Robbing forces both children to be skipped; skipping lets each child choose its better option.
* **Core Concept:** Tree DP with two states per node (post-order)
* **When to Use This Pattern?** Choose nodes in a tree under parent–child constraints: maximum independent set, minimum vertex cover, tree colouring.
* **Mistakes to Avoid:**
  * Recursion that recomputes grandchildren — exponential without the pair trick or memo.
  * Recursive DFS on a 10⁴-node skewed tree in Python → `RecursionError`. The iterative post-order below avoids it.

## 🔹 Optimization Path

* **Brute Force:** O(2ⁿ) — every node subset.
* **Optimized Solution:** O(n) — one post-order pass.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:**
  * `rob(v) = v.val + skip(left) + skip(right)`
  * `skip(v) = max(rob(left), skip(left)) + max(rob(right), skip(right))`
* **Why This Works?** The only constraint is between a node and its children, so each subtree's best answer depends only on whether its root is taken.
* **Edge Cases Considered:**
  * Empty tree → 0.
  * Skewed (linked-list) tree.

## 🔹 Tricks & Patterns Used

* **Return a tuple of states** from each subtree instead of memoising separate calls.
* **Iterative post-order:** reverse a pre-order (root, then children) so children are processed before parents.

## 🔹 Alternative Data Structures

* Recursive version (shorter): `def dfs(node): ... return (rob, skip)` with `sys.setrecursionlimit` raised.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional

# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right


class Solution:
    def rob(self, root: Optional["TreeNode"]) -> int:
        if not root:
            return 0
        order, stack = [], [root]
        while stack:  # pre-order; reversed later => children before parents
            node = stack.pop()
            order.append(node)
            if node.left:
                stack.append(node.left)
            if node.right:
                stack.append(node.right)

        best = {None: (0, 0)}  # node -> (rob it, skip it)
        for node in reversed(order):
            l_rob, l_skip = best[node.left]
            r_rob, r_skip = best[node.right]
            best[node] = (node.val + l_skip + r_skip,
                          max(l_rob, l_skip) + max(r_rob, r_skip))
        return max(best[root])
```
