# 1483. Kth Ancestor of a Tree Node

**🔗 Link:** [LeetCode 1483](https://leetcode.com/problems/kth-ancestor-of-a-tree-node/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

A rooted tree (root is node 0) is given as a `parent` array, where `parent[0] = -1`. Build a `TreeAncestor` object whose `getKthAncestor(node, k)` returns the k-th node on the path from `node` up to the root, or `-1` if the path is shorter than `k`.

* **Example:** `["TreeAncestor","getKthAncestor","getKthAncestor","getKthAncestor"]`, `[[7,[-1,0,0,1,1,2,2]],[3,1],[5,2],[6,3]]` → `[null,1,0,-1]`
* **Constraints:** `1 ≤ k ≤ n ≤ 5·10⁴`; `parent[0] == -1`; `0 ≤ parent[i] < n` for `i > 0`; at most `5·10⁴` queries.

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Precompute `up[j][v]` = the `2^j`-th ancestor of `v`. Answer a query by jumping along the set bits of `k`.
* **Core Concept:** Binary lifting (jump pointers)
* **When to Use This Pattern?** Many ancestor / LCA / "k steps along a functional graph" queries on large trees (here n and the query count are up to 5·10⁴).
* **Mistakes to Avoid:**
  * Walking parent by parent — O(k) per query, O(n · q) total.
  * Not propagating `-1` (past the root) through the table.

## 🔹 Optimization Path

* **Brute Force:** O(k) per query.
* **Optimized Solution:** O(n log n) preprocessing, O(log k) per query.
* **Further Improvements Possible?** Offline DFS with a path stack answers all queries in O(n + q).

## 🔹 Solution Breakdown

* **Optimal Approach:** `up[0] = parent`; `up[j][v] = up[j-1][ up[j-1][v] ]`. Query: for every bit `j` set in `k`, `node = up[j][node]`.
* **Why This Works?** Any `k` is a sum of distinct powers of two, and a `2^j` jump is two `2^(j-1)` jumps — so the table is built by doubling.
* **Edge Cases Considered:**
  * `k` larger than the depth → -1.
  * Querying the root.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class TreeAncestor:
    def __init__(self, n: int, parent: List[int]):
        self.parent = parent

    def getKthAncestor(self, node: int, k: int) -> int:
        while k and node != -1:
            node = self.parent[node]
            k -= 1
        return node
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class TreeAncestor:
    def __init__(self, n: int, parent: List[int]):
        levels = max(1, n.bit_length())  # k <= n < 2**levels
        self.up = [parent[:]]  # up[j][v]: 2^j-th ancestor of v, or -1
        for _ in range(1, levels):
            prev = self.up[-1]
            self.up.append([prev[p] if p != -1 else -1 for p in prev])

    def getKthAncestor(self, node: int, k: int) -> int:
        j = 0
        while k and node != -1:
            if k & 1:
                if j >= len(self.up):
                    return -1
                node = self.up[j][node]
            k >>= 1
            j += 1
        return node
```
