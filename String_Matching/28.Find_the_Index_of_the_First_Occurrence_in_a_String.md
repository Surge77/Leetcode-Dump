# 🔹 Problem Name: 28. Find the Index of the First Occurrence in a String (KMP, Easy)

**🔗 Link:** [LeetCode 28](https://leetcode.com/problems/find-the-index-of-the-first-occurrence-in-a-string/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy (KMP makes it a Hard-level technique)
* **Main Approach:** Build the KMP prefix function of the needle (`pi[i]` = length of the longest proper prefix of `needle[:i+1]` that is also its suffix). Scan the haystack; on a mismatch fall back to `pi[j-1]` instead of restarting.
* **Core Concept:** Knuth–Morris–Pratt string matching
* **When to Use This Pattern?** Pattern search in O(n + m), counting occurrences, periodicity ("is the string a repetition?"), borders (prefix = suffix).
* **Mistakes to Avoid:**
  * Restarting the comparison from scratch after a mismatch — O(n · m).
  * Off-by-one in the fallback (`j = pi[j - 1]`).

## 🔹 Optimization Path

* **Brute Force:** O(n · m) — compare at every start.
* **Optimized Solution:** O(n + m) KMP.
* **Further Improvements Possible?** Z-function or Rabin–Karp give the same bound.

## 🔹 Solution Breakdown

* **Optimal Approach:** Prefix function in O(m); then a second loop over the haystack, keeping `j` = number of matched needle characters.
* **Why This Works?** After matching `j` characters and failing, the longest prefix of the needle that can still be "in progress" is the longest border of `needle[:j]`, which is `pi[j-1]` — no haystack character is ever re-read.
* **Edge Cases Considered:**
  * Needle longer than the haystack → -1.
  * Overlapping candidates (`"aaab"` in `"aaaab"`).

## 🔹 Pattern Recognition

* **Belongs To:** String Matching
* **Common Problems Using This:**

## 🔹 Tricks & Patterns Used

* **Prefix function reuse:** the same `while` fallback builds `pi` and scans the text.
* **Periodicity:** smallest period of `s` = `n - pi[n-1]`.

## 🔹 Alternative Data Structures

* **Z-function** on `needle + '#' + haystack`.
* **Rolling hash** (Rabin–Karp) — simple, but verify matches to avoid collisions.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n + m)
* **Space Complexity:** O(m)

## 🔹 Code Snippet (Optimized)

```python
from typing import List


def prefix_function(p: str) -> List[int]:
    pi = [0] * len(p)
    k = 0
    for i in range(1, len(p)):
        while k and p[i] != p[k]:
            k = pi[k - 1]  # fall back to the next shorter border
        if p[i] == p[k]:
            k += 1
        pi[i] = k
    return pi


class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        pi = prefix_function(needle)
        j = 0  # needle characters matched so far
        for i, c in enumerate(haystack):
            while j and c != needle[j]:
                j = pi[j - 1]
            if c == needle[j]:
                j += 1
            if j == len(needle):
                return i - j + 1
        return -1
```
