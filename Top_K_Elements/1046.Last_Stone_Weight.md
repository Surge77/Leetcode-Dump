# 🔹 Problem Name: 1046. Last Stone Weight (Max Heap Simulation, Easy)

**🔗 Link:** [LeetCode 1046](https://leetcode.com/problems/last-stone-weight/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Max-heap simulation.** Put all stones in a max-heap (negated values). Repeatedly pop the two heaviest `y ≥ x`; if `y > x`, push back `y − x`. Return the remaining stone or `0`.
* **Core Concept:** a process that always needs "the current maximum" after inserts → priority queue
* **When to Use This Pattern?** Greedy simulations that repeatedly take the largest/smallest items and put a result back — connecting ropes/sticks, task scheduling, reducing piles.
* **Mistakes to Avoid:**
  * Re-sorting the whole list every round: O(n² log n) (fine at `n ≤ 30`, but not the pattern).
  * Forgetting that `heapq` is a min-heap — negate on push and pop.
  * Returning `None` when all stones cancel; the answer is `0`.

## 🔹 Optimization Path

* **Brute Force:** sort every round and smash the last two — O(n² log n).
* **Optimized Solution:** max-heap — O(n log n).
* **Further Improvements Possible?** With weights ≤ 1000, bucket counts over weights give O(n + W), rarely worth it.

## 🔹 Solution Breakdown

* **Optimal Approach:** `heap = [-s for s in stones]`, heapify; while ≥ 2 stones: pop `y`, pop `x`, push `-(y − x)` if non-zero.
* **Why This Works?** Each round removes at least one stone, so there are at most `n − 1` rounds, each O(log n); the heap always exposes the two heaviest as required by the rules.
* **Edge Cases Considered:**
  * One stone → that stone.
  * Two equal stones → `0`.

* **Negation for a max-heap** in Python.
* **`heapq.heapify`** builds the initial heap in O(n) instead of n pushes.

## 🔹 Alternative Data Structures

* Sorted list with `bisect.insort` for the remainder — O(n) per insert.
* Counting array over weights `1..1000`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n log n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def lastStoneWeight(self, stones: List[int]) -> int:
        pile = list(stones)
        while len(pile) > 1:
            pile.sort()
            y, x = pile.pop(), pile.pop()
            if y != x:
                pile.append(y - x)
        return pile[0] if pile else 0
```

## 🔹 Code Snippet (Optimized)

```python
import heapq
from typing import List


class Solution:
    def lastStoneWeight(self, stones: List[int]) -> int:
        heap = [-s for s in stones]  # negated: heapq only provides a min-heap
        heapq.heapify(heap)
        while len(heap) > 1:
            y = -heapq.heappop(heap)
            x = -heapq.heappop(heap)
            if y != x:
                heapq.heappush(heap, -(y - x))
        return -heap[0] if heap else 0
```
