# 231. Power of Two

**🔗 Link:** [LeetCode 231](https://leetcode.com/problems/power-of-two/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given an integer `n`, decide whether it equals `2^x` for some integer `x ≥ 0`. Return `true` if so, otherwise `false`. A follow-up asks for a solution without loops or recursion.

* **Example:** `n = 1` → `true`
* **Constraints:** `−2^31 ≤ n ≤ 2^31 − 1`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Exactly one set bit.** A positive power of two looks like `1000…0`; subtracting 1 gives `0111…1`, so `n & (n − 1) == 0`. Require `n > 0` to exclude 0 and negatives.
* **Core Concept:** `n & (n − 1)` clears the lowest set bit — it is zero exactly when `n` had at most one set bit
* **When to Use This Pattern?** Any "is it a power of two / has a single bit" test, and as a building block for counting set bits (191) or stepping through set bits.
* **Mistakes to Avoid:**
  * Forgetting `n > 0`: `0 & −1 == 0` would wrongly say 0 is a power of two.
  * Negative inputs: `−2³¹` has a single bit in 32-bit two's complement but is not a power of two.

## 🔹 Optimization Path

* **Brute Force:** divide by 2 while even; check you reach 1 — O(log n).
* **Optimized Solution:** `n > 0 and n & (n − 1) == 0` — O(1).
* **Further Improvements Possible?** Equivalent O(1) checks: `n > 0 and n & −n == n` (lowest set bit is the whole number), or `n > 0 and 2³⁰ % n == 0` (2³⁰ is the largest power of two in range).

## 🔹 Solution Breakdown

* **Optimal Approach:** one comparison and one AND.
* **Why This Works?** Subtracting 1 flips the lowest set bit to 0 and every bit below it to 1, leaving higher bits unchanged. The AND therefore keeps exactly the higher set bits — none of them exist iff `n` has one set bit.
* **Edge Cases Considered:**
  * `n = 1` (`2⁰`) → true.
  * `n = 0` and negatives → false.

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        if n <= 0:
            return False
        while n % 2 == 0:
            n //= 2
        return n == 1
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        # n - 1 turns the lowest set bit off and the bits below it on
        return n > 0 and n & (n - 1) == 0
```
