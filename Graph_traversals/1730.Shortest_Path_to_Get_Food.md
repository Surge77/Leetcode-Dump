## 🔹 Problem Statement

You are given a grid with one `*` (your start), some `#` food cells, `O` free cells and `X` obstacles. Moving one step up, down, left or right through non-obstacle cells, return the length of the shortest path from the start to any food cell, or `-1` if no food can be reached. *(premium — paraphrased from memory, not checked against the official page)*

* **Example:** `grid = [["X","X","X","X","X","X"],["X","*","O","O","O","X"],["X","O","O","#","O","X"],["X","X","X","X","X","X"]]` → `3`
* **Constraints:** `1 ≤ m, n ≤ 200`, each cell is `*`, `#`, `O` or `X`, exactly one `*`, at least one `#`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **BFS from `*` over free cells.** Cells: `*` start (exactly one), `#` food, `O` free, `X` obstacle. Expand 4-directionally level by level and return the level at which any `#` is reached; `-1` if the queue empties first.
* **Core Concept:** BFS on an unweighted grid gives the shortest distance to the *nearest* target of any kind, with no need to try targets one by one
* **When to Use This Pattern?** "Minimum steps to reach the nearest X" on a grid.
* **Mistakes to Avoid:**
  * DFS: it finds a path, not the shortest.
  * Running a separate search per `#` cell — one BFS covers all of them.
  * Forgetting to mark visited when **enqueuing**; cells get queued repeatedly.

## 🔹 Optimization Path

* **Brute Force:** relax distances repeatedly (Bellman–Ford style) over the whole grid until nothing improves — O((m·n)²) worst case.
* **Optimized Solution:** BFS — O(m · n).
* **Further Improvements Possible?** No; every cell may need to be read once.

## 🔹 Solution Breakdown

* **Optimal Approach:** locate `*`, push it with distance 0, mark visited. Pop a cell; for each neighbour in bounds, not `X`, not visited: if it is `#` return `dist + 1`, else mark and enqueue.
* **Why This Works?** BFS pops cells in non-decreasing distance, so the first food cell discovered is at the minimum distance.
* **Edge Cases Considered:**
  * Food walled off (`X` all around) → `-1`.
  * Food adjacent to the start → `1`.
  * Several foods — the nearest is found first.

* **Direction tuple list** for the four moves.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def getFood(self, grid: List[List[str]]) -> int:
        rows, cols = len(grid), len(grid[0])
        INF = float("inf")
        dist = [[INF] * cols for _ in range(rows)]
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == "*":
                    dist[r][c] = 0
        changed = True
        while changed:  # keep relaxing until no cell gets closer
            changed = False
            for r in range(rows):
                for c in range(cols):
                    if grid[r][c] == "X":
                        continue
                    for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                        nr, nc = r + dr, c + dc
                        if 0 <= nr < rows and 0 <= nc < cols and dist[nr][nc] + 1 < dist[r][c]:
                            dist[r][c] = dist[nr][nc] + 1
                            changed = True
        best = min((dist[r][c] for r in range(rows) for c in range(cols) if grid[r][c] == "#"), default=INF)
        return -1 if best == INF else best
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def getFood(self, grid: List[List[str]]) -> int:
        rows, cols = len(grid), len(grid[0])
        start = next((r, c) for r in range(rows) for c in range(cols) if grid[r][c] == "*")
        queue = deque([(start[0], start[1], 0)])
        seen = {start}
        while queue:
            r, c, dist = queue.popleft()
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] != "X" and (nr, nc) not in seen:
                    if grid[nr][nc] == "#":
                        return dist + 1
                    seen.add((nr, nc))
                    queue.append((nr, nc, dist + 1))
        return -1
```
