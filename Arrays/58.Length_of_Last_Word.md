# 🔹 Problem Name: 58. Length of Last Word (Reverse Scan, Easy)

**🔗 Link:** [LeetCode 58](https://leetcode.com/problems/length-of-last-word/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Scan from the end.** Skip trailing spaces, then count non-space characters until the next space or the start of the string.
* **Core Concept:** the answer lives at the tail, so only the tail needs to be read
* **When to Use This Pattern?** Questions about the last token, the last occurrence, or a suffix property — reading backwards stops as soon as the answer is known.
* **Mistakes to Avoid:**
  * Trailing spaces (`"fly me   to   the moon  "`): `s.split(" ")[-1]` is `""`. `s.split()` (no argument) drops empty tokens.
  * Running past index 0 while counting — the last word may also be the first.

## 🔹 Optimization Path

* **Brute Force:** `len(s.split()[-1])` — builds every word: O(n) time and O(n) extra space.
* **Optimized Solution:** backward scan — O(t) time where `t` = trailing spaces + last word length (≤ n), O(1) space.
* **Further Improvements Possible?** No; the last word's characters must be read to count them.

## 🔹 Solution Breakdown

* **Optimal Approach:** `end = len(s) − 1`; while `s[end] == " "`: `end -= 1`; `start = end`; while `start ≥ 0` and `s[start] != " "`: `start -= 1`; return `end − start`.
* **Why This Works?** After the first loop `end` is the last letter of the last word (the problem guarantees at least one word). The second loop stops one position before that word's first letter, so `end − start` is its length.
* **Edge Cases Considered:**
  * A single word, no spaces → `start` runs to `−1`, length `n`.
  * Leading and repeated inner spaces are never reached or do not matter.

## 🔹 Tricks & Patterns Used

* **Two-phase backward scan:** first skip the noise (spaces), then measure the token.
* **`str.split()` without arguments** splits on runs of whitespace and ignores leading/trailing whitespace.

## 🔹 Alternative Data Structures

* `len(s.rstrip().split(" ")[-1])` — still splits the whole string.
* `s.rstrip()` then `rfind(" ")` — O(n) copy for `rstrip`, then the answer is `len(stripped) − 1 − index`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n) worst case (one long word), typically much less
* **Space Complexity:** O(1)

```python
class Solution:

```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        end = len(s) - 1
        while s[end] == " ":  # safe: at least one word exists
            end -= 1
        start = end
        while start >= 0 and s[start] != " ":
            start -= 1
        return end - start
```
