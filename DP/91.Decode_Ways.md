# 🔹 Problem Name: 91. Decode Ways (1D DP, Medium)

**🔗 Link:** [LeetCode 91](https://leetcode.com/problems/decode-ways/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Fibonacci-style DP.** `ways[i]` = number of decodings of the prefix `s[:i]`. The last letter used either is one digit `s[i-1]` (valid if it is not `'0'`) or two digits `s[i-2:i]` (valid if it is `10..26`): `ways[i] = (s[i-1] != '0') · ways[i-1] + (10 ≤ int(s[i-2:i]) ≤ 26) · ways[i-2]`. Only the last two values are needed.
* **Core Concept:** count the ways to split a sequence into pieces of length 1 or 2, each piece with a validity check
* **When to Use This Pattern?** "Count the ways to build / split a sequence where each step uses the last 1 or 2 elements" — climbing stairs, tilings, decode ways.
* **Mistakes to Avoid:**
  * `'0'` alone is not a letter: `"06"` → 0, and a string starting with `'0'` → 0.
  * A two-digit chunk starting with `'0'` (`"05"`) is not valid — check `10..26`, not `1..26`.
  * Recursion without memo: O(2ⁿ) on `"111…1"` (`n ≤ 100`).

## 🔹 Optimization Path

* **Brute Force:** recursion trying a 1-digit and a 2-digit piece at every position — O(2ⁿ) / O(φⁿ).
* **Optimized Solution:** iterate the recurrence with two rolling variables — O(n) time, O(1) space.
* **Further Improvements Possible?** No; every digit must be read.

## 🔹 Solution Breakdown

* **Optimal Approach:** `prev2 = 1` (empty prefix), `prev1 = 1 if s[0] != '0' else 0`. For each `i` from 2 to `n`, combine as above, then shift.
* **Why This Works?** Every decoding of `s[:i]` ends with exactly one last letter of length 1 or 2, so the two cases are disjoint and together cover everything.
* **Edge Cases Considered:**
  * Leading zero → 0.
  * `"10"`, `"20"` → 1 (the `0` must pair with the previous digit).
  * `"30"`, `"100"` → 0 (a `0` with no valid partner kills every decoding).

## 🔹 Tricks & Patterns Used

* **Empty prefix has one decoding:** `ways[0] = 1` makes the two-digit case at `i = 2` work without special code.
* **Rolling variables:** the recurrence only looks two steps back.

## 🔹 Alternative Data Structures

* Full array `ways[0..n]` — same time, O(n) space, easier to debug.
* Top-down recursion with `lru_cache` — depth ≤ 100, fine here.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def numDecodings(self, s: str) -> int:
        def count(i: int) -> int:
            if i == len(s):
                return 1
            if s[i] == "0":
                return 0
            total = count(i + 1)
            if i + 1 < len(s) and int(s[i:i + 2]) <= 26:
                total += count(i + 2)
            return total

        return count(0)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def numDecodings(self, s: str) -> int:
        prev2, prev1 = 1, int(s[0] != "0")  # prev2 = ways for the empty prefix
        for i in range(2, len(s) + 1):
            current = prev1 if s[i - 1] != "0" else 0
            if 10 <= int(s[i - 2:i]) <= 26:
                current += prev2
            prev2, prev1 = prev1, current
        return prev1
```
