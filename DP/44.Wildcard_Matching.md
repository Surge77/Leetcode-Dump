# 🔹 Problem Name: 44. Wildcard Matching (String DP, Hard)

**🔗 Link:** [LeetCode 44](https://leetcode.com/problems/wildcard-matching/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Greedy with star backtracking** (equivalent to the `dp[i][j]` table). Walk `s` and `p` together; `?` or an equal letter advances both. On `*`, remember its position and the current `s` index and first let it match nothing. On a mismatch, go back to the last `*` and let it swallow one more character of `s`. At the end only `*`s may remain in `p`.
* **Core Concept:** `dp[i][j]` = "does `s[i:]` match `p[j:]`"; `*` → `dp[i][j+1] or dp[i+1][j]` (empty, or eat one char and stay on the star)
* **When to Use This Pattern?** Two strings consumed left to right where a symbol can consume a variable-length chunk — glob matching, regex (10), edit distance (72), LCS (1143).
* **Mistakes to Avoid:**
  * Plain recursion without memo: a pattern like `*a*a*a*b` on `aaaa…a` is exponential.
  * Forgetting that `*` may match the empty string — `s = ""`, `p = "***"` is `True`.
  * In the greedy, only the **last** star needs to be retried: an earlier star can never do better, because the later star can absorb anything the earlier one would have.

## 🔹 Optimization Path

* **Brute Force:** recursion trying both choices for every `*` — exponential.
* **Optimized Solution:** greedy two pointers with backtracking to the last `*` — O(m·n) worst case, O(1) extra space; usually close to linear.
* **Further Improvements Possible?** The memoized / bottom-up table is also O(m·n) (with `m, n ≤ 2000` that is 4·10⁶ cells) and easier to prove; the greedy wins on space and typical speed.

## 🔹 Solution Breakdown

* **Optimal Approach:** pointers `i` (in `s`), `j` (in `p`), `star` (last `*` index, `-1` if none), `mark` (index in `s` where that star's match ends). Loop while `i < len(s)`: match/`?` → `i += 1, j += 1`; `*` → `star, mark = j, i; j += 1`; else if a star exists → `mark += 1; i = mark; j = star + 1`; else `False`. Finally skip trailing `*`s and check `j == len(p)`.
* **Why This Works?** Segments between stars must appear in `s` in order. Matching each segment at its **earliest** possible position leaves the longest suffix for the rest, so it never hurts; backtracking to the latest star tries the next earliest position.
* **Edge Cases Considered:**
  * Empty `s` with a pattern of only `*` → `True`; with any letter or `?` → `False`.
  * Pattern without stars → must have equal length.
  * Consecutive stars behave like one star.

## 🔹 Tricks & Patterns Used

* **Star = "skip or consume and stay":** the transition `dp[i][j+1] or dp[i+1][j]` avoids looping over every length a star could take.
* **Greedy earliest match + latest-star backtrack:** turns the table into two pointers.

## 🔹 Alternative Data Structures

* Bottom-up `dp` with two rows of length `len(p) + 1` — O(m·n) time, O(n) space.
* `functools.lru_cache` on `(i, j)` — same complexity but recursion depth up to `m + n = 4000`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m·n) worst case (each backtrack restarts the segment after the last star), with `m = len(s)`, `n = len(p)`
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        def match(i: int, j: int) -> bool:
            if j == len(p):
                return i == len(s)
            if p[j] == "*":
                return match(i, j + 1) or (i < len(s) and match(i + 1, j))
            return i < len(s) and p[j] in (s[i], "?") and match(i + 1, j + 1)

        return match(0, 0)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        i = j = 0
        star, mark = -1, 0
        while i < len(s):
            if j < len(p) and p[j] in (s[i], "?"):
                i += 1
                j += 1
            elif j < len(p) and p[j] == "*":
                star, mark = j, i  # try the star as empty first
                j += 1
            elif star != -1:
                # only the latest star needs retrying: it can absorb anything an earlier one could
                mark += 1
                i, j = mark, star + 1
            else:
                return False
        while j < len(p) and p[j] == "*":
            j += 1
        return j == len(p)
```
