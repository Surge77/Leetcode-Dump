# 🔹 Problem Name: 1372. Longest ZigZag Path in a Binary Tree (Tree DP, Medium)

**🔗 Link:** [LeetCode 1372](https://leetcode.com/problems/longest-zigzag-path-in-a-binary-tree/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Top-down DP with two lengths per node.** For each node keep `left_end` = length of the longest zigzag ending at it whose last step went left, and `right_end` likewise for a right step. A left child extends the zigzag that arrived by a right step: `child.left_end = node.right_end + 1`, and its `right_end` restarts at 0 (and symmetrically for a right child). The answer is the maximum over all nodes.
* **Core Concept:** the next move direction alternates, so state = "which way did I just come from"
* **When to Use This Pattern?** Paths whose validity depends on the previous step (alternating, increasing, same colour) — zigzag, longest univalue path, consecutive sequence.
* **Mistakes to Avoid:**
  * Length counts **edges**, so a single node is 0 and the root starts at `(0, 0)`.
  * Carrying only one length: after going left you may only continue right, and a repeated direction must restart from 1, not continue.
  * Recursion on a 5·10⁴-node chain — too deep for Python; use an explicit stack.
  * Assuming the path must start at the root; it can start at any node.

## 🔹 Optimization Path

* **Brute Force:** from every node, try both starting directions and walk the alternating chain — O(n · h).
* **Optimized Solution:** one traversal passing `(left_end, right_end)` down — O(n).
* **Further Improvements Possible?** No; each node is visited once.

## 🔹 Solution Breakdown

* **Optimal Approach:** stack of `(node, left_end, right_end)` starting with `(root, 0, 0)`. At each node `best = max(best, left_end, right_end)`; push `(node.left, right_end + 1, 0)` and `(node.right, 0, left_end + 1)`.
* **Why This Works?** A zigzag ending at the left child arrived through a right step at its parent (or starts fresh at length 1), so its length is the parent's `right_end + 1`. The other direction at the child is 0 because a left arrival cannot be extended into a zigzag that last went right.
* **Edge Cases Considered:**
  * Single node → 0.
  * A straight chain of left children → 1.
  * The longest zigzag starts deep inside the tree, not at the root.

## 🔹 Tricks & Patterns Used

* **Direction-indexed state pair:** `(ended going left, ended going right)` encodes the alternation rule without branching logic.
* **Pass state down instead of returning it up:** lets a plain stack loop replace recursion.

## 🔹 Alternative Data Structures

* Recursive DFS returning `(left_len, right_len)` from each child — the usual solution; needs `setrecursionlimit` at 5·10⁴ depth.
* BFS with the same `(node, left_end, right_end)` triples — works equally well.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(h) for the stack, up to O(n) on a skewed tree

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def longestZigZag(self, root: Optional[TreeNode]) -> int:
        def walk(start: TreeNode, go_left: bool) -> int:
            steps, node = 0, start
            while True:
                node = node.left if go_left else node.right
                if node is None:
                    return steps
                steps += 1
                go_left = not go_left

        best = 0
        stack = [root]
        while stack:
            node = stack.pop()
            best = max(best, walk(node, True), walk(node, False))
            for child in (node.left, node.right):
                if child:
                    stack.append(child)
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def longestZigZag(self, root: Optional[TreeNode]) -> int:
        best = 0
        stack = [(root, 0, 0)]  # (node, longest zigzag ending here via a left step, via a right step)
        while stack:
            node, left_end, right_end = stack.pop()
            best = max(best, left_end, right_end)
            if node.left:
                stack.append((node.left, right_end + 1, 0))
            if node.right:
                stack.append((node.right, 0, left_end + 1))
        return best
```
