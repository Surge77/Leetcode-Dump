# 763. Partition Labels

**🔗 Link:** [LeetCode 763](https://leetcode.com/problems/partition-labels/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Split a string into as many consecutive pieces as possible such that no letter appears in more than one piece. Return the length of each piece, in order; joining the pieces must give back the original string.

* **Example:** `s = "ababcbacadefegdehijhklij"` → `[9,7,8]`
* **Constraints:** `1 ≤ s.length ≤ 500`, `s` consists of lowercase English letters.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Last occurrence + running end.** Precompute `last[c]`, the final index of each letter. Scan left to right keeping `end = max(end, last[s[i]])`; when `i == end`, every letter seen in the current part has no later copy, so cut here and record the size.
* **Core Concept:** each letter spans the interval `[first, last]`; the answer is the merged intervals — the scan merges them implicitly
* **When to Use This Pattern?** "Split into as many pieces as possible so that each X appears in only one piece" — the piece must stretch to the last occurrence of everything inside it.
* **Mistakes to Avoid:**
  * Cutting as soon as the current letter's last occurrence is reached — another letter in the part may extend further; use the running max.
  * Returning cut indices instead of part lengths.

## 🔹 Optimization Path

* **Brute Force:** extend each part by recomputing `s.rindex(c)` for every character in it — O(n²).
* **Optimized Solution:** precompute last occurrences once — O(n).
* **Further Improvements Possible?** No; one pass over the string is required.

## 🔹 Solution Breakdown

* **Optimal Approach:** `last = {c: i for i, c in enumerate(s)}`; `start = end = 0`; for each `i`, `end = max(end, last[s[i]])`; if `i == end`, append `end − start + 1`, `start = i + 1`.
* **Why This Works?** A part starting at `start` must include `last[c]` for every letter `c` inside it, so its smallest valid end is the fixed point of `end = max(last[c])` over `s[start..end]`; the scan reaches exactly that fixed point. Cutting at the earliest valid point maximises the number of parts, because any valid split must also cut there or later.
* **Edge Cases Considered:**
  * One distinct letter (`"aaaa"`) → `[4]`.
  * All distinct letters → `[1, 1, …, 1]`.
  * A letter at index 0 that reappears at the end → one part of length `n`.

* **Running farthest reach:** `end = max(end, reach[i])`, cut/step when `i == end`.
* **Last-occurrence table** built in one pass by overwriting.

* **Space Complexity:** O(1) — at most 26 letters in `last`

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        sizes = []
        start = 0
        while start < len(s):
            end = start
            i = start
            while i <= end:
                end = max(end, s.rindex(s[i]))
                i += 1
            sizes.append(end - start + 1)
            start = end + 1
        return sizes
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        last = {ch: i for i, ch in enumerate(s)}
        sizes = []
        start = end = 0
        for i, ch in enumerate(s):
            end = max(end, last[ch])
            if i == end:  # nothing seen in this part appears after i
                sizes.append(end - start + 1)
                start = i + 1
        return sizes
```
