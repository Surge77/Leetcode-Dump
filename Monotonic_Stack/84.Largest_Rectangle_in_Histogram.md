# 🔹 Problem Name: 84. Largest Rectangle in Histogram (Monotonic Stack, Hard)

**🔗 Link:** [LeetCode 84](https://leetcode.com/problems/largest-rectangle-in-histogram/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Keep a stack of indices with increasing heights. When a shorter bar arrives, pop taller bars: each popped bar's rectangle spans from the new stack top + 1 to the current index − 1.
* **Core Concept:** Monotonic increasing stack (previous/next smaller element)
* **When to Use This Pattern?** "For each element, how far does it extend as the minimum/maximum?" — histograms, maximal rectangles in binary matrices, subarray-min sums.
* **Mistakes to Avoid:**
  * Forgetting to flush the stack at the end (append a `0` sentinel).
  * Wrong width: `i - stack[-1] - 1` after popping (or `i` if the stack is empty).

## 🔹 Optimization Path

* **Brute Force:** O(n²) — every pair `(i, j)` with a running min.
* **Optimized Solution:** O(n) — each index pushed and popped once.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Iterate `heights + [0]`; while the current bar is lower than the top, pop `h = heights[top]` and compute `h · width`.
* **Why This Works?** When a bar is popped, the current index is its first smaller bar to the right and the new top is its last smaller bar to the left, so the rectangle with that bar's full height is exactly between them.
* **Edge Cases Considered:**
  * Increasing heights (all popped by the sentinel).
  * Equal heights.
  * Single bar.

## 🔹 Pattern Recognition

* **Belongs To:** Monotonic Stack
* **Common Problems Using This:**
  * 85. Maximal Rectangle (run this per matrix row)
  * 907. Sum of Subarray Minimums
  * 1856. Maximum Subarray Min-Product

## 🔹 Tricks & Patterns Used

* **Sentinel `0`** at the end flushes the stack.
* **Width from the stack**, not stored separately.

## 🔹 Alternative Data Structures

* Precompute `left_smaller` and `right_smaller` arrays with two monotonic passes — easier to debug.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        stack = []  # indices with increasing heights
        best = 0
        for i, h in enumerate(heights + [0]):  # sentinel flushes the stack
            while stack and heights[stack[-1]] > h:
                height = heights[stack.pop()]
                left = stack[-1] if stack else -1  # previous smaller bar
                best = max(best, height * (i - left - 1))
            stack.append(i)
        return best
```
