# 🔹 Problem Name: 699. Falling Squares (Segment Tree with Lazy Propagation, Hard)

**🔗 Link:** [LeetCode 699](https://leetcode.com/problems/falling-squares/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Squares are dropped one by one onto the x-axis: `positions[i] = [left, sideLength]`. Each falls until it rests on the x-axis or on top of earlier squares it overlaps (merely touching a side does not count), then stays put. After each drop, record the height of the tallest stack so far and return those heights.

* **Example:** `positions = [[1,2],[2,3],[6,1]]` → `[2,5,5]`
* **Constraints:** `1 ≤ positions.length ≤ 1000`, `1 ≤ left ≤ 10^8`, `1 ≤ sideLength ≤ 10^6`

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Compress the x-coordinates. For each square: `base = max height over [left, left+size)`, then **assign** `base + size` to that whole range. A segment tree with range-assign + range-max (lazy propagation) does both in O(log n).
* **Core Concept:** Coordinate compression + lazy segment tree
* **When to Use This Pattern?** Range updates *and* range queries together (set/add a value on `[l, r]`, ask max/sum on `[l, r]`) — typical SP hard-question material.
* **Mistakes to Avoid:**
  * Treating edges as overlapping — squares touching at `x = left + size` do **not** stack (half-open intervals).
  * Forgetting to push lazy tags down before visiting children.
  * Building a tree over raw coordinates (up to 10⁸) instead of compressed ones (right edges reach about 10⁸ + 10⁶).

## 🔹 Optimization Path

* **Brute Force:** O(n²) — compare each square with all previous ones (n ≤ 1000 here, so it passes; the segment tree is the version that scales).
* **Optimized Solution:** O(n log n) — compression + lazy segment tree.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Points = sorted unique `{left, left+size}`; tree index `i` represents the unit `[pts[i], pts[i+1])`. A square covers indices `idx(left) .. idx(left+size) - 1`.
* **Why This Works?** Inside one compressed unit the height is constant, so storing one value per unit loses nothing; lazy tags delay the assignment to sub-ranges until they are actually visited.
* **Edge Cases Considered:**
  * Squares side by side (no stacking).
  * A small square landing on top of a big one.
  * Identical squares (each adds its full height).

## 🔹 Pattern Recognition

* **Belongs To:** Segment Tree — lazy propagation
* **Common Problems Using This:**
  * 732. My Calendar III (range add, global max)
  * 715. Range Module

## 🔹 Tricks & Patterns Used

* **Coordinate compression:** `index = {x: i for i, x in enumerate(sorted(set(xs)))}`.
* **Lazy propagation:** a pending assignment stored at a node, pushed to children on demand.

## 🔹 Alternative Data Structures

* Sorted list of disjoint height intervals (interval map) — also works, trickier to code bug-free.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n log n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def fallingSquares(self, positions: List[List[int]]) -> List[int]:
        heights = []
        answer, tallest = [], 0
        for left, size in positions:
            right = left + size
            base = 0
            for (l2, size2), h2 in zip(positions, heights):
                if l2 < right and left < l2 + size2:  # overlaps an earlier square
                    base = max(base, h2)
            heights.append(base + size)
            tallest = max(tallest, base + size)
            answer.append(tallest)
        return answer
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class MaxAssignTree:
    """Range assign + range max over indices 0..n-1, with lazy propagation."""

    def __init__(self, n: int):
        self.n = n
        self.mx = [0] * (4 * n)
        self.tag = [0] * (4 * n)  # pending assignment; 0 = none (heights are > 0)

    def _push(self, node: int) -> None:
        if self.tag[node]:
            for child in (2 * node, 2 * node + 1):
                self.mx[child] = self.tag[child] = self.tag[node]
            self.tag[node] = 0

    def query(self, l: int, r: int, node: int = 1, lo: int = 0, hi: int = -1) -> int:
        hi = self.n - 1 if hi < 0 else hi
        if r < lo or hi < l:
            return 0
        if l <= lo and hi <= r:
            return self.mx[node]
        self._push(node)
        mid = (lo + hi) // 2
        return max(self.query(l, r, 2 * node, lo, mid),
                   self.query(l, r, 2 * node + 1, mid + 1, hi))

    def assign(self, l: int, r: int, val: int, node: int = 1, lo: int = 0, hi: int = -1) -> None:
        hi = self.n - 1 if hi < 0 else hi
        if r < lo or hi < l:
            return
        if l <= lo and hi <= r:
            self.mx[node] = self.tag[node] = val
            return
        self._push(node)
        mid = (lo + hi) // 2
        self.assign(l, r, val, 2 * node, lo, mid)
        self.assign(l, r, val, 2 * node + 1, mid + 1, hi)
        self.mx[node] = max(self.mx[2 * node], self.mx[2 * node + 1])


class Solution:
    def fallingSquares(self, positions: List[List[int]]) -> List[int]:
        pts = sorted({x for left, size in positions for x in (left, left + size)})
        index = {x: i for i, x in enumerate(pts)}
        tree = MaxAssignTree(len(pts))
        answer, tallest = [], 0
        for left, size in positions:
            l, r = index[left], index[left + size] - 1  # units covered (half-open)
            height = tree.query(l, r) + size
            tree.assign(l, r, height)
            tallest = max(tallest, height)
            answer.append(tallest)
        return answer
```
