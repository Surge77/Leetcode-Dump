# 130. Surrounded Regions

**🔗 Link:** [LeetCode 130](https://leetcode.com/problems/surrounded-regions/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

The board contains `'X'` and `'O'` cells. Any group of 4-connected `'O'` cells that does not touch the board's edge is captured: change all of its cells to `'X'`, modifying the board in place and returning nothing.

* **Example:** `board = [["X","X","X","X"],["X","O","O","X"],["X","X","O","X"],["X","O","X","X"]]` → `[["X","X","X","X"],["X","X","X","X"],["X","X","X","X"],["X","O","X","X"]]`
* **Constraints:** `1 ≤ m, n ≤ 200`, each cell is `'X'` or `'O'`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Flood fill from the border.** An `'O'` region survives exactly when it touches the border. Start a DFS/BFS from every border `'O'` and mark everything it reaches as safe (`'S'`). Then one sweep: leftover `'O'` → `'X'` (captured), `'S'` → `'O'`.
* **Core Concept:** invert the question — instead of "is this region enclosed?", find everything connected to the boundary
* **When to Use This Pattern?** Grid problems where cells are decided by "can it reach the edge / some source": enclaves, closed islands, water flowing to an ocean.
* **Mistakes to Avoid:**
  * Recursive DFS: a snake-shaped region on a 200 × 200 board is 20 000 deep → `RecursionError`. Use an explicit stack.
  * Flipping cells while still deciding which regions are enclosed — mark first, flip in a separate pass.
  * Checking each `'O'` separately with its own search: O((m·n)²).

## 🔹 Optimization Path

* **Brute Force:** for every `'O'`, search its region to see whether it reaches the border — O((m·n)²).
* **Optimized Solution:** one flood fill from the border cells — O(m·n).
* **Further Improvements Possible?** No; every cell must be looked at. Union-Find with a virtual "border" node is an equal-cost alternative.

## 🔹 Solution Breakdown

* **Optimal Approach:** push every border `'O'` (marked `'S'`) onto a stack; pop, mark unmarked `'O'` neighbours `'S'` and push them. Final sweep rewrites each cell: `'S'` → `'O'`, anything else → `'X'`.
* **Why This Works?** A region is captured iff none of its cells is on the border. The flood fill from the border reaches exactly the cells of non-captured regions, so whatever `'O'` is left is enclosed.
* **Edge Cases Considered:**
  * One row or one column — every cell is a border cell, nothing is captured.
  * A board with no `'O'` — the stack starts empty.

## 🔹 Tricks & Patterns Used

* **Search from the boundary inward:** one traversal answers the question for every cell at once.
* **In-place marker `'S'`:** the board itself is the visited set — O(1) extra marking memory.

## 🔹 Alternative Data Structures

* BFS with a `deque` — same result, same cost.
* Union-Find: union border `'O'`s with a dummy node, union adjacent `'O'`s; flip every `'O'` not connected to the dummy.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n)
* **Space Complexity:** O(m · n) for the stack in the worst case

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def solve(self, board: List[List[str]]) -> None:
        m, n = len(board), len(board[0])

        def reaches_border(r: int, c: int) -> bool:
            seen, stack = {(r, c)}, [(r, c)]
            while stack:
                r, c = stack.pop()
                if r in (0, m - 1) or c in (0, n - 1):
                    return True
                # an interior cell has all four neighbours inside the board
                for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                    if board[nr][nc] == "O" and (nr, nc) not in seen:
                        seen.add((nr, nc))
                        stack.append((nr, nc))
            return False

        captured = [(r, c) for r in range(m) for c in range(n)
                    if board[r][c] == "O" and not reaches_border(r, c)]
        for r, c in captured:
            board[r][c] = "X"
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def solve(self, board: List[List[str]]) -> None:
        m, n = len(board), len(board[0])
        stack = [(r, c) for r in range(m) for c in range(n)
                 if (r in (0, m - 1) or c in (0, n - 1)) and board[r][c] == "O"]
        for r, c in stack:
            board[r][c] = "S"  # marked on push so no cell is pushed twice
        while stack:
            r, c = stack.pop()
            for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                if 0 <= nr < m and 0 <= nc < n and board[nr][nc] == "O":
                    board[nr][nc] = "S"
                    stack.append((nr, nc))
        for row in board:
            for c, cell in enumerate(row):
                row[c] = "O" if cell == "S" else "X"
```
