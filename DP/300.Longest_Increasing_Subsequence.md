# 300. Longest Increasing Subsequence

**🔗 Link:** [LeetCode 300](https://leetcode.com/problems/longest-increasing-subsequence/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given an integer array, return the length of its longest strictly increasing subsequence (elements keep their original order but need not be adjacent). The follow-up asks for an `O(n log n)` solution.

* **Example:** `nums = [10,9,2,5,3,7,101,18]` → `4`
* **Constraints:** `1 ≤ nums.length ≤ 2500`; `−10⁴ ≤ nums[i] ≤ 10⁴`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Keep `tails[k]` = the smallest possible tail of an increasing subsequence of length `k+1`. Each number either extends the longest one or replaces the first tail `>=` it (binary search).
* **Core Concept:** Patience sorting — DP with binary search
* **When to Use This Pattern?** Longest chain under an ordering; LeetCode caps `n` at 2500 (O(n²) passes), but the follow-up asks for O(n log n), and with `n` around 10⁵ the quadratic DP is too slow.
* **Mistakes to Avoid:**
  * Thinking `tails` *is* an LIS — only its **length** is meaningful.
  * `bisect_right` instead of `bisect_left` — that computes the longest **non-decreasing** subsequence.

## 🔹 Optimization Path

* **Brute Force:** O(2ⁿ) — every subsequence.
* **Classic DP:** O(n²) — `dp[i] = 1 + max(dp[j])` for `j < i`, `a[j] < a[i]`.
* **Optimized Solution:** O(n log n) — `tails` + `bisect_left`.

## 🔹 Solution Breakdown

* **Optimal Approach:** For each `x`: `i = bisect_left(tails, x)`; if `i == len(tails)` append, else `tails[i] = x`.
* **Why This Works?** `tails` stays sorted. Lowering a tail never hurts — a smaller ending value can only make future extensions easier — so `len(tails)` always equals the best length so far.
* **Edge Cases Considered:**
  * All equal elements → 1.
  * Strictly decreasing → 1.
  * Negative numbers.

## 🔹 Tricks & Patterns Used

* **`bisect_left` → strict increase; `bisect_right` → non-decreasing.**
* LIS length = minimum number of non-increasing piles the array can be split into (Dilworth / patience sorting).

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        def longest(i: int, prev: float) -> int:
            if i == len(nums):
                return 0
            skip = longest(i + 1, prev)
            if nums[i] > prev:  # take nums[i] only if it keeps the run increasing
                return max(skip, 1 + longest(i + 1, nums[i]))
            return skip

        return longest(0, float("-inf"))
```

## 🔹 Code Snippet (Optimized)

```python
from bisect import bisect_left
from typing import List


class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        tails = []  # tails[k]: smallest tail of an increasing subsequence of length k+1
        for x in nums:
            i = bisect_left(tails, x)
            if i == len(tails):
                tails.append(x)  # x extends the longest subsequence
            else:
                tails[i] = x  # x is a smaller tail for length i+1
        return len(tails)
```
