# 🔹 Problem Name: 684. Redundant Connection (Union-Find, Medium)

**🔗 Link:** [LeetCode 684](https://leetcode.com/problems/redundant-connection/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Add edges one by one with Union-Find. The first edge whose endpoints are already connected closes the cycle — return it.
* **Core Concept:** Disjoint Set Union (DSU) with path compression + union by size
* **When to Use This Pattern?** Dynamic connectivity: "are these connected?", "how many groups?", detecting cycles while edges are added, Kruskal's MST.
* **Mistakes to Avoid:**
  * DFS from scratch for every edge — O(n²).
  * Skipping path compression / union by size — degenerate trees make `find` O(n).

## 🔹 Optimization Path

* **Brute Force:** For each edge (from the end), remove it and test if the rest is a tree — O(n²).
* **Optimized Solution:** O(n · α(n)) ≈ O(n).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `union(u, v)` returns False if `find(u) == find(v)`; that edge is the answer.
* **Why This Works?** The graph is a tree plus one edge, so there is exactly one cycle. Processing in input order, the edge that closes it is the cycle edge appearing last in the input — exactly what the problem asks for.
* **Edge Cases Considered:**
  * Extra edge forms a triangle with the first two edges.
  * Extra edge is the last in the list.

## 🔹 Tricks & Patterns Used

* **Path halving:** `parent[x] = parent[parent[x]]` during `find` — iterative, no recursion.
* **Union by size:** attach the smaller tree under the larger.

## 🔹 Alternative Data Structures

* DFS cycle detection after building the graph — O(n), but more code.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · α(n))
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def findRedundantConnection(self, edges: List[List[int]]) -> List[int]:
        n = len(edges)
        for skip in range(n - 1, -1, -1):  # try removing the latest edge first
            graph = [[] for _ in range(n + 1)]
            for i, (u, v) in enumerate(edges):
                if i != skip:
                    graph[u].append(v)
                    graph[v].append(u)

            seen = {1}
            stack = [1]
            while stack:
                node = stack.pop()
                for nxt in graph[node]:
                    if nxt not in seen:
                        seen.add(nxt)
                        stack.append(nxt)
            if len(seen) == n:  # still connected with n - 1 edges, so it is a tree
                return edges[skip]
        return []
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class DSU:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x: int) -> int:
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]  # path halving
            x = self.parent[x]
        return x

    def union(self, a: int, b: int) -> bool:
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False  # already connected
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        return True


class Solution:
    def findRedundantConnection(self, edges: List[List[int]]) -> List[int]:
        dsu = DSU(len(edges) + 1)  # nodes are 1..n
        for u, v in edges:
            if not dsu.union(u, v):
                return [u, v]
        return []
```
