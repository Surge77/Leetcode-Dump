# 🔹 Problem Name: 32. Longest Valid Parentheses (Stack of Indices, Hard)

**🔗 Link:** [LeetCode 32](https://leetcode.com/problems/longest-valid-parentheses/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Stack of indices with a base sentinel.** Push `-1` first. For `(` push its index. For `)` pop; if the stack is now empty, this `)` is unmatched, so push its index as the new base; otherwise the valid run ends here and has length `i - stack[-1]`.
* **Core Concept:** the index left on top of the stack is the last position that is **not** part of the current valid run
* **When to Use This Pattern?** Longest/maximum balanced stretch rather than just a yes/no validity (20) — you need positions, not just matching.
* **Mistakes to Avoid:**
  * Storing characters instead of indices — lengths cannot be computed from them.
  * Forgetting the `-1` sentinel, which makes a run that starts at index `0` come out one short.
  * Taking `max` only when popping to empty; every successful match must update the answer.
  * Recursion for this one: depth up to 3·10⁴ — keep it iterative.

## 🔹 Optimization Path

* **Brute Force:** from every start index, scan forward keeping a balance; stop when it goes negative, and record the length whenever it hits `0` — O(n²).
* **Optimized Solution:** single pass with an index stack — O(n).
* **Further Improvements Possible?** Two passes (left→right then right→left) with two counters achieve O(1) space; a DP array `dp[i]` = longest valid ending at `i` is the third classic option.

## 🔹 Solution Breakdown

* **Optimal Approach:** `stack = [-1]`. On `(`: push `i`. On `)`: `stack.pop()`; if empty push `i`, else `best = max(best, i - stack[-1])`.
* **Why This Works?** After popping a match, the new top is the index just before the earliest still-open position of the current valid chain, so `i - top` is the full length of the contiguous valid substring ending at `i`. An unmatched `)` can never be inside a valid substring, so it becomes the new boundary.
* **Edge Cases Considered:**
  * Empty string → `0`.
  * `"(()"` → `2` (the leading `(` stays unmatched).
  * `")()())"` → `4`.
  * Concatenated valid blocks, e.g. `"()(())"`, are merged automatically because the stack top stays at the base.

## 🔹 Tricks & Patterns Used

* **Sentinel `-1`** as the left boundary of the first run.
* **Reset the base** to the index of every unmatched `)`.

## 🔹 Alternative Data Structures

* **Two counters, two passes:** scan left→right resetting when `close > open`, record `2 * close` when equal; repeat right→left with reversed roles. O(1) space.
* **DP:** `dp[i]` = length of the longest valid substring ending at `i`; extend through `dp[i - 1]` and `dp[i - dp[i - 1] - 2]`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n) for the stack

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        best = 0
        for start in range(len(s)):
            balance = 0
            for end in range(start, len(s)):
                balance += 1 if s[end] == "(" else -1
                if balance < 0:
                    break
                if balance == 0:
                    best = max(best, end - start + 1)
        return best
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        stack = [-1]  # index just before the current candidate run
        best = 0
        for i, ch in enumerate(s):
            if ch == "(":
                stack.append(i)
                continue
            stack.pop()
            if stack:
                best = max(best, i - stack[-1])
            else:
                stack.append(i)  # unmatched ')': nothing before it can be reused
        return best
```
