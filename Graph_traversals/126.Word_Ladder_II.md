# 🔹 Problem Name: 126. Word Ladder II (BFS + Backtracking, Hard)

**🔗 Link:** [LeetCode 126](https://leetcode.com/problems/word-ladder-ii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Layered BFS, then backtrack.** BFS from `beginWord` one level at a time; every word found on the next level records **all** its parents on the current level. Stop after the level that contains `endWord`. Each parent link goes from distance `d` to `d + 1`, so following parent links back from `endWord` spells out exactly the shortest ladders — and nothing else.
* **Core Concept:** BFS shortest-path DAG (all parents per node) + enumerate its paths
* **When to Use This Pattern?** "Return **all** shortest paths" or "count shortest paths" on an unweighted graph — word ladders, all shortest routes in a grid; with weights it becomes Dijkstra + parent lists (1976).
* **Mistakes to Avoid:**
  * Removing a word from `unvisited` the moment it is first reached: a second parent on the same level is then lost and ladders go missing. Remove the whole next level only after the current level is done.
  * Keeping whole paths in the BFS queue: memory explodes with partial paths that never reach `endWord`.
  * Continuing BFS past the level of `endWord` — longer ladders are not wanted.

## 🔹 Optimization Path

* **Brute Force:** DFS over every simple path from `beginWord`, keep the shortest ones ending at `endWord` — exponential.
* **Optimized Solution:** layered BFS storing parents, then backtrack from `endWord` — O(N · 26 · L²) + O(P · K) for P ladders of K words.
* **Further Improvements Possible?** Bidirectional BFS explores less of a big dictionary. The output itself can be exponential, so nothing beats O(output).

## 🔹 Solution Breakdown

* **Optimal Approach:** `unvisited = set(wordList) − {beginWord}`. For each word of the level, try all `26 · L` one-letter changes; a candidate in `unvisited` joins `next_level` and gets the word appended to `parents[candidate]`. After the level: `unvisited -= next_level`. Once `endWord` is reached, DFS from `endWord` along `parents` to `beginWord` and reverse each path.
* **Why This Works?** BFS gives each word its distance `d`, and its recorded parents are exactly its neighbours at distance `d − 1`. So every parent chain from `endWord` has the shortest length, and every shortest ladder is such a chain. Every recorded parent is itself reachable from `beginWord`, so the backtracking never hits a dead end — its work is proportional to the output.
* **Edge Cases Considered:**
  * `endWord` not in `wordList` → `[]`.
  * `beginWord` inside `wordList` — taken out of `unvisited` so it is never its own descendant.
  * `endWord` unreachable → a level comes out empty → `[]`.

## 🔹 Tricks & Patterns Used

* **Mark visited per level, not per node:** lets a node collect every parent at the same distance.
* **Backtrack from the target:** only words that lie on a shortest ladder are ever visited.

## 🔹 Alternative Data Structures

* Plain BFS for `dist[word]`, then a forward DFS from `beginWord` that only takes `dist + 1` edges — same idea, but it can wander into branches that never reach `endWord`.
* Wildcard buckets (`h*t`, as in 127) instead of trying 26 letters per position.

## 🔹 Complexity Analysis

* **Time Complexity:** O(N · 26 · L²) for the BFS (N ≤ 500 words, each candidate string costs O(L)) + O(P · K) to write P ladders of K words
* **Space Complexity:** O(N · L) for the sets and parent lists, plus the output

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def findLadders(self, beginWord: str, endWord: str, wordList: List[str]) -> List[List[str]]:
        def one_apart(a: str, b: str) -> bool:
            return sum(x != y for x, y in zip(a, b)) == 1

        ladders, path, used = [], [beginWord], {beginWord}

        def dfs(word: str) -> None:
            if word == endWord:
                ladders.append(path[:])
                return
            for nxt in wordList:
                if nxt not in used and one_apart(word, nxt):
                    used.add(nxt)
                    path.append(nxt)
                    dfs(nxt)
                    path.pop()
                    used.remove(nxt)

        dfs(beginWord)
        shortest = min(map(len, ladders), default=0)
        return [ladder for ladder in ladders if len(ladder) == shortest]
```

## 🔹 Code Snippet (Optimized)

```python
from collections import defaultdict
from string import ascii_lowercase
from typing import List


class Solution:
    def findLadders(self, beginWord: str, endWord: str, wordList: List[str]) -> List[List[str]]:
        unvisited = set(wordList)
        if endWord not in unvisited:
            return []
        unvisited.discard(beginWord)
        parents = defaultdict(list)
        level = {beginWord}
        while level and endWord not in level:
            next_level = set()
            for word in level:
                for i in range(len(word)):
                    for ch in ascii_lowercase:
                        cand = word[:i] + ch + word[i + 1:]
                        if cand in unvisited:
                            next_level.add(cand)
                            parents[cand].append(word)
            unvisited -= next_level  # only now, so every same-level parent got recorded
            level = next_level
        if endWord not in level:
            return []

        ladders, path = [], [endWord]

        def backtrack(word: str) -> None:
            # depth ≤ ladder length ≤ len(wordList) + 1 = 501, under Python's default limit
            if word == beginWord:
                ladders.append(path[::-1])
                return
            for parent in parents[word]:
                path.append(parent)
                backtrack(parent)
                path.pop()

        backtrack(endWord)
        return ladders
```
