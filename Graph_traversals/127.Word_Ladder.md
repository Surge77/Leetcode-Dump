# 🔹 Problem Name: 127. Word Ladder (BFS on Implicit Graph, Hard)

**🔗 Link:** [LeetCode 127](https://leetcode.com/problems/word-ladder/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Words are nodes; an edge joins words differing in one letter. BFS from `beginWord` gives the shortest transformation. Build neighbours through wildcard buckets: `h*t` groups `hot`, `hit`, `hat`.
* **Core Concept:** BFS on an implicit graph + pattern bucketing
* **When to Use This Pattern?** Shortest number of single-step transformations: gene mutations, lock combinations (752), state puzzles.
* **Mistakes to Avoid:**
  * Comparing every pair of words — O(n² · L) to build the graph.
  * Answer counts **words** in the sequence, not edges (`edges + 1`).
  * Not clearing a bucket after use — the same bucket gets scanned again and again.

## 🔹 Optimization Path

* **Brute Force:** O(n² · L) pairwise graph + BFS.
* **Optimized Solution:** O(n · L²) with wildcard buckets.
* **Further Improvements Possible?** Bidirectional BFS — explores far fewer nodes on big dictionaries.

## 🔹 Solution Breakdown

* **Optimal Approach:** `buckets[pattern]` = words matching it. BFS: for each word and each position, visit every word in that bucket, then empty the bucket.
* **Why This Works?** All edges have weight 1, so BFS order = shortest distance. Emptying a bucket is safe because everyone in it was reached at the current (minimal) distance.
* **Edge Cases Considered:**
  * `endWord` not in the list → 0.
  * `beginWord` not in the list (allowed).

## 🔹 Pattern Recognition

* **Belongs To:** Graph Traversal — BFS (implicit graph)
* **Common Problems Using This:**
  * 433. Minimum Genetic Mutation
  * 752. Open the Lock
  * 126. Word Ladder II (all shortest paths)

## 🔹 Tricks & Patterns Used

* **Wildcard keys** `w[:i] + '*' + w[i+1:]` instead of pairwise comparisons.
* **Empty bucket after use** → each bucket is scanned once.

## 🔹 Alternative Data Structures

* Generate neighbours by trying all 26 letters per position and checking a set — O(n · 26 · L²), simpler, a bit slower.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · L²)
* **Space Complexity:** O(n · L²)

## 🔹 Code Snippet (Optimized)

```python
from collections import defaultdict, deque
from typing import List


class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        if endWord not in wordList:
            return 0
        L = len(beginWord)
        buckets = defaultdict(list)
        for w in wordList:
            for i in range(L):
                buckets[w[:i] + "*" + w[i + 1:]].append(w)

        seen = {beginWord}
        q = deque([(beginWord, 1)])  # (word, words in the sequence so far)
        while q:
            word, length = q.popleft()
            if word == endWord:
                return length
            for i in range(L):
                key = word[:i] + "*" + word[i + 1:]
                for nxt in buckets[key]:
                    if nxt not in seen:
                        seen.add(nxt)
                        q.append((nxt, length + 1))
                buckets[key] = []  # bucket fully explored
        return 0
```
