# 1044. Longest Duplicate Substring

**🔗 Link:** [LeetCode 1044](https://leetcode.com/problems/longest-duplicate-substring/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given a string, find a substring that appears at least twice (the occurrences may overlap) and has the greatest possible length. Return any one such substring, or the empty string if nothing repeats.

* **Example:** `s = "banana"` → `"ana"`
* **Constraints:** `2 ≤ s.length ≤ 3 · 10⁴`; `s` has only lowercase letters

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** If a duplicate of length `L` exists, one of every shorter length exists too → binary search `L`. For a fixed `L`, slide a polynomial rolling hash over all windows and look for a repeat (confirm by comparing the actual substrings).
* **Core Concept:** Rabin–Karp rolling hash + binary search on the answer
* **When to Use This Pattern?** Comparing many substrings of the same length quickly: repeats, common substrings of two strings, palindrome checks.
* **Mistakes to Avoid:**
  * Trusting a hash match without checking — collisions give wrong answers.
  * Recomputing each window's hash from scratch — O(n · L).

## 🔹 Optimization Path

* **Brute Force:** O(n³) — for each length from `n − 1` down, hash up to `n` slices of up to `n` characters into a set.
* **Optimized Solution:** O(n log n) expected.
* **Further Improvements Possible?** Suffix array + LCP array gives O(n log n) deterministic.

## 🔹 Solution Breakdown

* **Optimal Approach:** `h(i+1) = h(i) · B - s[i] · B^L + s[i+L]` (mod a large prime). Store start positions per hash; on a hash hit, compare substrings.
* **Why This Works?** Monotonicity (a duplicate of length `L` contains duplicates of every shorter length) makes binary search valid; the rolling update turns each window's hash into O(1).
* **Edge Cases Considered:**
  * No repeated character → `""`.
  * Overlapping occurrences (`"aaaa"` → `"aaa"`).

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def longestDupSubstring(self, s: str) -> str:
        n = len(s)
        for length in range(n - 1, 0, -1):
            seen = set()
            for i in range(n - length + 1):
                sub = s[i:i + length]
                if sub in seen:
                    return sub
                seen.add(sub)
        return ""
```

## 🔹 Code Snippet (Optimized)

```python
MOD = (1 << 61) - 1
BASE = 131


class Solution:
    def longestDupSubstring(self, s: str) -> str:
        n = len(s)
        vals = [ord(c) for c in s]

        def repeat_start(length: int) -> int:
            """Start of a second occurrence of some repeated substring of this length, or -1."""
            power = pow(BASE, length, MOD)
            h = 0
            for i in range(length):
                h = (h * BASE + vals[i]) % MOD
            seen = {h: [0]}
            for i in range(1, n - length + 1):
                h = (h * BASE - vals[i - 1] * power + vals[i + length - 1]) % MOD
                for j in seen.get(h, ()):
                    if s[j:j + length] == s[i:i + length]:  # rule out collisions
                        return i
                seen.setdefault(h, []).append(i)
            return -1

        best, lo, hi = "", 1, n - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            start = repeat_start(mid)
            if start != -1:
                best, lo = s[start:start + mid], mid + 1
            else:
                hi = mid - 1
        return best
```
