# 🔹 Problem Name: 198. House Robber (Dynamic Programming, Medium)

**🔗 Link:** [LeetCode 198](https://leetcode.com/problems/house-robber/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** At each house choose: skip it (keep the best up to `i-1`) or rob it (best up to `i-2` + `nums[i]`).
* **Core Concept:** 1D DP / Fibonacci-style recurrence
* **When to Use This Pattern?** "Pick elements to maximise a sum, no two adjacent" — any take/skip choice that depends only on the last one or two decisions.
* **Mistakes to Avoid:**
  * Greedily taking all odd or all even indices (fails on `[2, 1, 1, 2]`, answer 4).
  * Forgetting the single-house case.

## 🔹 Optimization Path

* **Brute Force:** O(2ⁿ) — try every non-adjacent subset.
* **Optimized Solution:** O(n) time, O(1) space — two rolling variables.
* **Further Improvements Possible?** No; every house must be read once.

## 🔹 Solution Breakdown

* **Optimal Approach:** `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`, kept in two variables.
* **Why This Works?** The best plan for the first `i` houses either excludes house `i` (then it equals the best plan for `i-1`) or includes it (then house `i-1` is excluded, leaving the best plan for `i-2`).
* **Edge Cases Considered:**
  * One house.
  * All zeros.
  * Alternating large/small values.

## 🔹 Pattern Recognition

* **Belongs To:** DP — Fibonacci numbers / take-or-skip
* **Common Problems Using This:**
  * 213. House Robber II (circular: solve twice, excluding the first or the last house)
  * 740. Delete and Earn (bucket values, then house robber)
  * 2140. Solving Questions With Brainpower

## 🔹 Tricks & Patterns Used

* **Dynamic Programming Recurrence:** `take = prev2 + x`, `skip = prev1`.
* **Space compression:** only the last two states are ever read.

## 🔹 Alternative Data Structures

* A full `dp` array is clearer when you must reconstruct *which* houses were robbed (walk back from the end).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        prev2, prev1 = 0, 0  # best total up to i-2, best total up to i-1
        for x in nums:
            prev2, prev1 = prev1, max(prev1, prev2 + x)
        return prev1
```
