# 🔹 Problem Name: 1207. Unique Number of Occurrences (Hash Map Counting, Easy)

**🔗 Link:** [LeetCode 1207](https://leetcode.com/problems/unique-number-of-occurrences/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Count, then check for duplicates in the counts.** Build `value → frequency`, then ask whether the frequencies are all different: `len(set(freqs)) == len(freqs)`.
* **Core Concept:** a frequency table of a frequency table
* **When to Use This Pattern?** Any "are the counts distinct / equal / matching" question — anagram checks, "close strings", majority checks.
* **Mistakes to Avoid:**
  * Comparing the *values* to each other instead of their counts.
  * Calling `arr.count(x)` for every element — it works but is O(n²) (the brute force below).

## 🔹 Optimization Path

* **Brute Force:** for every distinct value call `arr.count(value)`, then compare the counts — O(n²).
* **Optimized Solution:** one `Counter` pass, then a set of its values — O(n).
* **Further Improvements Possible?** Values lie in `[-1000, 1000]`, so a fixed array of 2001 counters works too. The asymptotics stay O(n).

## 🔹 Solution Breakdown

* **Optimal Approach:** `counts = Counter(arr).values()`; answer is `len(set(counts)) == len(counts)`.
* **Why This Works?** A set drops duplicates, so it is smaller than the list of counts exactly when two different values share the same count.
* **Edge Cases Considered:**
  * A single distinct value → one count → `True`.
  * `[1, 2]` → both occur once → `False`.
  * Negative numbers are ordinary hash keys.

## 🔹 Alternative Data Structures

* Sort the counts and compare neighbours.
* A boolean array `seen[count]` — counts are at most `len(arr) <= 1000`, so it needs 1001 slots.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(k), k = number of distinct values (at most 2001 here)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def uniqueOccurrences(self, arr: List[int]) -> bool:
        counts = [arr.count(value) for value in set(arr)]
        for i in range(len(counts)):
            for j in range(i + 1, len(counts)):
                if counts[i] == counts[j]:
                    return False
        return True
```

## 🔹 Code Snippet (Optimized)

```python
from collections import Counter
from typing import List


class Solution:
    def uniqueOccurrences(self, arr: List[int]) -> bool:
        counts = Counter(arr).values()
        return len(set(counts)) == len(counts)
```
