# 🔹 Problem Name: 139. Word Break (Dynamic Programming, Medium)

**🔗 Link:** [LeetCode 139](https://leetcode.com/problems/word-break/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given a string `s` and a list of dictionary words, decide whether `s` can be written as a sequence of one or more dictionary words joined with no gaps. Each dictionary word may be used any number of times. Return `true` or `false`.

* **Example:** `s = "leetcode", wordDict = ["leet","code"]` → `true`
* **Constraints:** `1 ≤ s.length ≤ 300`, `1 ≤ wordDict.length ≤ 1000`, `1 ≤ wordDict[i].length ≤ 20`, lowercase letters, all dictionary words unique

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** `dp[i]` = can the prefix `s[:i]` be split into dictionary words? Try every last word ending at `i`.
* **Core Concept:** 1D DP over prefixes (string partition DP)
* **When to Use This Pattern?** "Can the string be cut into valid pieces?" / "how many ways to cut it?" / "minimum cuts".
* **Mistakes to Avoid:**
  * Plain recursion without memo — exponential on inputs like `"aaaa…ab"`.
  * Using a list for the dictionary (O(m) lookups) instead of a set.

## 🔹 Optimization Path

* **Brute Force:** O(2ⁿ) — try every set of cut positions.
* **Optimized Solution:** O(n · L²) — for each end `i`, try only start points within the longest word length `L` (slice + hash costs O(L)).
* **Further Improvements Possible?** A Trie walked forward from every `j` with `dp[j] = True` avoids re-hashing slices.

## 🔹 Solution Breakdown

* **Optimal Approach:** `dp[0] = True`; `dp[i] = True` if some `j` has `dp[j]` and `s[j:i]` in the dictionary.
* **Why This Works?** Any valid split of `s[:i]` ends with some word `s[j:i]`; what remains, `s[:j]`, must itself be splittable.
* **Edge Cases Considered:**
  * The whole string is one word.
  * Words that are prefixes of each other (`"cat"`, `"cats"`).
  * No valid split at all.

## 🔹 Pattern Recognition

* **Belongs To:** DP on prefixes / partition DP
* **Common Problems Using This:**
  * 140. Word Break II (return all sentences — DFS + memo)
  * 132. Palindrome Partitioning II (minimum cuts) (in this repo)
  * 91. Decode Ways (count splits) (in this repo)

## 🔹 Tricks & Patterns Used

* **Bound the inner loop** by the longest word length — turns O(n²) start points into O(n·L).
* **Early `break`** once `dp[i]` becomes True.

## 🔹 Alternative Data Structures

* **Trie** instead of a hash set: walk characters forward from each reachable index; stops as soon as no word continues.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · L²), L = longest word length
* **Space Complexity:** O(n + total dictionary size)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)

        def can_split(start):  # plain recursion, no memo: tries every set of cuts
            if start == len(s):
                return True
            for end in range(start + 1, len(s) + 1):
                if s[start:end] in words and can_split(end):
                    return True
            return False

        return can_split(0)
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)
        max_len = max(map(len, words))
        n = len(s)
        dp = [False] * (n + 1)  # dp[i]: s[:i] can be segmented
        dp[0] = True
        for i in range(1, n + 1):
            for j in range(max(0, i - max_len), i):
                if dp[j] and s[j:i] in words:
                    dp[i] = True
                    break
        return dp[n]
```
