# 🔹 Problem Name: 1466. Reorder Routes to Make All Paths Lead to the City Zero (Tree BFS, Medium)

**🔗 Link:** [LeetCode 1466](https://leetcode.com/problems/reorder-routes-to-make-all-paths-lead-to-the-city-zero/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Traverse the undirected tree from 0 and count edges pointing away.** Store every road in both directions, tagging the real direction (cost 1 if it points away from the visited side, cost 0 if it points toward it). BFS from city 0; the sum of the costs of the tree edges used is the answer.
* **Core Concept:** `n` cities and `n − 1` roads form a tree, so each road is crossed exactly once when exploring from 0
* **When to Use This Pattern?** Orienting or counting edges relative to a root in a tree given as a directed edge list.
* **Mistakes to Avoid:**
  * Adding edges only in their given direction: from city 0 nothing is reachable.
  * Recursive DFS on a path of 5·10⁴ cities — recursion-limit crash; use BFS.
  * Counting edges `a → b` with `a` "closer" to 0 incorrectly: an edge is **wrong** when it leads away from 0 (we reach `b` from `a` along the edge direction).

## 🔹 Optimization Path

* **Brute Force:** for each road `(a, b)` run a BFS from 0 in the undirected graph **without** that road; if `a` is reachable, 0 lies on `a`'s side, so the road points away from 0 and must be reversed — O(n²).
* **Optimized Solution:** one BFS with signed adjacency — O(n).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `adj[a].append((b, 1))` (original direction `a → b`, leaving `a`) and `adj[b].append((a, 0))`. BFS from 0: moving along an entry with flag 1 means the road points away from 0, so add 1.
* **Why This Works?** Every road is a tree edge, and BFS from 0 crosses each exactly once from the side nearer to 0 to the farther one. A road needs reversing iff its direction goes from near to far, which is exactly the flagged traversal.
* **Edge Cases Considered:**
  * All roads already point to 0 → `0`.
  * `n = 2` → `0` or `1`.
  * Deep paths — handled iteratively.

## 🔹 Tricks & Patterns Used

* **Bidirectional adjacency with a direction flag** — reuse the traversal as the counter.
* **BFS visited via the `seen` array**, which also prevents walking back to the parent.

## 🔹 Alternative Data Structures

* Recursive DFS with `sys.setrecursionlimit` — fine on small trees, fragile at 5·10⁴ depth.
* Set of directed edges: a BFS over undirected neighbours counts a road iff `(parent, child)` is in the set.

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from collections import deque
from typing import List


class Solution:
    def minReorder(self, n: int, connections: List[List[int]]) -> int:
        adj = [[] for _ in range(n)]
        for a, b in connections:
            adj[a].append(b)
            adj[b].append(a)

        def reaches_without(a: int, b: int, target: int) -> bool:
            seen = {0}
            queue = deque([0])
            while queue:
                v = queue.popleft()
                if v == target:
                    return True
                for w in adj[v]:
                    if {v, w} != {a, b} and w not in seen:
                        seen.add(w)
                        queue.append(w)
            return False

        # a -> b needs reversing when 0 is on a's side of the road
        return sum(1 for a, b in connections if reaches_without(a, b, a))
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def minReorder(self, n: int, connections: List[List[int]]) -> int:
        adj = [[] for _ in range(n)]
        for a, b in connections:
            adj[a].append((b, 1))  # real direction a -> b: leaving a means pointing away from 0
            adj[b].append((a, 0))
        seen = [False] * n
        seen[0] = True
        queue = deque([0])
        reversals = 0
        while queue:
            v = queue.popleft()
            for w, points_away in adj[v]:
                if not seen[w]:
                    seen[w] = True
                    reversals += points_away
                    queue.append(w)
        return reversals
```
