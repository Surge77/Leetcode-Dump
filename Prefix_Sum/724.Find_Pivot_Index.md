# 724. Find Pivot Index

**🔗 Link:** [LeetCode 724](https://leetcode.com/problems/find-pivot-index/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Find the leftmost index whose strict left-side sum equals its strict right-side sum (the element itself is in neither; an empty side sums to `0`). Return `-1` if no index qualifies.

* **Example:** `nums = [1,7,3,6,5,6]` → `3`
* **Constraints:** `1 ≤ nums.length ≤ 10^4`, `-1000 ≤ nums[i] ≤ 1000`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Running left sum against `total - left - nums[i]`.** Compute the total once; while scanning, `left` is the sum of everything before `i`. Index `i` is a pivot when `left == total - left - nums[i]`.
* **Core Concept:** the right sum is derived from the total, so no second array is needed
* **When to Use This Pattern?** "Split / balance point" questions where one side's sum determines the other's.
* **Mistakes to Avoid:**
  * Excluding the pivot from only one side — the element at `i` belongs to **neither** sum.
  * Returning any pivot: the problem wants the **leftmost**, so return on the first match.
  * Assuming positive values: negatives are allowed, so you cannot stop early once `left` exceeds the right.

## 🔹 Optimization Path

* **Brute Force:** for every index, sum the left slice and the right slice — O(n²).
* **Optimized Solution:** one pass with a running `left` — O(n).
* **Further Improvements Possible?** No; reading the array once is a lower bound.

## 🔹 Solution Breakdown

* **Optimal Approach:** `total = sum(nums)`, `left = 0`. For each `i`: if `left == total - left - nums[i]` return `i`; else `left += nums[i]`. Return `-1`.
* **Why This Works?** `total - left - nums[i]` is the sum of everything after `i`. Updating `left` after the check keeps it equal to the sum of `nums[0..i-1]` at every comparison.
* **Edge Cases Considered:**
  * Pivot at index `0` → left sum is `0`, so the rest must sum to `0` (`[2, 1, -1]` → `0`).
  * Pivot at the last index → right sum is `0`.
  * Several pivots (e.g. all zeros) → the leftmost is returned.
  * No pivot → `-1`.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def pivotIndex(self, nums: List[int]) -> int:
        for i in range(len(nums)):
            if sum(nums[:i]) == sum(nums[i + 1:]):
                return i
        return -1
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def pivotIndex(self, nums: List[int]) -> int:
        total = sum(nums)
        left = 0
        for i, value in enumerate(nums):
            if left == total - left - value:  # the pivot itself belongs to neither side
                return i
            left += value
        return -1
```
