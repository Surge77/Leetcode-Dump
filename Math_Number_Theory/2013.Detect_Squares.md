# 🔹 Problem Name: 2013. Detect Squares (Hash Map Counting, Medium)

**🔗 Link:** [LeetCode 2013](https://leetcode.com/problems/detect-squares/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Fix the diagonal.** For a query point `(x, y)`, the opposite corner `(px, py)` of an axis-aligned square must satisfy `|px − x| = |py − y| > 0`. Iterate over the distinct stored points as that diagonal corner; the other two corners `(x, py)` and `(px, y)` are then forced, so multiply the three stored counts.
* **Core Concept:** one free choice determines the whole shape — enumerate it and look the rest up in a counter
* **When to Use This Pattern?** Counting rectangles/squares/triangles from a multiset of points where some corners pin down the others.
* **Mistakes to Avoid:**
  * Counting zero-area "squares" — skip diagonals with `px == x` (which also covers `py == y` once `|dx| = |dy|` is required).
  * Ignoring duplicates: added points are a multiset, so the answer is `cnt[diag] · cnt[(x, py)] · cnt[(px, y)]`, not 1 per match.
  * Adding the query point to the structure — `count` must not store it.

## 🔹 Optimization Path

* **Brute Force:** keep a list of every added point; for each stored point as diagonal, scan the list twice to count the other two corners — O(n²) per `count`.
* **Optimized Solution:** `Counter` of points; per `count`, iterate distinct points and do O(1) lookups — O(D) per `count`, O(1) per `add`.
* **Further Improvements Possible?** Group by x (`x → Counter(y)`): iterate only points on the query's column, choose the side length from `py`, and look up the two corners at `x ± side` — O(points sharing the column) per `count`.

## 🔹 Solution Breakdown

* **Optimal Approach:** `add`: `cnt[(x, y)] += 1`. `count(x, y)`: for each `(px, py), c` in `cnt`: if `abs(px − x) == abs(py − y) != 0`, add `c * cnt[(x, py)] * cnt[(px, y)]` (read with `.get` so no keys are created).
* **Why This Works?** In an axis-aligned square, the query point and its diagonal opposite differ by the same nonzero amount in x and y; the remaining corners share x with one and y with the other. Each square containing the query point has exactly one diagonal corner, so every square is counted once, and the product counts every choice of duplicate copies.
* **Edge Cases Considered:**
  * Stored copies of the query point itself — skipped as a diagonal (zero area) and never one of the other two corners, which differ from the query in x or in y.
  * Duplicate points multiply the count (official example: adding `[11, 2]` twice doubles the answer).

## 🔹 Tricks & Patterns Used

* **Enumerate the most constraining corner:** once the diagonal is fixed, the square is determined.
* **`.get` instead of `cnt[key]`:** indexing a `Counter` does not insert, but a `defaultdict` would — avoid growing the map during iteration.

## 🔹 Alternative Data Structures

* `defaultdict(Counter)` keyed by x — faster in practice when points spread over many columns.
* 1001 × 1001 count grid (coordinates are in `[0, 1000]`) — O(1) lookups with no hashing.

## 🔹 Complexity Analysis

* **Time Complexity:** `add` O(1); `count` O(D), D = distinct points (≤ 3000 calls total)
* **Space Complexity:** O(D)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class DetectSquares:

    def __init__(self):
        self.points = []

    def add(self, point: List[int]) -> None:
        self.points.append((point[0], point[1]))

    def count(self, point: List[int]) -> int:
        x, y = point
        total = 0
        for px, py in self.points:
            if abs(px - x) != abs(py - y) or px == x:
                continue
            total += self.points.count((x, py)) * self.points.count((px, y))
        return total
```

## 🔹 Code Snippet (Optimized)

```python
from collections import Counter
from typing import List


class DetectSquares:

    def __init__(self):
        self.cnt = Counter()

    def add(self, point: List[int]) -> None:
        self.cnt[(point[0], point[1])] += 1

    def count(self, point: List[int]) -> int:
        x, y = point
        total = 0
        for (px, py), c in self.cnt.items():
            if abs(px - x) != abs(py - y) or px == x:
                continue
            total += c * self.cnt.get((x, py), 0) * self.cnt.get((px, y), 0)
        return total
```
