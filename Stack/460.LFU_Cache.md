# 🔹 Problem Name: 460. LFU Cache (Hash Map Design, Hard)

**🔗 Link:** [LeetCode 460](https://leetcode.com/problems/lfu-cache/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Design a cache with a fixed capacity supporting `get(key)` (value or `-1`) and `put(key, value)`. When full, a `put` of a new key evicts the least frequently used key (use count rises on every `get`/`put` of a key); ties go to the least recently used. Both operations must run in O(1) average time.

* **Example:** `LFUCache(2)`; `put(1,1)`, `put(2,2)`, `get(1)`, `put(3,3)`, `get(2)`, `get(3)`, `put(4,4)`, `get(1)`, `get(3)`, `get(4)` → `[null,null,null,1,null,-1,3,null,-1,3,4]`
* **Constraints:** `1 ≤ capacity ≤ 10^4`, `0 ≤ key ≤ 10^5`, `0 ≤ value ≤ 10^9`, at most `2·10^5` calls

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Frequency buckets of LRU lists.** `vals[key] = (value, freq)`; `buckets[freq]` is an `OrderedDict` of keys with that frequency in least-recently-used order; `min_freq` tracks the smallest non-empty bucket. A hit moves the key from bucket `f` to the end of bucket `f + 1`. Eviction pops the front of `buckets[min_freq]`. A new key always resets `min_freq = 1`.
* **Core Concept:** LFU = LRU inside every frequency class; `min_freq` only ever moves by +1 on a touch or resets to 1 on insert, so it is O(1) to maintain
* **When to Use This Pattern?** Caches and schedulers that evict by (count, recency); any "group items by a counter that only increments, need the min group fast".
* **Mistakes to Avoid:**
  * Updating an existing key with `put` must also count as a use (frequency +1).
  * Ties on frequency are broken by **least recently used**, not by insertion order.
  * Evict before inserting the new key — otherwise you may evict the newcomer (frequency 1).
  * Bumping `min_freq` only when the emptied bucket was the minimum.

## 🔹 Optimization Path

* **Brute Force:** store `(value, freq, last_used)` per key and scan all keys for the minimum `(freq, last_used)` on eviction — O(capacity) per `put`.
* **Optimized Solution:** hash map + frequency buckets of ordered dicts — O(1) per operation.
* **Further Improvements Possible?** No asymptotically. A hand-written doubly linked list per bucket is the language-agnostic version.

## 🔹 Solution Breakdown

* **Optimal Approach:** `_touch(key)` removes the key from `buckets[f]` (deleting the bucket if empty and bumping `min_freq` if it was `f`) and appends it to `buckets[f + 1]`. `get` = touch + return. `put` on an existing key = overwrite value + touch; on a new key = evict front of `buckets[min_freq]` if full, insert into `buckets[1]`, `min_freq = 1`.
* **Why This Works?** Within a bucket, keys are appended when they reach that frequency — i.e. at their most recent use — so the front is the LRU key of that frequency. `min_freq` is correct because a touch moves exactly one key from `f` to `f + 1`, so if bucket `f = min_freq` empties, `f + 1` is non-empty.
* **Edge Cases Considered:**
  * Capacity 1 — every new key evicts the old one.
  * `put` on an existing key while full — no eviction.
  * Capacity 0 (older versions of the problem; now `capacity ≥ 1`) — `put` is a no-op.

## 🔹 Tricks & Patterns Used

* **`OrderedDict.popitem(last=False)`** pops the LRU entry in O(1); appending a key puts it at the MRU end.
* **`defaultdict(OrderedDict)`** creates buckets on demand.

## 🔹 Alternative Data Structures

* Heap of `(freq, time, key)` with lazy deletion — O(log n) per operation.
* Doubly linked list of frequency nodes, each holding a doubly linked list of keys — the classic O(1) layout in Java/C++.

## 🔹 Complexity Analysis

* **Time Complexity:** O(1) average per `get` / `put`
* **Space Complexity:** O(capacity)

## 🔹 Code Snippet (Brute Force)

```python
class LFUCache:

    def __init__(self, capacity: int):
        self.capacity = capacity
        self.data = {}  # key -> [value, freq, last_used]
        self.tick = 0

    def get(self, key: int) -> int:
        if key not in self.data:
            return -1
        self.tick += 1
        entry = self.data[key]
        entry[1] += 1
        entry[2] = self.tick
        return entry[0]

    def put(self, key: int, value: int) -> None:
        if self.capacity == 0:
            return
        self.tick += 1
        if key in self.data:
            entry = self.data[key]
            entry[0] = value
            entry[1] += 1
            entry[2] = self.tick
            return
        if len(self.data) == self.capacity:
            victim = min(self.data, key=lambda k: (self.data[k][1], self.data[k][2]))
            del self.data[victim]
        self.data[key] = [value, 1, self.tick]
```

## 🔹 Code Snippet (Optimized)

```python
from collections import OrderedDict, defaultdict


class LFUCache:

    def __init__(self, capacity: int):
        self.capacity = capacity
        self.vals = {}  # key -> (value, freq)
        self.buckets = defaultdict(OrderedDict)  # freq -> keys, least recently used first
        self.min_freq = 0

    def _touch(self, key: int) -> None:
        value, freq = self.vals[key]
        bucket = self.buckets[freq]
        del bucket[key]
        if not bucket:
            del self.buckets[freq]
            if self.min_freq == freq:  # the key just moved to freq + 1, so that bucket exists
                self.min_freq += 1
        self.vals[key] = (value, freq + 1)
        self.buckets[freq + 1][key] = None

    def get(self, key: int) -> int:
        if key not in self.vals:
            return -1
        self._touch(key)
        return self.vals[key][0]

    def put(self, key: int, value: int) -> None:
        if self.capacity == 0:
            return
        if key in self.vals:
            self.vals[key] = (value, self.vals[key][1])
            self._touch(key)
            return
        if len(self.vals) == self.capacity:
            bucket = self.buckets[self.min_freq]
            victim, _ = bucket.popitem(last=False)
            if not bucket:
                del self.buckets[self.min_freq]
            del self.vals[victim]
        self.vals[key] = (value, 1)
        self.buckets[1][key] = None
        self.min_freq = 1
```
