## 🔹 Problem Statement

Design `encode` and `decode` for a list of strings: `encode` turns the list into one single string, and `decode` must rebuild exactly the original list from that string. The strings can contain any characters, so no separator is safe by itself. *(premium — paraphrased from memory, not checked against the official page)*

* **Example:** `["Hello","World"]` → `["Hello","World"]` (decode(encode(strs)) returns the same list)
* **Constraints:** `1 ≤ strs.length ≤ 200`; `0 ≤ strs[i].length ≤ 200`; each string may contain any of the 256 ASCII characters

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Length-prefix framing.** Encode each string as `<length>#<string>`. To decode, read digits up to the next `#`, then take exactly `length` characters — whatever they contain, including `#` and digits.
* **Core Concept:** a delimiter alone is ambiguous when strings may contain it; a length header tells the decoder where the payload ends without inspecting it
* **When to Use This Pattern?** Serialising a list of arbitrary strings / byte blobs into one string — network protocols (HTTP `Content-Length`, netstrings), serialising trees (297), storing lists in one field.
* **Mistakes to Avoid:**
  * Joining with a "rare" separator such as `","` or `"#"`: strings may contain any of the 256 ASCII characters, so any single delimiter can appear inside a string.
  * Losing the difference between `[]` and `[""]` — both must round-trip (an empty list is outside the stated constraints, but this scheme handles it anyway).
  * Searching for `#` from the start of the whole string each time instead of from the current index.

## 🔹 Optimization Path

* **Brute Force:** write every character as its decimal code, `","`-separated, and start each string with `"#"` — safe because the payload only uses digits and `","`, but it inflates the output ~3–4× and decodes with `int()`/`chr()` per character.
* **Optimized Solution:** length prefix — output is input size + a few header characters per string; O(total length) both ways.
* **Further Improvements Possible?** Fixed-width binary headers (e.g. 4 bytes) avoid scanning for `#`; escaping (`#` → `##`) is another valid scheme.

## 🔹 Solution Breakdown

* **Optimal Approach:** `encode = "".join(f"{len(s)}#{s}" for s in strs)`. Decode with a pointer `i`: `j = s.index("#", i)`, `size = int(s[i:j])`, word = `s[j + 1 : j + 1 + size]`, `i = j + 1 + size`.
* **Why This Works?** The decoder is always at the start of a header, and a header is digits followed by the first `#` after them — the payload is never scanned, so `#` or digits inside a string can't confuse it.
* **Edge Cases Considered:**
  * `[]` → `""` → `[]`; `[""]` → `"0#"` → `[""]`.
  * Strings that look like headers, e.g. `["3#a", "#"]`.

## 🔹 Tricks & Patterns Used

* **Length-prefixed records (netstrings):** the universal fix for "the separator might be inside the data".
* **`str.index(sub, start)`:** continue searching from the current pointer to keep decoding linear.

## 🔹 Alternative Data Structures

* Escaping: replace `/` with `//` inside strings and separate with `/:` — correct but needs a careful character-by-character decoder.
* Character-code encoding (the brute force) — simple to reason about, wasteful in size.

## 🔹 Complexity Analysis

* **Time Complexity:** O(L) for both encode and decode, `L` = total characters
* **Space Complexity:** O(L) for the output

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Codec:
    def encode(self, strs: List[str]) -> str:
        # payload uses only digits and ",", so "#" can safely mark each string's start
        return "".join("#" + ",".join(str(ord(c)) for c in s) for s in strs)

    def decode(self, s: str) -> List[str]:
        if not s:
            return []
        words = []
        for part in s.split("#")[1:]:
            words.append("".join(chr(int(code)) for code in part.split(",")) if part else "")
        return words
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Codec:
    def encode(self, strs: List[str]) -> str:
        return "".join(f"{len(s)}#{s}" for s in strs)

    def decode(self, s: str) -> List[str]:
        words = []
        i = 0
        while i < len(s):
            j = s.index("#", i)  # the header's digits never contain "#"
            size = int(s[i:j])
            words.append(s[j + 1:j + 1 + size])
            i = j + 1 + size
        return words
```
