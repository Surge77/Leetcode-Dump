# 🔹 Problem Name: 37. Sudoku Solver (Constraint Backtracking, Hard)

**🔗 Link:** [LeetCode 37](https://leetcode.com/problems/sudoku-solver/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Backtracking with bitmasks and "most constrained cell first".** Keep one 9-bit mask per row, column and box of the digits already used. At every step pick the empty cell with the **fewest** legal digits (`~(row | col | box)`), try each of them, recurse, undo on failure.
* **Core Concept:** constraint propagation lite — O(1) legality checks plus a choice order that fails fast (0 options) or is forced (1 option)
* **When to Use This Pattern?** Fill a grid / assign values under "all different" constraints — Sudoku, N-Queens, exact cover, map colouring, KenKen.
* **Mistakes to Avoid:**
  * Rescanning the row, column and box for every trial digit: 27 reads per check — fine for easy boards, slow on hard ones.
  * Forgetting to undo the masks (and the cell) when a branch fails.
  * Returning a new board — the method must modify `board` **in place** and return `None`.

## 🔹 Optimization Path

* **Brute Force:** visit cells in row-major order, try `1..9`, check legality by scanning — O(9^m) with an O(27) check, `m` = empty cells.
* **Optimized Solution:** bitmask state + minimum-remaining-values cell choice — same worst case, but the search tree on real puzzles shrinks by orders of magnitude.
* **Further Improvements Possible?** Knuth's Dancing Links (exact cover) or adding "hidden single" propagation; unnecessary at LeetCode's scale.

## 🔹 Solution Breakdown

* **Optimal Approach:** Collect the empty cells. `solve(remaining)` scans the first `remaining` empty cells, swaps the one with the fewest candidates to position `remaining − 1`, and tries each candidate bit (`free & −free` extracts the lowest).
* **Why This Works?** Every digit placement keeps the masks equal to "digits used in this unit", so a candidate is exactly a digit that breaks no rule. The search still tries every legal option of the chosen cell, so it is complete: if a solution exists it is found. Swapping only reorders the unsolved prefix, so the set of cells still to fill is unchanged on backtrack.
* **Edge Cases Considered:**
  * A cell with zero candidates → that branch dies immediately (no deeper work).
  * The input is guaranteed to have exactly one solution, so the first full board found is the answer.

## 🔹 Tricks & Patterns Used

* **Unit masks:** `box = r // 3 * 3 + c // 3`; a digit `d` is the bit `1 << (d − 1)`.
* **Lowest set bit:** `bit = free & −free`, then `free ^= bit` to iterate candidates; `bit.bit_length()` recovers the digit.
* **MRV heuristic:** branch on the cell with the fewest options; stop scanning early once a cell has ≤ 1.

## 🔹 Alternative Data Structures

* Three `9 × 9` boolean arrays (`row_used[r][d]`, …) instead of bitmasks — same idea, slightly slower.
* Dancing Links over the 324-column exact-cover matrix.

## 🔹 Complexity Analysis

* **Time Complexity:** O(9^m) worst case for `m ≤ 81` empty cells (each MRV step costs O(m)); the board is fixed-size, and real puzzles finish in milliseconds.
* **Space Complexity:** O(m) for the empty-cell list and recursion depth (≤ 81).

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def solveSudoku(self, board: List[List[str]]) -> None:
        def legal(r: int, c: int, ch: str) -> bool:
            for i in range(9):
                if board[r][i] == ch or board[i][c] == ch:
                    return False
                if board[r // 3 * 3 + i // 3][c // 3 * 3 + i % 3] == ch:
                    return False
            return True

        def solve(pos: int) -> bool:
            if pos == 81:
                return True
            r, c = divmod(pos, 9)
            if board[r][c] != ".":
                return solve(pos + 1)
            for ch in "123456789":
                if legal(r, c, ch):
                    board[r][c] = ch
                    if solve(pos + 1):
                        return True
            board[r][c] = "."
            return False

        solve(0)
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def solveSudoku(self, board: List[List[str]]) -> None:
        full = 0x1FF
        rows, cols, boxes = [0] * 9, [0] * 9, [0] * 9
        empty = []
        for r in range(9):
            for c in range(9):
                if board[r][c] == ".":
                    empty.append((r, c))
                    continue
                bit = 1 << (int(board[r][c]) - 1)
                rows[r] |= bit
                cols[c] |= bit
                boxes[r // 3 * 3 + c // 3] |= bit

        def solve(remaining: int) -> bool:
            if remaining == 0:
                return True
            pick, pick_free, pick_count = 0, 0, 10
            for i in range(remaining):
                r, c = empty[i]
                free = full & ~(rows[r] | cols[c] | boxes[r // 3 * 3 + c // 3])
                count = bin(free).count("1")
                if count < pick_count:
                    pick, pick_free, pick_count = i, free, count
                    if count <= 1:  # dead end or forced move: no cell can beat it
                        break
            # parking the chosen cell at the end keeps the unsolved cells in empty[:remaining - 1]
            empty[pick], empty[remaining - 1] = empty[remaining - 1], empty[pick]
            r, c = empty[remaining - 1]
            b = r // 3 * 3 + c // 3
            free = pick_free
            while free:
                bit = free & -free
                free ^= bit
                rows[r] |= bit
                cols[c] |= bit
                boxes[b] |= bit
                if solve(remaining - 1):
                    board[r][c] = str(bit.bit_length())
                    return True
                rows[r] ^= bit
                cols[c] ^= bit
                boxes[b] ^= bit
            return False

        solve(len(empty))
```
