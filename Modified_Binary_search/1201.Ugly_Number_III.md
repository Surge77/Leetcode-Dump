# 🔹 Problem Name: 1201. Ugly Number III (Binary Search + Inclusion–Exclusion, Medium)

**🔗 Link:** [LeetCode 1201](https://leetcode.com/problems/ugly-number-iii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Call a positive integer "ugly" if it is divisible by at least one of `a`, `b` or `c`. Given `n`, `a`, `b`, `c`, return the `n`-th ugly number in increasing order.

* **Example:** `n = 3, a = 2, b = 3, c = 5` → `4` (the ugly numbers are 2, 3, 4, 5, 6, ...)
* **Constraints:** `1 ≤ n, a, b, c ≤ 10^9`; `1 ≤ a · b · c ≤ 10^18`; the answer lies in `[1, 2 · 10^9]`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** `count(x)` = how many numbers `≤ x` are divisible by `a`, `b` or `c` (inclusion–exclusion with LCMs). Binary search the smallest `x` with `count(x) >= n`.
* **Core Concept:** Binary search on answer + inclusion–exclusion + LCM
* **When to Use This Pattern?** "k-th number with a divisibility property" where the numbers are too large to generate one by one.
* **Mistakes to Avoid:**
  * Generating the sequence — the answer can reach 2·10⁹ (and `n` up to 10⁹).
  * LCM overflow in C++/Java (Python integers are unbounded).
  * Returning `mid` as soon as `count(mid) == n` — that `mid` may not be an ugly number (every `x` between two consecutive ugly numbers has the same count); the *smallest* `x` with `count(x) >= n` always is.

## 🔹 Optimization Path

* **Brute Force:** O(answer) — walk the numbers.
* **Optimized Solution:** O(log(2·10⁹)) iterations, O(1) each.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `count(x) = x//a + x//b + x//c - x//ab - x//bc - x//ac + x//abc` (each a pairwise or triple LCM).
* **Why This Works?** `count` is non-decreasing and jumps exactly at ugly numbers, so the first `x` where it reaches `n` is the n-th ugly number.
* **Edge Cases Considered:**
  * One of `a, b, c` divides another.
  * `a = b = c`.

## 🔹 Tricks & Patterns Used

* **Inclusion–exclusion:** add singles, subtract pairs, add the triple.
* **`lcm(x, y) = x // gcd(x, y) * y`** (`math.lcm` in Python 3.9+).

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def nthUglyNumber(self, n: int, a: int, b: int, c: int) -> int:
        count, x = 0, 0
        while count < n:
            x += 1
            if x % a == 0 or x % b == 0 or x % c == 0:
                count += 1
        return x
```

## 🔹 Code Snippet (Optimized)

```python
from math import lcm


class Solution:
    def nthUglyNumber(self, n: int, a: int, b: int, c: int) -> int:
        ab, bc, ac = lcm(a, b), lcm(b, c), lcm(a, c)
        abc = lcm(ab, c)

        def count(x: int) -> int:  # numbers <= x divisible by a, b or c
            return (x // a + x // b + x // c
                    - x // ab - x // bc - x // ac
                    + x // abc)

        lo, hi = 1, 2 * 10**9
        while lo < hi:
            mid = (lo + hi) // 2
            if count(mid) >= n:
                hi = mid
            else:
                lo = mid + 1
        return lo
```
