# 733. Flood Fill

**🔗 Link:** [LeetCode 733](https://leetcode.com/problems/flood-fill/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You are given an image as a grid of integer pixel values, a starting pixel `(sr, sc)` and a new `color`. Recolour the starting pixel and every pixel connected to it through up, down, left or right moves that has the same original colour as the start pixel, then return the modified image.

* **Example:** `image = [[1,1,1],[1,1,0],[1,0,1]], sr = 1, sc = 1, color = 2` → `[[2,2,2],[2,2,0],[2,0,1]]`
* **Constraints:** `1 ≤ m, n ≤ 50`, `0 ≤ image[i][j], color < 2^16`, `0 ≤ sr < m`, `0 ≤ sc < n`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Paint as you push.** Remember the start colour `start`. If it already equals `color`, return the image untouched. Otherwise DFS (explicit stack) from `(sr, sc)`, recolouring every 4-connected cell whose colour is `start` at the moment it is pushed.
* **Core Concept:** the recoloured cells are exactly the connected component of `(sr, sc)` among cells with colour `start`
* **When to Use This Pattern?** "Change / count / measure the region connected to this cell" — paint bucket, islands, enclosed regions.
* **Mistakes to Avoid:**
  * Missing the `start == color` early return: painted cells still look unvisited, so the fill revisits them forever.
  * Recursive DFS on a 50 × 50 grid of one colour: depth up to 2 500 > Python's default limit of 1 000.

## 🔹 Optimization Path

* **Brute Force:** keep a `filled` matrix; sweep the whole grid repeatedly, adding any `start`-coloured cell next to a filled one, until a sweep adds nothing — up to m·n sweeps of m·n cells: O((m·n)²).
* **Optimized Solution:** one DFS that touches each cell of the region once — O(m·n).
* **Further Improvements Possible?** No; the region itself can be the whole grid.

## 🔹 Solution Breakdown

* **Optimal Approach:** `image[sr][sc] = color`, push it; pop a cell, and for each in-bounds neighbour still equal to `start`, recolour and push.
* **Why This Works?** Once `start != color`, the new colour doubles as the visited mark: a recoloured cell no longer matches `start`, so it is never pushed again, and every cell reachable through `start`-coloured cells is reached.
* **Edge Cases Considered:**
  * `color == image[sr][sc]` → image returned as is.
  * Single-cell image.
  * Start cell isolated by other colours → only it changes.

## 🔹 Tricks & Patterns Used

* **The output doubles as the visited set** — valid only because the guard makes old and new colours differ.
* **Direction tuple inline:** `((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1))` with one bounds check.

## 🔹 Alternative Data Structures

* `deque` BFS — same result and complexity.
* A separate `visited` matrix removes the need for the `start == color` guard at the cost of O(m·n) extra memory.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n)
* **Space Complexity:** O(m · n) for the stack in the worst case

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def floodFill(self, image: List[List[int]], sr: int, sc: int, color: int) -> List[List[int]]:
        rows, cols = len(image), len(image[0])
        start = image[sr][sc]
        filled = [[False] * cols for _ in range(rows)]
        filled[sr][sc] = True
        changed = True
        while changed:  # each sweep only grows the region by cells touching it, so repeat until stable
            changed = False
            for r in range(rows):
                for c in range(cols):
                    if filled[r][c] or image[r][c] != start:
                        continue
                    if any(0 <= x < rows and 0 <= y < cols and filled[x][y]
                           for x, y in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1))):
                        filled[r][c] = changed = True
        return [[color if filled[r][c] else image[r][c] for c in range(cols)] for r in range(rows)]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def floodFill(self, image: List[List[int]], sr: int, sc: int, color: int) -> List[List[int]]:
        start = image[sr][sc]
        if start == color:
            return image  # painted cells would still match `start` and be pushed forever
        rows, cols = len(image), len(image[0])
        image[sr][sc] = color
        stack = [(sr, sc)]
        while stack:
            r, c = stack.pop()
            for x, y in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                if 0 <= x < rows and 0 <= y < cols and image[x][y] == start:
                    image[x][y] = color
                    stack.append((x, y))
        return image
```
