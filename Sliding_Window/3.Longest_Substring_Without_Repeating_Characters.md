# 🔹 Problem Name: 3. Longest Substring Without Repeating Characters (Sliding Window, Medium)

**🔗 Link:** [LeetCode 3](https://leetcode.com/problems/longest-substring-without-repeating-characters/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Variable-size sliding window with a last-seen map.** Move `right` over the string; when `s[right]` was last seen at an index `≥ left`, the window already holds it, so jump `left` to one past that index. The window `[left, right]` is then repeat-free; track its maximum length.
* **Core Concept:** the window only ever shrinks from the left, and the last-seen index tells exactly how far in one step
* **When to Use This Pattern?** "Longest/shortest contiguous substring/subarray such that <a property that stays true when you shrink the window>" — at most `k` distinct, no duplicates, sum ≤ target.
* **Mistakes to Avoid:**
  * Jumping `left` backwards: a character last seen **before** `left` is no longer in the window — use `left = max(left, last[c] + 1)` (or the `≥ left` check).
  * Assuming only lowercase letters: `s` contains letters, digits, symbols and spaces — use a dict, not a 26-slot array.
  * `s = ""` (length 0 is allowed) → answer 0.

## 🔹 Optimization Path

* **Brute Force:** from every start, extend until a character repeats — O(n · min(n, Σ)), Σ = distinct characters.
* **Optimized Solution:** one pass with a last-seen map — O(n).
* **Further Improvements Possible?** No; every character must be read once.

## 🔹 Solution Breakdown

* **Optimal Approach:** `last = {}`; for each `right, c`: if `last.get(c, -1) >= left`, set `left = last[c] + 1`; store `last[c] = right`; `best = max(best, right - left + 1)`.
* **Why This Works?** If `[left, right]` has a duplicate, so does every window that contains it, so the best window ending at `right` starts at the smallest `left` that removes the earlier copy of `s[right]` — exactly one past its last occurrence. `left` never needs to move back, which gives the single pass.
* **Edge Cases Considered:**
  * Empty string → 0.
  * All characters equal (`"bbbbb"`) → 1.
  * A repeat whose earlier copy is already outside the window (`"abba"`: at the last `a`, `left` is 2, the old `a` at 0 must be ignored).

## 🔹 Tricks & Patterns Used

* **Jump instead of crawl:** storing the last index (not a count) lets `left` skip straight past the duplicate.
* **Stale entries are harmless:** entries in `last` with index `< left` are ignored by the `≥ left` test, so the map never needs cleaning.

## 🔹 Alternative Data Structures

* A set plus a crawling `left` (`while c in window: remove s[left]; left += 1`) — also O(n) amortised, just more steps.
* A 128-slot array instead of the dict when the input is guaranteed ASCII.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n), n ≤ 5·10⁴
* **Space Complexity:** O(min(n, Σ))

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        best = 0
        for start in range(len(s)):
            seen = set()
            for c in s[start:]:
                if c in seen:
                    break
                seen.add(c)
            best = max(best, len(seen))
        return best
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last = {}
        left = best = 0
        for right, c in enumerate(s):
            if last.get(c, -1) >= left:  # only a copy inside the window forces a shrink
                left = last[c] + 1
            last[c] = right
            best = max(best, right - left + 1)
        return best
```
