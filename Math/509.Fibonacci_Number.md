# 509. Fibonacci Number

**🔗 Link:** [LeetCode 509](https://leetcode.com/problems/fibonacci-number/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

The Fibonacci sequence starts `F(0) = 0`, `F(1) = 1`, and every later term is the sum of the two before it. Given `n`, return `F(n)`.

* **Example:** `n = 2` → `1`
* **Constraints:** `0 ≤ n ≤ 30`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Bottom-up with two rolling variables.** `F(n) = F(n−1) + F(n−2)` only ever needs the previous two values, so keep `(a, b) = (F(i), F(i+1))` and advance `n` times.
* **Core Concept:** overlapping subproblems — compute each value once, keep only the window you need
* **When to Use This Pattern?** Any linear recurrence of fixed order: climbing stairs, tribonacci, house robber, tiling counts.
* **Mistakes to Avoid:**
  * Plain recursion `fib(n−1) + fib(n−2)` — exponential, O(φⁿ) calls; fine for `n ≤ 30` here but explodes beyond ~35.
  * Off-by-one in the base cases: `F(0) = 0`, `F(1) = 1`.

## 🔹 Optimization Path

* **Brute Force:** naive recursion — O(φⁿ) ≈ O(1.618ⁿ) time, O(n) stack.
* **Optimized Solution:** iterative rolling pair — O(n) time, O(1) space.
* **Further Improvements Possible?** Matrix exponentiation of `[[1, 1], [1, 0]]` or fast doubling (`F(2k) = F(k)(2F(k+1) − F(k))`, `F(2k+1) = F(k)² + F(k+1)²`) — O(log n) arithmetic operations. Overkill for `n ≤ 30`.

## 🔹 Solution Breakdown

* **Optimal Approach:** `a, b = 0, 1`; repeat `n` times: `a, b = b, a + b`; return `a`.
* **Why This Works?** Invariant: after `i` iterations `a = F(i)` and `b = F(i + 1)`. The update maps `(F(i), F(i+1))` to `(F(i+1), F(i) + F(i+1)) = (F(i+1), F(i+2))`.
* **Edge Cases Considered:**
  * `n = 0` → loop does not run → 0.
  * `n = 1` → 1.

## 🔹 Tricks & Patterns Used

* **Rolling variables:** tuple assignment `a, b = b, a + b` swaps without a temporary.
* **Memoisation as the bridge:** `@lru_cache` on the naive recursion turns it into O(n) with no other changes.

## 🔹 Alternative Data Structures

* Full `dp` array of size `n + 1` — O(n) space, useful if all values are needed.
* 2×2 matrix power — O(log n) multiplications.

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def fib(self, n: int) -> int:
        if n < 2:
            return n
        return self.fib(n - 1) + self.fib(n - 2)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def fib(self, n: int) -> int:
        a, b = 0, 1
        for _ in range(n):
            a, b = b, a + b
        return a
```
