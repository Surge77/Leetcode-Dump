# 1456. Maximum Number of Vowels in a Substring of Given Length

**🔗 Link:** [LeetCode 1456](https://leetcode.com/problems/maximum-number-of-vowels-in-a-substring-of-given-length/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given a string `s` and an integer `k`, return the largest number of vowels (`a`, `e`, `i`, `o`, `u`) found in any substring of length exactly `k`.

* **Example:** `s = "abciiidef"`, `k = 3` → `3`
* **Constraints:** `1 ≤ s.length ≤ 10^5`, `s` is lowercase English letters, `1 ≤ k ≤ s.length`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Fixed window with a running vowel count.** Count vowels in the first `k` characters, then slide: add `1` if the entering character is a vowel, subtract `1` if the leaving one is. Track the maximum.
* **Core Concept:** only the two characters at the window's edges change when it slides
* **When to Use This Pattern?** "Best window of exactly `k`" where the score is an additive count over its elements.
* **Mistakes to Avoid:**
  * Recounting the window from scratch on each step — O(n·k).
  * Forgetting to remove the character that leaves.
  * Checking vowels with `in "aeiou"` on every call is fine, but build a `set` once if you want the constant factor down.

## 🔹 Optimization Path

* **Brute Force:** for every start, count vowels in `s[i:i+k]` — O(n·k).
* **Optimized Solution:** slide with an incremental count — O(n).
* **Further Improvements Possible?** Stop early if the count reaches `k` (the theoretical maximum); the worst case stays O(n).

## 🔹 Solution Breakdown

* **Optimal Approach:** `count = vowels in s[:k]`, `best = count`. For `i` in `k..n-1`: `count += is_vowel(s[i]) - is_vowel(s[i-k])`; `best = max(best, count)`.
* **Why This Works?** The new window is the old one minus `s[i-k]` plus `s[i]`, so the vowel count changes only by those two indicator values. Every window of length `k` is visited once.
* **Edge Cases Considered:**
  * `k == len(s)` → single window.
  * No vowels anywhere → `0`.
  * Window made only of vowels → early exit is possible at `k`.

## 🔹 Tricks & Patterns Used

* **Booleans as integers:** `count += s[i] in VOWELS` adds `1` or `0`.
* **Incremental update** instead of recomputation.

## 🔹 Alternative Data Structures

* Prefix array `pre[i]` = vowels in `s[:i]`; each window is `pre[i + k] - pre[i]` — O(n) extra space.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1) for the algorithm (the Python `s[:k]` slice copy is O(k); `sum(... for ch in islice(s, k))` avoids it)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        return max(sum(ch in "aeiou" for ch in s[i:i + k]) for i in range(len(s) - k + 1))
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        vowels = set("aeiou")
        count = sum(ch in vowels for ch in s[:k])
        best = count
        for i in range(k, len(s)):
            count += (s[i] in vowels) - (s[i - k] in vowels)
            best = max(best, count)
        return best
```
