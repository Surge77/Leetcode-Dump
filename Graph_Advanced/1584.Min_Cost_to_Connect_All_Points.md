# 1584. Min Cost to Connect All Points

**🔗 Link:** [LeetCode 1584](https://leetcode.com/problems/min-cost-to-connect-all-points/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You get points on a 2D plane with integer coordinates. Linking two points costs their Manhattan distance. Return the smallest total cost that connects all points so that exactly one simple path exists between any two of them (a spanning tree).

* **Example:** `points = [[0,0],[2,2],[3,10],[5,2],[7,0]]` → `20`
* **Constraints:** `1 ≤ points.length ≤ 1000`; `-10^6 ≤ xi, yi ≤ 10^6`; all points are distinct.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Build all `n(n-1)/2` Manhattan edges, sort them, and add each edge that joins two different components (Kruskal) until `n - 1` edges are used.
* **Core Concept:** Minimum Spanning Tree — Kruskal with Union-Find
* **When to Use This Pattern?** "Connect everything at minimum total cost" (roads, cables, pipelines).
* **Mistakes to Avoid:**
  * Shortest paths (Dijkstra) — minimises distance from one source, not total wiring cost.
  * Not stopping after `n - 1` edges (wastes time).

## 🔹 Optimization Path

* **Brute Force:** Try every spanning tree — exponential.
* **Kruskal:** O(n² log n) — sort all edges.
* **Prim (array version):** O(n²) — best for complete/dense graphs like this one.

## 🔹 Solution Breakdown

* **Optimal Approach:** Sort edges by cost; DSU-union each edge; count used edges; stop at `n - 1`.
* **Why This Works?** Cut property: the cheapest edge crossing any cut belongs to some MST. Kruskal always adds the cheapest edge that does not form a cycle, which is the cheapest edge across the cut between its two components.
* **Edge Cases Considered:**
  * One point → 0.
  * Duplicate coordinates are not allowed (all points distinct), but equal edge weights are fine.

## 🔹 Pattern Recognition

* **Belongs To:** Union-Find / Minimum Spanning Tree
* **Common Problems Using This:**

* **Kruskal = sort + DSU.**
* **Early stop** at `n - 1` edges.

## 🔹 Alternative Data Structures

* **Prim with a `dist` array:** each step pick the closest unvisited point, then relax all others — O(n²), no sorting, fastest here.

* **Time Complexity:** O(n² log n)
* **Space Complexity:** O(n²)

## 🔹 Code Snippet (Brute Force)

```python
from itertools import combinations
from typing import List


class Solution:
    def minCostConnectPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        edges = [
            (abs(points[i][0] - points[j][0]) + abs(points[i][1] - points[j][1]), i, j)
            for i in range(n)
            for j in range(i + 1, n)
        ]
        best = float("inf")
        for tree in combinations(edges, n - 1):  # every candidate set of n - 1 edges
            label = list(range(n))
            total = 0
            is_tree = True
            for cost, i, j in tree:
                if label[i] == label[j]:  # this edge closes a cycle
                    is_tree = False
                    break
                old, new = label[j], label[i]
                label = [new if x == old else x for x in label]
                total += cost
            if is_tree:
                best = min(best, total)
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def minCostConnectPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        edges = []
        for i in range(n):
            xi, yi = points[i]
            for j in range(i + 1, n):
                xj, yj = points[j]
                edges.append((abs(xi - xj) + abs(yi - yj), i, j))
        edges.sort()

        parent = list(range(n))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        total = used = 0
        for cost, i, j in edges:
            ri, rj = find(i), find(j)
            if ri != rj:
                parent[ri] = rj
                total += cost
                used += 1
                if used == n - 1:
                    break
        return total
```
