# 🔹 Problem Name: 67. Add Binary (Bit Manipulation, Easy)

**🔗 Link:** [LeetCode 67](https://leetcode.com/problems/add-binary/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Two non-empty strings made only of `'0'` and `'1'` are given, each a binary number. Return their sum, also as a binary string (no leading zeros except for the number zero itself).

* **Example:** `a = "11", b = "1"` → `"100"`
* **Constraints:** `1 ≤ a.length, b.length ≤ 10^4`, only `'0'`/`'1'` characters, no leading zeros except `"0"`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Two pointers from the right with a carry.** Walk both strings from their last character; at each step `total = bit_a + bit_b + carry`, emit `total % 2`, carry `total // 2`. Continue while either string has digits **or** a carry remains, then reverse the collected bits.
* **Core Concept:** schoolbook addition in base 2 — one column at a time, least significant first
* **When to Use This Pattern?** Adding numbers stored as strings, arrays or linked lists that may be too long for a machine integer — 2. Add Two Numbers, 415. Add Strings, 989. Add to Array-Form of Integer.
* **Mistakes to Avoid:**
  * `int(a, 2) + int(b, 2)` — works in Python, overflows everywhere else (`a` can be 10⁴ bits).
  * Dropping the final carry: `"1" + "1"` is `"10"`, not `"0"`.
  * Prepending to a string each step: O(n²). Append to a list and reverse once.

## 🔹 Optimization Path

* **Brute Force:** convert to integers and add with the XOR/carry loop of 371 (`a, b = a ^ b, (a & b) << 1`) — up to `n` rounds, each touching all `n` bits: O(n²) bit operations.
* **Optimized Solution:** one right-to-left pass — O(max(m, n)).
* **Further Improvements Possible?** No; the output alone has `max(m, n) + 1` characters.

## 🔹 Solution Breakdown

* **Optimal Approach:** indices `i, j` at the ends; loop `while i >= 0 or j >= 0 or carry`.
* **Why This Works?** Column `k` of the sum depends only on column `k` of each input and the carry from column `k − 1`, and the carry is at most 1 (`1 + 1 + 1 = 3 = 11₂`). Processing columns right to left therefore produces each output bit exactly once.
* **Edge Cases Considered:**
  * Different lengths — the shorter string contributes 0 once exhausted.
  * `"0" + "0"` → `"0"`.
  * All-ones inputs — carry ripples through and adds one extra digit.

## 🔹 Tricks & Patterns Used

* **Loop condition includes the carry**, so the extra leading digit needs no special case.
* **Build reversed, flip once** to keep the pass linear.

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        x, y = int(a, 2), int(b, 2)
        while y:
            x, y = x ^ y, (x & y) << 1
        return bin(x)[2:]
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        i, j, carry = len(a) - 1, len(b) - 1, 0
        bits = []
        while i >= 0 or j >= 0 or carry:  # a leftover carry is one more digit
            total = carry
            if i >= 0:
                total += ord(a[i]) - ord("0")
                i -= 1
            if j >= 0:
                total += ord(b[j]) - ord("0")
                j -= 1
            bits.append(str(total % 2))
            carry = total // 2
        return "".join(reversed(bits))
```
