# 🔹 Problem Name: 322. Coin Change (Dynamic Programming, Medium)

**🔗 Link:** [LeetCode 322](https://leetcode.com/problems/coin-change/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** `dp[a]` = fewest coins that make amount `a`; try every coin as the last coin used.
* **Core Concept:** Unbounded knapsack (minimisation)
* **When to Use This Pattern?** Items can be reused without limit and you minimise or maximise a count/cost to hit an exact total.
* **Mistakes to Avoid:**
  * Greedy "largest coin first" — fails for `coins = [1, 3, 4], amount = 6` (greedy 3 coins, optimal 2).
  * Using `float('inf')` and forgetting to map it back to `-1`.

## 🔹 Optimization Path

* **Brute Force:** Exponential — recursion over every coin at every step.
* **Optimized Solution:** O(amount · coins) bottom-up DP.
* **Further Improvements Possible?** BFS over amounts gives the same bound and stops early when the target is reached.

## 🔹 Solution Breakdown

* **Optimal Approach:** `dp[0] = 0`; `dp[a] = 1 + min(dp[a - c])` over coins `c <= a`.
* **Why This Works?** An optimal set for `a` has some last coin `c`; the rest must be an optimal set for `a - c` (optimal substructure).
* **Edge Cases Considered:**
  * `amount = 0` → 0.
  * Amount not reachable → -1.
  * One coin larger than the amount.

## 🔹 Pattern Recognition

* **Belongs To:** DP — Unbounded Knapsack

## 🔹 Tricks & Patterns Used

* **Sentinel `amount + 1`** acts as infinity (no answer can use more than `amount` coins), so everything stays an `int`.

## 🔹 Alternative Data Structures

* **BFS:** each level adds one coin; the first level that hits `amount` is the answer.

## 🔹 Complexity Analysis

* **Time Complexity:** O(amount · len(coins))
* **Space Complexity:** O(amount)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        def fewest(rest: int) -> int:
            if rest == 0:
                return 0
            best = -1
            for c in coins:  # try every coin as the next one, no memo
                if c <= rest:
                    sub = fewest(rest - c)
                    if sub != -1 and (best == -1 or sub + 1 < best):
                        best = sub + 1
            return best

        return fewest(amount)
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        INF = amount + 1  # more coins than any real answer could need
        dp = [0] + [INF] * amount  # dp[a]: fewest coins to make a
        for a in range(1, amount + 1):
            for c in coins:
                if c <= a and dp[a - c] + 1 < dp[a]:
                    dp[a] = dp[a - c] + 1
        return dp[amount] if dp[amount] != INF else -1
```
