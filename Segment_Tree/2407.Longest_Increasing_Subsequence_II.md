# 🔹 Problem Name: 2407. Longest Increasing Subsequence II (Segment Tree + DP, Hard)

**🔗 Link:** [LeetCode 2407](https://leetcode.com/problems/longest-increasing-subsequence-ii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** `best[v]` = longest valid subsequence ending with value `v`. For each `x`: `best[x] = 1 + max(best[x-k .. x-1])`. A max segment tree over **values** answers that range max in O(log M).
* **Core Concept:** DP optimised with a segment tree indexed by value
* **When to Use This Pattern?** A DP transition takes the max/sum over a **range of values or indices** — the segment tree replaces the inner loop. Very typical of SP-level hard questions.
* **Mistakes to Avoid:**
  * Patience-sorting LIS (`bisect`) — cannot enforce the "difference ≤ k" rule.
  * Including `x` itself in the query range (the sequence must be strictly increasing).

## 🔹 Optimization Path

* **Brute Force:** O(n²) DP over pairs.
* **Optimized Solution:** O(n log M), M = max value.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Iterative max segment tree of size `M + 1`; for each `x` query `[max(0, x-k), x-1]`, then point-update `x` with `query + 1` (keep the max).
* **Why This Works?** Processing left to right, the tree holds the best chains ending at each value among earlier elements only, so the query respects index order automatically.
* **Edge Cases Considered:**
  * Repeated values (strictly increasing → equal values do not chain).
  * `k` larger than every gap.

## 🔹 Tricks & Patterns Used

* **Index the tree by value**, not by position.
* **Point update with max** (`tree[i] = max(tree[i], v)`) then recompute ancestors.

## 🔹 Alternative Data Structures

* A Fenwick tree only supports prefix max cleanly; here the window `[x-k, x-1]` needs a real range max → segment tree.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n log M)
* **Space Complexity:** O(M)

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def lengthOfLIS(self, nums: List[int], k: int) -> int:
        size = max(nums) + 1
        tree = [0] * (2 * size)  # iterative max segment tree over values 0..size-1

        def update(i: int, val: int) -> None:
            i += size
            if val <= tree[i]:
                return
            tree[i] = val
            while i > 1:
                i //= 2
                tree[i] = max(tree[2 * i], tree[2 * i + 1])

        def query(l: int, r: int) -> int:  # max over values [l, r]
            res = 0
            l, r = l + size, r + size + 1
            while l < r:
                if l & 1:
                    res = max(res, tree[l])
                    l += 1
                if r & 1:
                    r -= 1
                    res = max(res, tree[r])
                l //= 2
                r //= 2
            return res

        answer = 0
        for x in nums:
            best = query(max(0, x - k), x - 1) + 1  # nums[i] >= 1, so x - 1 >= 0
            update(x, best)
            answer = max(answer, best)
        return answer
```
