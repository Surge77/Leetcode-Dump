# 1192. Critical Connections in a Network

**🔗 Link:** [LeetCode 1192](https://leetcode.com/problems/critical-connections-in-a-network/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

`n` servers are joined by undirected connections that make the whole network connected. A connection is critical if removing it leaves some pair of servers unable to reach each other. Return all critical connections, in any order (and either endpoint order).

* **Example:** `n = 4, connections = [[0,1],[1,2],[2,0],[1,3]]` → `[[1,3]]`
* **Constraints:** `2 ≤ n ≤ 10^5`, `n - 1 ≤ connections.length ≤ 10^5`, no repeated connections

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** DFS with discovery times `disc[u]` and `low[u]` = earliest discovery time reachable from `u`'s subtree using at most one back edge. Tree edge `(p, u)` is a bridge iff `low[u] > disc[p]`.
* **Core Concept:** Tarjan's bridge-finding algorithm
* **When to Use This Pattern?** "Which single edge (or node) removal disconnects the graph?" — critical links, articulation points, 2-edge-connected components.
* **Mistakes to Avoid:**
  * Removing each edge and re-running BFS — O(E · (V + E)).
  * Skipping the parent by **node** — breaks with parallel edges; skip by **edge id**.
  * Recursive DFS in Python on 10⁵ nodes → `RecursionError`. The version below is iterative.

## 🔹 Optimization Path

* **Brute Force:** Remove each edge, test connectivity — O(E · (V + E)).
* **Optimized Solution:** O(V + E) single DFS.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Iterative DFS with a stack of `(node, entering edge id, next neighbour index)`. When a child finishes, fold its `low` into the parent and test `low[child] > disc[parent]`.
* **Why This Works?** If nothing in `u`'s subtree can reach `p` or above without the edge `(p, u)`, then that edge is the only connection — removing it disconnects the subtree.
* **Edge Cases Considered:**
  * A tree → every edge is a bridge.
  * A single cycle → no bridges.
  * Parallel edges (never bridges; the constraints rule them out, but edge ids keep the code correct anyway).

## 🔹 Pattern Recognition

* **Belongs To:** Graph — Advanced (Tarjan, low-link)
* **Common Problems Using This:**
  * Articulation points (cut vertices): `low[child] >= disc[parent]`
  * 1568. Minimum Number of Days to Disconnect Island
  * Strongly connected components (Tarjan / Kosaraju)

## 🔹 Tricks & Patterns Used

* **Low-link values** summarise back edges of a whole subtree.
* **Edge ids** instead of parent nodes.
* **Explicit stack** to simulate recursion.

## 🔹 Alternative Data Structures

* Chain decomposition, or a DSU-based offline method — both less common in exams.

## 🔹 Complexity Analysis

* **Time Complexity:** O(V + E)
* **Space Complexity:** O(V + E)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def criticalConnections(self, n: int, connections: List[List[int]]) -> List[List[int]]:
        def components(skip: int) -> int:  # connected components without edge `skip`
            parent = list(range(n))

            def find(x: int) -> int:
                while parent[x] != x:
                    parent[x] = parent[parent[x]]
                    x = parent[x]
                return x

            count = n
            for eid, (u, v) in enumerate(connections):
                ru, rv = find(u), find(v)
                if eid != skip and ru != rv:
                    parent[ru] = rv
                    count -= 1
            return count

        base = components(-1)
        return [[u, v] for eid, (u, v) in enumerate(connections) if components(eid) > base]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def criticalConnections(self, n: int, connections: List[List[int]]) -> List[List[int]]:
        adj = [[] for _ in range(n)]
        for eid, (u, v) in enumerate(connections):
            adj[u].append((v, eid))
            adj[v].append((u, eid))

        disc = [-1] * n  # discovery time
        low = [0] * n  # lowest discovery time reachable from the subtree
        timer = 0
        bridges = []
        for root in range(n):
            if disc[root] != -1:
                continue
            disc[root] = low[root] = timer
            timer += 1
            stack = [(root, -1, 0)]  # (node, edge used to enter it, next neighbour index)
            while stack:
                u, enter_edge, i = stack[-1]
                if i < len(adj[u]):
                    stack[-1] = (u, enter_edge, i + 1)
                    v, eid = adj[u][i]
                    if eid == enter_edge:
                        continue  # do not go back along the same edge
                    if disc[v] == -1:  # tree edge
                        disc[v] = low[v] = timer
                        timer += 1
                        stack.append((v, eid, 0))
                    else:  # back edge
                        low[u] = min(low[u], disc[v])
                else:
                    stack.pop()
                    if stack:
                        p = stack[-1][0]
                        low[p] = min(low[p], low[u])
                        if low[u] > disc[p]:
                            bridges.append([p, u])
        return bridges
```
