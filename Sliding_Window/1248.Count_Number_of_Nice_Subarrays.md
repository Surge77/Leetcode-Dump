# 🔹 Problem Name: 1248. Count Number of Nice Subarrays (Sliding Window, Medium)

**🔗 Link:** [LeetCode 1248](https://leetcode.com/problems/count-number-of-nice-subarrays/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Map to 0/1, then "at most" trick.** Replace each number by `num % 2`; a nice subarray is one whose sum is exactly `k`. Count `atMost(k) − atMost(k − 1)` with a sliding window.
* **Core Concept:** same problem as 930 once odd → 1 and even → 0
* **When to Use This Pattern?** "Exactly K elements with property P in the subarray" — reduce P to 0/1 and count with two "at most" windows.
* **Mistakes to Avoid:**
  * One window for "exactly k odds": the even numbers on the left give several valid starts per `right`, and a single window counts only one.
  * Forgetting the even numbers before the first odd and after the last odd also extend nice subarrays.

## 🔹 Optimization Path

* **Brute Force:** every start, extend and count odds — O(n²), about 1.25·10⁹ steps at `n = 5·10⁴`.
* **Optimized Solution:** `atMost(k) − atMost(k − 1)` — O(n), O(1) space.
* **Further Improvements Possible?** Prefix count of odds + array of counts (`cnt[odds − k]`) also O(n), with O(n) space.

## 🔹 Solution Breakdown

* **Optimal Approach:** `atMost(k)`: `odds += nums[right] & 1`; while `odds > k`, `odds -= nums[left] & 1`, `left += 1`; add `right − left + 1`.
* **Why This Works?** Dropping elements from the left never raises the odd count, so the valid starts for each `right` are a suffix `[left, right]` and `left` only moves forward. Subtracting the "≤ k − 1" count leaves exactly the subarrays with `k` odds.
* **Edge Cases Considered:**
  * Fewer than `k` odd numbers in total: answer 0 (e.g. `[2,4,6]`, `k = 1`).
  * `k ≥ 1` by constraint, so `atMost(k − 1)` never sees a negative limit.

## 🔹 Pattern Recognition

* **Belongs To:** Sliding Window — counting with "at most K"

## 🔹 Tricks & Patterns Used

* **Parity as 0/1:** `num & 1` turns "count odds" into "sum of a binary array".
* **`exact(K) = atMost(K) − atMost(K − 1)`.**

## 🔹 Alternative Data Structures

* Positions of the odd numbers: for each group of `k` consecutive odds, multiply (evens before + 1) × (evens after + 1).
* Prefix-count array `cnt` indexed by odd count — the hashmap from 560 specialised to small keys.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        count = 0
        for start in range(len(nums)):
            odds = 0
            for end in range(start, len(nums)):
                odds += nums[end] & 1
                if odds == k:
                    count += 1
                elif odds > k:
                    break
        return count
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def numberOfSubarrays(self, nums: List[int], k: int) -> int:
        def at_most(limit: int) -> int:
            left = odds = count = 0
            for right, value in enumerate(nums):
                odds += value & 1
                while odds > limit:
                    odds -= nums[left] & 1
                    left += 1
                count += right - left + 1
            return count

        return at_most(k) - at_most(k - 1)
```
