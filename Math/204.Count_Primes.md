# 204. Count Primes

**🔗 Link:** [LeetCode 204](https://leetcode.com/problems/count-primes/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given a non-negative integer `n`, return how many prime numbers are strictly smaller than `n`. The bound `n` itself is never counted, even when it is prime.

* **Example:** `n = 10` → `4` (the primes are 2, 3, 5, 7)
* **Constraints:** `0 ≤ n ≤ 5 · 10^6`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Sieve of Eratosthenes: for every prime `p ≤ √n`, cross out `p², p²+p, …`. Whatever is left uncrossed is prime.
* **Core Concept:** Sieve of Eratosthenes
* **When to Use This Pattern?** Many primality queries up to a limit (10⁶–10⁷), prime factorisation of many numbers, counting primes in a range — a frequent Infosys building block.
* **Mistakes to Avoid:**
  * Testing each number with trial division — O(n√n), too slow for n = 5·10⁶.
  * Starting the crossing at `2p` instead of `p²` (correct but slower).
  * The problem counts primes **strictly less than** `n`.

## 🔹 Optimization Path

* **Brute Force:** O(n√n) — trial division per number.
* **Optimized Solution:** O(n log log n) sieve.
* **Further Improvements Possible?** Linear sieve O(n) (also yields the smallest prime factor); segmented sieve for ranges up to 10¹² with small width.

## 🔹 Solution Breakdown

* **Optimal Approach:** `bytearray` of ones; zero out multiples with slice assignment (runs in C, very fast in Python).
* **Why This Works?** Every composite `c` has a prime factor `p ≤ √c`, so it is crossed out when that `p` is processed; primes are never crossed out.
* **Edge Cases Considered:**
  * `n ≤ 2` → 0.
  * `n` itself prime (not counted).

## 🔹 Tricks & Patterns Used

* **Start at `p * p`** — smaller multiples were already crossed out by smaller primes.
* **Slice assignment** `sieve[p*p::p] = bytes(k)` instead of a Python loop.

## 🔹 Alternative Data Structures

* `spf` (smallest prime factor) array: one sieve, then factorise any `x ≤ n` in O(log x).

* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def countPrimes(self, n: int) -> int:
        count = 0
        for x in range(2, n):
            d = 2
            while d * d <= x and x % d:
                d += 1
            if d * d > x:
                count += 1
        return count
```

## 🔹 Code Snippet (Optimized)

```python
from math import isqrt


class Solution:
    def countPrimes(self, n: int) -> int:
        if n < 3:
            return 0
        sieve = bytearray([1]) * n  # sieve[x] == 1 => x is (still) prime
        sieve[0] = sieve[1] = 0
        for p in range(2, isqrt(n - 1) + 1):
            if sieve[p]:
                sieve[p * p::p] = bytes(len(range(p * p, n, p)))
        return sum(sieve)
```
