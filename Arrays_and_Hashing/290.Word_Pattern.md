# 290. Word Pattern

**🔗 Link:** [LeetCode 290](https://leetcode.com/problems/word-pattern/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given a pattern of letters and a string of space-separated words, decide whether the words follow the pattern. This needs a one-to-one match: each letter stands for exactly one word, and each word is stood for by exactly one letter.

* **Example:** `pattern = "abba", s = "dog cat cat dog"` → `true`
* **Constraints:** `1 ≤ pattern.length ≤ 300`; `1 ≤ s.length ≤ 3000`; `s` has lowercase letters and single spaces only, with no leading or trailing spaces

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Bijection with two maps.** Split `s` into words; if the count differs from `len(pattern)` return `False`. Then walk letters and words together, requiring `letter → word` and `word → letter` to stay consistent.
* **Core Concept:** "follows the pattern" = a one-to-one mapping between pattern letters and words — exactly 205 Isomorphic Strings with words as the second alphabet
* **When to Use This Pattern?** Matching the "shape" of two sequences: isomorphic strings, find-and-replace pattern, grouping by structure.
* **Mistakes to Avoid:**
  * Skipping the length check: `zip` silently stops at the shorter sequence (`"aaa"`, `"dog dog dog dog"` would wrongly pass).
  * Only one direction: `"abba"`, `"dog dog dog dog"` maps `a→dog`, `b→dog` — must be `False`.

## 🔹 Optimization Path

* **Brute Force:** for all pairs `i < j`, require `pattern[i] == pattern[j]` ⇔ `words[i] == words[j]` — O(n²) word comparisons.
* **Optimized Solution:** two dictionaries, one pass — O(n + |s|).
* **Further Improvements Possible?** No; reading `s` is already O(|s|).

## 🔹 Solution Breakdown

* **Optimal Approach:** `words = s.split()`; length check; for each `(c, w)` use `setdefault` on both maps and fail on any mismatch.
* **Why This Works?** Two maps reject every pair of positions where equality differs between the sequences (equal letters ↦ different words, or different letters ↦ the same word), which is precisely the bijection condition.
* **Edge Cases Considered:**
  * Different counts → `False`.
  * One letter, one word → `True`.
  * A word equal to a letter (`"a"`, `"a"`) — the maps are separate, no clash.

## 🔹 Tricks & Patterns Used

* **Length guard before `zip`:** `zip` truncates; check sizes first.
* **Set-size identity:** bijection ⇔ `len(set(pattern)) == len(set(words)) == len(set(zip(pattern, words)))` (with equal lengths).

## 🔹 Alternative Data Structures

* Map both sequences to "index of first occurrence" lists and compare them.
* One dict plus a set of already-used words.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n + |s|) — split plus one pass (word hashing reads each character)
* **Space Complexity:** O(|s|) for the words and maps

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        words = s.split()
        if len(words) != len(pattern):
            return False
        n = len(words)
        for i in range(n):
            for j in range(i + 1, n):
                if (pattern[i] == pattern[j]) != (words[i] == words[j]):
                    return False
        return True
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        words = s.split()
        if len(words) != len(pattern):
            return False  # zip would silently drop the extra items
        letter_to_word = {}
        word_to_letter = {}
        for c, w in zip(pattern, words):
            if letter_to_word.setdefault(c, w) != w or word_to_letter.setdefault(w, c) != c:
                return False
        return True
```
