# 71. Simplify Path

**🔗 Link:** [LeetCode 71](https://leetcode.com/problems/simplify-path/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You are given an absolute Unix-style path and must return its canonical form: `.` means the current directory, `..` goes up one level (the root has no parent), repeated slashes collapse into one, and a run of three or more dots is an ordinary name. The result starts with a single `/`, has no trailing slash (except for the root itself) and contains no `.` or `..` components.

* **Example:** `path = "/home/"` → `"/home"`
* **Constraints:** `1 ≤ path.length ≤ 3000`; `path` uses letters, digits, `.`, `/` and `_` and is a valid absolute path

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Stack of directory names.** Split on `/`. Skip empty pieces (from `//` or a trailing slash) and `.`; `..` pops the last directory if there is one; anything else (including `...`) is a name and is pushed. Answer = `"/" + "/".join(stack)`.
* **Core Concept:** `..` always cancels the most recent surviving directory — last in, first out
* **When to Use This Pattern?** A token that undoes "the latest thing still standing": paths, backspace strings (844), undo logs, matching brackets.
* **Mistakes to Avoid:**
  * Treating `...` or `..a` as special — only exactly `.` and `..` are.
  * Popping on `..` when the stack is empty: the parent of root is root.
  * Returning `""` for the root — it must be `"/"`.

## 🔹 Optimization Path

* **Brute Force:** filter out `""` and `.`, then repeatedly find the first `..`, delete it together with the name before it and rebuild the list — O(n²) on a path like `/a/../a/../…`.
* **Optimized Solution:** one pass with a stack — O(n).
* **Further Improvements Possible?** No; every character must be read.

## 🔹 Solution Breakdown

* **Optimal Approach:** `for part in path.split("/")`: skip `""`/`"."`, pop on `".."` if non-empty, else push.
* **Why This Works?** After processing a prefix, the stack is exactly the canonical directory chain of that prefix; `..` can only affect its last element, so the top of the stack is all we ever need.
* **Edge Cases Considered:**
  * `"/../"` → `"/"`.
  * `"/home//foo/"` → `"/home/foo"` (empty pieces dropped).
  * `"/.../a/../b"` → `"/.../b"` (`...` is a name).

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def simplifyPath(self, path: str) -> str:
        parts = [p for p in path.split("/") if p not in ("", ".")]
        while ".." in parts:
            i = parts.index("..")
            # every piece before the first ".." is a real name, so it is the one ".." cancels
            parts = parts[:max(i - 1, 0)] + parts[i + 1:]
        return "/" + "/".join(parts)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def simplifyPath(self, path: str) -> str:
        stack = []
        for part in path.split("/"):
            if part in ("", "."):
                continue
            if part == "..":
                if stack:  # the parent of root is root
                    stack.pop()
            else:
                stack.append(part)
        return "/" + "/".join(stack)
```
