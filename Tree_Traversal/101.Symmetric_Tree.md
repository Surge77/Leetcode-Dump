# 🔹 Problem Name: 101. Symmetric Tree (Tree DFS, Easy)

**🔗 Link:** [LeetCode 101](https://leetcode.com/problems/symmetric-tree/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Compare mirror pairs.** The tree is symmetric iff `root.left` and `root.right` are mirror images: two subtrees `a`, `b` are mirrors when their roots hold the same value, `a.left` mirrors `b.right`, and `a.right` mirrors `b.left`. Check pairs from a stack and stop at the first mismatch.
* **Core Concept:** Same Tree (100) with one side's children crossed
* **When to Use This Pattern?** Comparing two trees (or two halves of one) node by node — same tree, mirror, subtree, flip-equivalent, merge two trees.
* **Mistakes to Avoid:**
  * Pairing `a.left` with `b.left` — that tests equality, not mirroring.
  * Testing whether the inorder traversal is a palindrome: `[1,2,2,2,null,2]` has inorder `[2,2,1,2,2]` but is not symmetric — values alone lose the shape.

## 🔹 Optimization Path

* **Brute Force:** BFS that writes each level as its list of child slots (`None` for a missing child) and checks the list reads the same backwards — O(n) time, but O(w) memory for whole levels (`w` = max width), and a mismatch is only seen once its level is complete.
* **Optimized Solution:** stack of mirror pairs — O(n) time, O(h) space, exits on the first bad pair.
* **Further Improvements Possible?** No — a symmetric tree forces a look at every node.

## 🔹 Solution Breakdown

* **Optimal Approach:** `stack = [(root.left, root.right)]`; pop `(a, b)`: both `None` → fine; exactly one `None` or `a.val != b.val` → `False`; otherwise push `(a.left, b.right)` and `(a.right, b.left)`.
* **Why This Works?** Reflecting across the root's vertical axis sends the left child of a node to the right child of its image. Every node is checked against its image exactly once, which is the definition of symmetry.
* **Edge Cases Considered:**
  * Single node → `True`.
  * Same values, different shape (`[1,2,2,null,3,null,3]`) → `False`; the `None` checks catch the shape.

## 🔹 Tricks & Patterns Used

* **Push pairs, not nodes:** the pairing rule (`left/left` vs `left/right`) is the only line that differs between Same Tree and Symmetric Tree.
* **`None` checks first:** `both None → skip`, `one None → fail` makes the value comparison safe.

## 🔹 Alternative Data Structures

* Recursive `mirror(a, b)` — four lines; it only recurses while both nodes exist, so the depth is at most the shorter side's height (≈ 500 for 1000 nodes) and stays under Python's limit.
* Queue of pairs (BFS) — same logic, O(w) memory instead of O(h).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(h) — each pop pushes two pairs, so at most one waiting pair per level

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        level = [root] if root else []
        while level:
            slots = []
            for node in level:
                slots += [node.left, node.right]
            values = [None if node is None else node.val for node in slots]
            if values != values[::-1]:
                return False
            level = [node for node in slots if node]
        return True
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        stack = [(root.left, root.right)] if root else []
        while stack:
            a, b = stack.pop()
            if a is None and b is None:
                continue
            if a is None or b is None or a.val != b.val:
                return False
            stack.append((a.left, b.right))  # outer children reflect onto each other
            stack.append((a.right, b.left))  # and so do the inner ones
        return True
```
