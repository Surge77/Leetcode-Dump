# 210. Course Schedule II

**🔗 Link:** [LeetCode 210](https://leetcode.com/problems/course-schedule-ii/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given `numCourses` and prerequisite pairs `[a, b]` (take `b` before `a`), return one order in which all courses can be taken. Any valid order is accepted; if the prerequisites contain a cycle, return an empty list.

* **Example:** `numCourses = 2, prerequisites = [[1,0]]` → `[0,1]`
* **Constraints:** `1 ≤ numCourses ≤ 2000`, `0 ≤ prerequisites.length ≤ numCourses · (numCourses - 1)`, `ai != bi`, all pairs distinct

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Kahn's algorithm; the order in which nodes leave the queue *is* a topological order. Return `[]` if not every node was output (cycle).
* **Core Concept:** Topological ordering
* **When to Use This Pattern?** You need an actual valid order: build systems, spreadsheet recalculation, instruction scheduling.
* **Mistakes to Avoid:**
  * Returning a partial order when a cycle exists — must return `[]`.
  * Assuming the answer is unique — any valid order is accepted.

## 🔹 Optimization Path

* **Brute Force:** Permutations, checking every prerequisite against each — O(n! · (n + E)).
* **Optimized Solution:** O(V + E).
* **Further Improvements Possible?** Use a min-heap instead of a queue to get the lexicographically smallest order (O(E log V)).

## 🔹 Solution Breakdown

* **Optimal Approach:** Same as 207, but append each popped node to `order`.
* **Why This Works?** A node is output only after all its prerequisites were output (its in-degree reached 0), so every edge points forward in `order`.
* **Edge Cases Considered:**
  * No prerequisites → any permutation (e.g., `0..n-1`).
  * Cycle → `[]`.

## 🔹 Code Snippet (Brute Force)

```python
from itertools import permutations
from typing import List


class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        for order in permutations(range(numCourses)):  # try every order of the courses
            pos = {c: i for i, c in enumerate(order)}
            if all(pos[pre] < pos[course] for course, pre in prerequisites):
                return list(order)
        return []
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        adj = [[] for _ in range(numCourses)]
        indeg = [0] * numCourses
        for course, pre in prerequisites:
            adj[pre].append(course)
            indeg[course] += 1

        q = deque(c for c in range(numCourses) if indeg[c] == 0)
        order = []
        while q:
            c = q.popleft()
            order.append(c)
            for nxt in adj[c]:
                indeg[nxt] -= 1
                if indeg[nxt] == 0:
                    q.append(nxt)
        return order if len(order) == numCourses else []
```
