# 🔹 Problem Name: 1752. Check if Array Is Sorted and Rotated (Linear Scan, Easy)

**🔗 Link:** [LeetCode 1752](https://leetcode.com/problems/check-if-array-is-sorted-and-rotated/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Count the drops around the circle.** Treat the array as circular and count the indices with `nums[i] > nums[(i + 1) % n]`. A non-decreasing array rotated by any amount has at most one such drop — the seam where the largest value meets the smallest. Two or more drops and no rotation can sort it.
* **Core Concept:** rotation only moves the starting point of a circular sequence, so the number of circular descents never changes
* **When to Use This Pattern?** Property checks on rotated sorted arrays ("is this a rotation of a sorted array", "where is the rotation point" in linear time), and any circular-array comparison written with `% n`.
* **Mistakes to Avoid:**
  * Ignoring the wrap-around pair `nums[n − 1]` vs `nums[0]` — `[2, 1, 3, 4]` has one internal drop but is not a rotation; `4 > 2` is its second drop.
  * Counting equal neighbours as a drop — the original is only non-decreasing, so `[1, 1, 1]` and `[2, 1, 1, 2]` are valid.

## 🔹 Optimization Path

* **Brute Force:** build every one of the `n` rotations and check each for being non-decreasing — O(n²).
* **Optimized Solution:** one circular pass counting drops — O(n) time, O(1) space.
* **Further Improvements Possible?** No; every element must be read.

## 🔹 Solution Breakdown

* **Optimal Approach:** `drops = Σ [nums[i] > nums[(i + 1) % n]]`; return `drops <= 1`.
* **Why This Works?** Read circularly, a non-decreasing array has exactly one drop (last → first) unless all values are equal (zero drops); rotating does not change the circular sequence, so a valid input has at most one drop. Conversely, with at most one drop, reading the circle starting right after the drop (anywhere, if there is none) gives a non-decreasing array — the sorted original.
* **Edge Cases Considered:**
  * `n = 1` — the only pair is the element with itself, 0 drops → `true`.
  * Rotation by 0 (already sorted) — the single drop is the wrap pair.
  * All values equal → 0 drops.

## 🔹 Tricks & Patterns Used

* **`% n` closes the circle:** one loop covers the wrap-around pair.
* **Count violations instead of locating them:** the property is decided by a single number.

## 🔹 Alternative Data Structures

* Find the drop position `k`, then check `nums[k + 1:] + nums[:k + 1]` is non-decreasing — O(n), more code.
* Check whether `sorted(nums)` appears as a contiguous window of `nums + nums` — O(n²) naively.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def check(self, nums: List[int]) -> bool:
        n = len(nums)
        for x in range(n):
            rotated = nums[x:] + nums[:x]
            if all(rotated[i] <= rotated[i + 1] for i in range(n - 1)):
                return True
        return False
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def check(self, nums: List[int]) -> bool:
        n = len(nums)
        drops = sum(nums[i] > nums[(i + 1) % n] for i in range(n))  # % n also compares last with first
        return drops <= 1
```
