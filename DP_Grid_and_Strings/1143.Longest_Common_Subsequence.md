# 🔹 Problem Name: 1143. Longest Common Subsequence (Dynamic Programming, Medium)

**🔗 Link:** [LeetCode 1143](https://leetcode.com/problems/longest-common-subsequence/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given two strings, return the length of their longest common subsequence: the longest string you can get from both by deleting characters (possibly none) without reordering the rest. If they share no characters, the answer is `0`.

* **Example:** `text1 = "abcde", text2 = "ace"` → `3`
* **Constraints:** `1 ≤ text1.length, text2.length ≤ 1000`; lowercase English letters only.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** `dp[i][j]` = LCS of `a[:i]` and `b[:j]`. Matching last characters → `1 + dp[i-1][j-1]`; otherwise drop one character: `max(dp[i-1][j], dp[i][j-1])`.
* **Core Concept:** 2D DP on two strings
* **When to Use This Pattern?** Comparing two sequences: diff tools, minimum deletions to make strings equal, shortest common supersequence.
* **Mistakes to Avoid:**
  * Confusing subsequence (gaps allowed) with substring (contiguous — different recurrence: reset to 0 on mismatch).
  * Off-by-one: the table is `(n+1) × (m+1)` with an empty-prefix row/column.

## 🔹 Optimization Path

* **Brute Force:** O(2ⁿ · (n + m)) — every subsequence of `a`, build it and check it against `b`.
* **Optimized Solution:** O(n · m) time, O(m) space with two rows.
* **Further Improvements Possible?** Bit-parallel LCS (O(n·m/64)) — rarely needed.

## 🔹 Solution Breakdown

* **Optimal Approach:** Iterate `a` in the outer loop; keep `prev` (row `i-1`) and `cur` (row `i`).
* **Why This Works?** If `a[i-1] == b[j-1]` some LCS uses that pair; if not, at least one of the two last characters is unused, so dropping it loses nothing.
* **Edge Cases Considered:**
  * No common characters → 0.
  * Identical strings → full length.

* **Time Complexity:** O(n · m)
* **Space Complexity:** O(m)

## 🔹 Code Snippet (Brute Force)

```python
from itertools import combinations


class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        def is_subsequence(sub, s):
            it = iter(s)
            return all(c in it for c in sub)

        for k in range(min(len(text1), len(text2)), 0, -1):  # longest first
            for idx in combinations(range(len(text1)), k):
                if is_subsequence([text1[i] for i in idx], text2):
                    return k
        return 0
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m = len(text2)
        prev = [0] * (m + 1)  # row i-1
        for ch in text1:
            cur = [0] * (m + 1)  # row i
            for j in range(1, m + 1):
                if ch == text2[j - 1]:
                    cur[j] = prev[j - 1] + 1
                else:
                    cur[j] = max(prev[j], cur[j - 1])
            prev = cur
        return prev[m]
```
