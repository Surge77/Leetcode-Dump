# 🔹 Problem Name: 1359. Count All Valid Pickup and Delivery Options (Combinatorics, Hard)

**🔗 Link:** [LeetCode 1359](https://leetcode.com/problems/count-all-valid-pickup-and-delivery-options/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Insert orders one at a time. With `i-1` orders placed (`2i-2` items), there are `2i-1` gaps; choosing two gaps for `P_i` before `D_i` gives `C(2i, 2) = i · (2i - 1)` ways. Multiply for `i = 1..n`.
* **Core Concept:** Combinatorics by incremental insertion, mod 10⁹+7
* **When to Use This Pattern?** Counting arrangements with "A before B" constraints; whenever a formula exists, find it by adding one element at a time.
* **Mistakes to Avoid:**
  * Brute-force permutations — `(2n)!` explodes.
  * Forgetting `% MOD` inside the loop.

## 🔹 Optimization Path

* **Brute Force:** O((2n)!) — enumerate permutations.
* **DP:** `dp[i] = dp[i-1] · i · (2i - 1)` — this *is* the formula.
* **Optimized Solution:** O(n) time, O(1) space. Closed form: `(2n)! / 2ⁿ`.

## 🔹 Solution Breakdown

* **Optimal Approach:** `ans = 1`; for `i` in `1..n`: `ans = ans · i · (2i - 1) % MOD`.
* **Why This Works?** Among all `(2n)!` orderings, each pair is in the correct order in exactly half of them, independently → `(2n)! / 2ⁿ`, which equals the product above.
* **Edge Cases Considered:**
  * `n = 1` → 1.
  * Large `n` → modulo at every step.

* **Symmetry:** each ordering constraint halves the count.

## 🔹 Code Snippet (Brute Force)

```python
from itertools import permutations

MOD = 10**9 + 7


class Solution:
    def countOrders(self, n: int) -> int:
        # items 0..n-1 are pickups, n..2n-1 their deliveries
        count = 0
        for order in permutations(range(2 * n)):
            position = {item: i for i, item in enumerate(order)}
            if all(position[i] < position[i + n] for i in range(n)):
                count += 1
        return count % MOD
```

## 🔹 Code Snippet (Optimized)

```python
MOD = 10**9 + 7


class Solution:
    def countOrders(self, n: int) -> int:
        ans = 1
        for i in range(1, n + 1):
            # 2i-1 gaps among 2i-2 items: choose 2 slots for (P_i, D_i) in order
            ans = ans * i * (2 * i - 1) % MOD
        return ans
```
