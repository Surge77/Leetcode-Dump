## 🔹 Problem Statement

Given a string `s` and an integer `k`, return the length of the longest substring that contains at most `k` different characters. *(premium — paraphrased from memory, not checked against the official page)*

* **Example:** `s = "eceba"`, `k = 2` → `3` (the substring `"ece"`)
* **Constraints:** `1 ≤ s.length ≤ 5·10^4`, `0 ≤ k ≤ 50`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Variable-size sliding window with a frequency map.** Extend `right`, counting characters; while the map has more than `k` keys, drop `s[left]` (deleting keys that reach 0) and move `left`. The window is then valid; track its maximum length.
* **Core Concept:** "at most `k` distinct" is monotone — shrinking a valid window keeps it valid — so two pointers suffice
* **When to Use This Pattern?** Longest window under a constraint that only gets easier when the window shrinks: at most `k` distinct, at most `k` zeros (1004), at most `k` replacements (424).
* **Mistakes to Avoid:**
  * Not deleting keys whose count drops to 0 — `len(counts)` would overcount distinct characters.
  * `k = 0` → answer 0 (the loop shrinks every window to empty; make sure no special case breaks this).

## 🔹 Optimization Path

* **Brute Force:** from every start, extend while the distinct count stays ≤ `k` — O(n²).
* **Optimized Solution:** one sliding window — O(n).
* **Further Improvements Possible?** Not asymptotically — every character must be read. For a stream where `s` cannot be revisited, keep each character's last index in an `OrderedDict` and evict the least recent one to jump `left` directly.

## 🔹 Solution Breakdown

* **Optimal Approach:** `counts[s[right]] += 1`; `while len(counts) > k`: decrement `counts[s[left]]`, delete it at 0, `left += 1`; `best = max(best, right - left + 1)`.
* **Why This Works?** For a fixed `right`, the valid starts form a suffix `[L(right), right]`, and `L(right)` never decreases as `right` grows (adding a character can only add distinct ones). So `left` only moves forward and each index is added and removed once.
* **Edge Cases Considered:**
  * `k = 0` → 0.
  * `k ≥` number of distinct characters in `s` → `len(s)`.

## 🔹 Tricks & Patterns Used

* **Delete at zero:** keeps `len(counts)` equal to the number of distinct characters in the window, an O(1) check.
* **Exactly `k` distinct** (e.g. 992 on counts) = `atMost(k) − atMost(k − 1)`.

## 🔹 Alternative Data Structures

* A fixed array of 128/256 counts plus a separate `distinct` counter (increment when a count goes 0→1, decrement on 1→0).
* `OrderedDict` of last positions — evict the least recently seen character to jump `left` in one step.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n), n ≤ 5·10⁴
* **Space Complexity:** O(k) for the map (at most `k + 1` keys)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        best = 0
        for start in range(len(s)):
            seen = set()
            for end in range(start, len(s)):
                seen.add(s[end])
                if len(seen) > k:
                    break
                best = max(best, end - start + 1)
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from collections import defaultdict


class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        counts = defaultdict(int)
        left = best = 0
        for right, c in enumerate(s):
            counts[c] += 1
            while len(counts) > k:
                counts[s[left]] -= 1
                if counts[s[left]] == 0:
                    del counts[s[left]]  # so len(counts) stays the distinct count
                left += 1
            best = max(best, right - left + 1)
        return best
```
