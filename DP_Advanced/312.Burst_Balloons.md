# 312. Burst Balloons

**🔗 Link:** [LeetCode 312](https://leetcode.com/problems/burst-balloons/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You have balloons with values `nums`. Bursting balloon `i` earns `nums[i-1] * nums[i] * nums[i+1]` coins, where a neighbour that falls outside the array counts as `1`. Burst every balloon in the best order and return the maximum total coins.

* **Example:** `nums = [3,1,5,8]` → `167`
* **Constraints:** `1 ≤ n ≤ 300`; `0 ≤ nums[i] ≤ 100`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Pad with `1` on both ends. `dp[l][r]` = best coins from bursting every balloon strictly between `l` and `r`. Choose `k` = the balloon burst **last** in that gap: `a[l]·a[k]·a[r] + dp[l][k] + dp[k][r]`.
* **Core Concept:** Interval DP — "which element is processed last?"
* **When to Use This Pattern?** Removing/merging elements where the cost depends on current neighbours: merge stones, polygon triangulation, matrix-chain multiplication, cutting a stick.
* **Mistakes to Avoid:**
  * Choosing the balloon burst **first** — its neighbours keep changing, so subproblems are not independent.
  * Iterating `l, r` in the wrong order — shorter gaps must be solved before longer ones.

## 🔹 Optimization Path

* **Brute Force:** O(n!) — try every burst order.
* **Optimized Solution:** O(n³) time, O(n²) space.
* **Further Improvements Possible?** No general speed-up; n ≤ 300 is designed for O(n³).

## 🔹 Solution Breakdown

* **Optimal Approach:** For gap lengths 2..n+1, for each `l` (with `r = l + gap`), try every `k` in `(l, r)`.
* **Why This Works?** If `k` is the last balloon burst between `l` and `r`, then at that moment its neighbours are exactly `l` and `r`, and the two sides `(l, k)` and `(k, r)` were burst independently.
* **Edge Cases Considered:**
  * One balloon → `1 · a · 1`.
  * Zeros (bursting them early is free).

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        def best(alive):  # try every balloon as the next one to burst
            if not alive:
                return 0
            result = 0
            for p in range(len(alive)):
                left = alive[p - 1] if p > 0 else 1
                right = alive[p + 1] if p + 1 < len(alive) else 1
                coins = left * alive[p] * right
                result = max(result, coins + best(alive[:p] + alive[p + 1:]))
            return result

        return best(list(nums))
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        a = [1] + nums + [1]  # sentinels: bursting at the edge multiplies by 1
        n = len(a)
        dp = [[0] * n for _ in range(n)]  # dp[l][r]: best for balloons strictly between l and r
        for gap in range(2, n):
            for l in range(n - gap):
                r = l + gap
                edge = a[l] * a[r]
                row_l = dp[l]
                best = 0
                for k in range(l + 1, r):  # k = last balloon burst in (l, r)
                    val = row_l[k] + dp[k][r] + edge * a[k]
                    if val > best:
                        best = val
                row_l[r] = best
        return dp[0][n - 1]
```
