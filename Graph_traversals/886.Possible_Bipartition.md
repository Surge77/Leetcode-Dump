# 🔹 Problem Name: 886. Possible Bipartition (Graph Colouring, Medium)

**🔗 Link:** [LeetCode 886](https://leetcode.com/problems/possible-bipartition/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

You have `n` people labelled `1` to `n` and a list of pairs `[a, b]` meaning `a` and `b` dislike each other. Decide whether everyone can be split into two groups of any size so that no two people who dislike each other end up in the same group.

* **Example:** `n = 4, dislikes = [[1,2],[1,3],[2,4]]` → `true`
* **Constraints:** `1 ≤ n ≤ 2000`, `0 ≤ dislikes.length ≤ 10^4`, `1 ≤ ai < bi ≤ n`, all pairs distinct

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** People are nodes, "dislikes" are edges. Two groups with no dislike inside a group exist iff the graph is bipartite — BFS 2-colouring.
* **Core Concept:** Bipartite check on an edge list
* **When to Use This Pattern?** Word problems about splitting into two teams/rooms with "must be apart" constraints.
* **Mistakes to Avoid:**
  * People are numbered `1..n` — size arrays `n + 1`.
  * Forgetting people with no dislikes (they fit anywhere).

## 🔹 Optimization Path

* **Brute Force:** 2ⁿ group assignments, each checked against every dislike pair — O(2ⁿ · E).
* **Optimized Solution:** O(n + E).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Build an adjacency list, then BFS-colour every component.
* **Why This Works?** A valid split is exactly a proper 2-colouring of the dislike graph.
* **Edge Cases Considered:**
  * No dislikes → True.
  * Triangle of dislikes → False.

## 🔹 Code Snippet (Brute Force)

```python
from itertools import product
from typing import List


class Solution:
    def possibleBipartition(self, n: int, dislikes: List[List[int]]) -> bool:
        for group in product((0, 1), repeat=n):  # group[p - 1] = side of person p
            if all(group[a - 1] != group[b - 1] for a, b in dislikes):
                return True
        return False
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def possibleBipartition(self, n: int, dislikes: List[List[int]]) -> bool:
        adj = [[] for _ in range(n + 1)]
        for a, b in dislikes:
            adj[a].append(b)
            adj[b].append(a)
        colour = [-1] * (n + 1)
        for start in range(1, n + 1):
            if colour[start] != -1:
                continue
            colour[start] = 0
            q = deque([start])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if colour[v] == -1:
                        colour[v] = 1 - colour[u]
                        q.append(v)
                    elif colour[v] == colour[u]:
                        return False
        return True
```
