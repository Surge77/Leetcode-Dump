# 🔹 Problem Name: 2581. Count Number of Possible Root Nodes (Rerooting DP, Hard)

**🔗 Link:** [LeetCode 2581](https://leetcode.com/problems/count-number-of-possible-root-nodes/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

An unknown root is to be chosen for an undirected tree on `n` nodes. Each guess `[u, v]` claims that `u` is the parent of `v` (the pair is always a real edge). Given the edges, the guesses and a threshold `k`, count how many nodes could be the root such that at least `k` guesses come out true; return 0 if none can.

* **Example:** `edges = [[0,1],[1,2],[1,3],[4,2]], guesses = [[1,3],[0,1],[1,0],[2,4]], k = 3` → `3`
* **Constraints:** `2 ≤ n ≤ 10^5`, `1 ≤ guesses.length ≤ 10^5`, `0 ≤ k ≤ guesses.length`, guesses are unique edges of the tree

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** A guess `[u, v]` says "`u` is the parent of `v`". Count the guesses that are true with root 0. Rerooting from `p` to its child `v` flips the direction of **one** edge only: guess `(p, v)` stops being true and guess `(v, p)` becomes true. So `correct[v] = correct[p] − [(p,v) guessed] + [(v,p) guessed]`. Count roots with `correct ≥ k`.
* **Core Concept:** rerooting — only the edge between old and new root changes
* **When to Use This Pattern?** Any per-root quantity that is a sum over edges whose contribution depends only on the edge's direction.
* **Mistakes to Avoid:**
  * Re-evaluating all guesses per root: O(n · g).
  * Treating a guess as undirected.

## 🔹 Optimization Path

* **Brute Force:** for every root, BFS for parents and count true guesses — O(n · (n + g)).
* **Optimized Solution:** one BFS + one pass over the BFS order — O(n + g).

## 🔹 Solution Breakdown

* **Optimal Approach:** store guesses in a `Counter` keyed by `(u, v)`; BFS from 0 for parents and an order; `correct[0] = Σ guesses[(parent[v], v)]`; propagate down the BFS order.
* **Why This Works?** Changing the root from `p` to a neighbour `v` reverses exactly the edge `p–v` (every other edge keeps its parent/child orientation), so only guesses on that edge change truth value.
* **Edge Cases Considered:**
  * `k = 0` → every node qualifies.
  * Both `(u, v)` and `(v, u)` guessed — exactly one is true for every root; the formula handles both terms.

## 🔹 Tricks & Patterns Used

* **Directed edge lookups** in a hash map keyed by `(parent, child)` tuples.
* **BFS order** instead of recursion (n up to 10⁵).

## 🔹 Alternative Data Structures

* A set of tuples works if guesses are unique; a `Counter` is equally fast and also correct with duplicates.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n + g)
* **Space Complexity:** O(n + g)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def rootCount(self, edges: List[List[int]], guesses: List[List[int]], k: int) -> int:
        n = len(edges) + 1
        adj = [[] for _ in range(n)]
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)
        roots = 0
        for root in range(n):
            parent, order = [-1] * n, [root]
            parent[root] = root
            for v in order:
                for w in adj[v]:
                    if parent[w] == -1:
                        parent[w] = v
                        order.append(w)
            correct = sum(1 for u, v in guesses if v != root and parent[v] == u)
            roots += correct >= k
        return roots
```

## 🔹 Code Snippet (Optimized)

```python
from collections import Counter
from typing import List


class Solution:
    def rootCount(self, edges: List[List[int]], guesses: List[List[int]], k: int) -> int:
        n = len(edges) + 1
        adj = [[] for _ in range(n)]
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)
        guessed = Counter((u, v) for u, v in guesses)

        parent, order = [-1] * n, [0]
        parent[0] = 0
        for v in order:
            for w in adj[v]:
                if parent[w] == -1:
                    parent[w] = v
                    order.append(w)

        correct = [0] * n
        correct[0] = sum(guessed[(parent[v], v)] for v in order[1:])
        for v in order[1:]:  # root moves from parent[v] to v: only edge p–v flips
            p = parent[v]
            correct[v] = correct[p] - guessed[(p, v)] + guessed[(v, p)]
        return sum(1 for c in correct if c >= k)
```
