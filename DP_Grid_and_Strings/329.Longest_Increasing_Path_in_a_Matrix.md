# 329. Longest Increasing Path in a Matrix

**🔗 Link:** [LeetCode 329](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given an `m x n` integer matrix, return the length of the longest path whose values strictly increase. You may start in any cell and move up, down, left or right; diagonal moves and leaving the grid are not allowed.

* **Example:** `matrix = [[9,9,4],[6,6,8],[2,1,1]]` → `4`
* **Constraints:** `1 ≤ m, n ≤ 200`; `0 ≤ matrix[i][j] ≤ 2³¹ − 1`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Edges go from smaller to strictly larger neighbours, so the grid is a DAG. Peel it layer by layer from cells with no larger neighbour (Kahn's algorithm); the number of layers is the longest path.
* **Core Concept:** Longest path in a DAG — DFS + memo or topological sort
* **When to Use This Pattern?** Paths where values must strictly increase/decrease — strictness guarantees no cycles.
* **Mistakes to Avoid:**
  * Plain DFS from every cell without memo — exponential.
  * Recursive DFS in Python on a 200×200 grid → `RecursionError` (path length can reach 40 000). The BFS version below has no recursion.

## 🔹 Optimization Path

* **Brute Force:** DFS from every cell, no memo — exponential.
* **Optimized Solution:** O(m · n) — each cell and edge processed once.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `out[c]` = number of strictly larger neighbours. Start a queue with all `out = 0` cells (local maxima). Process level by level; when a cell's `out` hits 0 it joins the next level.
* **Why This Works?** A cell enters level `k` exactly when the longest increasing path *starting* from it has length `k`, so the number of levels equals the global maximum.
* **Edge Cases Considered:**
  * All equal values → 1.
  * Single cell.
  * A snake-shaped increasing path through the whole grid.

## 🔹 Tricks & Patterns Used

* **Strict order ⇒ DAG** — no visited set needed.
* **Level-order Kahn** to measure longest path length iteratively.

## 🔹 Alternative Data Structures

* DFS + `lru_cache`: `f(cell) = 1 + max(f(larger neighbour))` — shortest to write; needs a raised recursion limit in Python.
* Sort cells by value descending and relax — O(mn log mn) because of the sort, slower than the O(mn) approaches above.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n)
* **Space Complexity:** O(m · n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        m, n = len(matrix), len(matrix[0])

        def dfs(i, j):  # no memo: recomputes shared suffixes
            best = 1
            for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                x, y = i + di, j + dj
                if 0 <= x < m and 0 <= y < n and matrix[x][y] > matrix[i][j]:
                    best = max(best, 1 + dfs(x, y))
            return best

        return max(dfs(i, j) for i in range(m) for j in range(n))
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        m, n = len(matrix), len(matrix[0])
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))
        out = [[0] * n for _ in range(m)]  # number of strictly larger neighbours
        for i in range(m):
            for j in range(n):
                for di, dj in dirs:
                    x, y = i + di, j + dj
                    if 0 <= x < m and 0 <= y < n and matrix[x][y] > matrix[i][j]:
                        out[i][j] += 1

        q = deque((i, j) for i in range(m) for j in range(n) if out[i][j] == 0)
        levels = 0
        while q:
            levels += 1
            for _ in range(len(q)):
                i, j = q.popleft()
                for di, dj in dirs:
                    x, y = i + di, j + dj
                    if 0 <= x < m and 0 <= y < n and matrix[x][y] < matrix[i][j]:
                        out[x][y] -= 1
                        if out[x][y] == 0:
                            q.append((x, y))
        return levels
```
