# 2918. Minimum Equal Sum of Two Arrays After Replacing Zeros

**🔗 Link:** [2918. Minimum Equal Sum of Two Arrays After Replacing Zeros](https://leetcode.com/problems/minimum-equal-sum-of-two-arrays-after-replacing-zeros/description/?envType=daily-question&envId=2025-05-10)

**🟢 Status:** ✅ Solved


## 🔹 Problem Statement

Two arrays of non-negative integers contain some zeros. Every zero must be replaced by a strictly positive integer (any value you like), so that both arrays end up with the same sum. Return the smallest such common sum, or -1 if no replacement can make the sums equal.

* **Example:** `nums1 = [3,2,0,1,0], nums2 = [6,5,0]` → `12`
* **Constraints:** `1 ≤ nums1.length, nums2.length ≤ 10^5`, `0 ≤ nums1[i], nums2[i] ≤ 10^6`.

## 🔹Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Greedily replace `0`s with `1` (smallest possible value)
* **Core Concept:** Greedy Algorithm
* **When to Use This Pattern?**
  * When a decision can be made at each step with a local optimum (like replacing zero with minimum non-zero)
  * When you’re allowed to tweak or simulate values to minimize or balance two totals
* **Mistakes to Avoid:**
  * Forgetting to simulate zero as +1
  * Ignoring edge case when **no zeros are present** but the sums are unequal
  * Summing in a 32-bit `int`: sums reach about `10^5 · 10^6 = 10^11`, so use `long`

## 🔹 Optimization Path

* **Brute Force:** Try all combinations of values replacing zeros → exponential time (not feasible)
* **Optimized Solution:** Greedy simulation → **O(m + n)**
* **Further Improvements Possible?** Not really; this is optimal in terms of time and space for the given constraints

## 🔹 Solution Breakdown

* **Optimal Approach:**
  * Traverse both arrays
  * Sum elements, and for each zero, simulate replacing it with a `1`
  * After processing, compare the two sums — if the smaller one has no zeros, and is still smaller, return `-1`
  * Else, return the larger sum
* **Why This Works?**
  * The greedy choice (replace each 0 with `1`) ensures we're adding the **least possible value** to balance the sum
  * Each side's minimum possible sum is `sum + zeros` (every 0 becomes 1), so the answer can't be below `max(minSum1, minSum2)`
  * The side with the smaller minimum can reach that max if it has at least one zero (raise that zero as far as needed); if it has no zero its sum is fixed below the other side's minimum, so the answer is `-1`
* **Edge Cases Considered:**
  * No zeros at all
  * Arrays of different sizes
  * Already equal sums
  * All elements are zeros

## 🔹 Code Snippet (Optimized)

```java

class Solution {
    public long minSum(int[] nums1, int[] nums2) {
        long sum1 = 0, sum2 = 0;
        long zero1 = 0, zero2 = 0;

        for (int num : nums1) {
            sum1 += num;
            if (num == 0) {
                zero1++;
                sum1 += 1; // simulate 0 as 1
            }
        }

        for (int num : nums2) {
            sum2 += num;
            if (num == 0) {
                zero2++;
                sum2 += 1; // simulate 0 as 1
            }
        }

        if ((sum1 < sum2 && zero1 == 0) || (sum2 < sum1 && zero2 == 0)) {
            return -1;
        }

        return Math.max(sum1, sum2);
    }
}

```

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def minSum(self, nums1: List[int], nums2: List[int]) -> int:
        # The answer (if any) is max of the two "all zeros -> 1" sums, so no zero ever needs a bigger value.
        limit = max(sum(nums1) + nums1.count(0), sum(nums2) + nums2.count(0))

        def reachable(nums: List[int]) -> set:
            sums = {sum(nums)}
            for _ in range(nums.count(0)):  # try every value 1..limit for each zero
                sums = {s + v for s in sums for v in range(1, limit + 1) if s + v <= limit}
            return sums

        common = reachable(nums1) & reachable(nums2)
        return min(common) if common else -1
```

## 🔹 Code Snippet (Python)

```python
from typing import List


class Solution:
    def minSum(self, nums1: List[int], nums2: List[int]) -> int:
        zeros1, zeros2 = nums1.count(0), nums2.count(0)
        sum1 = sum(nums1) + zeros1  # every 0 becomes at least 1
        sum2 = sum(nums2) + zeros2
        if (sum1 < sum2 and zeros1 == 0) or (sum2 < sum1 and zeros2 == 0):
            return -1  # the smaller side has no zero to grow
        return max(sum1, sum2)
```
