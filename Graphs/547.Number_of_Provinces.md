# 547. Number of Provinces

**🔗 Link:** [LeetCode 547](https://leetcode.com/problems/number-of-provinces/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You are given an `n × n` matrix where `isConnected[i][j] = 1` means cities `i` and `j` are directly linked. A province is a group of cities connected directly or through other cities, with no link to cities outside it. Return the number of provinces.

* **Example:** `isConnected = [[1,1,0],[1,1,0],[0,0,1]]` → `2`
* **Constraints:** `1 ≤ n ≤ 200`, `isConnected[i][i] == 1`, `isConnected[i][j] == isConnected[j][i]`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Count DFS starts.** The adjacency matrix is the graph. Scan the cities; each city not yet seen starts a new province — DFS from it marks the whole province as seen. The number of DFS starts is the answer.
* **Core Concept:** connected components of an undirected graph given as an adjacency matrix
* **When to Use This Pattern?** "How many groups" where membership spreads through direct links — friend circles, islands, networks.
* **Mistakes to Avoid:**
  * Counting direct connections instead of components: `1–2` and `2–3` make one province, not two.
  * Recursive DFS: fine for `n ≤ 200`, but an explicit stack never risks the recursion limit.

## 🔹 Optimization Path

* **Brute Force:** transitive closure (Warshall: `reach[i][j] |= reach[i][k] and reach[k][j]`), then count cities that cannot reach any smaller-numbered city — O(n³).
* **Optimized Solution:** DFS from every unseen city — O(n²), reading each matrix cell once.
* **Further Improvements Possible?** No; the input itself has n² cells. Union-Find over the upper triangle has the same O(n² · α(n)) cost.

## 🔹 Solution Breakdown

* **Optimal Approach:** `seen = [False] * n`. For each unseen `city`: `provinces += 1`, push it, and pop/push every unseen `nb` with `isConnected[cur][nb] == 1`.
* **Why This Works?** DFS from a city reaches exactly its connected component. A city is unseen only if no earlier DFS reached it, i.e. it belongs to a province not counted yet.
* **Edge Cases Considered:**
  * All cities isolated (identity matrix) → `n`.
  * Everything connected → `1`.

## 🔹 Tricks & Patterns Used

* **Row of the matrix = neighbour list:** no adjacency list needed.
* **Mark on push:** each city enters the stack once.

## 🔹 Alternative Data Structures

* Union-Find: union `i, j` for every `isConnected[i][j] == 1` with `i < j`; count roots.
* BFS with a `deque` — same cost.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n²)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def findCircleNum(self, isConnected: List[List[int]]) -> int:
        n = len(isConnected)
        reach = [row[:] for row in isConnected]
        for k in range(n):
            for i in range(n):
                if reach[i][k]:
                    for j in range(n):
                        if reach[k][j]:
                            reach[i][j] = 1
        # count each province once, at its smallest-numbered city
        return sum(1 for i in range(n) if not any(reach[i][:i]))
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def findCircleNum(self, isConnected: List[List[int]]) -> int:
        n = len(isConnected)
        seen = [False] * n
        provinces = 0
        for city in range(n):
            if seen[city]:
                continue
            provinces += 1  # no earlier search reached it, so it opens a new province
            seen[city] = True
            stack = [city]
            while stack:
                cur = stack.pop()
                for nb, linked in enumerate(isConnected[cur]):
                    if linked and not seen[nb]:
                        seen[nb] = True
                        stack.append(nb)
        return provinces
```
