# 🔹 Problem Name: 994. Rotting Oranges (Multi-source BFS, Medium)

**🔗 Link:** [LeetCode 994](https://leetcode.com/problems/rotting-oranges/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

The grid holds empty cells (0), fresh oranges (1) and rotten oranges (2). Each minute, every fresh orange that touches a rotten one up, down, left or right becomes rotten. Return the number of minutes until no fresh orange is left, or -1 if some fresh orange can never rot.

* **Example:** `grid = [[2,1,1],[1,1,0],[0,1,1]]` → `4`
* **Constraints:** `1 ≤ m, n ≤ 10`, each `grid[i][j]` is 0, 1 or 2.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Put **all** rotten oranges in the queue at minute 0 and BFS level by level; each level is one minute. Afterwards, any fresh orange left means `-1`.
* **Core Concept:** Multi-source BFS on a grid
* **When to Use This Pattern?** Something spreads from several starting points at once (fire, infection, signal); "minimum time until everything is reached".
* **Mistakes to Avoid:**
  * Running a separate BFS from each rotten orange — O((mn)²).
  * Counting a minute after the last level (answer off by one).
  * Forgetting the "no fresh oranges at all" case → 0.

## 🔹 Optimization Path

* **Brute Force:** Simulate minute by minute over the whole grid — O((mn)²).
* **Optimized Solution:** O(m · n) multi-source BFS.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Count fresh oranges; BFS from all rotten ones, rotting neighbours and decrementing the count; stop when the queue empties or nothing fresh remains.
* **Why This Works?** Multi-source BFS = BFS from a virtual source connected to every rotten orange, so each orange is reached at its minimum distance to *any* rotten orange.
* **Edge Cases Considered:**
  * No fresh oranges → 0.
  * Fresh orange walled off by empty cells → -1.
  * No rotten oranges but some fresh → -1.

## 🔹 Tricks & Patterns Used

* **Level-by-level BFS** (`for _ in range(len(q))`) to count time steps.
* **Fresh counter** avoids a final scan of the grid.

## 🔹 Alternative Data Structures

* Store `(r, c, minute)` in the queue instead of level loops.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n)
* **Space Complexity:** O(m · n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        cur = [row[:] for row in grid]
        minutes = 0
        while True:
            nxt = [row[:] for row in cur]
            changed = False
            for i in range(m):  # rescan the whole grid every minute
                for j in range(n):
                    if cur[i][j] != 1:
                        continue
                    for x, y in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
                        if 0 <= x < m and 0 <= y < n and cur[x][y] == 2:
                            nxt[i][j] = 2
                            changed = True
                            break
            if not changed:
                break
            cur = nxt
            minutes += 1
        if any(1 in row for row in cur):
            return -1
        return minutes
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        q = deque()
        fresh = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 2:
                    q.append((i, j))  # every rotten orange is a source
                elif grid[i][j] == 1:
                    fresh += 1

        minutes = 0
        while q and fresh:
            minutes += 1
            for _ in range(len(q)):
                i, j = q.popleft()
                for x, y in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
                    if 0 <= x < m and 0 <= y < n and grid[x][y] == 1:
                        grid[x][y] = 2
                        fresh -= 1
                        q.append((x, y))
        return minutes if fresh == 0 else -1
```
