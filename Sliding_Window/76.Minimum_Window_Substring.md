# 🔹 Problem Name: 76. Minimum Window Substring (Sliding Window, Hard)

**🔗 Link:** [LeetCode 76](https://leetcode.com/problems/minimum-window-substring/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Expand the right end until the window contains every character of `t` (with multiplicity), then shrink from the left as far as possible while it stays valid; record the best.
* **Core Concept:** Variable-size sliding window with a "missing" counter
* **When to Use This Pattern?** Shortest/longest substring or subarray that satisfies a coverage condition.
* **Mistakes to Avoid:**
  * Re-checking the whole counter on every step — O(26) or O(|t|) each; keep a single `missing` count.
  * Ignoring duplicates in `t` (`"aa"` needs two `a`s).

## 🔹 Optimization Path

* **Brute Force:** O(n² · |Σ|) — check every substring.
* **Optimized Solution:** O(n + m).
* **Further Improvements Possible?** Filter `s` to positions of characters in `t` when `t` is tiny.

## 🔹 Solution Breakdown

* **Optimal Approach:** `need = Counter(t)`, `missing = len(t)`. Moving right: if `need[c] > 0`, `missing -= 1`; `need[c] -= 1`. While `missing == 0`: update the answer, then release `s[l]` (`need[s[l]] += 1`; if it becomes positive, `missing += 1`), `l += 1`.
* **Why This Works?** For each right end, the loop finds the largest valid left end, i.e., the shortest valid window ending there; the overall minimum is among these.
* **Edge Cases Considered:**
  * `t` longer than `s` → `""`.
  * No valid window → `""`.

## 🔹 Tricks & Patterns Used

* **Negative counts** in `need` mean "surplus" — no second map required.
* **`missing` counter** gives an O(1) validity check.

## 🔹 Alternative Data Structures

* Fixed array of size 128 instead of `Counter` — faster.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n + m)
* **Space Complexity:** O(|Σ|)

## 🔹 Code Snippet (Brute Force)

```python
from collections import Counter


class Solution:
    def minWindow(self, s: str, t: str) -> str:
        need = Counter(t)
        best = ""
        for i in range(len(s)):
            for j in range(i, len(s)):
                window = Counter(s[i:j + 1])
                covers = all(window[c] >= cnt for c, cnt in need.items())
                if covers and (not best or j - i + 1 < len(best)):
                    best = s[i:j + 1]
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from collections import Counter


class Solution:
    def minWindow(self, s: str, t: str) -> str:
        need = Counter(t)  # positive = still needed, negative = surplus
        missing = len(t)
        best_l, best_r = 0, -1
        l = 0
        for r, c in enumerate(s):
            if need[c] > 0:
                missing -= 1
            need[c] -= 1
            while missing == 0:  # valid: shrink from the left
                if best_r == -1 or r - l < best_r - best_l:
                    best_l, best_r = l, r
                need[s[l]] += 1
                if need[s[l]] > 0:
                    missing += 1
                l += 1
        return s[best_l:best_r + 1]
```
