# 🔹 Problem Name: 678. Valid Parenthesis String (Greedy Range Tracking, Medium)

**🔗 Link:** [LeetCode 678](https://leetcode.com/problems/valid-parenthesis-string/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Track the range of possible open counts.** Keep `low` = fewest unmatched `(` possible so far and `high` = most possible. `(` → both +1; `)` → both −1; `*` → `low − 1` (treat as `)`), `high + 1` (treat as `(`). If `high < 0`, too many `)` no matter what — fail. Clamp `low` at 0 because a negative open count is never a valid choice. At the end the string is valid iff `low == 0`.
* **Core Concept:** instead of branching on each `*`, carry the whole set of reachable balances — it is always a contiguous interval
* **When to Use This Pattern?** Bracket validity with wildcards, or any "can some choice of unknowns make this sequence balanced" question where the reachable states form an interval.
* **Mistakes to Avoid:**
  * Forgetting to clamp `low` at 0: `"*("` would wrongly pass, with `low` going −1 then 0.
  * Only checking counts at the end — order matters: `"*)("` has balanced counts but `(` at the end can never be closed.

## 🔹 Optimization Path

* **Brute Force:** try every replacement of each `*` (as `(`, `)` or empty) via recursion on `(index, open)` without memo — O(3ᵏ).
* **Better:** memoise `(index, open)` — O(n²) states.
* **Optimized Solution:** greedy `[low, high]` interval — O(n) time, O(1) space.
* **Further Improvements Possible?** No; every character must be read.

## 🔹 Solution Breakdown

* **Optimal Approach:** one left-to-right pass updating `low`/`high` as above; early exit when `high < 0`; answer `low == 0`.
* **Why This Works?** By induction, the set of balances reachable after each prefix (never going negative) is exactly the integers in `[max(low, 0), high]`: each step shifts every value by −1, 0 or +1, and the union of shifted intervals stays contiguous. The string is valid iff 0 is reachable at the end, and since `low ≥ 0` after clamping, that means `low == 0`.
* **Edge Cases Considered:**
  * All stars, e.g. `"***"` → valid (all empty).
  * `")"` first → `high = −1` immediately → invalid.
  * Trailing `(` after stars, e.g. `"*("` → `low = 1` at the end → invalid.

## 🔹 Tricks & Patterns Used

* **State-set compression:** when the reachable states are contiguous, store only their min and max.
* **Clamping the lower bound** to discard invalid (negative) states.

## 🔹 Alternative Data Structures

* Two stacks of indices (one for `(`, one for `*`): match `)` with `(` first, else `*`; then pair each remaining `(` with a later `*`. O(n) time, O(n) space.
* DP over `(index, open)` — O(n²), easy to derive but slower.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n), `n ≤ 100`
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        def can_finish(i: int, open_count: int) -> bool:
            if open_count < 0:
                return False
            if i == len(s):
                return open_count == 0
            if s[i] == "(":
                return can_finish(i + 1, open_count + 1)
            if s[i] == ")":
                return can_finish(i + 1, open_count - 1)
            return (can_finish(i + 1, open_count + 1)
                    or can_finish(i + 1, open_count - 1)
                    or can_finish(i + 1, open_count))

        return can_finish(0, 0)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        low = high = 0
        for ch in s:
            if ch == "(":
                low, high = low + 1, high + 1
            elif ch == ")":
                low, high = low - 1, high - 1
            else:
                low, high = low - 1, high + 1
            if high < 0:
                return False  # even turning every star into "(" cannot cover these ")"
            low = max(low, 0)  # a negative balance is never a legal choice, so drop it
        return low == 0
```
