# 🔹 Problem Name: 2. Add Two Numbers (Linked List Simulation, Medium)

**🔗 Link:** [LeetCode 2](https://leetcode.com/problems/add-two-numbers/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Grade-school addition with a carry.** The digits are stored in reverse order, so the heads are the ones digits — exactly where column addition starts. Walk both lists together, add `carry + a + b`, emit `total % 10`, carry `total // 10`; keep going while either list or the carry is left.
* **Core Concept:** reverse-order digits turn number addition into a single left-to-right walk
* **When to Use This Pattern?** Arithmetic on numbers stored as digit sequences (lists, strings, arrays) — too long for a machine integer, or when the digit structure is the point.
* **Mistakes to Avoid:**
  * Stopping when both lists end and dropping the final carry: `[5] + [5]` must give `[0, 1]`.
  * Assuming equal lengths — treat a finished list as contributing `0`.
  * Converting to integers in Java/C++: 100 digits overflow any built-in type.

## 🔹 Optimization Path

* **Brute Force:** read each list into an integer, add, write the sum's digits back out — relies on Python's big integers.
* **Optimized Solution:** digit-by-digit addition with a carry and a dummy head — O(max(m, n)), no big-integer arithmetic.
* **Further Improvements Possible?** No; every digit must be read and every output digit written.

## 🔹 Solution Breakdown

* **Optimal Approach:** `dummy = tail = ListNode()`; loop `while l1 or l2 or carry`, append `ListNode(total % 10)`, advance whichever lists remain; return `dummy.next`.
* **Why This Works?** Position `i` of each list has weight `10ⁱ`, so adding position by position and pushing `total // 10` (0 or 1, since `9 + 9 + 1 = 19`) into position `i + 1` is exactly long addition.
* **Edge Cases Considered:**
  * Different lengths (`[9,9,9,9,9,9,9] + [9,9,9,9]`).
  * Final carry creates a new most-significant digit.
  * `[0] + [0]` → `[0]` (constraints rule out leading zeros otherwise).

## 🔹 Tricks & Patterns Used

* **Dummy head:** the first output node needs no special case.
* **`while l1 or l2 or carry`:** one loop condition handles unequal lengths and the trailing carry.

## 🔹 Alternative Data Structures

* Write the result into `l1`'s nodes in place to save allocations — but it mutates the input, which LeetCode does not ask for.

## 🔹 Complexity Analysis

* **Time Complexity:** O(max(m, n))
* **Space Complexity:** O(1) extra besides the output list of `max(m, n) + 1` nodes

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        def to_int(node):
            value, place = 0, 1
            while node:
                value += node.val * place
                place *= 10
                node = node.next
            return value

        dummy = tail = ListNode()
        for digit in reversed(str(to_int(l1) + to_int(l2))):  # least significant digit first
            tail.next = ListNode(int(digit))
            tail = tail.next
        return dummy.next
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = tail = ListNode()
        carry = 0
        while l1 or l2 or carry:  # a leftover carry still needs its own node
            total = carry
            if l1:
                total += l1.val
                l1 = l1.next
            if l2:
                total += l2.val
                l2 = l2.next
            carry, digit = divmod(total, 10)
            tail.next = ListNode(digit)
            tail = tail.next
        return dummy.next
```
