# 🔹 Problem Name: 1155. Number of Dice Rolls With Target Sum (Dynamic Programming, Medium)

**🔗 Link:** [LeetCode 1155](https://leetcode.com/problems/number-of-dice-rolls-with-target-sum/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

You roll `n` dice, each with faces `1..k`. Count the outcomes (out of `kⁿ` possible sequences) whose face values add up to `target`, and return the count modulo `10⁹ + 7`.

* **Example:** `n = 1, k = 6, target = 3` → `1`
* **Constraints:** `1 ≤ n, k ≤ 30`; `1 ≤ target ≤ 1000`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** `dp[s]` after `d` dice = ways to reach sum `s`. Each new die adds a face `1..k`, so `new[s] = dp[s-1] + … + dp[s-k]` — a sliding-window sum.
* **Core Concept:** Bounded counting DP + modular arithmetic
* **When to Use This Pattern?** Counting sequences/compositions with per-step limits; the answer is asked "modulo 10⁹ + 7" (very common in Infosys questions).
* **Mistakes to Avoid:**
  * Taking the modulo only at the end — numbers grow huge (slow in Python, overflow in C++/Java).
  * Off-by-one in the window (faces start at 1, not 0).

## 🔹 Optimization Path

* **Brute Force:** O(n · kⁿ) — enumerate every roll and sum it.
* **Standard DP:** O(n · target · k).
* **Optimized Solution:** O(n · target) — maintain the window sum instead of re-adding `k` terms.

## 🔹 Solution Breakdown

* **Optimal Approach:** For each die, slide over `s = 1..target`: add `dp[s-1]` entering the window, subtract `dp[s-k-1]` leaving it.
* **Why This Works?** The last die shows some face `f ∈ [1, k]`; the first `d-1` dice must sum to `s - f`. Summing over `f` is exactly the window.
* **Edge Cases Considered:**
  * `target < n` or `target > n·k` → 0.
  * `k = 1`.

## 🔹 Pattern Recognition

* **Belongs To:** DP — bounded knapsack / counting with modulo
* **Common Problems Using This:**
  * 70. Climbing Stairs (k = 2, no limit on dice) (in this repo)
  * 1223. Dice Roll Simulation

## 🔹 Tricks & Patterns Used

* **Modulo Arithmetic:** reduce every stored value by `MOD = 10**9 + 7`.
* **Prefix / window sums** to drop the inner loop over faces.

## 🔹 Alternative Data Structures

* Closed form via inclusion–exclusion with binomials (`nCr` mod p) — O(n) after factorial precomputation.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · target)
* **Space Complexity:** O(target)

## 🔹 Code Snippet (Brute Force)

```python
from itertools import product


class Solution:
    def numRollsToTarget(self, n: int, k: int, target: int) -> int:
        MOD = 10**9 + 7
        count = sum(1 for roll in product(range(1, k + 1), repeat=n) if sum(roll) == target)
        return count % MOD
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def numRollsToTarget(self, n: int, k: int, target: int) -> int:
        MOD = 10**9 + 7
        dp = [1] + [0] * target  # dp[s]: ways to reach s with the dice so far
        for _ in range(n):
            new = [0] * (target + 1)
            window = 0  # dp[s-1] + ... + dp[s-k]
            for s in range(1, target + 1):
                window += dp[s - 1]
                if s - k - 1 >= 0:
                    window -= dp[s - k - 1]
                new[s] = window % MOD
            dp = new
        return dp[target]
```
