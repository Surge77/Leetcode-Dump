## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Edge count + Union-Find.** A tree on `n` nodes has exactly `n − 1` edges, is connected and has no cycle — any two of these imply the third. So: reject unless `len(edges) == n − 1`, then union the edges; an edge whose endpoints already share a root closes a cycle. `n − 1` cycle-free merges leave exactly one component.
* **Core Concept:** tree ⇔ `n − 1` edges + acyclic
* **When to Use This Pattern?** "Is this undirected graph a tree?", "which edge creates a cycle?", building a spanning tree edge by edge.
* **Mistakes to Avoid:**
  * Checking only the edge count: `n = 4, [[0,1],[1,2],[2,0]]` has 3 edges but a cycle and an isolated node.
  * Checking only connectivity: a connected graph with an extra edge has a cycle.
  * Recursive DFS on a path of 2000 nodes → deeper than Python's default limit of 1000.

## 🔹 Optimization Path

* **Brute Force:** check connectivity with one BFS, then for every edge remove it and BFS again — if its endpoints are still connected, it lies on a cycle. O(E · (V + E)).
* **Optimized Solution:** edge count + Union-Find — O(n + E · α(n)).
* **Further Improvements Possible?** No; every edge must be read. One BFS from node 0 counting visited nodes (after the edge-count check) is equally fast.

## 🔹 Solution Breakdown

* **Optimal Approach:** `if len(edges) != n - 1: return False`. For each edge, `find` both roots; equal roots → `False`; else union by size. Return `True`.
* **Why This Works?** With no cycle, every one of the `n − 1` unions merges two different components, so the count drops from `n` to `1` — the graph is connected and acyclic, i.e. a tree.
* **Edge Cases Considered:**
  * `n = 1, edges = []` → `True`.
  * `n = 2, edges = []` → `False` (count check: needs 1 edge).

## 🔹 Tricks & Patterns Used

* **Edge count as a free filter:** rejects most non-trees in O(1).
* **Path halving + union by size:** keeps every `find` almost O(1).

## 🔹 Alternative Data Structures

* BFS/DFS from node 0 with a parent check (or just counting visited nodes once `E == n − 1` holds).

## 🔹 Code Snippet (Brute Force)

```python
from collections import deque
from typing import List


class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        def reachable(src: int, skip: int) -> set:
            adj = [[] for _ in range(n)]
            for i, (a, b) in enumerate(edges):
                if i != skip:
                    adj[a].append(b)
                    adj[b].append(a)
            seen, queue = {src}, deque([src])
            while queue:
                for w in adj[queue.popleft()]:
                    if w not in seen:
                        seen.add(w)
                        queue.append(w)
            return seen

        if len(reachable(0, -1)) != n:
            return False
        # acyclic ⇔ every edge is a bridge: without it, its endpoints fall apart
        return all(b not in reachable(a, i) for i, (a, b) in enumerate(edges))
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        if len(edges) != n - 1:
            return False
        parent, size = list(range(n)), [1] * n

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]  # path halving
                x = parent[x]
            return x

        for a, b in edges:
            ra, rb = find(a), find(b)
            if ra == rb:  # already connected, so this edge closes a cycle
                return False
            if size[ra] < size[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            size[ra] += size[rb]
        return True
```
