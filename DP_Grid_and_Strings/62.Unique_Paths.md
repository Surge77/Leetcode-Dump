# 62. Unique Paths

**🔗 Link:** [LeetCode 62](https://leetcode.com/problems/unique-paths/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

A robot starts at the top-left cell of an `m x n` grid and may only move right or down. Count the distinct paths that lead to the bottom-right cell. The answer is guaranteed to be at most `2 · 10⁹`.

* **Example:** `m = 3, n = 7` → `28`
* **Constraints:** `1 ≤ m, n ≤ 100`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Each cell is reached from the cell above or the cell to the left → `dp[j] += dp[j-1]`, one row at a time.
* **Core Concept:** Grid DP — or pure combinatorics: choose which `m-1` of the `m+n-2` moves go down.
* **When to Use This Pattern?** Counting monotone paths in a grid (add obstacles → 63; add costs → 64).
* **Mistakes to Avoid:**
  * Recursion without memo — exponential.
  * In exam variants with big grids: forgetting `% MOD` in the DP or using float division in `nCr`.

## 🔹 Optimization Path

* **Brute Force:** O(2^(m+n)) — enumerate paths.
* **Optimized DP:** O(m · n) time, O(n) space.
* **Math:** `C(m+n-2, m-1)` — O(min(m, n)).

## 🔹 Solution Breakdown

* **Optimal Approach:** Row DP: `dp[j]` (value from the row above) `+= dp[j-1]` (value from the left in this row).
* **Why This Works?** Every path makes exactly `m-1` down moves and `n-1` right moves; paths are just orderings of those moves.
* **Edge Cases Considered:**
  * `m = 1` or `n = 1` → 1 path.

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        def paths(i, j):  # enumerate every path from (i, j), no memo
            if i == m - 1 and j == n - 1:
                return 1
            total = 0
            if i + 1 < m:
                total += paths(i + 1, j)
            if j + 1 < n:
                total += paths(i, j + 1)
            return total

        return paths(0, 0)
```

## 🔹 Code Snippet (Optimized)

```python
from math import comb


class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [1] * n  # first row: one way to reach every cell
        for _ in range(1, m):
            for j in range(1, n):
                dp[j] += dp[j - 1]  # from above (old dp[j]) + from left (new dp[j-1])
        return dp[-1]

    def unique_paths_comb(self, m: int, n: int) -> int:
        return comb(m + n - 2, m - 1)  # choose which moves are 'down'
```
