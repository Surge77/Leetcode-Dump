# 🔹 Problem Name: 1137. N-th Tribonacci Number (Fibonacci DP, Easy)

**🔗 Link:** [LeetCode 1137](https://leetcode.com/problems/n-th-tribonacci-number/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Rolling three values.** `T(0) = 0, T(1) = T(2) = 1, T(n) = T(n−1) + T(n−2) + T(n−3)`. Keep only the last three terms and step forward `n` times.
* **Core Concept:** a recurrence over the previous `k` terms needs only `k` variables
* **When to Use This Pattern?** `dp[i]` depends on a fixed number of preceding states (Fibonacci, climbing stairs, house robber).
* **Mistakes to Avoid:**
  * Plain recursion: it recomputes the same terms and is exponential (~ 1.84ⁿ calls).
  * Wrong base cases: `T(2)` is `1`, not `2`.

## 🔹 Optimization Path

* **Brute Force:** direct recursion `T(n−1) + T(n−2) + T(n−3)` — exponential.
* **Optimized Solution:** iterate with three variables — O(n) time, O(1) space.
* **Further Improvements Possible?** Matrix exponentiation gives O(log n); pointless for `n ≤ 37`.

## 🔹 Solution Breakdown

* **Optimal Approach:** `a, b, c = 0, 1, 1`; repeat `n` times `a, b, c = b, c, a + b + c`; return `a`.
* **Why This Works?** After `i` steps `a = T(i), b = T(i+1), c = T(i+2)`, and the shift keeps that invariant.
* **Edge Cases Considered:**
  * `n = 0` → `0` (loop does not run).
  * `n = 37` → `2082876103`, the largest input; the answer still fits a 32-bit integer.

## 🔹 Tricks & Patterns Used

* **Tuple shift:** `a, b, c = b, c, a + b + c` updates all three at once from the old values.

## 🔹 Alternative Data Structures

* Memoised recursion (`functools.lru_cache`) — O(n) time and stack depth, fine for `n ≤ 37`.
* A full `dp` array — same time, O(n) space.

* **Time Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def tribonacci(self, n: int) -> int:
        if n == 0:
            return 0
        if n <= 2:
            return 1
        return self.tribonacci(n - 1) + self.tribonacci(n - 2) + self.tribonacci(n - 3)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def tribonacci(self, n: int) -> int:
        a, b, c = 0, 1, 1  # T(0), T(1), T(2)
        for _ in range(n):
            a, b, c = b, c, a + b + c
        return a
```
