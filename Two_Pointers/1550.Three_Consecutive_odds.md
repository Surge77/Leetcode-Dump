# 1550. Three Consecutive Odds

**🔗 Link:** [LeetCode 1550 – Three Consecutive Odds](https://leetcode.com/problems/three-consecutive-odds/description/?envType=daily-question&envId=2025-05-11)

## 🔹 Problem Statement

Given an array of positive integers, report whether it contains three odd numbers in a row (three adjacent positions). Return `true` if such a run exists and `false` otherwise.

* **Example:** `arr = [2,6,4,1]` → `false`
* **Constraints:** `1 ≤ arr.length ≤ 1000`; `1 ≤ arr[i] ≤ 1000`

## 🔹 Solution Breakdown

* **Optimal Approach:**
  Use bitwise `& 1` to check if each number is odd, and apply a pattern-based skip strategy to jump over impossible combinations faster.
* **Why This Works?**
  Odds have `LSB = 1`, so `num & 1 == 1` is a fast check. When a triplet fails, we analyze which number failed and skip past useless indices.
* **Edge Cases Considered:**
  * Array shorter than 3 → return false
  * Long even-only arrays
  * Triplet appears near the end

## 🔹 Code Snippet (Optimized)

```java

class Solution {
    public boolean threeConsecutiveOdds(int[] arr) {
        int n = arr.length, i = 0;
        while (i + 2 < n) {
            if ((arr[i] & 1) == 1 && (arr[i+1] & 1) == 1 && (arr[i+2] & 1) == 1)
                return true;

            // Skip logic to avoid redundant checks
            if ((arr[i+2] & 1) == 0) i += 3;
            else if ((arr[i+1] & 1) == 0) i += 2;
            else i += 1;
        }
        return false;
    }
}

```

## 🔹 Code Snippet (Python)

```python
from typing import List


class Solution:
    def threeConsecutiveOdds(self, arr: List[int]) -> bool:
        # Python variant: a run counter instead of pointer skipping; `x & 1` works the same as `x % 2` here
        run = 0  # length of the current run of odd numbers
        for x in arr:
            run = run + 1 if x & 1 else 0
            if run == 3:
                return True
        return False
```
