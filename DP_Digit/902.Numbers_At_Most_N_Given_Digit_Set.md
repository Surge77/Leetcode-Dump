# 🔹 Problem Name: 902. Numbers At Most N Given Digit Set (Digit DP / Combinatorics, Hard)

**🔗 Link:** [LeetCode 902](https://leetcode.com/problems/numbers-at-most-n-given-digit-set/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Count shorter numbers freely (`D^L` for each shorter length `L`), then walk `n`'s digits while staying tight: at each position, every allowed digit smaller than `n`'s digit frees the remaining positions.
* **Core Concept:** Digit DP collapsed to counting
* **When to Use This Pattern?** Counting numbers `≤ n` built from restricted digits — the "tight prefix" walk is the core of all digit-DP problems.
* **Mistakes to Avoid:**
  * Forgetting numbers with fewer digits than `n`.
  * Not stopping when `n`'s digit itself is not allowed (you cannot stay tight past it).
  * Forgetting to add `n` itself when all its digits are allowed.

## 🔹 Optimization Path

* **Brute Force:** O(n · log n) — check every number.
* **Optimized Solution:** O(log n · |D|).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:**
  * shorter lengths: `Σ D^L` for `L = 1 .. k-1`
  * same length: at position `i`, add `(#digits < s[i]) · D^(k-i-1)`; continue only if `s[i]` is allowed
  * if the walk finishes, `n` itself counts → `+1`
* **Why This Works?** Every valid number `≤ n` of the same length first differs from `n` at some position `i` with a smaller digit (counted there) or equals `n` (the final `+1`).
* **Edge Cases Considered:**
  * Single allowed digit larger than every digit of `n`.
  * `n` composed only of allowed digits.

## 🔹 Tricks & Patterns Used

* **Free suffix:** once a digit is strictly smaller, every remaining position has `D` choices.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def atMostNGivenDigitSet(self, digits: List[str], n: int) -> int:
        allowed = set(digits)
        return sum(1 for x in range(1, n + 1) if set(str(x)) <= allowed)
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def atMostNGivenDigitSet(self, digits: List[str], n: int) -> int:
        s = str(n)
        k, d = len(s), len(digits)
        total = sum(d ** length for length in range(1, k))  # all shorter numbers
        for i, ch in enumerate(s):
            smaller = sum(dig < ch for dig in digits)
            total += smaller * d ** (k - i - 1)  # smaller digit here => rest is free
            if ch not in digits:
                return total  # cannot stay equal to n's prefix
        return total + 1  # n itself is buildable
```
