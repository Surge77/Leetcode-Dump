# 🔹 Problem Name: 1406. Stone Game III (Minimax DP, Hard)

**🔗 Link:** [LeetCode 1406](https://leetcode.com/problems/stone-game-iii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** `best[i]` = the largest (my score − opponent's score) the player to move can force from stone `i`. Take 1, 2 or 3 stones: `best[i] = max(sum(taken) - best[i + k])`. The sign of `best[0]` decides the winner.
* **Core Concept:** Zero-sum game DP using score difference
* **When to Use This Pattern?** Two players alternately take from the ends/front, both play optimally, and you compare totals.
* **Mistakes to Avoid:**
  * Tracking both players' scores separately — the difference is enough.
  * Values can be negative: taking more is not always better.

## 🔹 Optimization Path

* **Brute Force:** Full game tree — O(3ⁿ).
* **Optimized Solution:** O(n) DP from the back.
* **Further Improvements Possible?** O(1) space with a rolling window of 4 values.

## 🔹 Solution Breakdown

* **Optimal Approach:** Iterate `i` from `n - 1` down to 0, trying `k = 1..3`.
* **Why This Works?** After you take stones, the opponent faces the same game from `i + k` and gets difference `best[i + k]` relative to you — so your difference is what you took minus theirs. Both play optimally, so each maximises.
* **Edge Cases Considered:**
  * All negative values.
  * Ties.

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def stoneGameIII(self, stoneValue: List[int]) -> str:
        n = len(stoneValue)
        best = [0] * (n + 3)  # best[i]: (mover's score - other's score) from i
        for i in range(n - 1, -1, -1):
            taken, best[i] = 0, float("-inf")
            for k in range(1, 4):
                if i + k > n:
                    break
                taken += stoneValue[i + k - 1]
                best[i] = max(best[i], taken - best[i + k])
        if best[0] > 0:
            return "Alice"
        return "Bob" if best[0] < 0 else "Tie"
```
