# 133. Clone Graph

**🔗 Link:** [LeetCode 133](https://leetcode.com/problems/clone-graph/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You get a reference to one node of a connected, undirected graph; every node holds an integer value and a list of its neighbours. Build and return a deep copy of the whole graph, returning the copy of the node you were given (always the one with `val = 1`). An empty graph is possible and the answer is then `None`.

* **Example:** `adjList = [[2,4],[1,3],[2,4],[1,3]]` → `[[2,4],[1,3],[2,4],[1,3]]`
* **Constraints:** `0 ≤ nodes ≤ 100`, `1 ≤ Node.val ≤ 100`, values are unique, no repeated edges or self-loops, the graph is connected

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **BFS with an original → copy map.** The map doubles as the visited set: the first time a node is seen, create its copy and queue it. When a node is popped, append the copies of its neighbours to its own copy's list.
* **Core Concept:** deep copy of a structure with cycles = traversal + memo of already-copied nodes
* **When to Use This Pattern?** Copying anything with shared references or cycles — graphs, lists with random pointers, trees with extra pointers.
* **Mistakes to Avoid:**
  * Creating a new copy every time a node is met as a neighbour → duplicated nodes, or an infinite loop on a cycle.
  * Returning original nodes inside the clone's neighbour lists (shallow copy).
  * Forgetting the empty graph: `node is None` → `None`.

## 🔹 Optimization Path

* **Brute Force:** collect the nodes in a list, then for each edge find the neighbour's copy by scanning the list — O(V · E).
* **Optimized Solution:** hash map from original to copy — O(V + E).
* **Further Improvements Possible?** No; every node and edge has to be copied.

## 🔹 Solution Breakdown

* **Optimal Approach:** `copies = {node: Node(node.val)}`, queue `[node]`. Pop `original`; for each neighbour `nb`: if `nb` has no copy yet, create it and queue `nb`; then `copies[original].neighbors.append(copies[nb])`.
* **Why This Works?** Each node gets exactly one copy (created on first sight) and is expanded exactly once (queued only at creation). Every edge `original → nb` is replayed as `copy(original) → copy(nb)` when `original` is expanded, in the same order — so the copy has the same adjacency lists.
* **Edge Cases Considered:**
  * Empty graph (`[]`) → `None`.
  * One node with no neighbours (`[[]]`) → a single new node.

## 🔹 Pattern Recognition

* **Belongs To:** Graph Traversal — BFS/DFS with a memo of visited nodes
* **Common Problems Using This:**
  * [138. Copy List with Random Pointer](../Linked_List/138.Copy_List_with_Random_Pointer.md)

## 🔹 Tricks & Patterns Used

* **Map = visited set:** "has a copy" ⇔ "already discovered".
* **Edges wired at expansion time:** each original adjacency list is read once.

## 🔹 Alternative Data Structures

* Recursive DFS with the same map — shorter, and fine here (≤ 100 nodes).
* An array indexed by `val` (values are unique, 1..100) instead of a dict.

## 🔹 Complexity Analysis

* **Time Complexity:** O(V + E)
* **Space Complexity:** O(V) for the map and queue (plus the copy itself)

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Node:
    def __init__(self, val: int = 0, neighbors: Optional[list] = None):
        self.val = val
        self.neighbors = neighbors if neighbors is not None else []


class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        if node is None:
            return None
        originals, stack = [node], [node]
        while stack:
            for nb in stack.pop().neighbors:
                if nb not in originals:
                    originals.append(nb)
                    stack.append(nb)
        copies = [Node(original.val) for original in originals]
        for original, copy in zip(originals, copies):
            for nb in original.neighbors:
                copy.neighbors.append(copies[originals.index(nb)])
        return copies[0]
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import Optional


class Node:
    def __init__(self, val: int = 0, neighbors: Optional[list] = None):
        self.val = val
        self.neighbors = neighbors if neighbors is not None else []


class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        if node is None:
            return None
        copies = {node: Node(node.val)}
        queue = deque([node])
        while queue:
            original = queue.popleft()
            for nb in original.neighbors:
                if nb not in copies:  # first sighting: copy once, expand once
                    copies[nb] = Node(nb.val)
                    queue.append(nb)
                copies[original].neighbors.append(copies[nb])
        return copies[node]
```
