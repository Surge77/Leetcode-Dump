# 🔹 Problem Name: 516. Longest Palindromic Subsequence (Interval DP, Medium)

**🔗 Link:** [LeetCode 516](https://leetcode.com/problems/longest-palindromic-subsequence/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** `dp[i][j]` = LPS of `s[i..j]`. Equal ends → `2 + dp[i+1][j-1]`; otherwise `max(dp[i+1][j], dp[i][j-1])`.
* **Core Concept:** Interval DP on a string
* **When to Use This Pattern?** Palindrome questions about *subsequences* (gaps allowed): min insertions/deletions to make a palindrome.
* **Mistakes to Avoid:**
  * Confusing it with Longest Palindromic **Substring** (5) — that one is expand-around-centre.
  * Filling `i` upwards — `dp[i]` needs row `i+1`, so iterate `i` from `n-1` down to 0.

## 🔹 Optimization Path

* **Brute Force:** O(2ⁿ · n) — every subsequence.
* **Optimized Solution:** O(n²) time, O(n) space with two rows.
* **Further Improvements Possible?** Equivalent to `LCS(s, reversed(s))`.

## 🔹 Solution Breakdown

* **Optimal Approach:** Keep `prev` = row `i+1`; build `cur` = row `i` from left to right.
* **Why This Works?** If `s[i] == s[j]`, using both as the outer pair is never worse; if they differ, one of them is not in the answer, so drop it.
* **Edge Cases Considered:**
  * Single character → 1.
  * All characters equal → n.

## 🔹 Tricks & Patterns Used

* **Row compression for interval DP:** `dp[i][*]` only reads `dp[i+1][*]` and itself.

## 🔹 Alternative Data Structures

* Full 2D table when you must reconstruct the palindrome.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n²)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        prev = [0] * n  # row i+1
        for i in range(n - 1, -1, -1):
            cur = [0] * n  # row i
            cur[i] = 1
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    cur[j] = prev[j - 1] + 2  # prev[j-1] = LPS of s[i+1..j-1]
                else:
                    cur[j] = max(prev[j], cur[j - 1])
            prev = cur
        return prev[n - 1]
```
