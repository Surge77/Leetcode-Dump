# 🔹 Problem Name: 904. Fruit Into Baskets (Sliding Window, Medium)

**🔗 Link:** [LeetCode 904](https://leetcode.com/problems/fruit-into-baskets/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Longest subarray with at most 2 distinct values.** Picking starts at some tree and stops at the first tree whose type does not fit the two baskets, so the picked trees are a contiguous subarray with ≤ 2 distinct types. Slide a window with a count map; shrink from the left while it has 3 types.
* **Core Concept:** translate the story into "longest window with at most `k = 2` distinct elements"
* **When to Use This Pattern?** Any "longest contiguous run under a distinct-count limit" — 340 with `k`, 159 with `k = 2` on strings.
* **Mistakes to Avoid:**
  * Thinking you may skip trees — once you start you must pick every tree until you stop, so the answer is a subarray.
  * Forgetting to delete a type when its count hits 0 — the distinct check breaks.

## 🔹 Optimization Path

* **Brute Force:** from every start, extend while at most 2 types are seen — O(n²) = 10¹⁰ for `n = 10⁵`, too slow.
* **Optimized Solution:** sliding window with a count map — O(n).
* **Further Improvements Possible?** O(1) space: track only the last two types and the length of the trailing run of the last type; on a third type the new window is that run plus the current tree.

## 🔹 Solution Breakdown

* **Optimal Approach:** `counts[fruits[right]] += 1`; while `len(counts) > 2`: decrement `counts[fruits[left]]`, delete at 0, `left += 1`; `best = max(best, right - left + 1)`.
* **Why This Works?** For each `right` the valid lefts form a suffix whose start never moves backward as `right` grows (a longer prefix can only add types), so each tree enters and leaves the window once.
* **Edge Cases Considered:**
  * One tree → 1.
  * Only one or two types in the whole row → `n`.

## 🔹 Pattern Recognition

* **Belongs To:** Sliding Window — variable size, at most `k` distinct
* **Common Problems Using This:**
  * 340. Longest Substring with At Most K Distinct Characters (in this repo)
  * 3. Longest Substring Without Repeating Characters (in this repo)
  * 159. Longest Substring with At Most Two Distinct Characters

## 🔹 Tricks & Patterns Used

* **Story → pattern:** "two baskets, one type each, stop at the first misfit" = "≤ 2 distinct in a contiguous window".
* **Delete at zero** so `len(counts)` is the distinct count.

## 🔹 Alternative Data Structures

* Last-two-types + trailing-run length (O(1) space), see above.
* A fixed array indexed by type (`0 ≤ fruits[i] < n`) plus a distinct counter.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n), n ≤ 10⁵
* **Space Complexity:** O(1) — the map never holds more than 3 keys

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        best = 0
        for start in range(len(fruits)):
            types = set()
            for end in range(start, len(fruits)):
                types.add(fruits[end])
                if len(types) > 2:
                    break
                best = max(best, end - start + 1)
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from collections import defaultdict
from typing import List


class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        counts = defaultdict(int)
        left = best = 0
        for right, fruit in enumerate(fruits):
            counts[fruit] += 1
            while len(counts) > 2:
                counts[fruits[left]] -= 1
                if counts[fruits[left]] == 0:
                    del counts[fruits[left]]  # so len(counts) stays the number of types
                left += 1
            best = max(best, right - left + 1)
        return best
```
