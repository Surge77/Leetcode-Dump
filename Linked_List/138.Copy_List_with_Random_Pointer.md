# 138. Copy List with Random Pointer

**🔗 Link:** [LeetCode 138](https://leetcode.com/problems/copy-list-with-random-pointer/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Every node of the given list has a `next` pointer and a `random` pointer that may target any node in the list or be null. Build a deep copy: exactly `n` new nodes with the same values, where the new `next`/`random` pointers mirror the original structure and never point into the original list. Return the head of the copy.

* **Example:** `head = [[7,null],[13,0],[11,4],[10,2],[1,0]]` → `[[7,null],[13,0],[11,4],[10,2],[1,0]]`
* **Constraints:** `0 ≤ n ≤ 1000`; `-10^4 ≤ Node.val ≤ 10^4`; `Node.random` is null or points to a node in the list.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Interleave copies with originals.** Pass 1: insert each node's copy right after it (`A → A' → B → B' …`). Now the copy of any node `X` is simply `X.next`. Pass 2: `X.next.random = X.random.next`. Pass 3: unzip the two lists, restoring the original `next` pointers.
* **Core Concept:** you need a map "original → copy"; storing it inside the list itself (`copy = original.next`) makes it O(1) extra space
* **When to Use This Pattern?** Deep-copying a structure with arbitrary cross pointers — random lists, graphs (133 Clone Graph uses the explicit hash map).
* **Mistakes to Avoid:**
  * Copying `random` during the first pass: the target's copy may not exist yet.
  * `X.random.next` when `X.random` is `None`.
  * Leaving the input modified — the third pass must restore every original `next`, or the judge rejects it.

## 🔹 Optimization Path

* **Brute Force:** copy the nodes in order, then for each `random` find its index by scanning the original list — O(n²).
* **Better:** hash map `original → copy` in two passes — O(n) time, O(n) extra space.
* **Optimized Solution:** interleaving — O(n) time, O(1) extra space besides the copy.
* **Further Improvements Possible?** No; every node has to be copied.

## 🔹 Solution Breakdown

* **Optimal Approach:** weave (`curr.next = Node(curr.val, curr.next)`), assign randoms, unweave (`curr.next = copy.next; copy.next = copy.next.next`).
* **Why This Works?** After weaving, the copy of every original node is its `next`, so `random`'s target's copy is one hop away. Unweaving only touches `next` pointers, so the randoms set in pass 2 survive.
* **Edge Cases Considered:**
  * Empty list → `None`.
  * `random` pointing to itself, to an earlier node, or to `None`.

## 🔹 Tricks & Patterns Used

* **Implicit map:** encode `original → copy` as `original.next` instead of a dictionary.
* **Restore what you borrow:** temporary changes to the input are undone in the last pass.

## 🔹 Alternative Data Structures

* `dict` from original node to copy (two passes, or one pass with `setdefault`) — simplest O(n) answer and usually acceptable in interviews.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1) extra besides the `n` copied nodes

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Node:
    def __init__(self, x: int, next: "Node" = None, random: "Node" = None):
        self.val = int(x)
        self.next = next
        self.random = random


class Solution:
    def copyRandomList(self, head: "Optional[Node]") -> "Optional[Node]":
        originals = []
        while head:
            originals.append(head)
            head = head.next
        copies = [Node(node.val) for node in originals]
        for i, node in enumerate(originals):
            if i + 1 < len(copies):
                copies[i].next = copies[i + 1]
            if node.random is not None:
                j = next(j for j, other in enumerate(originals) if other is node.random)  # identity, not value
                copies[i].random = copies[j]
        return copies[0] if copies else None
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Node:
    def __init__(self, x: int, next: "Node" = None, random: "Node" = None):
        self.val = int(x)
        self.next = next
        self.random = random


class Solution:
    def copyRandomList(self, head: "Optional[Node]") -> "Optional[Node]":
        if head is None:
            return None
        curr = head
        while curr:  # A -> A' -> B -> B' ...: each copy sits right after its original
            curr.next = Node(curr.val, curr.next)
            curr = curr.next.next

        curr = head
        while curr:
            if curr.random:
                curr.next.random = curr.random.next
            curr = curr.next.next

        copy_head = head.next
        curr = head
        while curr:  # unweave, restoring the input's next pointers
            copy = curr.next
            curr.next = copy.next
            copy.next = copy.next.next if copy.next else None
            curr = curr.next
        return copy_head
```
