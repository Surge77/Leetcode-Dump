# 🔹 Problem Name: 1011. Capacity To Ship Packages Within D Days (Binary Search on Answer, Medium)

**🔗 Link:** [LeetCode 1011](https://leetcode.com/problems/capacity-to-ship-packages-within-d-days/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Binary search the capacity in `[max(weights), sum(weights)]`. For a candidate capacity, load greedily in order and count the days needed.
* **Core Concept:** Binary search on answer + greedy feasibility check
* **When to Use This Pattern?** Split an ordered list into at most `D` contiguous groups minimising the largest group (shipping, painters, book allocation — classic placement questions).
* **Mistakes to Avoid:**
  * Lower bound below `max(weights)` — the heaviest package must fit.
  * Reordering packages — they must ship in the given order.

## 🔹 Optimization Path

* **Brute Force:** Try every capacity from max to sum — O(n · sum).
* **DP:** O(n² · D) partition DP.
* **Optimized Solution:** O(n log(sum)).

## 🔹 Solution Breakdown

* **Optimal Approach:** `days(cap)`: start a new day whenever the next package would overflow. Find the smallest `cap` with `days(cap) <= D`.
* **Why This Works?** Greedy loading (fill each day as much as possible) uses the fewest days for a fixed capacity, and more capacity never needs more days — so feasibility is monotone.
* **Edge Cases Considered:**
  * `D = 1` → `sum(weights)`.
  * `D = n` → `max(weights)`.

## 🔹 Tricks & Patterns Used

* **Tight search bounds** `[max, sum]` keep the check simple.
* **Greedy check** inside binary search.

## 🔹 Alternative Data Structures

* Prefix sums + binary search inside the check — useful when the check is called many times on a fixed array.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n log(sum(weights)))
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def shipWithinDays(self, weights: List[int], days: int) -> int:
        for capacity in range(max(weights), sum(weights) + 1):
            used, load = 1, 0
            for w in weights:
                if load + w > capacity:
                    used += 1
                    load = 0
                load += w
            if used <= days:
                return capacity
        return sum(weights)
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def shipWithinDays(self, weights: List[int], days: int) -> int:
        def days_needed(cap: int) -> int:
            used, load = 1, 0
            for w in weights:
                if load + w > cap:  # this package starts a new day
                    used += 1
                    load = 0
                load += w
            return used

        lo, hi = max(weights), sum(weights)
        while lo < hi:
            mid = (lo + hi) // 2
            if days_needed(mid) <= days:
                hi = mid
            else:
                lo = mid + 1
        return lo
```
