# 🔹 Problem Name: 1268. Search Suggestions System (Binary Search, Medium)

**🔗 Link:** [LeetCode 1268](https://leetcode.com/problems/search-suggestions-system/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Sort once, binary search each prefix.** After sorting `products`, all products with a given prefix form one contiguous block. For every prefix of `searchWord`, `bisect_left` finds where that block would start; the (at most) three suggestions are the next three products that still start with the prefix.
* **Core Concept:** lexicographic order makes "all strings with prefix P" a contiguous range
* **When to Use This Pattern?** Autocomplete / prefix queries over a static word list — suggestions, prefix counts, dictionary lookups.
* **Mistakes to Avoid:**
  * Filtering all products for each prefix: O(L · total length) is wasteful when a sort and a bisect do it.
  * Taking `products[i:i + 3]` without checking `startswith`: the slice can run past the block.
  * Forgetting to sort (or sorting the caller's list in place — copy with `sorted`).

## 🔹 Optimization Path

* **Brute Force:** for each prefix, filter the products that start with it, sort, keep three — O(L · P log P · len).
* **Optimized Solution:** sort once, then one `bisect_left` plus three checks per prefix — O(P log P · len + L · (log P + 3) · len).
* **Further Improvements Possible?** A trie that stores the top three at each node answers each prefix in O(1) after an O(total length) build; a two-pointer narrowing of `[lo, hi)` as the prefix grows also works.

## 🔹 Solution Breakdown

* **Optimal Approach:** `products = sorted(products)`. For `i` in `1…len(searchWord)`: `prefix = searchWord[:i]`, `start = bisect_left(products, prefix)`, keep `p` in `products[start:start + 3]` with `p.startswith(prefix)`.
* **Why This Works?** Any string with the prefix sorts at or after the prefix itself and before every string that does not start with it, so the block begins exactly at `bisect_left`. The first three entries of the block are the three lexicographically smallest matches; if the block is shorter than three, `startswith` stops the slice from leaking into the next block.
* **Edge Cases Considered:**
  * No product matches a prefix → `[]` for that prefix and all longer ones.
  * Fewer than three matches.
  * The prefix equals a product (`"mouse"` itself is a suggestion).

## 🔹 Tricks & Patterns Used

* **Sorted order = implicit trie:** neighbours in sorted order share the longest prefixes.
* **`bisect_left` with the prefix as the key:** returns the first product `≥ prefix`.

## 🔹 Alternative Data Structures

* **Trie** with a list of the three smallest words at each node — O(1) per prefix after construction.
* Two moving pointers `lo`, `hi` over the sorted list, tightening them as each character is added — no bisect needed.

## 🔹 Complexity Analysis

* **Time Complexity:** O(S log P + L · (log P + 1) · m), with `P` products, `S` = total characters sorted over, `L` = `len(searchWord)`, `m` = prefix compare cost (at most `L`)
* **Space Complexity:** O(P + L) for the sorted copy and the answer

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def suggestedProducts(self, products: List[str], searchWord: str) -> List[List[str]]:
        result = []
        for end in range(1, len(searchWord) + 1):
            prefix = searchWord[:end]
            matches = sorted(p for p in products if p.startswith(prefix))
            result.append(matches[:3])
        return result
```

## 🔹 Code Snippet (Optimized)

```python
from bisect import bisect_left
from typing import List


class Solution:
    def suggestedProducts(self, products: List[str], searchWord: str) -> List[List[str]]:
        products = sorted(products)
        result = []
        for end in range(1, len(searchWord) + 1):
            prefix = searchWord[:end]
            start = bisect_left(products, prefix)
            # startswith stops the slice at the end of the block of products sharing this prefix
            result.append([p for p in products[start:start + 3] if p.startswith(prefix)])
        return result
```
