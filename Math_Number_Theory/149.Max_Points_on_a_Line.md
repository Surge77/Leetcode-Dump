# 🔹 Problem Name: 149. Max Points on a Line (Geometry Hashing, Hard)

**🔗 Link:** [LeetCode 149](https://leetcode.com/problems/max-points-on-a-line/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Anchor + slope hash map.** Every line through anchor `p` is identified by its direction. For each anchor, hash the reduced direction `(dx, dy)` to every later point; the most frequent direction plus the anchor is the best line through `p`.
* **Core Concept:** lines through a fixed point ⇔ directions; count directions exactly with integer gcd-normalised pairs
* **When to Use This Pattern?** "How many points are collinear / share a slope / form a line" with up to a few thousand points.
* **Mistakes to Avoid:**
  * Floating-point slopes `dy / dx` — division by zero for vertical lines and precision collisions for nearby slopes. Use integers.
  * Not normalising the sign: `(1, −2)` and `(−1, 2)` are the same direction.
  * Returning 0 for a single point — the answer is 1.

## 🔹 Optimization Path

* **Brute Force:** for every pair `(i, j)`, count all points `k` with cross product `(pⱼ − pᵢ) × (pₖ − pᵢ) = 0` — O(n³) = 2.7·10⁷ cross products for `n = 300`.
* **Optimized Solution:** anchor each point and hash reduced directions to the points after it — O(n² log C) for the gcds.
* **Further Improvements Possible?** Not asymptotically for exact answers in general; O(n²) is the standard bound (3SUM-hard flavour).

## 🔹 Solution Breakdown

* **Optimal Approach:** for each `i`: `slopes = Counter()`; for `j > i`: `dx, dy = xⱼ − xᵢ, yⱼ − yᵢ`, divide both by `gcd(|dx|, |dy|)`, flip signs so `dx > 0` or (`dx == 0` and `dy > 0`), count it. `best = max(best, 1 + max(slopes.values()))`.
* **Why This Works?** Two points `a`, `b` lie on the same line through `p` iff `b − p` is a scalar multiple of `a − p`, iff their reduced, sign-normalised directions are equal. The optimal line contains some lowest-index point `i`; when `i` is the anchor, all its other points are counted under one key. Points are unique, so `(0, 0)` never occurs.
* **Edge Cases Considered:**
  * `n = 1` → 1; `n = 2` → 2.
  * Vertical lines (`dx = 0` → key `(0, 1)`) and horizontal lines (`dy = 0` → key `(1, 0)`).

## 🔹 Tricks & Patterns Used

* **Canonical direction:** `(dx/g, dy/g)` with a fixed sign rule — an exact, hashable stand-in for the slope.
* **Only look forward (`j > i`):** each line is counted from its first point, halving the work.

## 🔹 Alternative Data Structures

* Key by the rational slope `Fraction(dy, dx)` (and a sentinel for vertical) — exact but slower.
* Cross-product checks with no hashing (the brute force) — O(1) memory.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n² log C), `C = 2·10⁴` coordinate range for gcd
* **Space Complexity:** O(n) for one anchor's counter

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def maxPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        if n <= 2:
            return n
        best = 2
        for i in range(n):
            x1, y1 = points[i]
            for j in range(i + 1, n):
                dx, dy = points[j][0] - x1, points[j][1] - y1
                on_line = sum(1 for x, y in points if dx * (y - y1) == dy * (x - x1))
                best = max(best, on_line)
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from collections import Counter
from math import gcd
from typing import List


class Solution:
    def maxPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        best = 1
        for i in range(n):
            x1, y1 = points[i]
            slopes = Counter()
            for j in range(i + 1, n):
                dx, dy = points[j][0] - x1, points[j][1] - y1
                g = gcd(dx, dy)  # points are unique, so g > 0
                dx, dy = dx // g, dy // g
                if dx < 0 or (dx == 0 and dy < 0):
                    dx, dy = -dx, -dy
                slopes[(dx, dy)] += 1
            if slopes:
                best = max(best, 1 + max(slopes.values()))
        return best
```
