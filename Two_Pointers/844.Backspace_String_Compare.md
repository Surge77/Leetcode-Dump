# 844. Backspace String Compare

**🔗 Link:** [LeetCode 844](https://leetcode.com/problems/backspace-string-compare/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Two strings are typed into empty text editors, where `#` acts as a backspace (it deletes the previous character, and does nothing on empty text). Return whether the two editors end up showing identical text. The follow-up asks for O(n) time and O(1) space.

* **Example:** `s = "ab#c", t = "ad#c"` → `true`
* **Constraints:** `1 ≤ s.length, t.length ≤ 200`; `s` and `t` contain only lowercase letters and `#`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Walk both strings from the back, skipping what a `#` erases.** From the end, a `#` cancels the next real character to its left, so keep a count of pending backspaces and skip characters while it is positive. Compare the surviving characters pairwise.
* **Core Concept:** processing from the end turns "delete the previous character" into "skip the next characters" — no storage needed
* **When to Use This Pattern?** Compare the final state of two edit sequences, or any "undo-the-previous" operation, in O(1) space.
* **Mistakes to Avoid:**
  * Scanning from the front: a `#` at position `i` affects characters before it, which you have already passed.
  * Treating `#` on an empty text as an error — it simply does nothing.
  * Comparing when only one string has remaining characters: that is a mismatch.
  * Forgetting that consecutive `#` accumulate (`"ab##"` erases both letters).

## 🔹 Optimization Path

* **Brute Force:** build each final string with a stack (push letters, pop on `#`), then compare — O(n) time, O(n) space.
* **Optimized Solution:** two pointers from the right with skip counters — O(n) time, O(1) space.
* **Further Improvements Possible?** No; every character is read once.

## 🔹 Solution Breakdown

* **Optimal Approach:** `_skip(text, i)` moves `i` left past erased characters: a `#` increments `back`, a letter with `back > 0` decrements it and is skipped, otherwise stop. The main loop calls it for both strings, compares the characters found (or detects that one string ended before the other), then steps both pointers left.
* **Why This Works?** A letter survives exactly when, by the time we reach it, every `#` to its right has already been used up skipping a letter; the counter holds the backspaces still pending while moving left.
* **Edge Cases Considered:**
  * Both strings reduce to empty (`"ab##"` vs `"c#d#"`) → `true`.
  * Only backspaces (`"a##c"` vs `"#a#c"`) → both become `"c"`.
  * Different lengths that reduce to the same text.

## 🔹 Tricks & Patterns Used

* **Scan in the direction in which "deletions" are already known:** the erasing character comes after the erased one, so go backwards.
* **Counter instead of a stack:** a stack holds the survivors; the counter only needs to know how many to skip.

## 🔹 Alternative Data Structures

* Stack per string (the brute force) — shortest code, O(n) space.
* Build both reduced strings with one function and compare.

* **Time Complexity:** O(n + m)
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def backspaceCompare(self, s: str, t: str) -> bool:
        def typed(text: str) -> list:
            stack = []
            for ch in text:
                if ch != "#":
                    stack.append(ch)
                elif stack:
                    stack.pop()
            return stack

        return typed(s) == typed(t)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def backspaceCompare(self, s: str, t: str) -> bool:
        i, j = len(s) - 1, len(t) - 1
        while i >= 0 or j >= 0:
            i = self._skip(s, i)
            j = self._skip(t, j)
            if i >= 0 and j >= 0:
                if s[i] != t[j]:
                    return False
            elif i >= 0 or j >= 0:  # one string has a surviving character, the other does not
                return False
            i -= 1
            j -= 1
        return True

    def _skip(self, text: str, i: int) -> int:
        back = 0
        while i >= 0:
            if text[i] == "#":
                back += 1
            elif back:
                back -= 1
            else:
                break
            i -= 1
        return i
```
