# 1851. Minimum Interval to Include Each Query

**🔗 Link:** [LeetCode 1851](https://leetcode.com/problems/minimum-interval-to-include-each-query/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You get a list of inclusive intervals `[left, right]` and a list of query points. For each query, find the size (`right - left + 1`) of the smallest interval that contains it, or `-1` if no interval does, and return the answers in query order.

* **Example:** `intervals = [[1,4],[2,4],[3,6],[4,4]], queries = [2,3,4,5]` → `[3,3,1,4]`
* **Constraints:** `1 ≤ intervals.length ≤ 10^5`; `1 ≤ queries.length ≤ 10^5`; `1 ≤ left ≤ right ≤ 10^7`; `1 ≤ queries[j] ≤ 10^7`

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Offline queries + min-heap.** Sort intervals by left end and the queries by value (remember original indices). For each query `q` in increasing order: push every interval with `left ≤ q` as `(size, right)`; pop heap tops whose `right < q` (they can never contain this or any later query); the top's size is the answer, or `−1` if the heap is empty.
* **Core Concept:** answering queries in sorted order lets an interval be added once and removed once — lazy deletion makes stale intervals disappear only when they reach the top
* **When to Use This Pattern?** Many queries "best interval / item that covers point `q`" where queries can be reordered — offline processing with a sweep and a heap keyed on the objective.
* **Mistakes to Avoid:**
  * O(n·q) scanning: 10⁵ × 10⁵ = 10¹⁰.
  * Returning answers in sorted-query order — map them back to the original positions (queries can repeat).
  * Interval size is `right − left + 1` (inclusive).

## 🔹 Optimization Path

* **Brute Force:** for each query, scan all intervals containing it and take the min size — O(n·q).
* **Optimized Solution:** sort both + heap with lazy deletion — O(n log n + q log q).
* **Further Improvements Possible?** Alternatives with the same bound: sort intervals by size and assign each to all still-unanswered queries in `[left, right]` using a sorted list / DSU "next unanswered" pointer.

## 🔹 Solution Breakdown

* **Optimal Approach:** pointer `i` over intervals sorted by `left`; for each `q` in sorted order: while `intervals[i].left ≤ q` push `(r − l + 1, r)`; while `heap[0].right < q` pop; record `heap[0].size` or `−1`.
* **Why This Works?** At query `q`, every interval with `left ≤ q` has been pushed. An interval contains `q` iff additionally `right ≥ q`. Popped intervals have `right < q ≤ every later query`, so removing them permanently is safe. The heap may still hold stale intervals below the top, but the top itself is valid, and it is the smallest among valid ones because all valid ones are in the heap.
* **Edge Cases Considered:**
  * Query covered by no interval → `−1`.
  * Duplicate queries — each gets its own answer slot.
  * Single-point intervals `[4, 4]` (size 1).

## 🔹 Tricks & Patterns Used

* **Offline processing:** sort queries with their indices (`sorted(range(q), key=queries.__getitem__)`) and write answers back by index.
* **Lazy deletion:** don't search the heap for expired items — discard them only when they surface at the top.
* **Heap key = objective:** push `(size, right)` so the top is the best candidate.

## 🔹 Alternative Data Structures

* Sort intervals by size, then for each interval assign the answer to all unanswered queries in its range (sorted unique query values + "next unassigned" DSU) — O((n + q) log q).
* Segment tree over compressed coordinates with range-chmin updates and point queries.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def minInterval(self, intervals: List[List[int]], queries: List[int]) -> List[int]:
        answer = []
        for q in queries:
            sizes = [r - l + 1 for l, r in intervals if l <= q <= r]
            answer.append(min(sizes) if sizes else -1)
        return answer
```

## 🔹 Code Snippet (Optimized)

```python
import heapq
from typing import List


class Solution:
    def minInterval(self, intervals: List[List[int]], queries: List[int]) -> List[int]:
        intervals = sorted(intervals)
        answer = [-1] * len(queries)
        heap = []
        i = 0
        for qi in sorted(range(len(queries)), key=queries.__getitem__):
            q = queries[qi]
            while i < len(intervals) and intervals[i][0] <= q:
                left, right = intervals[i]
                heapq.heappush(heap, (right - left + 1, right))
                i += 1
            while heap and heap[0][1] < q:
                heapq.heappop(heap)  # ends before q, so before every later query too
            if heap:
                answer[qi] = heap[0][0]
        return answer
```
