# 🔹 Problem Name: 309. Best Time to Buy and Sell Stock with Cooldown (Dynamic Programming, Medium)

**🔗 Link:** [LeetCode 309](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Track three states per day — `hold` (own a share), `sold` (sold today), `rest` (no share, free to buy).
* **Core Concept:** State-machine DP
* **When to Use This Pattern?** Problems with "modes" and rules for moving between them: cooldowns, fees, at most k transactions.
* **Mistakes to Avoid:**
  * Updating `hold` with the *new* `rest` instead of yesterday's — compute all three from the old values at once.
  * Allowing a buy on the day right after a sell (that is the cooldown).

## 🔹 Optimization Path

* **Brute Force:** O(3ⁿ) — try buy / sell / wait on every day.
* **Optimized Solution:** O(n) time, O(1) space.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:**
  * `hold = max(hold, rest - price)` — keep holding, or buy today (only allowed from `rest`)
  * `sold = hold + price` — sell today
  * `rest = max(rest, sold)` — idle, or yesterday's sale finished its cooldown
* **Why This Works?** Every valid trading history is a walk through these three states; the DP keeps the best profit for each state on each day.
* **Edge Cases Considered:**
  * One day (no trade possible).
  * Strictly decreasing prices (answer 0).

## 🔹 Pattern Recognition

* **Belongs To:** DP — state machine
* **Common Problems Using This:**
  * 122. Stock II (no cooldown)
  * 714. Stock with Transaction Fee
  * 123 / 188. Stock III / IV (at most k transactions)

## 🔹 Tricks & Patterns Used

* **Tuple assignment** updates all states from yesterday's values in one line.
* Start `hold` at `-inf` (owning a share before day 0 is impossible).

* Draw the state diagram first; each arrow becomes one term in a `max`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        hold, sold, rest = float("-inf"), float("-inf"), 0
        for p in prices:
            # all three new states come from yesterday's values
            hold, sold, rest = max(hold, rest - p), hold + p, max(rest, sold)
        return max(sold, rest)
```
