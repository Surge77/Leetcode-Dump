# 🔹 Problem Name: 12. Integer to Roman (Greedy, Medium)

**🔗 Link:** [LeetCode 12](https://leetcode.com/problems/integer-to-roman/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given a positive integer, write it as a Roman numeral. The numeral is built one decimal place at a time from the highest place to the lowest, using the symbols `I V X L C D M`. Only six subtractive forms exist (`IV IX XL XC CD CM`), and only `I`, `X`, `C`, `M` may repeat, at most three times in a row.

* **Example:** `num = 3749` → `"MMMDCCXLIX"`
* **Constraints:** `1 ≤ num ≤ 3999`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Greedy over 13 tokens.** Put the six subtractive pairs (`CM 900`, `CD 400`, `XC 90`, `XL 40`, `IX 9`, `IV 4`) into the value table next to the seven symbols, sorted descending. For each token emit it `num // value` times and keep `num % value`.
* **Core Concept:** once the subtractive forms are tokens of their own, Roman numerals become a canonical coin system — taking the largest token that fits is always right
* **When to Use This Pattern?** Converting a number into a "biggest unit first" representation: Roman numerals, English words (273), time `1d 3h 5m`, change-making with canonical coins.
* **Mistakes to Avoid:**
  * A table with only the 7 symbols: 4 becomes `IIII`, 900 becomes `DCCCC`.
  * Table not sorted descending — the greedy then picks a small token first.

## 🔹 Optimization Path

* **Brute Force:** build the purely additive form with the 7 symbols (`4 = IIII`, `900 = DCCCC`) by repeated subtraction, then rewrite the six over-long patterns into subtractive pairs.
* **Optimized Solution:** greedy with `divmod` over the 13-token table — at most 13 iterations.
* **Further Improvements Possible?** Four lookup tables (thousands, hundreds, tens, ones), each listing the 10 digit spellings: `M[n // 1000] + C[n % 1000 // 100] + X[n % 100 // 10] + I[n % 10]` — 4 lookups, still O(1).

## 🔹 Solution Breakdown

* **Optimal Approach:** `for value, symbol in TOKENS: count, num = divmod(num, value); parts.append(symbol * count)`.
* **Why This Works?** Each decimal digit is spelled independently (`d·10ᵏ`), and for a digit the descending greedy over `{9, 5, 4, 1}·10ᵏ` produces exactly the standard spelling: 9 → `IX`, 5–8 → `V` + `I`s, 4 → `IV`, 0–3 → `I`s. Higher tokens never reach into a lower digit because every token value is a single digit times a power of ten.
* **Edge Cases Considered:**
  * `num = 3999` → `MMMCMXCIX` (the maximum input); `3888` → `MMMDCCCLXXXVIII` is the longest output, 15 characters.
  * Digits 4 and 9 at every position (`CDXLIV` = 444, `CMXCIX` = 999).

## 🔹 Pattern Recognition

* **Belongs To:** Greedy — canonical "largest unit first" decomposition
* **Common Problems Using This:**
  * 13. Roman to Integer (the reverse direction) (in this repo)
  * 273. Integer to English Words
  * 322. Coin Change (in this repo, where greedy fails for arbitrary coins and DP is needed)

## 🔹 Tricks & Patterns Used

* **Promote exceptions to tokens:** the irregular cases (4, 9, 40, …) become ordinary table rows, so the loop has no special case.
* **`divmod`** gives the repeat count and the remainder in one call.

## 🔹 Alternative Data Structures

* Per-digit lookup tables (see Further Improvements).
* A `while num >= value` loop instead of `divmod` — same result, at most 3 repetitions per token.

## 🔹 Complexity Analysis

* **Time Complexity:** O(1) — 13 tokens, output at most 15 characters
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def intToRoman(self, num: int) -> str:
        parts = []
        for value, symbol in ((1000, "M"), (500, "D"), (100, "C"), (50, "L"), (10, "X"), (5, "V"), (1, "I")):
            while num >= value:
                parts.append(symbol)
                num -= value
        roman = "".join(parts)
        # the 5-letter patterns must go first, or DCCCC would turn into DCD
        for long_form, short_form in (("DCCCC", "CM"), ("CCCC", "CD"), ("LXXXX", "XC"),
                                      ("XXXX", "XL"), ("VIIII", "IX"), ("IIII", "IV")):
            roman = roman.replace(long_form, short_form)
        return roman
```

## 🔹 Code Snippet (Optimized)

```python
TOKENS = ((1000, "M"), (900, "CM"), (500, "D"), (400, "CD"), (100, "C"), (90, "XC"),
          (50, "L"), (40, "XL"), (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I"))


class Solution:
    def intToRoman(self, num: int) -> str:
        parts = []
        for value, symbol in TOKENS:
            count, num = divmod(num, value)
            parts.append(symbol * count)
        return "".join(parts)
```
