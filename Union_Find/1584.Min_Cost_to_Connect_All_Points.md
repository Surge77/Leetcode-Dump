# 🔹 Problem Name: 1584. Min Cost to Connect All Points (Minimum Spanning Tree, Medium)

**🔗 Link:** [LeetCode 1584](https://leetcode.com/problems/min-cost-to-connect-all-points/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Build all `n(n-1)/2` Manhattan edges, sort them, and add each edge that joins two different components (Kruskal) until `n - 1` edges are used.
* **Core Concept:** Minimum Spanning Tree — Kruskal with Union-Find
* **When to Use This Pattern?** "Connect everything at minimum total cost" (roads, cables, pipelines).
* **Mistakes to Avoid:**
  * Shortest paths (Dijkstra) — minimises distance from one source, not total wiring cost.
  * Not stopping after `n - 1` edges (wastes time).

## 🔹 Optimization Path

* **Brute Force:** Try every spanning tree — exponential.
* **Kruskal:** O(n² log n) — sort all edges.
* **Prim (array version):** O(n²) — best for complete/dense graphs like this one.

## 🔹 Solution Breakdown

* **Optimal Approach:** Sort edges by cost; DSU-union each edge; count used edges; stop at `n - 1`.
* **Why This Works?** Cut property: the cheapest edge crossing any cut belongs to some MST. Kruskal always adds the cheapest edge that does not form a cycle, which is the cheapest edge across the cut between its two components.
* **Edge Cases Considered:**
  * One point → 0.
  * Duplicate coordinates are not allowed (all points distinct), but equal edge weights are fine.

## 🔹 Pattern Recognition

* **Belongs To:** Union-Find / Minimum Spanning Tree
* **Common Problems Using This:**
  * 1135. Connecting Cities With Minimum Cost

## 🔹 Tricks & Patterns Used

* **Kruskal = sort + DSU.**
* **Early stop** at `n - 1` edges.

## 🔹 Alternative Data Structures

* **Prim with a `dist` array:** each step pick the closest unvisited point, then relax all others — O(n²), no sorting, fastest here.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n² log n)
* **Space Complexity:** O(n²)

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def minCostConnectPoints(self, points: List[List[int]]) -> int:
        n = len(points)
        edges = []
        for i in range(n):
            xi, yi = points[i]
            for j in range(i + 1, n):
                xj, yj = points[j]
                edges.append((abs(xi - xj) + abs(yi - yj), i, j))
        edges.sort()

        parent = list(range(n))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        total = used = 0
        for cost, i, j in edges:
            ri, rj = find(i), find(j)
            if ri != rj:
                parent[ri] = rj
                total += cost
                used += 1
                if used == n - 1:
                    break
        return total
```
