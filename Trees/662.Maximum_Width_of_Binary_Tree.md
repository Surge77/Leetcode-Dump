# 662. Maximum Width of Binary Tree

**🔗 Link:** [LeetCode 662](https://leetcode.com/problems/maximum-width-of-binary-tree/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Return the maximum width over all levels of a binary tree. A level's width is the distance between its leftmost and rightmost non-null nodes, counting the null slots between them as if the tree were complete. The answer is guaranteed to fit in a signed 32-bit integer.

* **Example:** `root = [1,3,2,5,3,null,9]` → `4`
* **Constraints:** `1 ≤ nodes ≤ 3000`, `-100 ≤ Node.val ≤ 100`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **BFS with heap positions.** Number slots like a complete binary tree: a node at position `p` has children at `2p` and `2p + 1`. A level's width is `last position − first position + 1`. Re-base positions by subtracting the level's first position so they stay small.
* **Core Concept:** null slots between the two end nodes count, so measure positions, not node counts
* **When to Use This Pattern?** Anything that depends on where a node *would* sit in a complete tree — width with gaps, completeness checks, heap-indexed trees.
* **Mistakes to Avoid:**
  * Counting the nodes in a level: gaps in between must be counted too.
  * Un-rebased positions double every level: a 3000-node path is 3000 levels deep → positions near 2²⁹⁹⁹ (overflow in Java/C++, needlessly huge ints in Python), even though its width is only 1.
  * Materializing the `None` slots level by level: a sparse deep tree has 2^depth slots.

## 🔹 Optimization Path

* **Brute Force:** BFS that keeps explicit `None` placeholders between the end nodes — O(sum of widths), exponential in depth for sparse trees.
* **Optimized Solution:** BFS carrying positions, only real nodes stored — O(n).
* **Further Improvements Possible?** No; O(n) is optimal.

## 🔹 Solution Breakdown

* **Optimal Approach:** `level = [(root, 0)]`; for each level take `first = level[0].pos`, update `best` with `level[-1].pos − first + 1`, then push children with `2(p − first)` and `2(p − first) + 1`.
* **Why This Works?** Subtracting the same `first` from every position in a level shifts the whole level left without changing differences, and children of shifted positions are still in the same relative order with the same gaps doubled — the width of every later level is unchanged.
* **Edge Cases Considered:**
  * Single node → 1.
  * One node per level (any zig-zag path) → width 1; re-based positions stay 0 or 1.
  * Two paths diverging at the root → the width doubles every level; LeetCode guarantees the answer fits a signed 32-bit int, and re-based positions stay below twice that.

## 🔹 Tricks & Patterns Used

* **Heap indexing:** `2p`, `2p + 1` places every node of a binary tree in one numbered grid.
* **Re-basing per level:** keeps numbers bounded by twice the level width.

## 🔹 Alternative Data Structures

* DFS recording the first position seen at each depth (`first[depth]`) and comparing every node against it — O(n), but needs depth-aware recursion or an explicit stack.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(w), the most nodes in one level

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def widthOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        best, level = 0, [root]
        while any(level):
            first = next(i for i, node in enumerate(level) if node)
            last = max(i for i, node in enumerate(level) if node)
            level = level[first:last + 1]  # slots outside the two end nodes never count
            best = max(best, len(level))
            level = [child for node in level for child in ((node.left, node.right) if node else (None, None))]
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def widthOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        best, level = 0, [(root, 0)]
        while level:
            first = level[0][1]
            best = max(best, level[-1][1] - first + 1)
            nxt = []
            for node, pos in level:
                pos -= first  # re-base so positions stay below 2·width instead of 2^depth
                if node.left:
                    nxt.append((node.left, 2 * pos))
                if node.right:
                    nxt.append((node.right, 2 * pos + 1))
            level = nxt
        return best
```
