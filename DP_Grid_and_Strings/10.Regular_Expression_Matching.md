# 🔹 Problem Name: 10. Regular Expression Matching (2D DP on Strings, Hard)

**🔗 Link:** [LeetCode 10](https://leetcode.com/problems/regular-expression-matching/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given a string `s` and a pattern `p`, decide whether the pattern matches the entire string. In the pattern, `.` matches any single character and `*` matches zero or more copies of the character (or `.`) immediately before it.

* **Example:** `s = "aa", p = "a"` → `false`
* **Constraints:** `1 ≤ s.length, p.length ≤ 20`, `s` is lowercase letters, `p` is lowercase letters, `.` or `*`, and every `*` has a valid preceding character

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Suffix DP.** `dp[i][j]` = does `s[i:]` match `p[j:]`? If `p[j+1] == '*'`, either skip the `x*` pair (`dp[i][j+2]`) or, when `s[i]` matches `x`, consume one char of `s` and stay on the pair (`dp[i+1][j]`). Otherwise both advance (`dp[i+1][j+1]`).
* **Core Concept:** a `*` is a choice (zero more copies / one more copy), and the choices overlap — memoise on the two positions.
* **When to Use This Pattern?** Matching a string against a pattern with optional / repeating tokens: wildcards, regex subsets, "can `t` be produced from `s` by these rules".
* **Mistakes to Avoid:**
  * Treating `*` on its own: it always belongs to the char **before** it, so look ahead at `p[j+1]`, not back.
  * Requiring `s[i]` to match when skipping `x*` — zero copies is always allowed, even with `s` exhausted.
  * `dp[len(s)][j]` is not just `j == len(p)`: an empty `s` still matches `a*b*`.

## 🔹 Optimization Path

* **Brute Force:** plain recursion trying both branches of every `*` — exponential (e.g. `s = "aaaa…a"`, `p = "a*a*a*…b"`).
* **Optimized Solution:** the recursion only ever depends on `(i, j)`, so there are `(|s|+1)(|p|+1)` states, each O(1) — O(|s| · |p|).
* **Further Improvements Possible?** Only `dp[i]` and `dp[i+1]` are read, so two rows of length `|p|+1` give O(|p|) space. With `|s|, |p| ≤ 20` the full table is already tiny.

## 🔹 Solution Breakdown

* **Optimal Approach:** fill `dp` from `i = |s|` down to `0` and `j = |p| − 1` down to `0`, with `dp[|s|][|p|] = True`. `first = i < |s| and p[j] in (s[i], '.')`.
* **Why This Works?** Any match of `s[i:]` against `p[j:]` either uses `x*` for zero chars (then `s[i:]` matches `p[j+2:]`) or for at least one char (then `s[i]` matches `x` and `s[i+1:]` matches `x*…` again). Without a `*`, the first chars must pair up. These cases are exhaustive, and each refers to a state with larger `i` or `j`, so the bottom-up order sees every dependency first.
* **Edge Cases Considered:**
  * `s` exhausted but pattern left: only `x*` pairs can be skipped (`"" ~ "a*b*"` is true, `"" ~ "a"` is false).
  * `.*` matches any suffix, including the empty one.
  * LeetCode guarantees every `*` has a valid preceding character, so `p[0]` is never `*`.

## 🔹 Tricks & Patterns Used

* **Suffix indexing:** defining `dp` on `s[i:]` / `p[j:]` makes the recursion and the table read the same way, and the base case is the single cell `dp[|s|][|p|]`.
* **Look-ahead for postfix operators:** decide at `p[j]` by checking `p[j+1] == '*'`.

## 🔹 Alternative Data Structures

* Top-down recursion with `functools.lru_cache` on `(i, j)` — same complexity, closer to the brute force.
* An NFA (Thompson construction) simulated over `s` — O(|s| · |p|), the way real regex engines avoid backtracking blow-ups.

## 🔹 Complexity Analysis

* **Time Complexity:** O(|s| · |p|)
* **Space Complexity:** O(|s| · |p|) for the table (O(|p|) with two rows)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        if not p:
            return not s
        first = bool(s) and p[0] in (s[0], '.')
        if len(p) >= 2 and p[1] == '*':
            return self.isMatch(s, p[2:]) or (first and self.isMatch(s[1:], p))
        return first and self.isMatch(s[1:], p[1:])
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        n, m = len(s), len(p)
        dp = [[False] * (m + 1) for _ in range(n + 1)]
        dp[n][m] = True
        for i in range(n, -1, -1):
            for j in range(m - 1, -1, -1):
                first = i < n and p[j] in (s[i], '.')
                if j + 1 < m and p[j + 1] == '*':
                    # zero copies of p[j], or eat s[i] and keep the x* pair available
                    dp[i][j] = dp[i][j + 2] or (first and dp[i + 1][j])
                else:
                    dp[i][j] = first and dp[i + 1][j + 1]
        return dp[0][0]
```
