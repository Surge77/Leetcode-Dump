# 🔹 Problem Name: 787. Cheapest Flights Within K Stops (Bellman-Ford, Medium)

**🔗 Link:** [LeetCode 787](https://leetcode.com/problems/cheapest-flights-within-k-stops/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** At most `k` stops = at most `k + 1` flights. Run exactly `k + 1` Bellman-Ford rounds, each relaxing from a **copy** of the previous round's prices.
* **Core Concept:** Bellman-Ford limited to a number of edges
* **When to Use This Pattern?** Shortest path with a cap on the number of edges/hops/transfers.
* **Mistakes to Avoid:**
  * Plain Dijkstra on node only — a cheaper path with more stops can block a valid one.
  * Relaxing in place within a round — lets one round use several edges and breaks the stop limit.

## 🔹 Optimization Path

* **Brute Force:** DFS over all paths with ≤ k+1 edges — exponential.
* **Optimized Solution:** O(k · E) Bellman-Ford.
* **Further Improvements Possible?** Dijkstra on state `(node, stops used)` or BFS by levels with pruning.

## 🔹 Solution Breakdown

* **Optimal Approach:** `price[src] = 0`; repeat `k + 1` times: `nxt = price[:]`, then for each flight `u → v` with cost `w`: `nxt[v] = min(nxt[v], price[u] + w)`.
* **Why This Works?** After round `r`, `price[v]` is the cheapest cost using at most `r` flights; reading only from the previous round guarantees each round adds at most one flight.
* **Edge Cases Considered:**
  * Destination unreachable within the limit → -1.
  * Direct flight more expensive than a 1-stop route.

## 🔹 Pattern Recognition

* **Belongs To:** Graph — Shortest Path (Bellman-Ford)
* **Common Problems Using This:**
  * 743. Network Delay Time

## 🔹 Tricks & Patterns Used

* **Copy per round** = edge-count-limited DP: `dp[r][v] = min(dp[r-1][u] + w)`.

## 🔹 Alternative Data Structures

* Heap of `(cost, node, stops)` with a `best_stops[node]` prune.

## 🔹 Complexity Analysis

* **Time Complexity:** O((k + 1) · E)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def findCheapestPrice(self, n: int, flights: List[List[int]], src: int, dst: int, k: int) -> int:
        INF = float("inf")
        price = [INF] * n
        price[src] = 0
        for _ in range(k + 1):  # at most k stops => at most k+1 flights
            nxt = price[:]  # read old round, write new round
            for u, v, w in flights:
                if price[u] + w < nxt[v]:
                    nxt[v] = price[u] + w
            price = nxt
        return price[dst] if price[dst] < INF else -1
```
