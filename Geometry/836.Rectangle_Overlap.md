# 🔹 Problem Name: 836. Rectangle Overlap (Geometry, Easy)

**🔗 Link:** [LeetCode 836](https://leetcode.com/problems/rectangle-overlap/)

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** Two axis-aligned rectangles overlap (with positive area) iff their x-intervals overlap **and** their y-intervals overlap: `max(left) < min(right)` and `max(bottom) < min(top)`.
* **Core Concept:** Interval overlap applied per axis
* **When to Use This Pattern?** Collision checks, intersection area (223. Rectangle Area), merging boxes.
* **Mistakes to Avoid:**
  * Treating touching edges/corners as overlap — use strict `<`.
  * Writing many case-by-case comparisons — the per-axis test covers everything.

## 🔹 Optimization Path

* **Brute Force:** Check corner containment — misses "cross" shaped overlaps.
* **Optimized Solution:** O(1) per-axis interval check.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `x_overlap = min(ax2, bx2) - max(ax1, bx1)`, same for `y`; overlap iff both are `> 0`.
* **Why This Works?** The intersection of two axis-aligned rectangles is the rectangle `[max(x1), min(x2)] × [max(y1), min(y2)]`; it has positive area iff both side lengths are positive.
* **Edge Cases Considered:**
  * Sharing only an edge or a corner → False.
  * One rectangle inside the other → True.
  * Cross-shaped overlap (no corner inside the other) → True.

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def isRectangleOverlap(self, rec1: List[int], rec2: List[int]) -> bool:
        ax1, ay1, ax2, ay2 = rec1
        bx1, by1, bx2, by2 = rec2
        x_overlap = min(ax2, bx2) - max(ax1, bx1)
        y_overlap = min(ay2, by2) - max(ay1, by1)
        return x_overlap > 0 and y_overlap > 0  # touching edges do not count
```
