# 417. Pacific Atlantic Water Flow

**🔗 Link:** [LeetCode 417](https://leetcode.com/problems/pacific-atlantic-water-flow/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

A rectangular island is given as a grid of heights. The Pacific Ocean touches its top and left edges and the Atlantic its bottom and right edges. Rain water moves from a cell to a neighbouring cell (up, down, left, right) of equal or lower height, and a cell next to an ocean can drain into it. Return the coordinates of every cell from which water can reach both oceans.

* **Example:** `heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]]` → `[[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]`
* **Constraints:** `1 ≤ m, n ≤ 200`, `0 ≤ heights[r][c] ≤ 10^5`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Search backwards from each ocean.** Water flows downhill (to a neighbour of height ≤ current). Reverse it: start from all Pacific border cells (top row, left column) and climb to neighbours of height **≥** current — every reached cell drains into the Pacific. Do the same from the Atlantic border (bottom row, right column). The answer is the intersection.
* **Core Concept:** "which cells can reach a target set" = one reverse traversal from the target set
* **When to Use This Pattern?** Many sources and few targets: reverse the edges and search from the targets once instead of from every source.
* **Mistakes to Avoid:**
  * Searching downhill from every cell: O((m·n)²).
  * Using `>` instead of `≥` when climbing — water also flows between equal heights.
  * Recursive DFS on a 200 × 200 grid → up to 40 000 deep → `RecursionError`.

## 🔹 Optimization Path

* **Brute Force:** from every cell, search downhill and record whether both oceans are touched — O((m·n)²).
* **Optimized Solution:** two multi-source BFS from the ocean borders — O(m·n).
* **Further Improvements Possible?** No; each cell is visited at most twice.

## 🔹 Solution Breakdown

* **Optimal Approach:** `climb(starts)` = BFS from the given border cells, moving to in-grid neighbours with `heights[next] ≥ heights[cur]`. Return `climb(pacific border) ∩ climb(atlantic border)`.
* **Why This Works?** A step uphill from `cur` to `next` is a step water can take downhill from `next` to `cur`. So a cell is reached from an ocean's border exactly when water starting there can flow into that ocean.
* **Edge Cases Considered:**
  * `1 × 1` grid → `[[0, 0]]` (touches both oceans).
  * A single row or column — every cell borders both oceans.

## 🔹 Tricks & Patterns Used

* **Reverse the edge direction** so one search covers all starting cells.
* **Set intersection** of the two reachable sets gives the answer directly.

* Two boolean matrices instead of sets — lower constant factor.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        m, n = len(heights), len(heights[0])

        def reaches_both(sr: int, sc: int) -> bool:
            pacific = atlantic = False
            seen, stack = {(sr, sc)}, [(sr, sc)]
            while stack:
                r, c = stack.pop()
                pacific |= r == 0 or c == 0
                atlantic |= r == m - 1 or c == n - 1
                for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                    if (0 <= nr < m and 0 <= nc < n and (nr, nc) not in seen
                            and heights[nr][nc] <= heights[r][c]):
                        seen.add((nr, nc))
                        stack.append((nr, nc))
            return pacific and atlantic

        return [[r, c] for r in range(m) for c in range(n) if reaches_both(r, c)]
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        m, n = len(heights), len(heights[0])

        def climb(starts: list) -> set:
            reached = set(starts)
            queue = deque(reached)
            while queue:
                r, c = queue.popleft()
                for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                    # uphill for us = downhill for water flowing from (nr, nc) to (r, c)
                    if (0 <= nr < m and 0 <= nc < n and (nr, nc) not in reached
                            and heights[nr][nc] >= heights[r][c]):
                        reached.add((nr, nc))
                        queue.append((nr, nc))
            return reached

        pacific = climb([(0, c) for c in range(n)] + [(r, 0) for r in range(m)])
        atlantic = climb([(m - 1, c) for c in range(n)] + [(r, n - 1) for r in range(m)])
        return [[r, c] for r, c in sorted(pacific & atlantic)]
```
