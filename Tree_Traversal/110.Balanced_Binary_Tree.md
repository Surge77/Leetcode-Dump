# 🔹 Problem Name: 110. Balanced Binary Tree (Tree DFS, Easy)

**🔗 Link:** [LeetCode 110](https://leetcode.com/problems/balanced-binary-tree/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Decide whether a binary tree is height-balanced: for every node, the heights of its left and right subtrees differ by at most 1.

* **Example:** `root = [3,9,20,null,null,15,7]` → `true`
* **Constraints:** the number of nodes is in `[0, 5000]`; `-10⁴ ≤ Node.val ≤ 10⁴`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Bottom-up heights.** Compute each node's height from its children's heights, children first, and fail the moment a node's two child heights differ by more than 1. Every height is computed exactly once.
* **Core Concept:** postorder DP — a node's answer is built from its children's answers
* **When to Use This Pattern?** A property that must hold at **every** node and depends on subtree aggregates (height, size, sum, min/max) — diameter, maximum path sum, house robber on a tree.
* **Mistakes to Avoid:**
  * Checking only the root: in `[1,2,2,3,null,null,3,4,null,null,4]` both root subtrees have height 3, yet each `2` has child heights 2 and 0.
  * Calling a separate `height()` at every node — the same heights get recomputed by every ancestor.
  * Recursive height on a 5000-node chain → `RecursionError` at Python's default limit of 1000.

## 🔹 Optimization Path

* **Brute Force:** top-down — at each node compute both child heights from scratch, then recurse into the children: O(n·h) (O(n log n) on a balanced tree).
* **Optimized Solution:** one bottom-up pass — O(n).
* **Further Improvements Possible?** No — a balanced tree forces a look at every node.

## 🔹 Solution Breakdown

* **Optimal Approach:** BFS to list the nodes with every parent before its children; walk the list backwards with `height[None] = 0`: `left, right = height[node.left], height[node.right]`; if `abs(left − right) > 1` return `False`; else `height[node] = 1 + max(left, right)`.
* **Why This Works?** Walking a parents-first order backwards handles both children before their parent — all a postorder computation needs. The tree is balanced iff no node fails the check, and each check uses exact heights.
* **Edge Cases Considered:**
  * Empty tree → `True`.
  * A 2-node chain is balanced; a 3-node chain is not (the root's child heights are 2 and 0).

## 🔹 Tricks & Patterns Used

* **Sentinel −1:** in the recursive form, return `-1` for "unbalanced" and pass it straight up, so one function returns both the height and the verdict.
* **Reversed BFS order instead of recursion:** gives children-before-parents with no call stack.

## 🔹 Alternative Data Structures

* Recursive `height(node)` returning `-1` on imbalance — the classic six-line answer; it descends to the bottom of a 5000-node chain before noticing anything, so it needs `sys.setrecursionlimit`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n) for the node order and the height map

## 🔹 Code Snippet (Brute Force)

```python
import sys
from typing import Optional


class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        sys.setrecursionlimit(10_000)  # height() on a 5000-node chain recurses 5000 deep
        if root is None:
            return True
        if abs(self.height(root.left) - self.height(root.right)) > 1:
            return False
        return self.isBalanced(root.left) and self.isBalanced(root.right)

    def height(self, node: Optional[TreeNode]) -> int:
        if node is None:
            return 0
        return 1 + max(self.height(node.left), self.height(node.right))
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        order = [root] if root else []
        for node in order:  # BFS: parents appear before their children
            for child in (node.left, node.right):
                if child:
                    order.append(child)
        height = {None: 0}
        for node in reversed(order):  # both children are already measured
            left, right = height[node.left], height[node.right]
            if abs(left - right) > 1:
                return False
            height[node] = 1 + max(left, right)
        return True
```
