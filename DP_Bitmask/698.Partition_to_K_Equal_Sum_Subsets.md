# 🔹 Problem Name: 698. Partition to K Equal Sum Subsets (Bitmask DP, Medium)

**🔗 Link:** [LeetCode 698](https://leetcode.com/problems/partition-to-k-equal-sum-subsets/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Fill buckets one at a time. State = set of used numbers (bitmask); `dp[mask]` = how full the current bucket is (`sum(mask) % target`), or `-1` if `mask` is unreachable.
* **Core Concept:** Bitmask DP over subsets
* **When to Use This Pattern?** `n ≤ 16–20` and you must assign items to groups/orders — the tiny `n` is the hint.
* **Mistakes to Avoid:**
  * Not checking `total % k` and `max(nums) <= target` first.
  * Plain backtracking without memo — exponential blow-up with many equal numbers.

## 🔹 Optimization Path

* **Brute Force:** O(kⁿ) — assign every number to every bucket.
* **Optimized Solution:** O(n · 2ⁿ) bitmask DP.
* **Further Improvements Possible?** Sorting + `break` prunes transitions (all later numbers are bigger).

## 🔹 Solution Breakdown

* **Optimal Approach:** From each reachable `mask`, add any unused number that fits into the current bucket: `dp[mask | 1<<i] = (dp[mask] + nums[i]) % target`.
* **Why This Works?** Only the set of used numbers matters — which bucket they went to is irrelevant because buckets are filled one after another. The fill level of the current bucket is determined by the set, so one value per mask suffices.
* **Edge Cases Considered:**
  * `k = 1` → always True.
  * One number bigger than `target`.

## 🔹 Tricks & Patterns Used

* **Bit Manipulation:** `mask >> i & 1` (is `i` used?), `mask | 1 << i` (use `i`).
* **`% target`** folds "current bucket fill" into the subset sum.

## 🔹 Alternative Data Structures

* Backtracking over buckets with memo on `mask` — same idea, recursive.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · 2ⁿ)
* **Space Complexity:** O(2ⁿ)

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def canPartitionKSubsets(self, nums: List[int], k: int) -> bool:
        total = sum(nums)
        if total % k:
            return False
        target = total // k
        nums.sort()
        if nums[-1] > target:
            return False
        n = len(nums)
        dp = [-1] * (1 << n)  # dp[mask]: fill of the current bucket, -1 = unreachable
        dp[0] = 0
        for mask in range(1 << n):
            if dp[mask] < 0:
                continue
            for i in range(n):
                if mask >> i & 1:
                    continue
                if dp[mask] + nums[i] > target:
                    break  # sorted: every later number is too big as well
                nxt = mask | 1 << i
                if dp[nxt] < 0:
                    dp[nxt] = (dp[mask] + nums[i]) % target
        return dp[-1] == 0
```
