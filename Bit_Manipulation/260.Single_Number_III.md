# 🔹 Problem Name: 260. Single Number III (Bit Manipulation, Medium)

**🔗 Link:** [LeetCode 260](https://leetcode.com/problems/single-number-iii/)

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **XOR, then split by a differing bit.** XOR of all numbers is `a ^ b` (pairs cancel), which is non-zero since `a ≠ b`. Pick any set bit of it — the lowest, `diff & −diff`. `a` and `b` differ there, so partition all numbers by that bit: each group contains one of them plus whole pairs, and XOR-ing each group yields `a` and `b`.
* **Core Concept:** a set bit of `a ^ b` is a position where the two unknowns disagree — use it to separate them, then solve two copies of 136
* **When to Use This Pattern?** Two (or more) unknowns hidden among cancelling duplicates — find two missing numbers, find the missing and the repeated number (645).
* **Mistakes to Avoid:**
  * Grouping by `num & lowbit == 1` — the masked value is `lowbit`, not 1; test for non-zero.
  * In fixed-width languages `−diff` overflows when `diff = −2³¹`; Python ints do not.

## 🔹 Optimization Path

* **Brute Force:** hash-map counts, return keys with count 1 — O(n) time, O(n) space.
* **Optimized Solution:** two XOR passes — O(n) time, O(1) extra space.
* **Further Improvements Possible?** No; each number must be read.

## 🔹 Solution Breakdown

* **Optimal Approach:** `diff = XOR(nums)`, `low = diff & −diff`, `a = XOR(num for num in nums if num & low)`, `b = diff ^ a`.
* **Why This Works?** Both copies of a duplicated number land in the same group (same bit), so they cancel inside it. `a` and `b` land in different groups because they differ on bit `low`. Each group's XOR is therefore its single survivor.
* **Edge Cases Considered:**
  * Negative values (`[-1, 0]`) — Python's `&` with negatives behaves like infinite two's complement, so `low` is still a positive single bit.
  * `n = 2` → both elements are the answers.
  * Output order is free — LeetCode accepts either order.

## 🔹 Code Snippet (Brute Force)

```python
from collections import Counter
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        return [num for num, count in Counter(nums).items() if count == 1]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        diff = 0
        for num in nums:
            diff ^= num  # pairs cancel, leaving a ^ b
        low = diff & -diff  # a and b disagree on this bit
        a = 0
        for num in nums:
            if num & low:
                a ^= num
        return [a, diff ^ a]
```
