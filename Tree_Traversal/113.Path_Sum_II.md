# 🔹 Problem Name: 113. Path Sum II (Tree DFS Backtracking, Medium)

**🔗 Link:** [LeetCode 113](https://leetcode.com/problems/path-sum-ii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **DFS with one shared path (backtracking).** Walk down from the root keeping the current path in a single list and the remaining sum. At a leaf, if the remainder is 0, copy the path into the answer. On the way back up, pop the node.
* **Core Concept:** enumerate root-to-leaf paths while reusing one buffer instead of copying a path at every node
* **When to Use This Pattern?** "List all root-to-leaf paths that satisfy X" — path sum, binary tree paths, paths with a given product.
* **Mistakes to Avoid:**
  * Checking `remaining == 0` at a non-leaf: the path must end at a **leaf** (`[1, 2]` with target 1 is no answer).
  * Appending the live `path` list itself: later pops would corrupt the stored answers — append a copy.
  * Pruning when the sum goes negative or too large: values can be negative (`-1000 … 1000`), so every path must be followed to the leaf.
  * Recursing on a skewed tree of 5000 nodes — deeper than Python's default limit, so this uses an explicit stack.

## 🔹 Optimization Path

* **Brute Force:** carry a full copy of the path to every node and sum it at each leaf — O(n · h) copying and summing.
* **Optimized Solution:** one shared path, running remainder — O(n + total length of the answers).
* **Further Improvements Possible?** No; writing each matching path out costs its length anyway.

## 🔹 Solution Breakdown

* **Optimal Approach:** stack entries `(node, remaining, leaving)`. First visit: push the value on `path`, subtract it from `remaining`; at a leaf record if the remainder is 0 and pop; otherwise re-push the node as "leaving" and then its children (right first so the left is processed first). A "leaving" entry only pops the path.
* **Why This Works?** The path list always equals the chain from the root to the node being processed: it grows on entry and shrinks on the matching exit entry, which is popped after everything beneath the node.
* **Edge Cases Considered:**
  * Empty tree → `[]`.
  * Single node: it is a leaf, so it matches only if `val == targetSum`.
  * Negative values and zero-sum paths (`[1, -1]` with target 0 → both nodes needed, only the leaf end counts).

## 🔹 Tricks & Patterns Used

* **Enter/exit markers on an explicit stack:** gives the push-before / pop-after structure of recursion without recursion.
* **Subtract instead of accumulate:** carrying `remaining` removes the need to re-sum the path.

## 🔹 Alternative Data Structures

* Recursive DFS with a path list — shortest code; needs `sys.setrecursionlimit` for 5000-deep trees.
* Pass an immutable tuple `path + (val,)` down — simple, but copies at every node.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n + P), `P` = total length of the returned paths (at most O(n · h) in the worst case, e.g. many leaves each with a long path)
* **Space Complexity:** O(h) for the path and the stack (excluding the output)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List, Optional


class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> List[List[int]]:
        result = []
        stack = [(root, [])] if root else []
        while stack:
            node, above = stack.pop()
            path = above + [node.val]
            if not node.left and not node.right:
                if sum(path) == targetSum:
                    result.append(path)
                continue
            for child in (node.right, node.left):
                if child:
                    stack.append((child, path))
        return result
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List, Optional


class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> List[List[int]]:
        result = []
        path = []
        stack = [(root, targetSum, False)] if root else []
        while stack:
            node, remaining, leaving = stack.pop()
            if leaving:
                path.pop()
                continue
            path.append(node.val)
            remaining -= node.val
            if not node.left and not node.right:
                if remaining == 0:
                    result.append(path[:])  # copy: the shared path keeps changing
                path.pop()
                continue
            stack.append((node, remaining, True))
            for child in (node.right, node.left):
                if child:
                    stack.append((child, remaining, False))
        return result
```
