# 🔹 Problem Name: 2521. Distinct Prime Factors of Product of Array (Number Theory, Medium)

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** The product's prime factors are the union of each element's prime factors — never compute the product. Factorise every number with a smallest-prime-factor (SPF) sieve.
* **Core Concept:** Prime factorisation with an SPF sieve
* **When to Use This Pattern?** Many factorisations of numbers ≤ 10⁶–10⁷: GCD/LCM questions, "numbers sharing a prime", divisor counts. (A Jan-2026 Infosys SP drive reportedly had a prime-factorisation question.)
* **Mistakes to Avoid:**
  * Multiplying everything first — the product has thousands of digits.
  * Trial division up to `x` instead of `√x`.

## 🔹 Optimization Path

* **Brute Force:** Trial division of each number up to √x — O(n√M).
* **Optimized Solution:** SPF sieve O(M log log M) once, then O(log x) per number.
* **Further Improvements Possible?** For a single number up to 10¹², trial division to 10⁶ is the right tool; SPF needs memory O(M).

## 🔹 Solution Breakdown

* **Optimal Approach:** `spf[x]` = smallest prime dividing `x`. Repeatedly divide `x` by `spf[x]`, collecting each prime into a set.
* **Why This Works?** Each division removes one prime factor, and `spf` gives a prime factor in O(1), so factorisation takes as many steps as the number has prime factors (≤ log₂ x).
* **Edge Cases Considered:**
  * Repeated primes across numbers (`[2, 4, 8]` → 1).
  * Prime numbers in the array.

## 🔹 Tricks & Patterns Used

* **SPF sieve:** for each prime `i`, mark `spf[j] = i` for multiples `j ≥ i²` not yet marked.
* **Set union** of factors instead of the product.

## 🔹 Alternative Data Structures

* `Counter` of prime exponents when you need divisor counts: `d(n) = Π (e + 1)`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(M log log M + n log M), M = max(nums)
* **Space Complexity:** O(M)

## 🔹 Code Snippet (Optimized)

```python
from math import isqrt
from typing import List


class Solution:
    def distinctPrimeFactors(self, nums: List[int]) -> int:
        limit = max(nums) + 1
        spf = list(range(limit))  # spf[x]: smallest prime factor of x
        for i in range(2, isqrt(limit - 1) + 1):
            if spf[i] == i:  # i is prime
                for j in range(i * i, limit, i):
                    if spf[j] == j:
                        spf[j] = i

        primes = set()
        for x in nums:
            while x > 1:
                p = spf[x]
                primes.add(p)
                while x % p == 0:
                    x //= p
        return len(primes)
```
