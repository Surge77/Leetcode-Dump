# 🔹 Problem Name: 416. Partition Equal Subset Sum (Dynamic Programming, Medium)

**🔗 Link:** [LeetCode 416](https://leetcode.com/problems/partition-equal-subset-sum/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Two equal halves ⇔ some subset sums to `total / 2`. Run 0/1 knapsack reachability up to that target.
* **Core Concept:** 0/1 Knapsack (subset sum)
* **When to Use This Pattern?** "Split into two groups with equal / closest sums", "can we pick items that sum to X?"
* **Mistakes to Avoid:**
  * Iterating sums forward — reuses the same element (turns it into unbounded knapsack).
  * Not returning early when the total is odd.

## 🔹 Optimization Path

* **Brute Force:** O(2ⁿ) — try every subset.
* **Optimized Solution:** O(n · target) boolean DP, iterating sums backwards.
* **Further Improvements Possible?** Bitset: one big-integer shift per number — the same O(n · total/2) bit operations, but done word-parallel in C, so far faster than the Python inner loop.

## 🔹 Solution Breakdown

* **Optimal Approach:** `can[s]` = some subset of the numbers seen so far sums to `s`. For each `x`, `can[s] |= can[s - x]` for `s` from target down to `x`.
* **Why This Works?** Going downwards, `can[s - x]` still holds the value from *before* `x` was considered, so each number is used at most once.
* **Edge Cases Considered:**
  * Odd total → impossible.
  * One element larger than `total / 2`.
  * One element.

## 🔹 Pattern Recognition

* **Belongs To:** DP — 0/1 Knapsack
* **Common Problems Using This:**
  * 494. Target Sum (in this repo)

## 🔹 Tricks & Patterns Used

* **Backward inner loop** = each item used once.
* **Bitset trick:** `bits |= bits << x`; bit `s` set ⇔ sum `s` reachable.

## 🔹 Alternative Data Structures

* A Python `set` of reachable sums works, but the bitset integer is far faster.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · total/2)
* **Space Complexity:** O(total/2)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total, n = sum(nums), len(nums)
        for mask in range(1 << n):  # every subset
            picked = sum(nums[i] for i in range(n) if mask >> i & 1)
            if 2 * picked == total:
                return True
        return False
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total % 2:
            return False
        target = total // 2
        can = [True] + [False] * target  # can[s]: subset sum s is reachable
        for x in nums:
            for s in range(target, x - 1, -1):  # backwards => x used once
                if can[s - x]:
                    can[s] = True
            if can[target]:
                return True
        return can[target]

    def can_partition_bitset(self, nums: List[int]) -> bool:
        total = sum(nums)
        if total % 2:
            return False
        bits = 1  # bit s set <=> sum s reachable
        for x in nums:
            bits |= bits << x
        return bool(bits >> (total // 2) & 1)
```
