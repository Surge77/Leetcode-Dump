# 🔹 Problem Name: 701. Insert into a Binary Search Tree (BST Insertion, Medium)

**🔗 Link:** [LeetCode 701](https://leetcode.com/problems/insert-into-a-binary-search-tree/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Descend to an empty slot.** Walk down as in a search; when the child you would move to is `None`, hang the new node there. New values always become leaves, so nothing else moves.
* **Core Concept:** the search path for a missing value ends exactly where it belongs
* **When to Use This Pattern?** Building a BST incrementally (1008 brute force), insert-then-query problems, any "add to an ordered tree" step.
* **Mistakes to Avoid:**
  * Empty tree (`n = 0`) — the new node is the root; return it.
  * Rebuilding or rebalancing — any valid BST is accepted, so the simple leaf insert is enough.
  * Recursive insertion on a 10⁴-node degenerate tree: recursion limit.

## 🔹 Optimization Path

* **Brute Force:** collect all values plus `val` in sorted order, rebuild a balanced BST — O(n).
* **Optimized Solution:** iterative descent and leaf attach — O(h) time, O(1) space.
* **Further Improvements Possible?** Self-balancing trees (AVL/red-black) keep `h = O(log n)` across many inserts.

## 🔹 Solution Breakdown

* **Optimal Approach:** `node = root`; loop: choose side by `val < node.val`; if that child is `None`, set it to `TreeNode(val)` and stop, else move to it.
* **Why This Works?** Every comparison on the way down keeps `val` on the correct side of that ancestor, so placing it as a leaf at the end of the path satisfies the BST property for all ancestors; no other node's relationships change. `val` is guaranteed absent, so no equality case.
* **Edge Cases Considered:**
  * Empty tree.
  * `val` smaller than everything / larger than everything — becomes the leftmost / rightmost leaf.

## 🔹 Tricks & Patterns Used

* **Look one step ahead:** check the child pointer before moving so you still hold the parent when you find the empty slot.

## 🔹 Alternative Data Structures

* Recursive `root.left = insertIntoBST(root.left, val)` — shortest code, O(h) stack.

## 🔹 Complexity Analysis

* **Time Complexity:** O(h) — O(n) for a degenerate tree
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def insertIntoBST(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        vals, stack = [val], [root]
        while stack:
            node = stack.pop()
            if node:
                vals.append(node.val)
                stack += [node.left, node.right]
        vals.sort()

        def build(lo: int, hi: int) -> Optional[TreeNode]:
            if lo > hi:
                return None
            mid = (lo + hi) // 2
            return TreeNode(vals[mid], build(lo, mid - 1), build(mid + 1, hi))

        return build(0, len(vals) - 1)  # balanced, so recursion depth is only log n
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def insertIntoBST(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        if root is None:
            return TreeNode(val)
        node = root
        while True:
            if val < node.val:
                if node.left is None:
                    node.left = TreeNode(val)  # the search for a missing val ends at its slot
                    return root
                node = node.left
            else:
                if node.right is None:
                    node.right = TreeNode(val)
                    return root
                node = node.right
```
