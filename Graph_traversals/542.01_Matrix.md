# 🔹 Problem Name: 542. 01 Matrix (Multi-source BFS, Medium)

**🔗 Link:** [LeetCode 542](https://leetcode.com/problems/01-matrix/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Start BFS from **every 0 at once**; the first time BFS reaches a `1`, that distance is final.
* **Core Concept:** Multi-source BFS (distance transform)
* **When to Use This Pattern?** "Distance from every cell to the nearest X" — run BFS *from all X*, not from every cell.
* **Mistakes to Avoid:**
  * BFS from each `1` separately — O((mn)²).
  * Using `0` as "unvisited" for distances (zeros are real answers) — use `-1`.

## 🔹 Optimization Path

* **Brute Force:** BFS from every cell — O((mn)²).
* **Optimized Solution:** O(m · n) multi-source BFS.
* **Further Improvements Possible?** Two DP passes (top-left → bottom-right, then reverse) — also O(mn), O(1) extra space.

## 🔹 Solution Breakdown

* **Optimal Approach:** `dist = 0` for zeros (queued), `-1` for ones; pop a cell, set unvisited neighbours to `dist + 1`, enqueue.
* **Why This Works?** BFS visits cells in non-decreasing distance from the source set, so each cell's first visit is via its nearest zero.
* **Edge Cases Considered:**
  * One zero in a corner.
  * All zeros.

## 🔹 Pattern Recognition

* **Belongs To:** Graph Traversal — Multi-source BFS

## 🔹 Tricks & Patterns Used

* **`-1` sentinel** doubles as the visited marker.

## 🔹 Alternative Data Structures

* Two-pass DP: `d[i][j] = min(d[i][j], d[i-1][j] + 1, d[i][j-1] + 1)`, then the mirror pass.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n)
* **Space Complexity:** O(m · n)

## 🔹 Code Snippet (Brute Force)

```python
from collections import deque
from typing import List


class Solution:
    def updateMatrix(self, mat: List[List[int]]) -> List[List[int]]:
        m, n = len(mat), len(mat[0])

        def nearest_zero(si: int, sj: int) -> int:
            seen = {(si, sj)}
            q = deque([(si, sj, 0)])
            while q:
                i, j, d = q.popleft()
                if mat[i][j] == 0:
                    return d
                for x, y in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
                    if 0 <= x < m and 0 <= y < n and (x, y) not in seen:
                        seen.add((x, y))
                        q.append((x, y, d + 1))
            return -1  # unreachable: the grid always contains a 0

        return [[nearest_zero(i, j) for j in range(n)] for i in range(m)]  # one BFS per cell
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def updateMatrix(self, mat: List[List[int]]) -> List[List[int]]:
        m, n = len(mat), len(mat[0])
        dist = [[-1] * n for _ in range(m)]
        q = deque()
        for i in range(m):
            for j in range(n):
                if mat[i][j] == 0:
                    dist[i][j] = 0
                    q.append((i, j))  # all zeros are sources

        while q:
            i, j = q.popleft()
            for x, y in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
                if 0 <= x < m and 0 <= y < n and dist[x][y] == -1:
                    dist[x][y] = dist[i][j] + 1
                    q.append((x, y))
        return dist
```
