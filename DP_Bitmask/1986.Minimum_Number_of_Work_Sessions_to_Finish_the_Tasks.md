# 🔹 Problem Name: 1986. Minimum Number of Work Sessions to Finish the Tasks (Bitmask DP, Medium)

**🔗 Link:** [LeetCode 1986](https://leetcode.com/problems/minimum-number-of-work-sessions-to-finish-the-tasks/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

You have a list of task durations and a session length limit. In one session you work at most `sessionTime` consecutive hours; every task must be completed entirely inside a single session, and tasks may be done in any order. Return the minimum number of sessions needed to finish all tasks (the longest task is guaranteed to fit in one session).

* **Example:** `tasks = [1,2,3], sessionTime = 3` → `2`
* **Constraints:** `1 ≤ n ≤ 14`, `1 ≤ tasks[i] ≤ 10`, `max(tasks[i]) ≤ sessionTime ≤ 15`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** `dp[mask]` = best `(sessions used, time used in the last session)` after finishing the tasks in `mask`, compared lexicographically.
* **Core Concept:** Bitmask DP (bin packing with n ≤ 14)
* **When to Use This Pattern?** Packing items into the fewest capacity-limited bins/days/trucks when `n` is tiny.
* **Mistakes to Avoid:**
  * Greedy "first fit decreasing" — good heuristic, not optimal.
  * Storing only the session count — you also need how full the open session is.

## 🔹 Optimization Path

* **Brute Force:** Try every assignment of tasks to sessions — Bell-number growth.
* **Optimized Solution:** O(n · 2ⁿ).
* **Further Improvements Possible?** Binary search on the answer `k` + backtracking with pruning also passes.

## 🔹 Solution Breakdown

* **Optimal Approach:** From `(s, t)` add unused task `i`: fits → `(s, t + task)`, else open a new session → `(s + 1, task)`. Keep the lexicographic minimum per mask.
* **Why This Works?** For the same finished set, fewer sessions always dominates (you can open a fresh session at any time), and with equal sessions a less-full last session dominates. So the lexicographic minimum is never worse than any other state.
* **Edge Cases Considered:**
  * Every task equals `sessionTime` → one session per task.
  * Everything fits in one session.

## 🔹 Pattern Recognition

* **Belongs To:** DP — Bitmask (assignment / packing)
* **Common Problems Using This:**
  * 698. Partition to K Equal Sum Subsets (in this repo)
  * 1723. Find Minimum Time to Finish All Jobs

## 🔹 Tricks & Patterns Used

* **Tuple comparison** in Python implements the lexicographic order for free.
* **Dominance argument** justifies keeping one state per mask.

## 🔹 Alternative Data Structures

* Precompute `fits[sub]` = sum(sub) ≤ T and run `dp[mask] = 1 + min(dp[mask ^ sub])` over submasks — O(3ⁿ).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · 2ⁿ)
* **Space Complexity:** O(2ⁿ)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def minSessions(self, tasks: List[int], sessionTime: int) -> int:
        best = len(tasks)

        def assign(i: int, sessions: List[int]) -> None:
            nonlocal best
            if i == len(tasks):
                best = min(best, len(sessions))
                return
            for j in range(len(sessions)):  # put task i into an existing session
                if sessions[j] + tasks[i] <= sessionTime:
                    sessions[j] += tasks[i]
                    assign(i + 1, sessions)
                    sessions[j] -= tasks[i]
            sessions.append(tasks[i])  # or open a new session for it
            assign(i + 1, sessions)
            sessions.pop()

        assign(0, [])
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def minSessions(self, tasks: List[int], sessionTime: int) -> int:
        n = len(tasks)
        size = 1 << n
        dp = [(n + 1, 0)] * size  # (sessions opened, time used in the last one)
        dp[0] = (1, 0)
        for mask in range(size):
            sessions, used = dp[mask]
            for i in range(n):
                if mask >> i & 1:
                    continue
                if used + tasks[i] <= sessionTime:
                    cand = (sessions, used + tasks[i])
                else:
                    cand = (sessions + 1, tasks[i])  # open a new session
                nxt = mask | 1 << i
                if cand < dp[nxt]:
                    dp[nxt] = cand
        return dp[size - 1][0]
```
