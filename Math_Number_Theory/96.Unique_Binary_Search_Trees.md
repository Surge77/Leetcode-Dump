# 🔹 Problem Name: 96. Unique Binary Search Trees (Catalan Numbers, Medium)

**🔗 Link:** [LeetCode 96](https://leetcode.com/problems/unique-binary-search-trees/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Count the structurally different binary search trees that can be built from the `n` distinct keys `1..n`, using every key exactly once. Only the tree shape matters, since the keys are fixed by the BST ordering.

* **Example:** `n = 3` → `5`
* **Constraints:** `1 ≤ n ≤ 19`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Pick the root `r`; the left subtree uses `r - 1` keys and the right uses `n - r`, independently: `G(n) = Σ G(r-1) · G(n-r)`. These are the **Catalan numbers**, `C(2n, n) / (n + 1)`.
* **Core Concept:** Catalan recurrence (DP) and its closed form
* **When to Use This Pattern?** Counting binary trees, balanced bracket strings, ways to triangulate a polygon, non-crossing handshakes, mountain ranges.
* **Mistakes to Avoid:**
  * Adding instead of multiplying the two sides (choices are independent).
  * For large `n` mod p: dividing by `n + 1` needs a modular inverse.

## 🔹 Optimization Path

* **Brute Force:** Recurse over every root choice with no memoisation (or build every tree) — exponential.
* **DP:** O(n²).
* **Optimized Solution:** O(n) with the binomial formula.

## 🔹 Solution Breakdown

* **Optimal Approach:** `G[0] = G[1] = 1`; `G[i] = Σ_{r=1..i} G[r-1] · G[i-r]`.
* **Why This Works?** In a BST the root splits the sorted keys into a left block and a right block; the shape of each block is chosen independently, so counts multiply, and different roots give different trees.
* **Edge Cases Considered:**
  * `n = 1` → 1.

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def numTrees(self, n: int) -> int:
        if n <= 1:
            return 1
        # try every key as the root: left shapes * right shapes
        return sum(self.numTrees(root - 1) * self.numTrees(n - root) for root in range(1, n + 1))
```

## 🔹 Code Snippet (Optimized)

```python
from math import comb


class Solution:
    def numTrees(self, n: int) -> int:
        trees = [1] * (n + 1)  # trees[k]: BST shapes with k keys
        for k in range(2, n + 1):
            trees[k] = sum(trees[r - 1] * trees[k - r] for r in range(1, k + 1))
        return trees[n]

    def num_trees_formula(self, n: int) -> int:
        return comb(2 * n, n) // (n + 1)  # n-th Catalan number
```
