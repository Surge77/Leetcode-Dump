# 🔹 Problem Name: 452. Minimum Number of Arrows to Burst Balloons (Greedy Intervals, Medium)

**🔗 Link:** [LeetCode 452](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Sort by end. Shoot an arrow at the end of the first balloon; it bursts every balloon starting at or before that point. The next arrow is needed only for a balloon that starts after it.
* **Core Concept:** Greedy interval stabbing (sort by end)
* **When to Use This Pattern?** Minimum points hitting all intervals; maximum non-overlapping intervals (same greedy, 435 is already in this repo).
* **Mistakes to Avoid:**
  * Sorting by start — needs extra bookkeeping.
  * Touching balloons (`[1,2]`, `[2,3]`) share one arrow → use `start > arrow`, not `>=`.

## 🔹 Optimization Path

* **Brute Force:** Try sets of arrow positions — exponential.
* **Optimized Solution:** O(n log n) sort + one pass.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `arrow = -inf`, `count = 0`; for `(s, e)` sorted by `e`: if `s > arrow`: `count += 1`, `arrow = e`.
* **Why This Works?** Some arrow must hit the balloon that ends first; placing it as far right as possible (at that end) hits a superset of what any other valid position hits.
* **Edge Cases Considered:**
  * Nested balloons.
  * Negative coordinates.

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def findMinArrowShots(self, points: List[List[int]]) -> int:
        points.sort(key=lambda p: p[1])  # by end
        arrows, arrow_x = 0, float("-inf")
        for start, end in points:
            if start > arrow_x:  # not hit by the last arrow
                arrows += 1
                arrow_x = end
        return arrows
```
