# 297. Serialize and Deserialize Binary Tree

**🔗 Link:** [LeetCode 297](https://leetcode.com/problems/serialize-and-deserialize-binary-tree/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Design a `serialize` that turns a binary tree into a string and a `deserialize` that rebuilds the identical tree from that string. Any encoding is allowed as long as the round trip restores the original structure and values.

* **Example:** `root = [1,2,3,null,null,4,5]` → serialize then deserialize gives back `[1,2,3,null,null,4,5]`
* **Constraints:** `0 ≤ nodes ≤ 10^4`, `-1000 ≤ Node.val ≤ 1000`

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Level order with null markers.** `serialize`: BFS, writing each node's value, or `#` for an empty child slot. `deserialize`: split, build the root, then BFS again — every dequeued node consumes the next **two** tokens as its left and right child. Both sides visit nodes in the same order, so the tokens line up. Fully iterative, so a 10⁴-deep path is fine.
* **Core Concept:** one traversal **plus explicit null markers** pins down the shape uniquely; without markers you need two traversals and distinct values
* **When to Use This Pattern?** Persisting or sending a tree, comparing subtrees by their encodings (652, 572), any "encode → decode" design question.
* **Mistakes to Avoid:**
  * Dropping the null markers: `1,2,3` fits many shapes.
  * Recursive preorder on a 10⁴-node path → `RecursionError` in Python unless the limit is raised.
  * Preorder + inorder (105): needs distinct values, but 10⁴ nodes in `[-1000, 1000]` must repeat.
  * `tokens.pop(0)` in the decoder: O(n) per call → O(n²); keep an index instead.

## 🔹 Optimization Path

* **Brute Force:** number nodes like a heap (root 1, children `2i` and `2i + 1`) and write `position:value` pairs — no markers needed, but positions double per level: on a 10⁴-deep path they reach ~3000 digits, so time and output size are O(n·h).
* **Optimized Solution:** BFS with `#` markers — O(n) time, exactly `2n + 1` tokens.
* **Further Improvements Possible?** Only constant factors: trim trailing `#`s (LeetCode's own format) or use a binary encoding.

## 🔹 Solution Breakdown

* **Optimal Approach:**
  * `serialize`: queue `[root]`; pop; `None` → `"#"`, else write the value and enqueue both children, even `None` ones.
  * `deserialize`: `tokens[0] == "#"` → `None`; else build the root, queue it, `i = 1`; for each dequeued node read `tokens[i]` and `tokens[i + 1]`, attach the non-`#` ones and enqueue them, `i += 2`.
* **Why This Works?** The serializer writes exactly two child tokens per real node, in queue order. The deserializer dequeues real nodes in that same order and reads two tokens each, so token `i` belongs to the same child slot on both sides. There are `n` real nodes and `n + 1` empty slots, so the decoder never reads past the end.
* **Edge Cases Considered:**
  * Empty tree → `"#"` → `None`.
  * Negative values — tokens are comma-separated, so `-` is just part of the number.
  * A 10⁴-deep path — no recursion anywhere.

## 🔹 Tricks & Patterns Used

* **Null markers make a single traversal invertible.**
* **Shared read index** instead of popping from the front of the token list.
* **Heap numbering** (brute force): perfect for complete trees, explodes on skewed ones.

## 🔹 Alternative Data Structures

* Preorder with markers and a recursive decoder over `iter(tokens)` — the shortest code; needs `sys.setrecursionlimit` for 10⁴-deep trees.
* Preorder + inorder (105) — only when values are distinct.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n) for each of `serialize` and `deserialize`
* **Space Complexity:** O(n) for the tokens and the queue

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Codec:
    def serialize(self, root: Optional[TreeNode]) -> str:
        pairs = []
        stack = [(root, 1)] if root else []
        while stack:
            node, pos = stack.pop()
            pairs.append(f"{pos}:{node.val}")
            # a heap position alone fixes where a node hangs, so empty slots need no marker
            if node.left:
                stack.append((node.left, 2 * pos))
            if node.right:
                stack.append((node.right, 2 * pos + 1))
        return ",".join(pairs)

    def deserialize(self, data: str) -> Optional[TreeNode]:
        if not data:
            return None
        nodes = {}
        for pair in data.split(","):
            pos, val = pair.split(":")
            nodes[int(pos)] = TreeNode(int(val))
        for pos, node in nodes.items():
            if pos == 1:
                continue
            parent = nodes[pos // 2]
            if pos % 2 == 0:
                parent.left = node
            else:
                parent.right = node
        return nodes[1]
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import Optional


class Codec:
    def serialize(self, root: Optional[TreeNode]) -> str:
        tokens, queue = [], deque([root])
        while queue:
            node = queue.popleft()
            if node:
                tokens.append(str(node.val))
                queue.append(node.left)
                queue.append(node.right)
            else:
                tokens.append("#")
        return ",".join(tokens)

    def deserialize(self, data: str) -> Optional[TreeNode]:
        tokens = data.split(",")
        if tokens[0] == "#":
            return None
        root = TreeNode(int(tokens[0]))
        queue, i = deque([root]), 1
        while queue:
            node = queue.popleft()
            left, right = tokens[i], tokens[i + 1]  # every real node wrote exactly two child slots
            i += 2
            if left != "#":
                node.left = TreeNode(int(left))
                queue.append(node.left)
            if right != "#":
                node.right = TreeNode(int(right))
                queue.append(node.right)
        return root
```
