# 368. Largest Divisible Subset

**🔗 Link:** [LeetCode 368](https://leetcode.com/problems/largest-divisible-subset/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given a set of distinct positive integers, return the largest subset in which every pair of elements is such that one divides the other. If several largest subsets exist, any one is accepted. The subset itself is returned, not its size.

* **Example:** `nums = [1,2,3]` → `[1,2]` (`[1,3]` is also accepted)
* **Constraints:** `1 ≤ nums.length ≤ 1000`, `1 ≤ nums[i] ≤ 2 * 10^9`, all values distinct

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Sort, then LIS with "divides" instead of "<".** After sorting, a set where every pair divides each other is exactly a chain `a₁ | a₂ | … | a_k`. `length[i]` = longest chain ending at `nums[i]`; `length[i] = 1 + max(length[j])` over `j < i` with `nums[i] % nums[j] == 0`. Store `parent[i]` to rebuild the chain from the best end.
* **Core Concept:** divisibility is transitive, so checking only consecutive elements of the sorted chain is enough
* **When to Use This Pattern?** "Longest subset / sequence where neighbours satisfy a transitive relation" — LIS (300), Russian dolls (354), longest string chain (1048).
* **Mistakes to Avoid:**
  * Not sorting first — then `j < i` does not mean `nums[j] ≤ nums[i]`, and the chain property breaks.
  * Checking divisibility with every earlier member of the chain: unnecessary thanks to transitivity (`a | b` and `b | c` ⇒ `a | c`).
  * Returning only the length — the problem wants the subset itself (any valid one).

## 🔹 Optimization Path

* **Brute Force:** check every subset for pairwise divisibility — O(2ⁿ · n²).
* **Optimized Solution:** sort + O(n²) chain DP with parent pointers — `n ≤ 1000` gives 5·10⁵ pairs.
* **Further Improvements Possible?** No general sub-quadratic method is standard here; O(n²) is the expected solution.

## 🔹 Solution Breakdown

* **Optimal Approach:** sort; for each `i`, scan `j < i`, keep the best `length[j]` with `nums[i] % nums[j] == 0` and remember `parent[i] = j`. Walk parents back from `argmax(length)` and reverse.
* **Why This Works?** In sorted order, a valid subset `b₁ < b₂ < … < b_k` must satisfy `b₁ | b₂ | … | b_k` (each pair divides, in particular consecutive ones). Conversely, a chain where consecutive elements divide is pairwise divisible by transitivity. So the answer is the longest such chain — a DAG longest path solved in sorted order.
* **Edge Cases Considered:**
  * `n = 1` → `[nums[0]]`.
  * `1` divides everything, so it extends any chain.
  * All values are distinct (guaranteed), so no duplicate handling is needed.

## 🔹 Tricks & Patterns Used

* **Sort to turn a set problem into a sequence problem.**
* **Parent pointers** to reconstruct the optimal chain instead of storing whole lists per index.

## 🔹 Alternative Data Structures

* Store the best list at each index (`chains[i] = chains[j] + [nums[i]]`) — simpler, but O(n²) memory in the worst case.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n²) (plus O(n log n) for sorting)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def largestDivisibleSubset(self, nums: List[int]) -> List[int]:
        nums = sorted(nums)
        n = len(nums)
        best: List[int] = []
        for mask in range(1, 1 << n):
            chosen = [nums[i] for i in range(n) if mask >> i & 1]
            if len(chosen) > len(best) and all(chosen[b] % chosen[a] == 0
                                               for a in range(len(chosen)) for b in range(a + 1, len(chosen))):
                best = chosen
        return best
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def largestDivisibleSubset(self, nums: List[int]) -> List[int]:
        nums = sorted(nums)  # sorted order makes "divides" only need checking against the chain's last element
        n = len(nums)
        length, parent = [1] * n, [-1] * n
        for i in range(n):
            for j in range(i):
                if nums[i] % nums[j] == 0 and length[j] + 1 > length[i]:
                    length[i], parent[i] = length[j] + 1, j
        i = max(range(n), key=length.__getitem__)
        chain = []
        while i != -1:
            chain.append(nums[i])
            i = parent[i]
        return chain[::-1]
```
