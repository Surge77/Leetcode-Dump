# 🔹 Problem Name: 1319. Number of Operations to Make Network Connected (Union-Find, Medium)

**🔗 Link:** [LeetCode 1319](https://leetcode.com/problems/number-of-operations-to-make-network-connected/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

There are `n` computers (0 to n-1) and a list of cables, each joining two computers. In one move you may unplug a cable and reconnect it between any two computers that are not yet directly connected. Return the minimum number of moves needed to make the whole network connected, or `-1` if that is impossible.

* **Example:** `n = 4, connections = [[0,1],[0,2],[1,2]]` → `1`
* **Constraints:** `1 ≤ n ≤ 10^5`; `1 ≤ connections.length ≤ min(n(n-1)/2, 10^5)`; no repeated connections.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Connecting `n` computers needs at least `n - 1` cables; if there are fewer, return `-1`. Otherwise the answer is `components - 1` (spare cables from cycles are always enough).
* **Core Concept:** Counting connected components with Union-Find
* **When to Use This Pattern?** "Minimum edges to add to connect everything" or "how many separate groups".
* **Mistakes to Avoid:**
  * Counting redundant cables and comparing them to `components - 1` — correct, but the simple `len(connections) < n - 1` check is equivalent.
  * Forgetting isolated computers (each is its own component).

## 🔹 Optimization Path

* **Brute Force:** BFS/DFS components — O(n + E), also fine.
* **Optimized Solution:** DSU — O(E log n) amortised with path halving alone (O(E · α(n)) once union by size is added).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Start with `components = n`; every successful union decreases it by 1.
* **Why This Works?** With `E ≥ n - 1` cables, the number of redundant cables is `E - (n - components) ≥ components - 1`, so we can always move enough cables to link the components in a chain.
* **Edge Cases Considered:**
  * Already connected → 0.
  * Too few cables → -1.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def makeConnected(self, n: int, connections: List[List[int]]) -> int:
        if len(connections) < n - 1:
            return -1  # not enough cables in total
        graph = [[] for _ in range(n)]
        for a, b in connections:
            graph[a].append(b)
            graph[b].append(a)

        seen = [False] * n
        components = 0
        for start in range(n):
            if seen[start]:
                continue
            components += 1
            seen[start] = True
            stack = [start]
            while stack:
                node = stack.pop()
                for nxt in graph[node]:
                    if not seen[nxt]:
                        seen[nxt] = True
                        stack.append(nxt)
        return components - 1
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def makeConnected(self, n: int, connections: List[List[int]]) -> int:
        if len(connections) < n - 1:
            return -1  # not enough cables in total
        parent = list(range(n))

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        components = n
        for a, b in connections:
            ra, rb = find(a), find(b)
            if ra != rb:
                parent[ra] = rb
                components -= 1
        return components - 1
```
