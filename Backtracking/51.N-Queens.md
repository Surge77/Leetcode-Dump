# 🔹 Problem Name: 51. N-Queens (Backtracking, Hard)

**🔗 Link:** [LeetCode 51](https://leetcode.com/problems/n-queens/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Place one queen per row. Track attacked columns, `row - col` diagonals and `row + col` anti-diagonals in sets so each placement check is O(1); undo on return.
* **Core Concept:** Backtracking with constraint sets
* **When to Use This Pattern?** Generate all configurations satisfying constraints (Sudoku, permutations with rules, graph colouring).
* **Mistakes to Avoid:**
  * Scanning the board to check attacks — O(n) per check.
  * Forgetting to remove the queen from the sets when backtracking.

## 🔹 Optimization Path

* **Brute Force:** Choose `n` cells out of `n²` — astronomically many.
* **Row-by-row backtracking:** about O(n!) with pruning.
* **Further Improvements Possible?** Bitmasks for columns/diagonals (used in 52. N-Queens II for counting).

## 🔹 Solution Breakdown

* **Optimal Approach:** `place(row)`: for each free `col` (not in `cols`, `diag`, `anti`), record it, recurse to `row + 1`, then remove it. At `row == n`, build the board strings.
* **Why This Works?** One queen per row is forced; the three sets capture every remaining attack line, so every leaf reached is a valid board and every valid board is reached once.
* **Edge Cases Considered:**
  * `n = 1` → one solution.
  * `n = 2, 3` → none.

## 🔹 Tricks & Patterns Used

* **Diagonal ids:** `r - c` is constant on `\` diagonals, `r + c` on `/` diagonals.
* **Choose → explore → un-choose** template.

## 🔹 Alternative Data Structures

* Integer bitmasks: `free = ~(cols | diag | anti) & full`, take the lowest bit with `free & -free`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n!) (pruned)
* **Space Complexity:** O(n) recursion + output

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        cols, diag, anti = set(), set(), set()
        queen_col = [0] * n  # queen_col[r]: column of the queen in row r
        boards = []

        def place(r: int) -> None:
            if r == n:
                boards.append(["." * c + "Q" + "." * (n - c - 1) for c in queen_col])
                return
            for c in range(n):
                if c in cols or (r - c) in diag or (r + c) in anti:
                    continue
                cols.add(c)
                diag.add(r - c)
                anti.add(r + c)
                queen_col[r] = c
                place(r + 1)
                cols.remove(c)
                diag.remove(r - c)
                anti.remove(r + c)

        place(0)
        return boards
```
