# 🔹 Problem Name: 2251. Number of Flowers in Full Bloom (Sweep Line + Binary Search, Hard)

**🔗 Link:** [LeetCode 2251](https://leetcode.com/problems/number-of-flowers-in-full-bloom/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** A flower `[start, end]` (inclusive) is blooming at time `t` iff `start ≤ t` and `end ≥ t`. So `blooming(t) = #(starts ≤ t) − #(ends < t)`: every flower that has started, minus the ones already finished. Sort starts and ends separately; each count is one `bisect`.
* **Core Concept:** sweep line — decouple interval starts from ends; answer point queries by counting with binary search
* **When to Use This Pattern?** "How many intervals cover point `p`?" for many points, when coordinates are too large (here 10⁹) for a difference array.
* **Mistakes to Avoid:**
  * Off-by-one on the inclusive end: use `bisect_right` for starts (`start ≤ t`) and `bisect_left` for ends (`end < t`).
  * Checking every flower per person: O(n · m) = 2.5·10⁹.

## 🔹 Optimization Path

* **Brute Force:** for each person count covering flowers — O(n · m).
* **Optimized Solution:** two sorted lists + 2 binary searches per person — O((n + m) log n).
* **Further Improvements Possible?** Sort the people too and sweep with two pointers (offline): O((n + m) log(n + m)) with simpler constants.

## 🔹 Solution Breakdown

* **Optimal Approach:** `starts = sorted(s)`, `ends = sorted(e)`, answer `bisect_right(starts, t) − bisect_left(ends, t)`.
* **Why This Works?** Every flower with `end < t` also has `start ≤ end < t`, so it is counted in both terms and cancels; what remains is exactly the flowers with `start ≤ t ≤ end`.
* **Edge Cases Considered:**
  * `t == start` or `t == end` — both count as blooming.
  * Several people at the same time — each gets the same answer independently.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def fullBloomFlowers(self, flowers: List[List[int]], people: List[int]) -> List[int]:
        return [sum(1 for start, end in flowers if start <= t <= end) for t in people]
```

## 🔹 Code Snippet (Optimized)

```python
from bisect import bisect_left, bisect_right
from typing import List


class Solution:
    def fullBloomFlowers(self, flowers: List[List[int]], people: List[int]) -> List[int]:
        starts = sorted(start for start, _ in flowers)
        ends = sorted(end for _, end in flowers)
        # started by t (start <= t) minus already finished before t (end < t)
        return [bisect_right(starts, t) - bisect_left(ends, t) for t in people]
```
