# 🔹 Problem Name: 27. Remove Element (Two Pointers, Easy)

**🔗 Link:** [LeetCode 27](https://leetcode.com/problems/remove-element/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Read/write pointers.** Scan every element with a read pointer; copy each element `!= val` to `nums[k]` and advance the write pointer `k`. Return `k`.
* **Core Concept:** in-place filtering — the kept prefix grows behind the reader, so the write never clobbers an element that has not been read yet
* **When to Use This Pattern?** "Remove / keep elements in place and return the new length" — remove duplicates (26, 80), move zeroes (283), partition by a predicate.
* **Mistakes to Avoid:**
  * `nums.remove(val)` or `del` in a loop: each removal shifts the tail → O(n²), and deleting while iterating skips elements.
  * Returning the list instead of `k` — the judge reads `k` and then the first `k` slots (in any order).

## 🔹 Optimization Path

* **Brute Force:** on each `val`, shift the whole tail left by one and shrink the logical length — O(n²).
* **Optimized Solution:** read/write pointers — O(n), one pass.
* **Further Improvements Possible?** When `val` is rare and writes are expensive, swap each `val` with the last live element and shrink from the right: writes = number of removals, but the order of the kept elements changes (allowed here).

## 🔹 Solution Breakdown

* **Optimal Approach:** `k = 0; for x in nums: if x != val: nums[k] = x; k += 1`.
* **Why This Works?** Invariant: `nums[:k]` holds exactly the kept elements among those read so far, in order. Since `k ≤` the read index, writing `nums[k]` only touches a slot that has already been read.
* **Edge Cases Considered:**
  * Empty array (`0 ≤ nums.length`) → `0`.
  * Every element equals `val` → `0`; none equals `val` → `n` (each element is copied onto itself).

## 🔹 Pattern Recognition

* **Belongs To:** Two Pointers — read/write (fast/slow) compaction
* **Common Problems Using This:**
  * 26. Remove Duplicates from Sorted Array (in this repo)
  * 283. Move Zeroes (in this repo)
  * 80. Remove Duplicates from Sorted Array II

## 🔹 Tricks & Patterns Used

* **Write pointer trails the read pointer:** the generic in-place `filter`.
* **Swap-with-end** variant when order does not matter and removals are rare.

## 🔹 Alternative Data Structures

* `nums[:] = [x for x in nums if x != val]` — O(n) time but O(n) extra space, not truly in place.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        k, i = len(nums), 0
        while i < k:
            if nums[i] == val:
                for j in range(i + 1, k):
                    nums[j - 1] = nums[j]
                k -= 1  # re-check index i: a new element was shifted into it
            else:
                i += 1
        return k
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        k = 0
        for x in nums:
            if x != val:
                nums[k] = x
                k += 1
        return k
```
