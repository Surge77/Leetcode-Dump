# 🔹 Problem Name: 1220. Count Vowels Permutation (Matrix Exponentiation, Hard)

**🔗 Link:** [LeetCode 1220](https://leetcode.com/problems/count-vowels-permutation/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Count the strings of length `n` over the vowels `a e i o u` that obey these follow-rules: `a` is followed only by `e`; `e` only by `a` or `i`; `i` by anything except another `i`; `o` only by `i` or `u`; `u` only by `a`. Return the count modulo `10⁹ + 7`.

* **Example:** `n = 1` → `5`
* **Constraints:** `1 ≤ n ≤ 2 · 10⁴`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** "Which vowel may follow which" is a 5×5 transition matrix. Strings of length `n` = walks of `n - 1` steps, so the answer is the sum of all entries of `M^(n-1)`.
* **Core Concept:** Counting walks with matrix exponentiation
* **When to Use This Pattern?** Count strings/sequences where each next symbol depends only on the previous one, especially when `n` is huge.
* **Mistakes to Avoid:**
  * Reading the rules backwards (the rules say what may **follow** each vowel).
  * Forgetting `% (10**9 + 7)`.

## 🔹 Optimization Path

* **Brute Force:** 5ⁿ strings.
* **DP:** O(5 · n) — enough for LeetCode's n ≤ 2·10⁴.
* **Optimized Solution:** O(5³ · log n) — works for n up to 10¹⁸.

## 🔹 Solution Breakdown

* **Optimal Approach:** Rules: `a → e`; `e → a, i`; `i → a, e, o, u`; `o → i, u`; `u → a`. Set `M[x][y] = 1` for each rule, compute `M^(n-1)`, sum all entries.
* **Why This Works?** Entry `(x, y)` of `M^k` counts valid length-`(k+1)` strings starting with `x` and ending with `y`.
* **Edge Cases Considered:**
  * `n = 1` → 5.

## 🔹 Code Snippet (Brute Force)

```python
from itertools import product

MOD = 10**9 + 7
FOLLOWS = {"a": "e", "e": "ai", "i": "aeou", "o": "iu", "u": "a"}


class Solution:
    def countVowelPermutation(self, n: int) -> int:
        count = 0
        for s in product("aeiou", repeat=n):  # all 5^n strings
            if all(s[k + 1] in FOLLOWS[s[k]] for k in range(n - 1)):
                count += 1
        return count % MOD
```

## 🔹 Code Snippet (Optimized)

```python
MOD = 10**9 + 7
VOWELS = "aeiou"
FOLLOWS = {"a": "e", "e": "ai", "i": "aeou", "o": "iu", "u": "a"}


def mat_mult(a, b):
    size = len(a)
    return [[sum(a[i][k] * b[k][j] for k in range(size)) % MOD for j in range(size)]
            for i in range(size)]


def mat_pow(m, e):
    result = [[int(i == j) for j in range(len(m))] for i in range(len(m))]
    while e:
        if e & 1:
            result = mat_mult(result, m)
        m = mat_mult(m, m)
        e >>= 1
    return result


class Solution:
    def countVowelPermutation(self, n: int) -> int:
        step = [[int(y in FOLLOWS[x]) for y in VOWELS] for x in VOWELS]
        walks = mat_pow(step, n - 1)
        return sum(map(sum, walks)) % MOD
```
