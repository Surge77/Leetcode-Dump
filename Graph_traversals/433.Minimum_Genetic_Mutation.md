# 🔹 Problem Name: 433. Minimum Genetic Mutation (BFS on Implicit Graph, Medium)

**🔗 Link:** [LeetCode 433](https://leetcode.com/problems/minimum-genetic-mutation/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **BFS over genes.** A gene is a node; one mutation (change one of the 8 characters to another of `A C G T`) is an edge, allowed only if the result is in `bank`. BFS from `startGene` gives the fewest mutations to `endGene`, or `-1`.
* **Core Concept:** shortest path in an unweighted implicit graph — generate neighbours on the fly
* **When to Use This Pattern?** "Minimum number of single-step changes" between states: word ladders, lock combinations (752), sliding puzzles.
* **Mistakes to Avoid:**
  * Requiring `startGene` to be in the bank — it does not have to be; only the mutated genes do.
  * Marking genes visited when popped instead of when pushed — the same gene gets queued many times.
  * `endGene` not in the bank → `-1` (BFS returns it naturally).

## 🔹 Optimization Path

* **Brute Force:** DFS over every chain of distinct bank genes, keeping the shortest that ends at `endGene` — exponential in the bank size.
* **Optimized Solution:** BFS — O(B · 8 · 4 · 8): each bank gene is expanded once, trying 32 mutations that each cost O(8) to build.
* **Further Improvements Possible?** Bidirectional BFS for big banks; with `bank.length ≤ 10` it does not matter.

## 🔹 Solution Breakdown

* **Optimal Approach:** `unvisited = set(bank) − {startGene}`; queue `(startGene, 0)`. Pop a gene; if it is `endGene` return its step count; otherwise try every position × letter, and push each candidate still in `unvisited` (removing it).
* **Why This Works?** All edges cost one mutation, so BFS pops genes in order of distance; the first time `endGene` is popped, its count is minimal. Removing a gene when it is pushed is safe because that first push already carries its smallest distance.
* **Edge Cases Considered:**
  * `startGene == endGene` → `0`.
  * Empty bank → `-1` (unless start equals end).

## 🔹 Pattern Recognition

* **Belongs To:** Graph Traversal — BFS (implicit graph)
* **Common Problems Using This:**
  * 127. Word Ladder (in this repo)
  * 752. Open the Lock
  * 126. Word Ladder II

## 🔹 Tricks & Patterns Used

* **Neighbours generated, not stored:** 8 positions × 4 letters, membership test in a set.
* **Delete from the set on push:** the set is both the bank and the visited marker.

## 🔹 Alternative Data Structures

* Compare every pair of bank genes to build an explicit graph — O(B² · 8), fine for 10 genes.

## 🔹 Complexity Analysis

* **Time Complexity:** O(B · 4 · 8²) with `B = bank.length`, gene length 8
* **Space Complexity:** O(B)

## 🔹 Code Snippet (Brute Force)

```python
from math import inf
from typing import List


class Solution:
    def minMutation(self, startGene: str, endGene: str, bank: List[str]) -> int:
        def one_apart(a: str, b: str) -> bool:
            return sum(x != y for x, y in zip(a, b)) == 1

        used = {startGene}

        def dfs(gene: str) -> float:
            if gene == endGene:
                return 0
            best = inf
            for nxt in bank:
                if nxt not in used and one_apart(gene, nxt):
                    used.add(nxt)
                    best = min(best, 1 + dfs(nxt))
                    used.remove(nxt)
            return best

        steps = dfs(startGene)
        return -1 if steps == inf else int(steps)
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def minMutation(self, startGene: str, endGene: str, bank: List[str]) -> int:
        unvisited = set(bank)
        unvisited.discard(startGene)
        queue = deque([(startGene, 0)])
        while queue:
            gene, steps = queue.popleft()
            if gene == endGene:
                return steps
            for i in range(len(gene)):
                for ch in "ACGT":
                    cand = gene[:i] + ch + gene[i + 1:]
                    if cand in unvisited:
                        unvisited.remove(cand)  # its first push already has the shortest distance
                        queue.append((cand, steps + 1))
        return -1
```
