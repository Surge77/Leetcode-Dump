# 🔹 Problem Name: 1392. Longest Happy Prefix (KMP Prefix Function, Hard)

**🔗 Link:** [LeetCode 1392](https://leetcode.com/problems/longest-happy-prefix/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** The longest proper prefix that is also a suffix is exactly `pi[n-1]` of the KMP prefix function.
* **Core Concept:** Prefix function / string borders
* **When to Use This Pattern?** Borders, periods, "smallest string that repeats to form s", counting prefix occurrences.
* **Mistakes to Avoid:**
  * Comparing `s[:k] == s[-k:]` for every `k` — O(n²) for n = 10⁵.
  * Returning the whole string (the prefix must be proper).

## 🔹 Optimization Path

* **Brute Force:** O(n²) slice comparisons.
* **Optimized Solution:** O(n) prefix function.
* **Further Improvements Possible?** Rolling hash comparison of prefix and suffix hashes — O(n) expected.

## 🔹 Solution Breakdown

* **Optimal Approach:** Build `pi`; return `s[:pi[-1]]`.
* **Why This Works?** By definition `pi[n-1]` is the length of the longest proper prefix of `s` that is also a suffix of `s`.
* **Edge Cases Considered:**
  * Single character → `""`.
  * Highly periodic strings (`"aaaa"` → `"aaa"`).

## 🔹 Pattern Recognition

* **Belongs To:** String Matching (KMP)
* **Common Problems Using This:**
  * 459. Repeated Substring Pattern (`pi[-1] > 0 and n % (n - pi[-1]) == 0`)
  * 214. Shortest Palindrome (in this repo)
  * 28. Find the Index of the First Occurrence in a String (in this repo)

## 🔹 Tricks & Patterns Used

* **Borders chain:** `pi[n-1], pi[pi[n-1]-1], …` lists every border from longest to shortest.

## 🔹 Alternative Data Structures

* Z-function: the smallest `i >= 1` with `i + z[i] == n` gives the longest border, of length `n - i`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def longestPrefix(self, s: str) -> str:
        pi = [0] * len(s)
        k = 0
        for i in range(1, len(s)):
            while k and s[i] != s[k]:
                k = pi[k - 1]
            if s[i] == s[k]:
                k += 1
            pi[i] = k
        return s[:pi[-1]]
```
