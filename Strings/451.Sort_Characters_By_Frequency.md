# 🔹 Problem Name: 451. Sort Characters By Frequency (Bucket Sort, Medium)

**🔗 Link:** [LeetCode 451](https://leetcode.com/problems/sort-characters-by-frequency/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Count, then bucket by frequency.** Count every character; put each character into `buckets[count]`; walk the buckets from `n` down to 1 and emit `char * count`.
* **Core Concept:** frequencies are bounded by `n`, so they can be sorted by indexing instead of comparing
* **When to Use This Pattern?** "Order items by how often they occur" — top-k frequent elements, frequency sort, reorganise by counts — whenever the key is a small integer bounded by `n`.
* **Mistakes to Avoid:**
  * Calling `s.count(c)` for every character: O(n²) on `n = 5·10⁵`.
  * Interleaving equal-frequency characters (`"eetr"` is fine, `"etre"` is not): each character's copies must be contiguous.
  * Case matters: `'A'` and `'a'` are different characters.

## 🔹 Optimization Path

* **Brute Force:** sort the characters of `s` by `(−s.count(c), c)` — the key alone costs O(n) per character, O(n²) total.
* **Better:** `Counter` + sort the distinct characters by count — O(n + k log k), `k ≤ 62`.
* **Optimized Solution:** `Counter` + bucket sort — O(n), independent of the alphabet.
* **Further Improvements Possible?** No; output size is `n`.

## 🔹 Solution Breakdown

* **Optimal Approach:** `freq = Counter(s)`; `buckets[f]` collects characters seen exactly `f` times; iterate `f` from `n` to 1 and append `ch * f` for each character in the bucket.
* **Why This Works?** Bucket index *is* the sort key, so visiting buckets in descending index order lists characters in non-increasing frequency, and writing `ch * f` at once keeps each character's copies together.
* **Edge Cases Considered:**
  * Single character / all identical characters.
  * Ties — any order among equal frequencies is accepted.

## 🔹 Tricks & Patterns Used

* **Bucket sort on bounded integer keys:** `n + 1` buckets turn a comparison sort into a linear pass.
* **`ch * f` string repetition** builds each group in one step; `"".join` avoids quadratic concatenation.

## 🔹 Alternative Data Structures

* Max-heap of `(−count, ch)` — O(n + k log k), handy when only a prefix of the order is needed.
* `Counter.most_common()` — sorts the `k` distinct characters, effectively O(n) here since `k ≤ 62`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n) for the buckets and the output

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def frequencySort(self, s: str) -> str:
        return "".join(sorted(s, key=lambda ch: (-s.count(ch), ch)))
```

## 🔹 Code Snippet (Optimized)

```python
from collections import Counter


class Solution:
    def frequencySort(self, s: str) -> str:
        buckets = [[] for _ in range(len(s) + 1)]
        for ch, count in Counter(s).items():
            buckets[count].append(ch)
        parts = []
        for count in range(len(s), 0, -1):
            for ch in buckets[count]:
                parts.append(ch * count)
        return "".join(parts)
```
