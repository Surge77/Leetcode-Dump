# 🔹 Problem Name: 64. Minimum Path Sum (Dynamic Programming, Medium)

**🔗 Link:** [LeetCode 64](https://leetcode.com/problems/minimum-path-sum/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`, compressed to one row.
* **Core Concept:** Grid DP (right/down moves only)
* **When to Use This Pattern?** Cheapest/most valuable monotone path in a grid.
* **Mistakes to Avoid:**
  * Using Dijkstra — works, but is overkill when moves are only right/down (the grid is a DAG).
  * Forgetting the first row/column have only one predecessor.

## 🔹 Optimization Path

* **Brute Force:** O(2^(m+n)) — every path.
* **Optimized Solution:** O(m · n) time, O(n) space.
* **Further Improvements Possible?** O(1) extra space by writing into `grid` (only if mutation is allowed).

## 🔹 Solution Breakdown

* **Optimal Approach:** Row by row; `dp[j]` holds the best cost to reach column `j` in the current row.
* **Why This Works?** The last step into `(i, j)` comes from above or from the left; the cheaper of those two optimal sub-paths wins.
* **Edge Cases Considered:**
  * Single row or column.
  * Zeros in the grid.

## 🔹 Pattern Recognition

* **Belongs To:** DP — Grid
* **Common Problems Using This:**
  * 62 / 63. Unique Paths I / II
  * 120. Triangle
  * 931. Minimum Falling Path Sum

## 🔹 Tricks & Patterns Used

* **`inf` initialisation** acts as the missing row above the grid, so the first row needs no special case (the first column is handled by `dp[0] += row[0]`).

## 🔹 Alternative Data Structures

* Dijkstra with a heap — needed only when moves go in all four directions.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        n = len(grid[0])
        dp = [float("inf")] * n
        dp[0] = 0
        for row in grid:
            dp[0] += row[0]  # first column: only from above
            for j in range(1, n):
                dp[j] = row[j] + min(dp[j], dp[j - 1])  # above vs left
        return dp[-1]
```
