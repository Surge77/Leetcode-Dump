# 🔹 Problem Name: 187. Repeated DNA Sequences (Rolling Hash / Bit Encoding, Medium)

**🔗 Link:** [LeetCode 187](https://leetcode.com/problems/repeated-dna-sequences/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

A DNA string is made of the letters `A`, `C`, `G`, `T`. Return every 10-letter substring that appears more than once in the given string, each listed once, in any order.

* **Example:** `s = "AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"` → `["AAAAACCCCC","CCCCCAAAAA"]`
* **Constraints:** `1 ≤ s.length ≤ 10⁵`; each character is `A`, `C`, `G` or `T`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Encode each nucleotide in 2 bits, so a 10-letter window is a 20-bit integer. Slide the window with shifts and a mask; any integer seen twice is a repeated sequence.
* **Core Concept:** Rolling hash with an exact (collision-free) encoding
* **When to Use This Pattern?** Fixed-length substring repeats over a small alphabet.
* **Mistakes to Avoid:**
  * Reporting a sequence once per extra occurrence — collect results in a set.
  * Forgetting to mask off the bits of the character leaving the window.

## 🔹 Optimization Path

* **Brute Force:** `Counter` of all 10-letter slices — O(n · 10) time and memory (fine here, but the slices are copies).
* **Optimized Solution:** O(n) with 20-bit integers.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `h = ((h << 2) | code[c]) & mask`; once `i ≥ 9`, check/insert `h` in `seen`.
* **Why This Works?** With 4 letters and 2 bits each, every 10-letter string maps to a distinct 20-bit number, so equal codes ⇔ equal sequences.
* **Edge Cases Considered:**
  * Length < 10 → `[]`.
  * Overlapping repeats (`"AAAAAAAAAAA"`).

## 🔹 Code Snippet (Brute Force)

```python
from collections import Counter
from typing import List


class Solution:
    def findRepeatedDnaSequences(self, s: str) -> List[str]:
        counts = Counter(s[i:i + 10] for i in range(len(s) - 9))
        return [seq for seq, c in counts.items() if c > 1]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List

CODE = {"A": 0, "C": 1, "G": 2, "T": 3}
LENGTH = 10


class Solution:
    def findRepeatedDnaSequences(self, s: str) -> List[str]:
        mask = (1 << (2 * LENGTH)) - 1  # keep only the last 10 letters (20 bits)
        seen, repeated = set(), set()
        h = 0
        for i, ch in enumerate(s):
            h = ((h << 2) | CODE[ch]) & mask
            if i >= LENGTH - 1:
                if h in seen:
                    repeated.add(s[i - LENGTH + 1:i + 1])
                else:
                    seen.add(h)
        return list(repeated)
```
