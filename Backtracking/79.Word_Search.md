# 🔹 Problem Name: 79. Word Search (Backtracking on Grid, Medium)

**🔗 Link:** [LeetCode 79](https://leetcode.com/problems/word-search/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** From every cell matching the first letter, DFS to neighbours matching the next letter. Mark the cell as used (overwrite with `#`) while it is on the current path; restore it on return.
* **Core Concept:** Backtracking DFS on a grid
* **When to Use This Pattern?** Find a path spelling a sequence where cells cannot be reused (word puzzles, Boggle).
* **Mistakes to Avoid:**
  * A global visited set that is never cleared — blocks other valid paths.
  * Forgetting to restore the cell after exploring.

## 🔹 Optimization Path

* **Brute Force:** Enumerate all simple paths — what backtracking does, with pruning.
* **Optimized Solution:** O(m · n · 3^L) worst case.
* **Further Improvements Possible?** Prune if the board lacks enough of some letter; search from the rarer end of the word (reverse it if its last letter is rarer).

## 🔹 Solution Breakdown

* **Optimal Approach:** `dfs(i, j, k)`: fail on mismatch; succeed at `k == len(word) - 1`; mark, try 4 neighbours, unmark.
* **Why This Works?** The marking enforces "each cell at most once per path", and restoring makes the cell available to other paths.
* **Edge Cases Considered:**
  * Word longer than the number of cells.
  * Single-cell board.

## 🔹 Pattern Recognition

* **Belongs To:** Backtracking

## 🔹 Tricks & Patterns Used

* **In-place marking** instead of a visited set.
* **Letter-count pruning** with `Counter` before searching.

## 🔹 Alternative Data Structures

* For many words at once → Trie of words (212).

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n · 3^L)
* **Space Complexity:** O(L) recursion

## 🔹 Code Snippet (Optimized)

```python
from collections import Counter
from typing import List


class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        m, n = len(board), len(board[0])
        have = Counter(ch for row in board for ch in row)
        if any(have[ch] < cnt for ch, cnt in Counter(word).items()):
            return False  # not enough letters at all
        if have[word[0]] > have[word[-1]]:
            word = word[::-1]  # start from the rarer end

        def dfs(i: int, j: int, k: int) -> bool:
            if board[i][j] != word[k]:
                return False
            if k == len(word) - 1:
                return True
            board[i][j] = "#"  # mark as used on this path
            for x, y in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
                if 0 <= x < m and 0 <= y < n and dfs(x, y, k + 1):
                    board[i][j] = word[k]
                    return True
            board[i][j] = word[k]  # restore
            return False

        return any(dfs(i, j, 0) for i in range(m) for j in range(n))
```
