# 🔹 Problem Name: 304. Range Sum Query 2D - Immutable (2D Prefix Sum, Medium)

**🔗 Link:** [LeetCode 304](https://leetcode.com/problems/range-sum-query-2d-immutable/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** `P[i+1][j+1]` = sum of the rectangle from `(0, 0)` to `(i, j)`. Any sub-rectangle sum = `P[r2+1][c2+1] - P[r1][c2+1] - P[r2+1][c1] + P[r1][c1]`.
* **Core Concept:** 2D prefix sums (inclusion–exclusion)
* **When to Use This Pattern?** Many rectangle-sum queries on a static grid; counting submatrices with a property; image "integral images".
* **Mistakes to Avoid:**
  * No padding row/column → messy `if` checks for `r1 = 0` or `c1 = 0`.
  * Forgetting to add back the doubly subtracted top-left corner.

## 🔹 Optimization Path

* **Brute Force:** O(m · n) per query.
* **Row prefix sums:** O(m) per query.
* **Optimized Solution:** O(m · n) build, O(1) per query.

## 🔹 Solution Breakdown

* **Optimal Approach:** Build `P` with a padded zero row and column: `P[i+1][j+1] = grid[i][j] + P[i][j+1] + P[i+1][j] - P[i][j]`.
* **Why This Works?** Inclusion–exclusion: the big rectangle minus the strip above minus the strip to the left, plus their overlap (subtracted twice).
* **Edge Cases Considered:**
  * Single-cell query.
  * Query covering the whole grid.
  * Negative values.

* **Padding** removes boundary cases.

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class NumMatrix:
    def __init__(self, matrix: List[List[int]]):
        m, n = len(matrix), len(matrix[0])
        self.P = [[0] * (n + 1) for _ in range(m + 1)]  # padded prefix table
        for i in range(m):
            for j in range(n):
                self.P[i + 1][j + 1] = (matrix[i][j] + self.P[i][j + 1]
                                        + self.P[i + 1][j] - self.P[i][j])

    def sumRegion(self, row1: int, col1: int, row2: int, col2: int) -> int:
        P = self.P
        return (P[row2 + 1][col2 + 1] - P[row1][col2 + 1]
                - P[row2 + 1][col1] + P[row1][col1])
```
