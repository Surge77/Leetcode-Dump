# 🔹 Problem Name: 394. Decode String (Stack, Medium)

**🔗 Link:** [LeetCode 394](https://leetcode.com/problems/decode-string/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

An encoded string uses the rule `k[text]`, meaning `text` repeated `k` times, and rules can nest. Decode and return the full string; the input is always well-formed and digits only appear as repeat counts.

* **Example:** `s = "3[a]2[bc]"` → `"aaabcbc"`
* **Constraints:** `1 ≤ s.length ≤ 30`, counts in `[1, 300]`, decoded length at most `10^5`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Stack of saved contexts.** Scan once, keeping the text built so far in the current bracket level and the repeat count being read. On `[` push `(text so far, count)` and start a fresh level; on `]` pop it and append `count × current level` to the saved text.
* **Core Concept:** nested structure → one stack frame per open bracket
* **When to Use This Pattern?** Nested, bracketed grammars where an inner part is resolved before the outer part uses it — calculators, decoding, tag matching, scoring parentheses.
* **Mistakes to Avoid:**
  * Reading the count one digit at a time: `12[a]` is 12, not 2 — accumulate `k = k * 10 + digit`.
  * Forgetting to reset the count after `[`, so `3[a]2[b]` repeats `b` 32 times.
  * Concatenating strings in the inner loop — collect pieces in a list and `join` once.

## 🔹 Optimization Path

* **Brute Force:** repeatedly replace the innermost `k[letters]` group (no brackets inside) with its expansion until no `[` is left — the string is rebuilt once per nesting level.
* **Optimized Solution:** one pass with a stack — O(length of the output).
* **Further Improvements Possible?** No; the output itself has to be written, so O(output) is optimal.

## 🔹 Solution Breakdown

* **Optimal Approach:** `cur` is the list of pieces of the current level, `k` the pending count. `[` → `stack.append((cur, k))`, new `cur`, `k = 0`. `]` → `prev, times = stack.pop()`; `prev.append("".join(cur) * times)`; `cur = prev`. Letters go into `cur`.
* **Why This Works?** A `]` closes exactly the most recent unclosed `[`, so the saved frame on top of the stack is the one that owns this group; popping restores the outer level with the repeated inner text attached.
* **Edge Cases Considered:**
  * Plain text without brackets (`"abc"`) → returned unchanged.
  * Counts above 9 (`10[a]`), and text after a group (`2[abc]3[cd]ef`).
  * Deep nesting (`3[a2[c]]`) — at most 30 characters, so the stack stays tiny.

## 🔹 Tricks & Patterns Used

* **Push the whole context, not one value:** the frame is `(text before the bracket, repeat count)`, so no index bookkeeping is needed.
* **`list` of pieces + one `join`:** avoids quadratic string concatenation.

## 🔹 Alternative Data Structures

* Recursive descent: a function that parses until `]` and returns the text — same idea, the call stack replaces the explicit stack (depth is at most 10 here).
* Two stacks (counts and strings) — equivalent to the single stack of tuples.

## 🔹 Complexity Analysis

* **Time Complexity:** O(L), where `L` is the length of the decoded string (every output character is written a constant number of times per nesting level, and the nesting is at most 10 deep, since each level needs a digit and two brackets in a 30-character string)
* **Space Complexity:** O(L) for the output plus O(depth) for the stack

## 🔹 Code Snippet (Brute Force)

```python
import re


class Solution:
    def decodeString(self, s: str) -> str:
        # A group with no bracket inside it can be expanded without looking at its context.
        innermost = re.compile(r"(\d+)\[([a-z]*)\]")
        while "[" in s:
            s = innermost.sub(lambda m: int(m.group(1)) * m.group(2), s)
        return s
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def decodeString(self, s: str) -> str:
        stack = []
        current = []
        count = 0
        for ch in s:
            if ch.isdigit():
                count = count * 10 + int(ch)
            elif ch == "[":
                stack.append((current, count))
                current, count = [], 0  # the count belongs to the group that just opened
            elif ch == "]":
                outer, times = stack.pop()
                outer.append("".join(current) * times)
                current = outer
            else:
                current.append(ch)
        return "".join(current)
```
