# 🔹 Problem Name: 935. Knight Dialer (Matrix Exponentiation, Medium)

**🔗 Link:** [LeetCode 935](https://leetcode.com/problems/knight-dialer/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** The DP "ways to end on digit `b` after `k` jumps" is a linear transition: `next = M · current`, where `M[a][b] = 1` if a knight jumps between `a` and `b`. So the answer is the sum of all entries of `M^(n-1)` — computed with fast matrix power.
* **Core Concept:** Linear recurrence → matrix exponentiation (mod 10⁹+7)
* **When to Use This Pattern?** A DP with a small fixed number of states, the same transition every step, and a huge step count (`n` up to 10¹⁸ in exam variants).
* **Mistakes to Avoid:**
  * Missing digit 5: no knight move touches it, so `n = 1` is the only time it counts.
  * Taking the modulo only at the end of a matrix product.

## 🔹 Optimization Path

* **Brute Force:** Enumerate numbers — exponential.
* **DP:** O(10 · n) — fine for n = 5000.
* **Optimized Solution:** O(10³ · log n) matrix power.

## 🔹 Solution Breakdown

* **Optimal Approach:** Build the 10×10 move matrix, raise it to `n - 1` by repeated squaring, sum all entries.
* **Why This Works?** Entry `(a, b)` of `M^k` counts the length-`k` jump sequences from `a` to `b` (matrix multiplication sums over the middle digit). Summing over all start and end digits counts every valid number.
* **Edge Cases Considered:**
  * `n = 1` → 10 (identity matrix).
  * Large `n` (log-time).

## 🔹 Code Snippet (Optimized)

```python
MOD = 10**9 + 7
MOVES = {0: [4, 6], 1: [6, 8], 2: [7, 9], 3: [4, 8], 4: [0, 3, 9],
         5: [], 6: [0, 1, 7], 7: [2, 6], 8: [1, 3], 9: [2, 4]}


def mat_mult(a, b):
    size = len(a)
    return [[sum(a[i][k] * b[k][j] for k in range(size)) % MOD for j in range(size)]
            for i in range(size)]


def mat_pow(m, e):
    result = [[int(i == j) for j in range(len(m))] for i in range(len(m))]  # identity
    while e:
        if e & 1:
            result = mat_mult(result, m)
        m = mat_mult(m, m)
        e >>= 1
    return result


class Solution:
    def knightDialer(self, n: int) -> int:
        move = [[0] * 10 for _ in range(10)]
        for a, targets in MOVES.items():
            for b in targets:
                move[a][b] = 1
        paths = mat_pow(move, n - 1)  # paths[a][b]: jump sequences a -> b
        return sum(map(sum, paths)) % MOD
```
