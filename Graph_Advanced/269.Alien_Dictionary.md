## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Derive letter-order edges from adjacent words, then topologically sort (Kahn's BFS).** For each adjacent pair `w1, w2`, the first position where they differ gives the edge `w1[k] → w2[k]`. If there is no difference and `w1` is longer than `w2` (`"abc"` before `"ab"`), the input is invalid → `""`. Run Kahn's algorithm over all letters that appear; if some letters never reach in-degree 0, there is a cycle → `""`.
* **Core Concept:** a sorted dictionary only reveals order through the **first** differing character of **adjacent** words; everything else is implied by transitivity
* **When to Use This Pattern?** "Recover an order from pairwise precedence facts", "is there a consistent ordering?" — course schedules, build orders, sequence reconstruction.
* **Mistakes to Avoid:**
  * Comparing characters after the first difference — they carry no information.
  * Missing the prefix rule: `["abc", "ab"]` is invalid.
  * Dropping letters with no edges — every letter that appears must be in the output.
  * Adding duplicate edges and double-counting in-degree — keep edges in sets.

## 🔹 Optimization Path

* **Brute Force:** try every permutation of the distinct letters and return one under which the word list is sorted — O(k! · total length) for `k` letters.
* **Optimized Solution:** edges from adjacent pairs + Kahn's algorithm — O(C) where `C` = total characters.
* **Further Improvements Possible?** No; every character may matter. (LintCode's version wants the lexicographically smallest valid order — use a min-heap instead of a queue, O(C + k log k).)

## 🔹 Solution Breakdown

* **Optimal Approach:** collect all letters; for each adjacent pair add the first-difference edge or detect the prefix violation; in-degree count; queue every letter with in-degree 0; pop, append, decrement neighbours. Return the order if it contains every letter, else `""`.
* **Why This Works?** Under an order π, the list is sorted iff each adjacent pair is (lexicographic order is transitive), and an adjacent pair is sorted iff its first differing letters are ordered by π (or one word is a prefix of the next). So valid orders are exactly the topological orders of the edge graph; Kahn's algorithm produces one iff the graph is acyclic.
* **Edge Cases Considered:**
  * A single word → its distinct letters in any order.
  * Identical adjacent words → no edge, valid.
  * Cycle (`["z", "x", "z"]`) → `""`.

## 🔹 Code Snippet (Brute Force)

```python
from itertools import permutations
from typing import List


class Solution:
    def alienOrder(self, words: List[str]) -> str:
        letters = sorted(set("".join(words)))
        for perm in permutations(letters):
            rank = {ch: i for i, ch in enumerate(perm)}
            keys = [[rank[ch] for ch in w] for w in words]
            if all(keys[i] <= keys[i + 1] for i in range(len(keys) - 1)):
                return "".join(perm)
        return ""
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def alienOrder(self, words: List[str]) -> str:
        graph = {ch: set() for w in words for ch in w}
        indegree = dict.fromkeys(graph, 0)
        for w1, w2 in zip(words, words[1:]):
            for a, b in zip(w1, w2):
                if a != b:
                    if b not in graph[a]:
                        graph[a].add(b)
                        indegree[b] += 1
                    break  # only the first difference carries information
            else:
                if len(w1) > len(w2):
                    return ""
        queue = deque(ch for ch, d in indegree.items() if d == 0)
        order = []
        while queue:
            ch = queue.popleft()
            order.append(ch)
            for nxt in graph[ch]:
                indegree[nxt] -= 1
                if indegree[nxt] == 0:
                    queue.append(nxt)
        return "".join(order) if len(order) == len(graph) else ""
```
