# 🔹 Problem Name: 743. Network Delay Time (Dijkstra, Medium)

**🔗 Link:** [LeetCode 743](https://leetcode.com/problems/network-delay-time/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Dijkstra from `k`; the answer is the largest shortest distance, or `-1` if some node is unreachable.
* **Core Concept:** Dijkstra's algorithm with a min-heap
* **When to Use This Pattern?** Single-source shortest paths with **non-negative** weights.
* **Mistakes to Avoid:**
  * Not skipping stale heap entries (`if d > dist[u]: continue`) — still correct but much slower.
  * Using Dijkstra with negative edges — use Bellman-Ford instead.
  * Nodes are 1-indexed here.

## 🔹 Optimization Path

* **Brute Force:** Bellman-Ford O(V · E).
* **Optimized Solution:** Dijkstra O(E log V).
* **Further Improvements Possible?** For dense graphs, the O(V²) array version (no heap) is better.

## 🔹 Solution Breakdown

* **Optimal Approach:** `dist[k] = 0`; pop the closest node, relax its edges, push improved distances.
* **Why This Works?** With non-negative weights, the closest unfinished node cannot be improved by any path through farther nodes, so its distance is final when popped.
* **Edge Cases Considered:**
  * Unreachable node → -1.
  * Zero-weight edges.
  * Single node → 0.

## 🔹 Tricks & Patterns Used

* **Lazy deletion:** push duplicates, skip outdated pops.
* **`heapq` tuples `(dist, node)`** order by distance automatically.

## 🔹 Alternative Data Structures

* 0-1 BFS with a deque when weights are only 0 or 1 (see 1368).

## 🔹 Complexity Analysis

* **Time Complexity:** O(E log V)
* **Space Complexity:** O(V + E)

## 🔹 Code Snippet (Optimized)

```python
import heapq
from collections import defaultdict
from typing import List


class Solution:
    def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
        adj = defaultdict(list)
        for u, v, w in times:
            adj[u].append((v, w))

        dist = [float("inf")] * (n + 1)
        dist[k] = 0
        pq = [(0, k)]
        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]:
                continue  # stale entry
            for v, w in adj[u]:
                if d + w < dist[v]:
                    dist[v] = d + w
                    heapq.heappush(pq, (dist[v], v))

        longest = max(dist[1:])
        return longest if longest < float("inf") else -1
```
