# 🔹 Problem Name: 643. Maximum Average Subarray I (Fixed Sliding Window, Easy)

**🔗 Link:** [LeetCode 643](https://leetcode.com/problems/maximum-average-subarray-i/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Slide a window of length `k`, updating its sum in O(1).** All windows have the same length, so the maximum average is the maximum sum divided by `k`. Moving the window one step adds the new element and removes the one leaving.
* **Core Concept:** the sum of the next window = previous sum + entering − leaving
* **When to Use This Pattern?** Any statistic over every fixed-length window that can be updated incrementally: sums, counts, vowel counts (1456), distinct counts.
* **Mistakes to Avoid:**
  * Dividing every window sum by `k` — compare integer sums and divide once at the end.
  * Initialising the maximum with `0`: values can be negative, so start from the first window's sum.
  * Re-summing each window (O(n·k)).

## 🔹 Optimization Path

* **Brute Force:** compute `sum(nums[i:i+k])` for every start — O(n·k).
* **Optimized Solution:** first window sum, then slide — O(n).
* **Further Improvements Possible?** No; each element is read once.

## 🔹 Solution Breakdown

* **Optimal Approach:** `window = sum(nums[:k])`, `best = window`; for `i` in `k..n-1`: `window += nums[i] - nums[i - k]`; `best = max(best, window)`. Return `best / k`.
* **Why This Works?** Adjacent windows share `k - 1` elements, so their sums differ by exactly the entering and leaving element. All windows have the same size, so ordering by sum equals ordering by average.
* **Edge Cases Considered:**
  * `k == n` → one window, the loop does not run.
  * All negative values → the answer is negative; `best` starts from a real window.
  * `n = k = 1` → returns `float(nums[0])`.

* **Add one, drop one** to maintain the window sum.
* **Defer the division** until after the maximum is found.

## 🔹 Alternative Data Structures

* Prefix sums: `pre[i + k] - pre[i]` per window — same O(n), O(n) space.

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        return max(sum(nums[i:i + k]) for i in range(len(nums) - k + 1)) / k
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        window = sum(nums[:k])
        best = window
        for i in range(k, len(nums)):
            window += nums[i] - nums[i - k]
            best = max(best, window)
        return best / k
```
