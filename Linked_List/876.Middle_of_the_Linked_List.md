# 876. Middle of the Linked List

**🔗 Link:** [LeetCode 876](https://leetcode.com/problems/middle-of-the-linked-list/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Return the middle node of a singly linked list; when the length is even there are two middle nodes and the second one is the answer. The result is the node itself, so the list from that node onward is what gets compared.

* **Example:** `head = [1,2,3,4,5]` → `[3,4,5]` (the node with value `3`)
* **Constraints:** `1 ≤ n ≤ 100`; `1 ≤ Node.val ≤ 100`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Fast and slow pointers.** `slow` moves 1 step, `fast` moves 2. When `fast` can't move any more, `slow` is at index `n // 2` — the middle, or the **second** middle for even `n`, as the problem asks.
* **Core Concept:** a 2:1 speed ratio finds the midpoint in one pass without knowing the length
* **When to Use This Pattern?** Splitting a list in half — merge sort on lists (148), palindrome check (234), reorder (143), deleting the middle (2095).
* **Mistakes to Avoid:**
  * `while fast.next and fast.next.next` — that returns the **first** middle for even `n`; the problem wants the second.
  * Dereferencing `fast.next` without checking `fast` first.

## 🔹 Optimization Path

* **Brute Force:** copy the nodes into an array and return `nodes[n // 2]` — O(n) time, O(n) space.
* **Optimized Solution:** fast/slow in one pass — O(n) time, O(1) space.
* **Further Improvements Possible?** Counting the length then walking `n // 2` is also O(1) space, just two passes.

## 🔹 Solution Breakdown

* **Optimal Approach:** `slow = fast = head; while fast and fast.next: slow, fast = slow.next, fast.next.next`.
* **Why This Works?** After `k` iterations `slow` is at index `k` and `fast` at `2k`. The loop runs while `2k + 1 ≤ n − 1`, i.e. it stops at the first `k` with `2k ≥ n − 1`, which is `k = n // 2`.
* **Edge Cases Considered:**
  * One node → itself.
  * Two nodes → the second.

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def middleNode(self, head: Optional[ListNode]) -> Optional[ListNode]:
        nodes = []
        while head:
            nodes.append(head)
            head = head.next
        return nodes[len(nodes) // 2]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def middleNode(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head
        while fast and fast.next:  # stops with slow at index n // 2, the second middle
            slow, fast = slow.next, fast.next.next
        return slow
```
