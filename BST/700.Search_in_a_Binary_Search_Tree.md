# 🔹 Problem Name: 700. Search in a Binary Search Tree (BST Search, Easy)

**🔗 Link:** [LeetCode 700](https://leetcode.com/problems/search-in-a-binary-search-tree/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Walk one path.** Start at the root; if `val` is smaller go left, larger go right, equal → return that node (its subtree is the answer). Falling off the tree → `None`.
* **Core Concept:** the BST property discards one whole subtree per comparison — binary search on a tree
* **When to Use This Pattern?** Every BST lookup-style problem: search, insert position (701), floor/ceil, LCA in a BST (235), closest value.
* **Mistakes to Avoid:**
  * Searching both subtrees — correct but O(n), wasting the BST order.
  * Returning `node.val` or a copy — LeetCode wants the existing subtree root.

## 🔹 Optimization Path

* **Brute Force:** traverse every node until `val` is found — O(n).
* **Optimized Solution:** follow the comparisons down one path — O(h).
* **Further Improvements Possible?** O(h) is optimal for an unbalanced BST; balanced trees make it O(log n).

## 🔹 Solution Breakdown

* **Optimal Approach:** `while node and node.val != val: node = node.left if val < node.val else node.right`; return `node`.
* **Why This Works?** Every value in the left subtree is smaller than `node.val` and every value in the right subtree is larger, so if `val` exists it can only be on the side the comparison picks.
* **Edge Cases Considered:**
  * `val` absent → `None` (serialised as `[]`).
  * `val` at the root → the whole tree.

## 🔹 Tricks & Patterns Used

* **Iterative descent:** no stack needed because only one path is followed — O(1) space.

## 🔹 Alternative Data Structures

* Recursive version — same time, O(h) call stack (a 5000-node path would exceed Python's default limit).

## 🔹 Complexity Analysis

* **Time Complexity:** O(h) — O(n) for a degenerate tree, O(log n) for a balanced one
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
from typing import Optional


class Solution:
    def searchBST(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        stack = [root]
        while stack:
            node = stack.pop()
            if node is None:
                continue
            if node.val == val:
                return node
            stack += [node.left, node.right]
        return None
```

## 🔹 Code Snippet (Optimized)

```python
from typing import Optional


class Solution:
    def searchBST(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        node = root
        while node and node.val != val:
            node = node.left if val < node.val else node.right  # the other side cannot hold val
        return node
```
