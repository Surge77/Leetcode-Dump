# 🔹 Problem Name: 115. Distinct Subsequences (Dynamic Programming, Hard)

**🔗 Link:** [LeetCode 115](https://leetcode.com/problems/distinct-subsequences/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** `ways[j]` = number of ways to form `t[:j]` from the part of `s` read so far. For each character of `s`, every matching position `j` in `t` gains `ways[j-1]`.
* **Core Concept:** Counting DP on two strings
* **When to Use This Pattern?** "How many times does pattern P occur as a subsequence of S?" — often asked with `% (10**9 + 7)`.
* **Mistakes to Avoid:**
  * Updating `j` left-to-right in the 1D array — reuses the same character of `s` twice.
  * Forgetting `ways[0] = 1` (the empty pattern is formed exactly once).

## 🔹 Optimization Path

* **Brute Force:** O(C(n, m) · m) — every index subset of size `m`.
* **2D DP:** O(n · m) time and space.
* **Optimized Solution:** O(n · m) time, O(m) space (right-to-left update).

## 🔹 Solution Breakdown

* **Optimal Approach:** For each `c` in `s`, for `j` from `m` down to 1: if `t[j-1] == c`, `ways[j] += ways[j-1]`.
* **Why This Works?** Each occurrence of `t[:j]` either does not use the current character of `s` (already counted in `ways[j]`) or uses it as its last character (then the first `j-1` characters came earlier: `ways[j-1]`).
* **Edge Cases Considered:**
  * `t` longer than `s` → 0.
  * Repeated characters (`"babgbag"`, `"bag"` → 5).

## 🔹 Pattern Recognition

* **Belongs To:** DP — two-string counting
* **Common Problems Using This:**
  * 940. Distinct Subsequences II
  * 1987. Number of Unique Good Subsequences
  * Count occurrences of "abc" / "ab" as subsequence (classic Infosys easy-medium)

## 🔹 Tricks & Patterns Used

* **Right-to-left update** = 0/1 knapsack idea: each character of `s` is used once per pattern position.
* **Modulo Arithmetic** when the count is asked mod 10⁹ + 7.

## 🔹 Alternative Data Structures

* Map each character of `t` to the list of its positions, so each `s` character only touches matching `j`s.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · m)
* **Space Complexity:** O(m)

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        m = len(t)
        ways = [1] + [0] * m  # ways[j]: ways to form t[:j] so far
        for c in s:
            for j in range(m, 0, -1):  # right-to-left: use c at most once per j
                if t[j - 1] == c:
                    ways[j] += ways[j - 1]
        return ways[m]
```
