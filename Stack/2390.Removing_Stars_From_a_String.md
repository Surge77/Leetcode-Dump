# 2390. Removing Stars From a String

**🔗 Link:** [LeetCode 2390](https://leetcode.com/problems/removing-stars-from-a-string/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

The string `s` contains lowercase letters and stars. Each star deletes itself and the closest letter to its left. Return the string left after all stars are processed (the input guarantees every star has a letter to remove).

* **Example:** `s = "leet**cod*e"` → `"lecoe"`
* **Constraints:** `1 ≤ s.length ≤ 10^5`, lowercase letters and `*` only

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Stack as the result.** Push every letter; a `*` pops the top (the closest non-star on its left). What remains is the answer.
* **Core Concept:** "remove the nearest previous element" = pop from a stack
* **When to Use This Pattern?** Backspace-style or cancel-the-neighbour operations applied left to right — backspace compare, adjacent-duplicate removal, asteroid collisions.
* **Mistakes to Avoid:**
  * Deleting from the middle of a string each time: every deletion copies the rest, O(n²) for `n = 10⁵`.
  * Pushing the `*` itself onto the stack.

## 🔹 Optimization Path

* **Brute Force:** find the first `*`, cut it and the character before it out of the string, repeat — O(n²) copying.
* **Optimized Solution:** one pass with a list used as a stack — O(n).
* **Further Improvements Possible?** Scanning from the right with a skip counter removes the stack, but still needs the output list; O(n) is already optimal.

## 🔹 Solution Breakdown

* **Optimal Approach:** `for ch in s: if ch == '*': out.pop() else: out.append(ch)`; return `"".join(out)`.
* **Why This Works?** Removing the leftmost star first is always valid: no star lies before it, so its left neighbour is a letter still in the string. The stack holds exactly the letters that survived so far, so its top is that neighbour.
* **Edge Cases Considered:**
  * Every character removed (`"erase*****"` → `""`).
  * The input is guaranteed valid, so a `*` never meets an empty stack.

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def removeStars(self, s: str) -> str:
        while "*" in s:
            i = s.index("*")
            # The first star has no star before it, so s[i - 1] is a letter.
            s = s[:i - 1] + s[i + 1:]
        return s
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def removeStars(self, s: str) -> str:
        kept = []
        for ch in s:
            if ch == "*":
                kept.pop()
            else:
                kept.append(ch)
        return "".join(kept)
```
