# 🔹 Problem Name: 1899. Merge Triplets to Form Target Triplet (Greedy Filtering, Medium)

**🔗 Link:** [LeetCode 1899](https://leetcode.com/problems/merge-triplets-to-form-target-triplet/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Discard bad triplets, merge all the rest.** Merging takes the element-wise max, which can only grow. Any triplet with some coordinate above the target poisons that coordinate forever, so ignore it. Every other triplet is safe to merge; the target is reachable iff the safe triplets together hit each target coordinate exactly.
* **Core Concept:** max is monotone and idempotent — merging every harmless triplet is never worse than merging a subset
* **When to Use This Pattern?** Building a target with an operation that only increases (max, OR, union): filter out items that overshoot, then combine everything that's left.
* **Mistakes to Avoid:**
  * Requiring one triplet to equal the target — different triplets may supply different coordinates (`[2,5,3] + [1,7,5] → [2,7,5]`).
  * Counting a coordinate as "found" from a triplet that overshoots on another coordinate.

## 🔹 Optimization Path

* **Brute Force:** try every non-empty subset, merge it, compare to the target — O(2ⁿ · n).
* **Optimized Solution:** one pass: skip overshooting triplets, mark which coordinates are matched — O(n).
* **Further Improvements Possible?** No; every triplet must be looked at.

## 🔹 Solution Breakdown

* **Optimal Approach:** `found = [False] * 3`; for each triplet with `t[k] ≤ target[k]` for all `k`, set `found[k] |= t[k] == target[k]`. Return `all(found)`.
* **Why This Works?** Let `G` be the safe triplets. Merging any subset of `G` gives a vector ≤ target; merging all of `G` gives the largest such vector. If even that misses a target coordinate, no subset can hit it (unsafe triplets would overshoot). Conversely, if each coordinate is attained by some safe triplet, merging all of `G` produces exactly the target.
* **Edge Cases Considered:**
  * A single triplet equal to the target → True.
  * All triplets overshoot somewhere → False.
  * Coordinates attained by three different triplets → True.

## 🔹 Tricks & Patterns Used

* **Monotone operator ⇒ "take everything allowed":** for max/OR/union, the best subset is all non-harmful items.
* **Per-coordinate flags** instead of building the merged triplet.

## 🔹 Alternative Data Structures

* Keep a running merged triplet `cur = max(cur, t)` over safe triplets and return `cur == target` — same logic, equally O(n).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n), `n ≤ 10⁵`
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
from itertools import combinations
from typing import List


class Solution:
    def mergeTriplets(self, triplets: List[List[int]], target: List[int]) -> bool:
        for size in range(1, len(triplets) + 1):
            for subset in combinations(triplets, size):
                if [max(column) for column in zip(*subset)] == target:
                    return True
        return False
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def mergeTriplets(self, triplets: List[List[int]], target: List[int]) -> bool:
        found = [False, False, False]
        for triplet in triplets:
            if any(value > goal for value, goal in zip(triplet, target)):
                continue  # max can only grow, so an overshoot can never be undone
            for k in range(3):
                found[k] = found[k] or triplet[k] == target[k]
        return all(found)
```
