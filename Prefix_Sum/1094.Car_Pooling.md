# 🔹 Problem Name: 1094. Car Pooling (Difference Array, Medium)

**🔗 Link:** [LeetCode 1094](https://leetcode.com/problems/car-pooling/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

A car with `capacity` empty seats only drives east. Each trip `[numPassengers, from, to]` picks passengers up at `from` and drops them off at `to` (drop-offs at a location happen before pick-ups there). Return `true` if the car never holds more than `capacity` passengers at any point, otherwise `false`.

* **Example:** `trips = [[2,1,5],[3,3,7]], capacity = 4` → `false`
* **Constraints:** `1 ≤ trips.length ≤ 1000`; `trips[i].length == 3`; `1 ≤ numPassengers ≤ 100`; `0 ≤ from < to ≤ 1000`; `1 ≤ capacity ≤ 10^5`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Difference array.** A trip `[num, from, to]` adds `num` passengers on `[from, to)`: record `+num` at `from` and `−num` at `to`. A running prefix sum over the locations is the car's load; fail if it ever exceeds `capacity`.
* **Core Concept:** range add with O(1) per update, read everything with one prefix-sum pass
* **When to Use This Pattern?** Many "add `x` to every position in `[l, r]`" updates followed by reads (or a max) — bookings, shifts, overlapping intervals, "how many intervals cover point `p`".
* **Mistakes to Avoid:**
  * Passengers leave **at** `to`, so the interval is half-open: subtract at `to`, not `to + 1`.
  * Adding `num` to every location of the trip: O(trips × length).

## 🔹 Optimization Path

* **Brute Force:** for each location, sum the trips covering it — O(locations × trips).
* **Optimized Solution:** difference array — O(trips + max location).
* **Further Improvements Possible?** If locations go up to 10⁹, sort the 2·trips events instead (sweep line): O(t log t).

## 🔹 Solution Breakdown

* **Optimal Approach:** `diff[from] += num`, `diff[to] -= num`; scan `diff` keeping `load += diff[i]`.
* **Why This Works?** The prefix sum of `diff` at `i` counts every `+num` with `from ≤ i` minus every `−num` with `to ≤ i` — exactly the trips active at `i`.
* **Edge Cases Considered:**
  * One trip dropping off where another picks up (`to₁ == from₂`) — they never overlap.

## 🔹 Tricks & Patterns Used

* **Difference array:** `diff[l] += x; diff[r + 1] -= x` for a closed range `[l, r]`, then prefix sums.

## 🔹 Alternative Data Structures

* Sorted events `(location, ±num)` — process drop-offs before pick-ups at the same location.
* Fenwick / segment tree with lazy propagation when updates and queries interleave.

## 🔹 Complexity Analysis

* **Time Complexity:** O(t + L) with `L = 1001` locations
* **Space Complexity:** O(L)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        last = max(to for _, _, to in trips)
        return all(sum(num for num, start, end in trips if start <= spot < end) <= capacity
                   for spot in range(last + 1))
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        diff = [0] * (max(to for _, _, to in trips) + 1)
        for num, start, end in trips:
            diff[start] += num
            diff[end] -= num  # they get out at `end`
        load = 0
        for change in diff:
            load += change
            if load > capacity:
                return False
        return True
```
