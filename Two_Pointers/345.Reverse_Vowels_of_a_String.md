# 🔹 Problem Name: 345. Reverse Vowels of a String (Two Pointers, Easy)

**🔗 Link:** [LeetCode 345](https://leetcode.com/problems/reverse-vowels-of-a-string/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Reverse the order of only the vowels in a string and leave every other character where it is. Vowels are `a e i o u` in either lower or upper case, and they may repeat. Return the resulting string.

* **Example:** `s = "IceCreAm"` → `"AceCreIm"`
* **Constraints:** `1 ≤ s.length ≤ 3 · 10^5`; `s` consists of printable ASCII characters

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Two pointers from both ends.** Move `lo` right until it sits on a vowel and `hi` left until it sits on a vowel, swap them, and step both inward. Consonants never move.
* **Core Concept:** reverse a subsequence in place by swapping matching pairs from the outside in
* **When to Use This Pattern?** Reverse or reorder only the elements that satisfy a predicate — reverse only letters, move zeroes, partition by property.
* **Mistakes to Avoid:**
  * Forgetting uppercase vowels (`A E I O U`) — they count as vowels.
  * Swapping when the pointers have crossed (`lo ≥ hi`).
  * Rebuilding the string with `s[:i] + c + s[i + 1:]` for every swap: O(n²) for `n = 3·10⁵`.
  * Treating `y` as a vowel.

## 🔹 Optimization Path

* **Brute Force:** collect the vowel positions, then rewrite the string one position at a time with the vowels in reverse order — each rewrite copies the string, O(n · v).
* **Optimized Solution:** two pointers on a list of characters — O(n).
* **Further Improvements Possible?** No; every character has to be inspected.

## 🔹 Solution Breakdown

* **Optimal Approach:** `chars = list(s)`; `lo, hi = 0, n − 1`. While `lo < hi`: advance `lo` past non-vowels, retreat `hi` past non-vowels; swap and move both (when the inner loops stop with `lo == hi`, the swap is a harmless self-swap).
* **Why This Works?** Reversing a sequence is the same as swapping its first element with its last, its second with its second-last, and so on. The pointers visit the vowels in exactly that pairing, skipping the consonants that stay in place.
* **Edge Cases Considered:**
  * No vowels, or a single vowel → unchanged.
  * String of one character.
  * Mixed case: `"IceCreAm"` → `"AceCreIm"`, case travels with the vowel.

## 🔹 Tricks & Patterns Used

* **Set membership for the vowel test:** `ch in VOWELS` is O(1) and keeps the loop readable.
* **Mutable `list` of characters:** Python strings are immutable, so swap in a list and `join` once.

## 🔹 Alternative Data Structures

* Collect the vowels in a list, `reverse()` it, then walk the string and substitute — O(n) and also very short.
* Stack of vowels popped while scanning left to right.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n) for the character list

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def reverseVowels(self, s: str) -> str:
        positions = [i for i, ch in enumerate(s) if ch in "aeiouAEIOU"]
        vowels = [s[i] for i in positions]
        for i, vowel in zip(positions, reversed(vowels)):
            s = s[:i] + vowel + s[i + 1:]
        return s
```

## 🔹 Code Snippet (Optimized)

```python
VOWELS = set("aeiouAEIOU")


class Solution:
    def reverseVowels(self, s: str) -> str:
        chars = list(s)
        lo, hi = 0, len(chars) - 1
        while lo < hi:
            while lo < hi and chars[lo] not in VOWELS:
                lo += 1
            while lo < hi and chars[hi] not in VOWELS:
                hi -= 1
            chars[lo], chars[hi] = chars[hi], chars[lo]
            lo += 1
            hi -= 1
        return "".join(chars)
```
