# 🔹 Problem Name: 97. Interleaving String (2D DP on Strings, Medium)

**🔗 Link:** [LeetCode 97](https://leetcode.com/problems/interleaving-string/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Decide whether `s3` can be built by weaving together all characters of `s1` and `s2`, where each of the two keeps its own internal left-to-right order. Return `true` or `false`.

* **Example:** `s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"` → `true`
* **Constraints:** `0 ≤ s1.length, s2.length ≤ 100`; `0 ≤ s3.length ≤ 200`; lowercase English letters only.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Prefix DP.** `dp[i][j]` = can `s3[:i+j]` be formed by interleaving `s1[:i]` and `s2[:j]`? The last char `s3[i+j-1]` came either from `s1` (`dp[i-1][j]` and `s1[i-1]` matches) or from `s2` (`dp[i][j-1]` and `s2[j-1]` matches).
* **Core Concept:** once you know how many chars of `s1` were used, the number used from `s2` is forced (`k − i`), so the state is just `(i, j)`.
* **When to Use This Pattern?** Merging / splitting a string into two ordered sources, "is `s3` a shuffle of `s1` and `s2`".
* **Mistakes to Avoid:**
  * Greedy matching (take from `s1` whenever it fits) — fails when both strings offer the same next char.
  * Skipping the length check: `len(s1) + len(s2) != len(s3)` must return `False` up front.
  * Two-pointer "is `s1` a subsequence and the rest equals `s2`" — the leftover check alone is not enough when chars repeat.

## 🔹 Optimization Path

* **Brute Force:** recursion that tries `s1` and `s2` at every step — O(2^(|s1|+|s2|)).
* **Optimized Solution:** only `(|s1|+1)(|s2|+1)` distinct states — O(|s1| · |s2|) time.
* **Further Improvements Possible?** The follow-up asks for O(|s2|) extra memory: keep one row `dp[j]`, since row `i` only reads row `i-1` (same column) and itself (column `j-1`).

## 🔹 Solution Breakdown

* **Optimal Approach:** `dp[0] = True`, first row `dp[j] = dp[j-1] and s2[j-1] == s3[j-1]`. For each `i ≥ 1`: `dp[0] = dp[0] and s1[i-1] == s3[i-1]`, then `dp[j] = (dp[j] and s1[i-1] == c) or (dp[j-1] and s2[j-1] == c)` with `c = s3[i+j-1]`.
* **Why This Works?** In any valid interleaving of `s1[:i]` and `s2[:j]`, the final char of `s3[:i+j]` is the last char of one of them, and removing it leaves a valid interleaving of the shorter prefixes. So `dp[i][j]` is true exactly when one of those two smaller states is true with a matching char.
* **Edge Cases Considered:**
  * All three empty → `True`.
  * One of `s1`, `s2` empty → reduces to `s3 == the other one`.
  * Both strings offer the same char (e.g. `"aabcc"` / `"dbbca"`) — the DP keeps both branches alive.

## 🔹 Tricks & Patterns Used

* **Derived index:** the position in `s3` is `i + j`, so it needs no dimension of its own.
* **1D rolling row** — "old `dp[j]`" is the row above, "new `dp[j-1]`" is the cell to the left.

## 🔹 Alternative Data Structures

* Top-down recursion with `lru_cache` on `(i, j)`.
* BFS / DFS over the `(i, j)` grid with a visited set — same states, explored only where reachable.

## 🔹 Complexity Analysis

* **Time Complexity:** O(|s1| · |s2|)
* **Space Complexity:** O(|s2|)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        if len(s1) + len(s2) != len(s3):
            return False

        def go(i: int, j: int) -> bool:
            if i + j == len(s3):
                return True
            k = i + j
            return ((i < len(s1) and s1[i] == s3[k] and go(i + 1, j))
                    or (j < len(s2) and s2[j] == s3[k] and go(i, j + 1)))

        return go(0, 0)
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        n, m = len(s1), len(s2)
        if n + m != len(s3):
            return False
        dp = [False] * (m + 1)
        dp[0] = True
        for j in range(1, m + 1):
            dp[j] = dp[j - 1] and s2[j - 1] == s3[j - 1]
        for i in range(1, n + 1):
            dp[0] = dp[0] and s1[i - 1] == s3[i - 1]
            for j in range(1, m + 1):
                c = s3[i + j - 1]
                # old dp[j] = last char taken from s1; new dp[j-1] = last char taken from s2
                dp[j] = (dp[j] and s1[i - 1] == c) or (dp[j - 1] and s2[j - 1] == c)
        return dp[m]
```
