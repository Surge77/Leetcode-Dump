# 42. Trapping Rain Water

**🔗 Link:** [LeetCode 42](https://leetcode.com/problems/trapping-rain-water/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given the heights of bars in an elevation map (each bar has width 1), compute how many units of rain water are trapped between the bars after it rains. Water over a bar is limited by the shorter of the tallest bars on its left and right.

* **Example:** `height = [0,1,0,2,1,0,1,3,2,1,2,1]` → `6`
* **Constraints:** `1 ≤ n ≤ 2 * 10^4` (`n = height.length`); `0 ≤ height[i] ≤ 10^5`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Water above bar `i` = `min(maxLeft, maxRight) - height[i]`. Two pointers move inward from the side with the smaller running maximum, because that side's level is already decided.
* **Core Concept:** Two pointers with running maxima (stack and prefix-max versions also work)
* **When to Use This Pattern?** Each position's answer depends on the best value to its left and to its right.
* **Mistakes to Avoid:**
  * Recomputing left/right maxima per index — O(n²).
  * Moving the pointer on the taller side.

## 🔹 Optimization Path

* **Brute Force:** O(n²) — scan left and right for each bar.
* **Prefix/Suffix max arrays:** O(n) time, O(n) space.
* **Optimized Solution:** O(n) time, O(1) space with two pointers.

## 🔹 Solution Breakdown

* **Optimal Approach:** `l, r` at the ends; if `left_max <= right_max`, the water at `l` is `left_max - height[l]` (after updating `left_max`); move `l`. Otherwise symmetric for `r`.
* **Why This Works?** If `left_max <= right_max`, the true right maximum for `l` is at least `right_max ≥ left_max`, so `min(...)` is `left_max` — known without seeing the middle.
* **Edge Cases Considered:**
  * Fewer than 3 bars → 0.
  * Monotone heights → 0.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def trap(self, height: List[int]) -> int:
        water = 0
        for i, h in enumerate(height):
            left_max = max(height[:i + 1])
            right_max = max(height[i:])
            water += min(left_max, right_max) - h
        return water
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def trap(self, height: List[int]) -> int:
        l, r = 0, len(height) - 1
        left_max = right_max = water = 0
        while l <= r:
            left_max = max(left_max, height[l])
            right_max = max(right_max, height[r])
            if left_max <= right_max:  # level at l is bounded by left_max
                water += left_max - height[l]
                l += 1
            else:  # level at r is bounded by right_max
                water += right_max - height[r]
                r -= 1
        return water
```
