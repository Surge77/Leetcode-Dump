# 🔹 Problem Name: 310. Minimum Height Trees (Topological Sort, Medium)

**🔗 Link:** [LeetCode 310](https://leetcode.com/problems/minimum-height-trees/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Peel leaves layer by layer.** Repeatedly remove all current leaves (degree 1) until at most 2 nodes remain; those are the centres of the tree, i.e. the roots with minimum height.
* **Core Concept:** the roots minimising height are the 1 or 2 centre nodes of the longest path, found by trimming from the outside in (a topological-sort style BFS on degrees)
* **When to Use This Pattern?** Tree centre / diameter midpoint, "best root" questions on unrooted trees.
* **Mistakes to Avoid:**
  * Running BFS from every node: O(n²) = 4·10⁸ for `n = 2·10⁴`.
  * Continuing the peel until the queue is empty: stop when `remaining ≤ 2`, otherwise you remove the answer.
  * Forgetting `n ≤ 2`: every node is a valid root (`n = 1` → `[0]`).

## 🔹 Optimization Path

* **Brute Force:** BFS from every node to get its height, keep the minimum — O(n²).
* **Optimized Solution:** leaf-trimming BFS — O(n).
* **Further Improvements Possible?** No; O(n) is optimal for reading the input.

## 🔹 Solution Breakdown

* **Optimal Approach:** build adjacency lists and degrees; queue all leaves; while `remaining > 2`: remove the current layer of leaves, decrement their neighbours' degrees, and enqueue new leaves. The nodes left are the answer.
* **Why This Works?** Any longest path has its midpoint(s) as the best roots, and every leaf layer removed shortens each longest path by 2 (one from each end), so after the peels the midpoint(s) — 1 node if the path has an even number of edges, otherwise 2 — are what remains. A tree has at most 2 centres.
* **Edge Cases Considered:**
  * `n = 1` → `[0]`; `n = 2` → `[0, 1]`.
  * A star (centre degree `n − 1`) → just the centre.
  * A path of 20 000 nodes — fully iterative, no recursion.

## 🔹 Tricks & Patterns Used

* **Layered Kahn:** process leaves in whole layers so the "remaining" counter reflects exact layers removed.
* **Degree array** instead of removing edges physically.

## 🔹 Alternative Data Structures

* Two BFS passes to find a diameter path, then return its middle node(s) — also O(n).
* Rerooting DP computing the height from every root (see 834).

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from collections import deque
from typing import List


class Solution:
    def findMinHeightTrees(self, n: int, edges: List[List[int]]) -> List[int]:
        adj = [[] for _ in range(n)]
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)

        def height(root: int) -> int:
            depth = {root: 0}
            queue = deque([root])
            while queue:
                v = queue.popleft()
                for w in adj[v]:
                    if w not in depth:
                        depth[w] = depth[v] + 1
                        queue.append(w)
            return max(depth.values())

        heights = [height(root) for root in range(n)]
        best = min(heights)
        return [root for root in range(n) if heights[root] == best]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def findMinHeightTrees(self, n: int, edges: List[List[int]]) -> List[int]:
        if n <= 2:
            return list(range(n))
        adj = [[] for _ in range(n)]
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)
        degree = [len(neighbours) for neighbours in adj]
        leaves = [v for v in range(n) if degree[v] == 1]

        remaining = n
        while remaining > 2:  # at most two centres can survive
            remaining -= len(leaves)
            next_leaves = []
            for leaf in leaves:
                for w in adj[leaf]:
                    degree[w] -= 1
                    if degree[w] == 1:
                        next_leaves.append(w)
            leaves = next_leaves
        return leaves
```
