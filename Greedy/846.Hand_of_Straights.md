# 🔹 Problem Name: 846. Hand of Straights (Greedy Hash Map, Medium)

**🔗 Link:** [LeetCode 846](https://leetcode.com/problems/hand-of-straights/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Alice holds cards with integer values. Decide whether all cards can be split into groups of exactly `groupSize`, where each group consists of consecutive values (like 3, 4, 5).

* **Example:** `hand = [1,2,3,6,2,3,4,7,8], groupSize = 3` → `true`
* **Constraints:** `1 ≤ hand.length ≤ 10^4`, `0 ≤ hand[i] ≤ 10^9`, `1 ≤ groupSize ≤ hand.length`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Smallest card starts a group.** Count cards with a hash map and walk the distinct values in sorted order. The smallest remaining value `x` can only be the *start* of a straight (nothing smaller is left to precede it), so all `count[x]` copies must start groups `x, x+1, …, x+groupSize−1`; subtract `count[x]` from each, failing if any falls short.
* **Core Concept:** the minimum element has a forced role — process it first and the rest of the problem shrinks
* **When to Use This Pattern?** Partition a multiset into runs of consecutive values (1296 is the same problem), or any arrangement where the smallest remaining item has only one legal place.
* **Mistakes to Avoid:**
  * Forgetting the `len(hand) % groupSize` check — not needed for correctness (the greedy would fail later anyway), but it is a free O(1) exit before sorting.
  * Processing values in arbitrary (hash) order: a middle card might be grabbed as a start and break an earlier straight.

## 🔹 Optimization Path

* **Brute Force:** repeatedly take `min` of the remaining list and `remove` each of `min … min+groupSize−1` — O(n²).
* **Optimized Solution:** `Counter` + sorted distinct keys, subtracting a whole batch of starts at once — O(n log n).
* **Further Improvements Possible?** Without sorting: from any card walk down to the start of its run, then sweep the run — O(n) expected, but trickier to get right.

## 🔹 Solution Breakdown

* **Optimal Approach:** for each key `x` in sorted order with `need = count[x] > 0`: for `y` in `x … x+groupSize−1`, if `count[y] < need` return False, else `count[y] -= need`.
* **Why This Works?** The smallest remaining card can't sit in the middle or end of a straight (its predecessor is gone), so it must start one; that choice is forced, never a guess. Repeating on the smaller multiset either empties it (true) or hits a missing card (false).
* **Edge Cases Considered:**
  * `groupSize = 1` → always true.
  * `len(hand)` not divisible by `groupSize` → false immediately.
  * Gaps in values (e.g. `[1, 2, 4, 5]`, `groupSize = 2` → true; `groupSize = 4` → false).

## 🔹 Pattern Recognition

* **Belongs To:** Greedy — forced choice on the minimum + frequency map
* **Common Problems Using This:**
  * 1296. Divide Array in Sets of K Consecutive Numbers (identical)
  * 659. Split Array into Consecutive Subsequences
  * 2007. Find Original Array From Doubled Array

## 🔹 Tricks & Patterns Used

* **Batch subtraction:** subtract `count[x]` starts at once instead of forming groups one by one.
* **Sorted distinct keys** instead of a heap — keys never re-enter, so a single sorted pass suffices.

## 🔹 Alternative Data Structures

* Min-heap of distinct values: pop when a value's count hits 0; fail if the popped value isn't the current start. O(n log n).
* `OrderedDict`/sorted container if values are streamed in.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n log n) for sorting the distinct values; the subtraction is O(n) because each value that starts groups removes at least `groupSize` cards, so there are at most `n / groupSize` inner loops of `groupSize` steps
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def isNStraightHand(self, hand: List[int], groupSize: int) -> bool:
        cards = list(hand)
        while cards:
            low = min(cards)
            for value in range(low, low + groupSize):
                if value not in cards:
                    return False
                cards.remove(value)
        return True
```

## 🔹 Code Snippet (Optimized)

```python
from collections import Counter
from typing import List


class Solution:
    def isNStraightHand(self, hand: List[int], groupSize: int) -> bool:
        if len(hand) % groupSize:
            return False
        count = Counter(hand)
        for start in sorted(count):
            need = count[start]
            if need == 0:
                continue
            # every remaining copy of the smallest value must begin its own straight
            for value in range(start, start + groupSize):
                if count[value] < need:
                    return False
                count[value] -= need
        return True
```
