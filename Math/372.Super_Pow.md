# 372. Super Pow

**🔗 Link:** [LeetCode 372](https://leetcode.com/problems/super-pow/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Compute `a^b mod 1337`, where `a` is a positive integer and the exponent `b` is far too large for an int, so it arrives as an array of its decimal digits (most significant first). Return the remainder.

* **Example:** `a = 2, b = [3]` → `8`
* **Constraints:** `1 ≤ a ≤ 2^31 − 1`; `1 ≤ b.length ≤ 2000`; `0 ≤ b[i] ≤ 9`; `b` has no leading zeros

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Process the exponent's digits left to right: `a^(10·x + d) = (a^x)^10 · a^d`, everything mod 1337.
* **Core Concept:** Binary (fast) exponentiation + modular arithmetic
* **When to Use This Pattern?** `x^k mod m` with huge `k` — counting problems with answers mod 10⁹+7, modular inverses (Fermat: `pow(x, m-2, m)`).
* **Mistakes to Avoid:**
  * Building the full exponent integer and calling `pow` once — works in Python, but the point is the digit-by-digit identity (needed in C++/Java).
  * Forgetting to reduce `a` mod 1337 before multiplying.

## 🔹 Optimization Path

* **Brute Force:** Multiply `a` by itself `b` times — impossible for a 2000-digit `b`. **Time:** O(value of `b`) multiplications.
* **Optimized Solution:** O(len(b) · log 10) multiplications.
* **Further Improvements Possible?** Euler's theorem (reduce `b` mod φ(1337) when `gcd(a, 1337) = 1`) — needs care when not coprime.

## 🔹 Solution Breakdown

* **Optimal Approach:** `result = 1`; for each digit `d`: `result = result^10 · a^d (mod 1337)`.
* **Why This Works?** Reading a decimal number digit by digit is `x → 10x + d`; exponent rules turn that into `r → r^10 · a^d`.
* **Edge Cases Considered:**
  * `a` a multiple of 1337 → 0.
  * `a = 1` → 1.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def superPow(self, a: int, b: List[int]) -> int:
        exponent = int("".join(map(str, b)))
        result = 1
        for _ in range(exponent):  # multiply a by itself b times
            result = result * a % 1337
        return result
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List

MOD = 1337


def mod_pow(base: int, exp: int, mod: int) -> int:
    """Binary exponentiation: O(log exp) multiplications."""
    result, base = 1 % mod, base % mod
    while exp:
        if exp & 1:
            result = result * base % mod
        base = base * base % mod
        exp >>= 1
    return result


class Solution:
    def superPow(self, a: int, b: List[int]) -> int:
        result = 1
        for d in b:  # a^(10x + d) = (a^x)^10 * a^d
            result = mod_pow(result, 10, MOD) * mod_pow(a, d, MOD) % MOD
        return result
```
