# 🔹 Problem Name: 2223. Sum of Scores of Built Strings (Z-Function, Hard)

**🔗 Link:** [LeetCode 2223](https://leetcode.com/problems/sum-of-scores-of-built-strings/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** The score of each suffix is the length of its longest common prefix with `s` — exactly the **Z-function** `z[i]`. Answer = `n + Σ z[i]`.
* **Core Concept:** Z-function (linear-time "match the prefix at every position")
* **When to Use This Pattern?** Pattern search (`p + '#' + text`), counting prefix matches, string periods.
* **Mistakes to Avoid:**
  * Comparing each suffix with `s` naively — O(n²) for n = 10⁵.
  * Forgetting the whole string itself scores `n` (`z[0]` is defined as 0 here).

## 🔹 Optimization Path

* **Brute Force:** O(n²) character comparisons.
* **Optimized Solution:** O(n) Z-algorithm.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Maintain the rightmost match window `[l, r)`. Inside it, start `z[i]` from the mirrored value `z[i - l]` (capped at `r - i`), then extend by direct comparison.
* **Why This Works?** Inside `[l, r)` the text equals the prefix, so `s[i..]` starts like `s[i-l..]`; only characters beyond `r` are new, and `r` only moves right, giving O(n) total extensions.
* **Edge Cases Considered:**
  * One character.
  * All characters equal (`z[i] = n - i`).

## 🔹 Tricks & Patterns Used

* **Reuse earlier matches** via the `[l, r)` window — the same amortised idea as KMP and Manacher.

## 🔹 Alternative Data Structures

* Prefix function (KMP) — `pi` and `z` carry the same information in different shapes.
* Binary search + rolling hash per suffix — O(n log n).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def sumScores(self, s: str) -> int:
        n = len(s)
        z = [0] * n  # z[i]: longest common prefix of s and s[i:]
        l = r = 0  # [l, r): rightmost window known to match the prefix
        for i in range(1, n):
            if i < r:
                z[i] = min(r - i, z[i - l])
            while i + z[i] < n and s[z[i]] == s[i + z[i]]:
                z[i] += 1
            if i + z[i] > r:
                l, r = i, i + z[i]
        return n + sum(z)
```
