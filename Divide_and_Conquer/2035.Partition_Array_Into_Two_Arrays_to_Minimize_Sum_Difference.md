# 2035. Partition Array Into Two Arrays to Minimize Sum Difference

**🔗 Link:** [LeetCode 2035](https://leetcode.com/problems/partition-array-into-two-arrays-to-minimize-sum-difference/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

You have `2n` integers and must split them into two arrays of exactly `n` elements each, every element going into one of them. Return the smallest possible absolute difference between the two arrays' sums.

* **Example:** `nums = [3,9,7,3]` → `2` (split `[3,9]` and `[7,3]`)
* **Constraints:** `1 ≤ n ≤ 15`; `nums.length == 2n`; `-10^7 ≤ nums[i] ≤ 10^7`

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Pick exactly `n` of the `2n` numbers for array A; the difference is `|total − 2·sum(A)|`. Split the input into halves L and R (`n` each). If A takes `k` numbers from L it must take `n − k` from R. So group subset sums **by size**: for every `k` and every `a` in `L_sums[k]`, binary-search `R_sums[n − k]` for the `b` that brings `2(a + b)` closest to `total`.
* **Core Concept:** meet in the middle **with a size constraint** — bucket half-sums by how many elements they use
* **When to Use This Pattern?** `2n ≤ 30` with "choose exactly `n`" and large / negative values (no sum DP possible).
* **Mistakes to Avoid:**
  * Ignoring the "exactly `n` each" rule — matching any left subset with any right subset (as in 1755) gives wrong answers.
  * Floating-point targets: compare `2·b` with `total − 2a` in integers.

## 🔹 Optimization Path

* **Brute Force:** all `C(2n, n)` choices — ~1.5·10⁸ for `n = 15`.
* **Optimized Solution:** `2ⁿ` subsets per half, sorted per size, one binary search per left subset — O(2ⁿ · n).

## 🔹 Solution Breakdown

* **Optimal Approach:** `L[k]`, `R[k]` = sorted sums of all size-`k` subsets of each half (`itertools.combinations`). For each `k` and `a ∈ L[k]`, let `t = total − 2a`; find `i = bisect_left(R[n−k], t // 2)` and test `R[n−k][i]` and `R[n−k][i−1]`.
* **Why This Works?** For fixed `a`, `|t − 2b|` is minimised by the `b` nearest to `t / 2`, and in a sorted list the nearest values sit right around the insertion point of `⌊t/2⌋`: index `i` is the smallest `b ≥ ⌊t/2⌋`, index `i − 1` the largest `b < ⌊t/2⌋`.
* **Edge Cases Considered:**
  * Negative numbers — nothing assumes positivity.
  * `n = 1` → `|x − y|`.

## 🔹 Tricks & Patterns Used

* **Bucket by subset size** to enforce a cardinality constraint across the two halves.
* **Nearest value in a sorted list:** check the insertion point and its left neighbour.

## 🔹 Alternative Data Structures

* Two pointers per `k` after sorting both buckets (left ascending, right descending) — same complexity without `bisect`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(2ⁿ · n) (sorting the buckets dominates)
* **Space Complexity:** O(2ⁿ)

## 🔹 Code Snippet (Brute Force)

```python
from itertools import combinations
from typing import List


class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n, total = len(nums) // 2, sum(nums)
        return min(abs(total - 2 * sum(nums[i] for i in chosen)) for chosen in combinations(range(2 * n), n))
```

## 🔹 Code Snippet (Optimized)

```python
from bisect import bisect_left
from itertools import combinations
from typing import List


class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n, total = len(nums) // 2, sum(nums)

        def sums_by_size(half):
            return [sorted(sum(c) for c in combinations(half, k)) for k in range(n + 1)]

        left, right = sums_by_size(nums[:n]), sums_by_size(nums[n:])
        best = float("inf")
        for k in range(n + 1):
            candidates = right[n - k]  # A takes k from the left half, n - k from the right
            for a in left[k]:
                target = total - 2 * a  # want 2b as close to target as possible
                i = bisect_left(candidates, target // 2)
                for j in (i - 1, i):
                    if 0 <= j < len(candidates):
                        best = min(best, abs(target - 2 * candidates[j]))
        return int(best)
```
