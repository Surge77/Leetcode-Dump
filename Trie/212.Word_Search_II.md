# 212. Word Search II

**🔗 Link:** [LeetCode 212](https://leetcode.com/problems/word-search-ii/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given a grid of letters and a list of words, return every word from the list that can be spelled by walking through horizontally or vertically adjacent cells. A single cell may not be used twice within one word. The words in the answer may come back in any order.

* **Example:** `board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]], words = ["oath","pea","eat","rain"]` → `["eat","oath"]`
* **Constraints:** `1 ≤ m, n ≤ 12`; `1 ≤ words.length ≤ 3 · 10^4`; `1 ≤ words[i].length ≤ 10`; lowercase letters; all words are unique

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Put all words in a trie, then backtrack over the board once.** From every cell, DFS while the path's letters still form a trie prefix; a node that stores a word means that word is found. Remove found words from the trie and prune empty branches so later searches never revisit them.
* **Core Concept:** one board traversal checks every word simultaneously — the trie cuts a DFS as soon as the current path is no word's prefix
* **When to Use This Pattern?** Many patterns searched in one structure (grid, text, stream): multi-word grid search, Boggle, Aho-Corasick-style matching.
* **Mistakes to Avoid:**
  * Running Word Search (79) once per word — up to 3·10⁴ separate board scans.
  * Adding a word twice when it can be traced along two paths — clear `node["$"]` after the first hit.
  * Forgetting to restore the cell after backtracking.

## 🔹 Optimization Path

* **Brute Force:** for each word, backtracking search from every cell — O(W · m · n · 3ᴸ).
* **Optimized Solution:** trie + one backtracking pass with pruning — O(m · n · 4 · 3ᴸ⁻¹) worst case, far less in practice because found branches are deleted.
* **Further Improvements Possible?** Drop words whose letter counts exceed the board's before building the trie; reverse a word if its last letter is rarer on the board than its first.

## 🔹 Solution Breakdown

* **Optimal Approach:** build a dict-trie, storing the full word at its end node under `"$"`. `dfs(r, c, parent)`: look up `board[r][c]` in `parent`; if absent, stop. If the child holds a word, record it and delete the marker. Mark the cell `"#"`, recurse into 4 neighbours, restore it. If the child is now empty, delete it from `parent`.
* **Why This Works?** Every path whose letters are not a trie prefix cannot extend to any word, so pruning there loses nothing. Each word is reported when its end node is first reached, and deleting the marker ensures it is reported once. Removing exhausted branches makes repeated searches across start cells cheaper without affecting unfound words.
* **Edge Cases Considered:**
  * A word that is a prefix of another (`"oa"`, `"oath"`) — found at an internal node; the DFS keeps going.
  * Paths may not reuse a cell — the `"#"` marker blocks it.
  * Recursion depth ≤ 10 (max word length), so recursion is safe.

## 🔹 Tricks & Patterns Used

* **Trie node pruning** after a word is found keeps the search from re-exploring dead branches.
* **In-place visited marker** (`board[r][c] = "#"`) instead of a separate set.

## 🔹 Alternative Data Structures

* Prefix hash set (all prefixes of all words) — simpler, but no branch pruning and more memory.
* Aho-Corasick automaton — for linear text; grids still need backtracking.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n · 4 · 3ᴸ⁻¹) worst case with `L ≤ 10`, plus O(total word length) to build the trie
* **Space Complexity:** O(total word length) for the trie, O(L) recursion stack

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def findWords(self, board: List[List[str]], words: List[str]) -> List[str]:
        m, n = len(board), len(board[0])

        def trace(r: int, c: int, word: str, i: int) -> bool:
            if i == len(word):
                return True
            if not (0 <= r < m and 0 <= c < n) or board[r][c] != word[i]:
                return False
            board[r][c] = "#"
            found = any(trace(r + dr, c + dc, word, i + 1) for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)))
            board[r][c] = word[i]
            return found

        return [w for w in words if any(trace(r, c, w, 0) for r in range(m) for c in range(n))]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def findWords(self, board: List[List[str]], words: List[str]) -> List[str]:
        root = {}
        for w in words:
            node = root
            for ch in w:
                node = node.setdefault(ch, {})
            node["$"] = w
        m, n = len(board), len(board[0])
        found = []

        def dfs(r: int, c: int, parent: dict) -> None:
            ch = board[r][c]
            node = parent.get(ch)
            if node is None:
                return
            if "$" in node:
                found.append(node.pop("$"))  # pop so a second path can't report it again
            board[r][c] = "#"
            for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                if 0 <= nr < m and 0 <= nc < n and board[nr][nc] in node:
                    dfs(nr, nc, node)
            board[r][c] = ch
            if not node:
                del parent[ch]  # branch exhausted: never walk it again

        for r in range(m):
            for c in range(n):
                dfs(r, c, root)
        return found
```
