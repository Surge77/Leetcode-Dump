# 🔹 Problem Name: 1922. Count Good Numbers (Combinatorics + Fast Power, Medium)

**🔗 Link:** [LeetCode 1922](https://leetcode.com/problems/count-good-numbers/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Positions are independent. Even indices have 5 choices (0, 2, 4, 6, 8), odd indices have 4 (2, 3, 5, 7). Answer = `5^ceil(n/2) · 4^floor(n/2) mod 1e9+7`.
* **Core Concept:** Multiplication principle + modular fast exponentiation
* **When to Use This Pattern?** Counting strings where each position has independent choices and `n` is huge (10¹⁵) — the hint that you need a formula plus `pow`.
* **Mistakes to Avoid:**
  * Looping `n` times — n is up to 10¹⁵.
  * Mixing up which index parity gets 5 vs 4 (index 0 is even).

## 🔹 Optimization Path

* **Brute Force:** O(10ⁿ) — enumerate strings.
* **Linear:** O(n) multiplications — still too slow.
* **Optimized Solution:** O(log n) with binary exponentiation.

## 🔹 Solution Breakdown

* **Optimal Approach:** `evens = (n + 1) // 2`, `odds = n // 2`; return `pow(5, evens, MOD) * pow(4, odds, MOD) % MOD`.
* **Why This Works?** Choices at different positions do not interact, so the counts multiply.
* **Edge Cases Considered:**
  * `n = 1` → 5.
  * Very large `n`.

## 🔹 Code Snippet (Brute Force)

```python
from itertools import product

MOD = 10**9 + 7


class Solution:
    def countGoodNumbers(self, n: int) -> int:
        even_digits = set("02468")
        prime_digits = set("2357")
        count = 0
        for digits in product("0123456789", repeat=n):
            if all(d in (even_digits if i % 2 == 0 else prime_digits) for i, d in enumerate(digits)):
                count += 1
        return count % MOD
```

## 🔹 Code Snippet (Optimized)

```python
MOD = 10**9 + 7


class Solution:
    def countGoodNumbers(self, n: int) -> int:
        evens = (n + 1) // 2  # indices 0, 2, 4, ... -> 5 even digits
        odds = n // 2  # indices 1, 3, 5, ... -> 4 prime digits
        return pow(5, evens, MOD) * pow(4, odds, MOD) % MOD
```
