# 🔹 Problem Name: 1368. Minimum Cost to Make at Least One Valid Path in a Grid (0-1 BFS, Hard)

**🔗 Link:** [LeetCode 1368](https://leetcode.com/problems/minimum-cost-to-make-at-least-one-valid-path-in-a-grid/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Every cell of an `m × n` grid holds an arrow (1 right, 2 left, 3 down, 4 up) that tells you which neighbour to move to next; some arrows may point off the grid. Starting at the top-left, you want a path that follows the arrows to the bottom-right. Changing a cell's arrow costs 1 (once per cell); return the minimum total cost for such a path to exist.

* **Example:** `grid = [[1,1,1,1],[2,2,2,2],[1,1,1,1],[2,2,2,2]]` → `3`
* **Constraints:** `1 ≤ m, n ≤ 100`, `1 ≤ grid[i][j] ≤ 4`

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Moving in the cell's arrow direction costs 0; any other direction costs 1 (changing the sign). Shortest path with 0/1 weights → **0-1 BFS** with a deque.
* **Core Concept:** 0-1 BFS
* **When to Use This Pattern?** Edge weights are only 0 or 1: free moves vs paid moves, "minimum walls to break", "minimum reversals".
* **Mistakes to Avoid:**
  * Plain BFS — treats every move as cost 1.
  * Marking cells visited when pushed (as in normal BFS) — in 0-1 BFS a cell can still improve later; compare distances instead.

## 🔹 Optimization Path

* **Brute Force:** Try every combination of sign changes — exponential.
* **Dijkstra:** O(mn log(mn)) — correct.
* **Optimized Solution:** 0-1 BFS — O(m · n).

## 🔹 Solution Breakdown

* **Optimal Approach:** `appendleft` neighbours reached with cost 0, `append` neighbours reached with cost 1; relax only when the distance improves.
* **Why This Works?** The deque always holds at most two distance values (`d` and `d+1`) in sorted order, so it behaves like Dijkstra's heap without the log factor.
* **Edge Cases Considered:**
  * Arrows already form a path → 0.
  * 1×1 grid → 0.
  * Arrows pointing out of the grid.

## 🔹 Pattern Recognition

* **Belongs To:** Graph — Shortest Path (0-1 BFS)
* **Common Problems Using This:**
  * 2290. Minimum Obstacle Removal to Reach Corner
  * 1263. Minimum Moves to Move a Box to Their Target Location (pushes cost 1, walking costs 0)
  * Minimum edge reversals to reach a node (classic)

## 🔹 Tricks & Patterns Used

* **Deque front for 0-cost, back for 1-cost.**
* **Direction table** indexed by the sign value (1 → right, 2 → left, 3 → down, 4 → up).

## 🔹 Alternative Data Structures

* Dijkstra with a heap — general but slower.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n)
* **Space Complexity:** O(m · n)

## 🔹 Code Snippet (Brute Force)

```python
from itertools import combinations, product
from typing import List

DIRS = {1: (0, 1), 2: (0, -1), 3: (1, 0), 4: (-1, 0)}


class Solution:
    def minCost(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        cells = [(i, j) for i in range(m) for j in range(n)]

        def follows_to_end(g):
            i, j, seen = 0, 0, set()
            while (i, j) != (m - 1, n - 1):
                if (i, j) in seen:
                    return False  # arrows loop
                seen.add((i, j))
                di, dj = DIRS[g[i][j]]
                i, j = i + di, j + dj
                if not (0 <= i < m and 0 <= j < n):
                    return False  # arrow leaves the grid
            return True

        # try every set of `cost` changed cells and every new sign for them, cheapest first
        for cost in range(m * n + 1):
            for chosen in combinations(cells, cost):
                options = [[s for s in DIRS if s != grid[i][j]] for i, j in chosen]
                for signs in product(*options):
                    g = [row[:] for row in grid]
                    for (i, j), s in zip(chosen, signs):
                        g[i][j] = s
                    if follows_to_end(g):
                        return cost
        return -1
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List

DIRS = {1: (0, 1), 2: (0, -1), 3: (1, 0), 4: (-1, 0)}


class Solution:
    def minCost(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dist = [[float("inf")] * n for _ in range(m)]
        dist[0][0] = 0
        dq = deque([(0, 0)])
        while dq:
            i, j = dq.popleft()
            d = dist[i][j]
            for sign, (di, dj) in DIRS.items():
                x, y = i + di, j + dj
                if not (0 <= x < m and 0 <= y < n):
                    continue
                cost = 0 if grid[i][j] == sign else 1
                if d + cost < dist[x][y]:
                    dist[x][y] = d + cost
                    if cost == 0:
                        dq.appendleft((x, y))  # same distance: front
                    else:
                        dq.append((x, y))  # distance + 1: back
        return dist[m - 1][n - 1]
```
