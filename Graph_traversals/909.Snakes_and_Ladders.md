# 🔹 Problem Name: 909. Snakes and Ladders (BFS, Medium)

**🔗 Link:** [LeetCode 909](https://leetcode.com/problems/snakes-and-ladders/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **BFS over squares.** Flatten the boustrophedon board into `cells[1..n²]`. From square `s`, each roll lands on `nxt ∈ [s+1, min(s+6, n²)]`; if `cells[nxt] != -1` you move to that target instead (once). Every roll costs one move, so BFS from square 1 gives the fewest moves to `n²`, or `-1` if it is never reached.
* **Core Concept:** shortest path in an unweighted implicit graph = BFS
* **When to Use This Pattern?** "Minimum number of moves / steps / mutations" where every move costs the same — board games, lock combinations, word ladders, knight moves.
* **Mistakes to Avoid:**
  * Wrong square ↔ cell mapping: rows are numbered from the **bottom**, and every other row runs right-to-left.
  * Chaining jumps: landing on a ladder's end that is itself a snake's start does **not** trigger the snake.
  * Marking the rolled-on square visited instead of the square you end up on after the jump.
  * DFS / greedy "take the biggest ladder" — neither guarantees the minimum.

## 🔹 Optimization Path

* **Brute Force:** Bellman-Ford style relaxation — repeat over every reachable square and every roll, lowering `moves[dest]`, until nothing improves: O(V · E) with `V = n²`, `E ≤ 6n²`.
* **Optimized Solution:** BFS — each square is dequeued once: O(n²).
* **Further Improvements Possible?** No; O(V + E) = O(n²) is the size of the graph.

## 🔹 Solution Breakdown

* **Optimal Approach:** build `cells` by reading `board` bottom-up, reversing every second row. `moves[1] = 0`; BFS; for each roll compute `dest`, and enqueue it the first time it is seen.
* **Why This Works?** All edges have weight 1, so BFS discovers squares in non-decreasing move count; the first time `dest` is assigned is its minimum. The state is just the square you stand on — the dice and jumps from there do not depend on how you arrived.
* **Edge Cases Considered:**
  * `n = 2` with a ladder straight to the end.
  * Snakes that make `n²` unreachable (six consecutive snakes) → `-1`.
  * A jump landing on another jump's start — not followed.

## 🔹 Tricks & Patterns Used

* **Flatten first:** `for i, row in enumerate(reversed(board))`, append `row` or `row[::-1]` — removes all index arithmetic from the BFS.
* **`moves` array as the visited set:** `-1` means unseen, so no separate set is needed.

## 🔹 Alternative Data Structures

* Compute `(row, col)` from the square number on the fly: `r = n − 1 − (s − 1) // n`, `c = (s − 1) % n` or its mirror on odd rows — same complexity, more error-prone.
* Dijkstra works but is unnecessary with unit weights.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n²) — at most `n² ≤ 400` squares, 6 rolls each
* **Space Complexity:** O(n²)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def snakesAndLadders(self, board: List[List[int]]) -> int:
        cells = [0]  # 1-indexed: cells[s] is the jump target of square s, or -1
        for i, row in enumerate(reversed(board)):
            cells.extend(row if i % 2 == 0 else row[::-1])
        last = len(cells) - 1
        INF = float("inf")
        moves = [INF] * (last + 1)
        moves[1] = 0
        changed = True
        while changed:  # relax every roll until no square improves, like Bellman-Ford
            changed = False
            for s in range(1, last):
                if moves[s] == INF:
                    continue
                for nxt in range(s + 1, min(s + 6, last) + 1):
                    dest = cells[nxt] if cells[nxt] != -1 else nxt
                    if moves[s] + 1 < moves[dest]:
                        moves[dest] = moves[s] + 1
                        changed = True
        return moves[last] if moves[last] < INF else -1
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def snakesAndLadders(self, board: List[List[int]]) -> int:
        cells = [0]  # 1-indexed: cells[s] is the jump target of square s, or -1
        for i, row in enumerate(reversed(board)):
            cells.extend(row if i % 2 == 0 else row[::-1])  # every other row runs right-to-left
        last = len(cells) - 1
        moves = [-1] * (last + 1)
        moves[1] = 0
        queue = deque([1])
        while queue:
            s = queue.popleft()
            if s == last:
                return moves[s]
            for nxt in range(s + 1, min(s + 6, last) + 1):
                dest = cells[nxt] if cells[nxt] != -1 else nxt  # at most one jump per roll
                if moves[dest] == -1:
                    moves[dest] = moves[s] + 1
                    queue.append(dest)
        return -1
```
