# 🔹 Problem Name: 102. Binary Tree Level Order Traversal (Tree BFS, Medium)

**🔗 Link:** [LeetCode 102](https://leetcode.com/problems/binary-tree-level-order-traversal/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **BFS, one level per round.** At the start of a round the queue holds exactly one level. Pop `len(queue)` nodes, record their values, and push their children — together those children are the next level.
* **Core Concept:** freezing `len(queue)` before the inner loop separates the levels without storing a depth per node
* **When to Use This Pattern?** Anything "per level" or "by distance from the root" — right side view, level averages, zigzag order, maximum width, next-right pointers, minimum depth (BFS can stop at the first leaf).
* **Mistakes to Avoid:**
  * `list.pop(0)` as the queue — O(n) per pop; use `collections.deque`.
  * Re-reading the queue length while children are being appended — the level boundary moves.
  * Empty tree → `[]`, not `[[]]`.

## 🔹 Optimization Path

* **Brute Force:** find the height `h`, then for every depth `d` run a fresh DFS that collects the nodes at depth `d` — O(n·h) (O(n²) on a path).
* **Optimized Solution:** a single BFS — O(n) time, O(w) queue (`w` = max level width).
* **Further Improvements Possible?** Not in time (the output has `n` values). A DFS that appends to `levels[depth]` is also O(n) and needs O(h) stack instead of O(w) queue.

## 🔹 Solution Breakdown

* **Optimal Approach:** `queue = deque([root])`; while it is non-empty: `level = []`; repeat `len(queue)` times: pop left, append the value, push the non-null children; append `level` to the answer.
* **Why This Works?** Induction: if the queue holds exactly level `d`, left to right, then popping all of it and pushing each node's children left-then-right leaves exactly level `d + 1`, left to right.
* **Edge Cases Considered:**
  * Empty tree → `[]`.
  * A path of 2000 nodes → 2000 levels with one value each (no recursion involved).

## 🔹 Tricks & Patterns Used

* **`for _ in range(len(queue))`:** `range` reads the length once, so children appended during the loop wait for the next round.
* **Depth-indexed DFS:** `if depth == len(levels): levels.append([])` gives the same output, because preorder reaches the nodes of each level from left to right.

## 🔹 Alternative Data Structures

* Two plain lists (`level`, `next_level`) instead of a deque — no `popleft` at all.
* Recursive DFS with a depth argument — a 2000-node path recurses 2000 deep, so raise the recursion limit or stay iterative.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(w) for the queue, plus O(n) for the output

## 🔹 Code Snippet (Brute Force)

```python
from typing import List, Optional


class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        height = 0
        stack = [(root, 1)] if root else []
        while stack:
            node, depth = stack.pop()
            height = max(height, depth)
            stack += [(child, depth + 1) for child in (node.left, node.right) if child]

        result = []
        for target in range(1, height + 1):
            level, stack = [], [(root, 1)]
            while stack:
                node, depth = stack.pop()
                if depth == target:
                    level.append(node.val)
                    continue  # nothing below this node is at the target depth
                for child in (node.right, node.left):  # left is popped first: left-to-right order
                    if child:
                        stack.append((child, depth + 1))
            result.append(level)
        return result
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List, Optional


class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        result = []
        queue = deque([root] if root else [])
        while queue:
            level = []
            for _ in range(len(queue)):  # exactly the nodes of the current level
                node = queue.popleft()
                level.append(node.val)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            result.append(level)
        return result
```
