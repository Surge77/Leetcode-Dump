# 872. Leaf-Similar Trees

**🔗 Link:** [LeetCode 872](https://leetcode.com/problems/leaf-similar-trees/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

The leaf value sequence of a binary tree is the list of its leaf values read from left to right. Return `true` exactly when two given trees have the same leaf value sequence.

* **Example:** `root1 = [3,5,1,6,2,9,8,null,null,7,4], root2 = [3,5,1,6,7,4,2,null,null,null,null,null,null,9,8]` → `true`
* **Constraints:** `1 ≤ nodes ≤ 200` in each tree, node values in `0 … 200`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Lazy leaf generators.** An iterative DFS that visits the left child before the right child yields leaves in left-to-right order. Zip the two generators together and stop at the first difference.
* **Core Concept:** compare two sequences produced by traversals without building them first
* **When to Use This Pattern?** Compare two trees by a derived sequence (leaf order, inorder, preorder) — leaf-similar, same-fringe, flatten-and-compare.
* **Mistakes to Avoid:**
  * Comparing only the multiset of leaves — the **order** matters.
  * Zipping without a fill value: `zip` stops at the shorter sequence, so `[1, 2, 3]` and `[1, 2]` would look equal. Use `zip_longest` with a sentinel.
  * Pushing the left child first on the stack, which yields right-to-left order for both trees (still consistent, but harder to reason about).

## 🔹 Optimization Path

* **Brute Force:** collect all leaves of both trees into lists (recursion with `+` recopies leaves at every level, so O(n·h) worst case, O(n²) on a chain), then compare the lists — O(L) extra space for the lists.
* **Optimized Solution:** two generators compared leaf by leaf — O(n₁ + n₂) worst-case time, early exit at the first mismatch, O(h) space.
* **Further Improvements Possible?** No; with at most 200 nodes the gain is only the early exit.

## 🔹 Solution Breakdown

* **Optimal Approach:** `leaves(root)`: stack = `[root]`; pop a node; if it has no children `yield node.val`, otherwise push the right child then the left child. Compare with `zip_longest(leaves(a), leaves(b), fillvalue=END)`.
* **Why This Works?** Popping from a stack with the right child pushed first visits nodes in preorder, left subtree before right subtree, so leaves come out left to right. The sentinel makes a length difference count as a mismatch.
* **Edge Cases Considered:**
  * One tree has more leaves than the other (the sentinel catches it).
  * Both trees are a single node: the roots are the leaves.
  * Different shapes with the same leaf sequence → `true`.

## 🔹 Tricks & Patterns Used

* **Generators for lazy traversal:** the comparison pulls leaves one at a time, so nothing is built that is not needed.
* **Sentinel fill value:** distinguishes "ended" from any legal node value.

## 🔹 Alternative Data Structures

* Recursive helper that appends leaves to a list (depth at most 200 here) — the most common solution.
* Serialise each leaf sequence to a tuple and compare — same as the brute force.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n₁ + n₂)
* **Space Complexity:** O(h₁ + h₂) for the two stacks

## 🔹 Code Snippet (Brute Force)

```python
from typing import List, Optional


class Solution:
    def leafSimilar(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> bool:
        def leaves(node: Optional[TreeNode]) -> List[int]:
            if node is None:
                return []
            if node.left is None and node.right is None:
                return [node.val]
            return leaves(node.left) + leaves(node.right)

        return leaves(root1) == leaves(root2)
```

## 🔹 Code Snippet (Optimized)

```python
from itertools import zip_longest
from typing import Optional

END = object()


def leaf_values(root: Optional[TreeNode]):
    stack = [root]
    while stack:
        node = stack.pop()
        if node.left is None and node.right is None:
            yield node.val
            continue
        for child in (node.right, node.left):  # left is popped first, so leaves come out left to right
            if child:
                stack.append(child)


class Solution:
    def leafSimilar(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> bool:
        return all(a == b for a, b in zip_longest(leaf_values(root1), leaf_values(root2), fillvalue=END))
```
