# 🔹 Problem Name: 45. Jump Game II (Greedy / Implicit BFS, Medium)

**🔗 Link:** [LeetCode 45](https://leetcode.com/problems/jump-game-ii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

You stand at index 0 of an array where `nums[i]` is the farthest forward jump allowed from index `i` (any shorter jump is fine too). Return the minimum number of jumps needed to reach the last index; the input guarantees it is reachable.

* **Example:** `nums = [2,3,1,1,4]` → `2`
* **Constraints:** `1 ≤ nums.length ≤ 10^4`, `0 ≤ nums[i] ≤ 1000`, the last index is always reachable.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** BFS by levels without a queue: indices reachable with `j` jumps form a window `[start, end]`. Scan it to find the farthest reach — that is the end of the next window.
* **Core Concept:** Greedy = level-order BFS over index ranges
* **When to Use This Pattern?** Minimum number of steps/refuels/taps when each position covers a range ahead.
* **Mistakes to Avoid:**
  * Counting a jump when already at the last index (loop must stop at `n - 2`).
  * Assuming the O(n²) DP is too slow: with `n ≤ 10⁴` and `nums[i] ≤ 1000` it does at most about `10⁷` steps and passes — the greedy is still the cleaner O(n).

## 🔹 Optimization Path

* **Brute Force:** DP `d[j] = min(d[i] + 1)` — O(n²) in general, O(n · min(n, max nums)) with the capped inner loop used below.
* **Optimized Solution:** O(n) greedy windows.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `jumps = end = far = 0`; for `i` in `0..n-2`: `far = max(far, i + nums[i])`; when `i == end`: `jumps += 1`, `end = far`.
* **Why This Works?** Reaching `i == end` means the current level is fully scanned; the next level extends exactly to `far`. BFS levels give minimum jump counts.
* **Edge Cases Considered:**
  * Single element → 0.
  * First jump reaches the end directly → 1.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def jump(self, nums: List[int]) -> int:
        n = len(nums)
        d = [0] + [float("inf")] * (n - 1)  # d[j] = fewest jumps to reach j
        for i in range(n):
            for j in range(i + 1, min(n, i + nums[i] + 1)):
                d[j] = min(d[j], d[i] + 1)
        return d[-1]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def jump(self, nums: List[int]) -> int:
        jumps = end = far = 0
        for i in range(len(nums) - 1):  # never jump from the last index
            far = max(far, i + nums[i])
            if i == end:  # current level fully scanned
                jumps += 1
                end = far
        return jumps
```
