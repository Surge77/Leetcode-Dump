# 🔹 Problem Name: 2215. Find the Difference of Two Arrays (Hash Set, Easy)

**🔗 Link:** [LeetCode 2215](https://leetcode.com/problems/find-the-difference-of-two-arrays/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Set difference both ways.** Put each array in a set; the answer is `[set1 - set2, set2 - set1]`. Sets remove duplicates and make membership O(1).
* **Core Concept:** hash sets turn "is it in the other array" into a constant-time test
* **When to Use This Pattern?** Distinct-element comparisons between collections: intersection, difference, symmetric difference, "common elements".
* **Mistakes to Avoid:**
  * Testing `x in nums2` against the *list* — O(m) each, O(n·m) overall.
  * Returning duplicates — the answer must contain each value once.

## 🔹 Optimization Path

* **Brute Force:** for each element of one list, scan the other list, skipping values already reported — O(n·m).
* **Optimized Solution:** two sets and two set differences — O(n + m).
* **Further Improvements Possible?** Values are within `[-1000, 1000]`, so two boolean arrays of 2001 also work; the complexity stays O(n + m).

## 🔹 Solution Breakdown

* **Optimal Approach:** `a, b = set(nums1), set(nums2)`; return `[list(a - b), list(b - a)]`.
* **Why This Works?** `a - b` is exactly the distinct values of `nums1` that never occur in `nums2`, and vice versa.
* **Edge Cases Considered:**
  * Identical arrays → `[[], []]`.
  * Disjoint arrays → each answer list is the distinct values of its own array.
  * Any order inside the answer lists is accepted.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
        only1, only2 = [], []
        for x in nums1:
            if x not in nums2 and x not in only1:
                only1.append(x)
        for x in nums2:
            if x not in nums1 and x not in only2:
                only2.append(x)
        return [only1, only2]
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
        a, b = set(nums1), set(nums2)
        return [list(a - b), list(b - a)]
```
