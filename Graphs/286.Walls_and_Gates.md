# 286. Walls and Gates

## 🔹 Problem Statement

You get a grid of rooms where `-1` is a wall, `0` is a gate and `2^31 − 1` marks an empty room. Fill each empty room, in place, with the number of steps (up, down, left, right) to its nearest gate; rooms that no gate can reach keep the value `2^31 − 1`. *(premium — paraphrased from memory, not checked against the official page)*

* **Example:** `rooms = [[INF,-1,0,INF],[INF,INF,INF,-1],[INF,-1,INF,-1],[0,-1,INF,INF]]` (`INF = 2^31 − 1`) → `[[3,-1,0,1],[2,2,1,-1],[1,-1,2,-1],[0,-1,3,4]]`
* **Constraints:** `1 ≤ m, n ≤ 250`, each cell is `-1`, `0` or `2^31 − 1`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Multi-source BFS from all gates at once.** Put every gate (`0`) in the queue at distance 0. BFS expands in rings of equal distance, so the first time an empty room (`2³¹ − 1`) is reached, it is reached from its nearest gate — write the distance and never touch it again.
* **Core Concept:** BFS from a set of sources = BFS from one virtual source joined to all of them
* **When to Use This Pattern?** "Distance from every cell to the nearest X" — nearest gate, nearest `0`, rotting oranges, farthest land from water.
* **Mistakes to Avoid:**
  * BFS from every room to find its gate: O((m·n)²), ~3.9·10⁹ for 250 × 250.
  * BFS from each gate separately, keeping the minimum: O(gates · m·n).
  * DFS from gates: it is only correct if it re-visits a cell every time a shorter distance shows up — far slower than BFS.

## 🔹 Optimization Path

* **Brute Force:** BFS from each empty room until it meets a gate — O((m·n)²).
* **Optimized Solution:** one multi-source BFS — O(m·n).
* **Further Improvements Possible?** No; every cell is visited once.

## 🔹 Solution Breakdown

* **Optimal Approach:** queue all gates. Pop `(r, c)`; for each in-grid neighbour still equal to `EMPTY`, set it to `rooms[r][c] + 1` and push it.
* **Why This Works?** BFS pops cells in non-decreasing distance from the source set. A room is first reached from a cell at distance `d`, which is the minimum over all gates, so `d + 1` is final. The grid value doubles as the visited flag: only `EMPTY` cells are ever updated.
* **Edge Cases Considered:**
  * No gates → nothing changes, rooms stay `2³¹ − 1`.
  * Rooms walled off from every gate → stay `2³¹ − 1`.

## 🔹 Tricks & Patterns Used

* **Seed the queue with every source:** one pass computes the minimum over all of them.
* **Grid as visited set:** `EMPTY` means "not reached yet".

## 🔹 Alternative Data Structures

* Two-pass DP sweep (top-left, then bottom-right) works for 01 Matrix but not here — walls make the shortest path wind back and forth.

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n)
* **Space Complexity:** O(m · n) for the queue

## 🔹 Code Snippet (Brute Force)

```python
from collections import deque
from typing import List

WALL, EMPTY = -1, 2**31 - 1


class Solution:
    def wallsAndGates(self, rooms: List[List[int]]) -> None:
        m, n = len(rooms), len(rooms[0])

        def nearest_gate(sr: int, sc: int) -> int:
            dist = {(sr, sc): 0}
            queue = deque([(sr, sc)])
            while queue:
                r, c = queue.popleft()
                if rooms[r][c] == 0:
                    return dist[r, c]
                for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                    if 0 <= nr < m and 0 <= nc < n and rooms[nr][nc] != WALL and (nr, nc) not in dist:
                        dist[nr, nc] = dist[r, c] + 1
                        queue.append((nr, nc))
            return EMPTY

        # filled-in rooms stay passable and are never mistaken for gates (distance ≥ 1)
        for r in range(m):
            for c in range(n):
                if rooms[r][c] == EMPTY:
                    rooms[r][c] = nearest_gate(r, c)
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List

EMPTY = 2**31 - 1


class Solution:
    def wallsAndGates(self, rooms: List[List[int]]) -> None:
        m, n = len(rooms), len(rooms[0])
        queue = deque((r, c) for r in range(m) for c in range(n) if rooms[r][c] == 0)
        while queue:
            r, c = queue.popleft()
            for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                if 0 <= nr < m and 0 <= nc < n and rooms[nr][nc] == EMPTY:
                    rooms[nr][nc] = rooms[r][c] + 1  # first visit comes from the nearest gate
                    queue.append((nr, nc))
```
