# 🔹 Problem Name: 895. Maximum Frequency Stack (Stack Design, Hard)

**🔗 Link:** [LeetCode 895](https://leetcode.com/problems/maximum-frequency-stack/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Design a stack-like structure where `push(val)` adds an element on top and `pop()` removes and returns the most frequent element currently in the stack. If several elements tie for most frequent, the one nearest the top is removed. `pop` is only called when the stack is non-empty.

* **Example:** `["FreqStack","push","push","push","push","push","push","pop","pop","pop","pop"]` with args `[[],[5],[7],[5],[7],[4],[5],[],[],[],[]]` → `[null,null,null,null,null,null,null,5,7,5,4]`
* **Constraints:** `0 ≤ val ≤ 10^9`, at most `2 * 10^4` calls

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Stack per frequency level.** `count[v]` is how often `v` is on the stack; `groups[f]` is a stack of the values whose count reached `f`, in push order. `push(v)`: `count[v] += 1` and append `v` to `groups[count[v]]`. `pop()`: take from `groups[maxFreq]`; decrement that value's count; lower `maxFreq` if the group became empty.
* **Core Concept:** a value with frequency `f` also sits in every level `1..f`, so the top of the highest level is the most frequent, most recent element
* **When to Use This Pattern?** "Pop the most frequent, ties broken by recency" and similar priority-with-tiebreak structures that need O(1) ops (LFU, max-stack).
* **Mistakes to Avoid:**
  * A heap keyed by `(−freq, −time)` also works but costs O(log n) per operation; the per-frequency stacks make it O(1).
  * Removing the value from **all** its levels on pop — only the top level entry goes; lower levels keep their older copies.

## 🔹 Optimization Path

* **Brute Force:** one list; `pop` counts frequencies, finds the max, scans from the top for the newest value with that frequency and deletes it — O(n) per pop.
* **Optimized Solution:** `count` dict + `groups` dict of stacks + `maxFreq` — O(1) per operation.
* **Further Improvements Possible?** No; both operations are constant time.

## 🔹 Solution Breakdown

* **Optimal Approach:** see Quick Breakdown. After `push(5), push(7), push(5)` we have `groups[1] = [5, 7]` and `groups[2] = [5]`; `pop()` returns `5`, leaving `groups[1] = [5, 7]` where `5` has count 1 again.
* **Why This Works?** `groups[f]` lists values in the order they reached frequency `f`; the top is the most recent among values currently at frequency `≥ f` that reached `f`. Taking the top of the maximum level therefore yields the most frequent value, and among ties the one whose `f`-th push was latest — exactly the one closest to the stack's top. Popping restores the state as if that last push never happened.
* **Edge Cases Considered:**
  * `pop` empties the top level → decrement `maxFreq`.
  * The same value pushed repeatedly lives in one group per level.

## 🔹 Tricks & Patterns Used

* **Frequency buckets:** group by count instead of keeping a sorted structure.
* **`maxFreq` drops by at most one per pop:** the popped value still has an entry in level `f − 1`, so that level is non-empty (for `f = 1` the stack is empty and `maxFreq` becomes 0).

## 🔹 Alternative Data Structures

* Heap of `(−frequency, −insertion index, value)` — O(log n) per op.

## 🔹 Complexity Analysis

* **Time Complexity:** O(1) per `push` and `pop`
* **Space Complexity:** O(n) for n pushes

## 🔹 Code Snippet (Brute Force)

```python
from collections import Counter


class FreqStack:
    def __init__(self):
        self.stack = []

    def push(self, val: int) -> None:
        self.stack.append(val)

    def pop(self) -> int:
        counts = Counter(self.stack)
        best = max(counts.values())
        for i in range(len(self.stack) - 1, -1, -1):  # newest first, so ties go to the latest push
            if counts[self.stack[i]] == best:
                return self.stack.pop(i)
```

## 🔹 Code Snippet (Optimized)

```python
from collections import defaultdict


class FreqStack:
    def __init__(self):
        self.count = defaultdict(int)
        self.groups = defaultdict(list)  # frequency -> values in the order they reached it
        self.max_freq = 0

    def push(self, val: int) -> None:
        self.count[val] += 1
        freq = self.count[val]
        self.groups[freq].append(val)
        self.max_freq = max(self.max_freq, freq)

    def pop(self) -> int:
        val = self.groups[self.max_freq].pop()
        self.count[val] -= 1
        if not self.groups[self.max_freq]:
            self.max_freq -= 1
        return val
```
