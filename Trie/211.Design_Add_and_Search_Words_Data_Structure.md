# 211. Design Add and Search Words Data Structure

**🔗 Link:** [LeetCode 211](https://leetcode.com/problems/design-add-and-search-words-data-structure/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Design a `WordDictionary` that lets you add words and then check whether any added word matches a query. A query may contain `.` characters, and each `.` stands for any single letter, so the match must have the same length as the query.

* **Example:** `["WordDictionary","addWord","addWord","addWord","search","search","search","search"]` with arguments `[[],["bad"],["dad"],["mad"],["pad"],["bad"],[".ad"],["b.."]]` → `[null,null,null,null,false,true,true,true]`
* **Constraints:** `1 ≤ word.length ≤ 25`; added words are lowercase letters; search patterns hold lowercase letters or `.`, with at most 2 dots; at most `10^4` calls to `addWord` and `search`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Trie + DFS for wildcards.** `addWord` inserts into a trie and marks the last node as a word end. `search` walks the trie; a letter follows one child, a `.` branches into **every** child. Search with an explicit stack of `(node, index)` pairs and succeed when a stack entry reaches the end of the pattern at a word-end node.
* **Core Concept:** shared prefixes are stored once, so a pattern is matched against all words in one walk instead of word by word
* **When to Use This Pattern?** Dictionary lookups with prefixes or single-character wildcards, autocomplete, word games over a fixed vocabulary.
* **Mistakes to Avoid:**
  * Treating reaching the last character as a match — the node must be marked as the end of a word (`"ba"` is not in `["bad"]`).
  * Regex over the stored words per search — O(total stored characters) each time.
  * Bucketing words only by length and scanning a bucket: fine on random data, degenerates when many words share a length.

## 🔹 Optimization Path

* **Brute Force:** store words in a list; `search` compares the pattern against every word of equal length — O(W · L) per search.
* **Optimized Solution:** trie — `addWord` O(L); `search` O(L) without dots, O(26² · L) with at most 2 dots (LeetCode's constraint).
* **Further Improvements Possible?** Precompute all patterns with up to two dots for each word into a hash set — O(1) search, but O(L²) patterns per insert; not worth it at these limits.

## 🔹 Solution Breakdown

* **Optimal Approach:** each node is a dict of children plus an end flag. `search` pops `(node, i)`; if `i == len(word)`, return `True` when `node` is an end; else push the matching child (letter) or all children (`.`).
* **Why This Works?** The trie path for any stored word spells it out, and a `.` exploring all children enumerates exactly the stored words consistent with the pattern so far. Each stack entry is a different trie node (a node has one path from the root, and the index equals its depth), so no work repeats.
* **Edge Cases Considered:**
  * Pattern of only dots (`"..."`) — matches any stored word of that length.
  * Pattern longer than every word — runs out of children → `False`.
  * Duplicate `addWord` — idempotent.

## 🔹 Tricks & Patterns Used

* **Branch on wildcard, follow on letter** — DFS width is bounded by the number of dots.
* **End-of-word flag** separate from "has children".

## 🔹 Alternative Data Structures

* Fixed array of 26 children per node — faster lookups, more memory.
* `dict[length → list of words]` — the brute force with a cheap filter.

## 🔹 Complexity Analysis

* **Time Complexity:** `addWord` O(L); `search` O(L) for plain words, O(26ᵈ · L) with `d ≤ 2` dots
* **Space Complexity:** O(total characters inserted)

## 🔹 Code Snippet (Brute Force)

```python
class WordDictionary:

    def __init__(self):
        self.words = []

    def addWord(self, word: str) -> None:
        self.words.append(word)

    def search(self, word: str) -> bool:
        return any(len(w) == len(word) and all(p in (".", c) for p, c in zip(word, w))
                   for w in self.words)
```

## 🔹 Code Snippet (Optimized)

```python
class WordDictionary:

    def __init__(self):
        self.root = {}

    def addWord(self, word: str) -> None:
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node["$"] = True  # "$" can't clash with a letter key

    def search(self, word: str) -> bool:
        stack = [(self.root, 0)]
        while stack:
            node, i = stack.pop()
            if i == len(word):
                if "$" in node:
                    return True
                continue
            ch = word[i]
            if ch == ".":
                stack.extend((child, i + 1) for key, child in node.items() if key != "$")
            elif ch in node:
                stack.append((node[ch], i + 1))
        return False
```
