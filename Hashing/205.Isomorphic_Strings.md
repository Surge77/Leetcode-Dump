# 🔹 Problem Name: 205. Isomorphic Strings (Hash Map, Easy)

**🔗 Link:** [LeetCode 205](https://leetcode.com/problems/isomorphic-strings/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Two maps (a bijection check).** Walk both strings together; `s_to_t[a]` must always be `b` and `t_to_s[b]` must always be `a`. The first conflict means "not isomorphic".
* **Core Concept:** isomorphic = a **one-to-one** character mapping; one map only guarantees "function", the second guarantees "no two chars map to the same char"
* **When to Use This Pattern?** "Does string A follow the same shape as string B?" — word pattern, matching patterns, grouping strings by structure.
* **Mistakes to Avoid:**
  * Checking only `s → t`: `s = "badc", t = "baba"` passes one map (`b→b, a→a, d→b, c→a`) but `b` and `d` both map to `b`.
  * Assuming lowercase letters only — `s` and `t` can be any valid ASCII characters (digits, symbols).

## 🔹 Optimization Path

* **Brute Force:** for every pair `i < j`, require `s[i] == s[j]` ⇔ `t[i] == t[j]` — O(n²) with `n ≤ 5·10⁴`, ~1.25·10⁹ comparisons.
* **Optimized Solution:** two dictionaries in one pass — O(n).
* **Further Improvements Possible?** No asymptotically; compact alternative: `len(set(s)) == len(set(t)) == len(set(zip(s, t)))`.

## 🔹 Solution Breakdown

* **Optimal Approach:** for each `(a, b)` in `zip(s, t)`: if `a` is mapped to something other than `b`, or `b` is mapped from something other than `a`, return `False`; otherwise record both directions.
* **Why This Works?** The pairwise brute-force condition "equal positions in `s` ⇔ equal positions in `t`" is exactly "the relation `{(s[i], t[i])}` is a function both ways". The two maps check both directions incrementally: any violating pair `(i, j)` is caught at position `j`.
* **Edge Cases Considered:**
  * Single character → `True`.
  * Same string (`s == t`) → `True` (identity mapping).
  * A character mapping to itself is allowed (`"ab"`, `"ab"`).

## 🔹 Tricks & Patterns Used

* **Bijection = two maps:** a forward map and a reverse map, both checked on every step.
* **Canonical form:** map each string to "index of first occurrence" for every character (`"egg" → [0, 1, 1]`); two strings are isomorphic iff the forms are equal — handy for grouping many strings.

## 🔹 Alternative Data Structures

* Two arrays of size 256 indexed by `ord(c)` holding the last position seen (+1) — same O(n), no hashing.
* The `zip`/`set` one-liner above — O(n) as well.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(σ), σ ≤ 256 distinct characters

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        n = len(s)
        for i in range(n):
            for j in range(i + 1, n):
                if (s[i] == s[j]) != (t[i] == t[j]):
                    return False
        return True
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        s_to_t = {}
        t_to_s = {}
        for a, b in zip(s, t):
            # setdefault both records a new pair and returns the existing partner
            if s_to_t.setdefault(a, b) != b or t_to_s.setdefault(b, a) != a:
                return False
        return True
```
