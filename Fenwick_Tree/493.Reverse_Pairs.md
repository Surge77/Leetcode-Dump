# 🔹 Problem Name: 493. Reverse Pairs (Fenwick Tree, Hard)

**🔗 Link:** [LeetCode 493](https://leetcode.com/problems/reverse-pairs/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Scan left to right. For each `nums[j]`, count earlier values `> 2 · nums[j]` using a Fenwick tree over sorted values, then insert `nums[j]`.
* **Core Concept:** Fenwick tree with binary-searched ranks (or merge sort)
* **When to Use This Pattern?** Counting pairs `i < j` with a condition between `nums[i]` and a function of `nums[j]` — the query value differs from the inserted value, so ranks come from `bisect`.
* **Mistakes to Avoid:**
  * Overflow of `2 · nums[j]` in C++/Java (use 64-bit); Python is safe.
  * Counting `>=` instead of strictly `>`.

## 🔹 Optimization Path

* **Brute Force:** O(n²).
* **Optimized Solution:** O(n log n).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `vals` = sorted unique `nums`. For `x = nums[j]`: `≤ 2x` count = `prefix(bisect_right(vals, 2x))`; earlier elements greater than `2x` = `seen - that`. Then `add(rank(x), 1)`.
* **Why This Works?** The tree holds exactly the elements with index `< j`; `bisect_right` maps any query value (even one not in the array) to the number of stored ranks `≤` it.
* **Edge Cases Considered:**
  * Negative numbers (`2 · -3 = -6`).
  * Duplicates.

## 🔹 Pattern Recognition

* **Belongs To:** Fenwick Tree / Divide and Conquer

## 🔹 Tricks & Patterns Used

* **Query rank via `bisect_right`** when the query key is not an inserted value.
* **`seen - prefix(...)`** turns "≤" counts into "greater than" counts.

## 🔹 Alternative Data Structures

* **Merge sort:** before merging two sorted halves, count pairs with a two-pointer sweep.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n log n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Optimized)

```python
from bisect import bisect_left, bisect_right
from typing import List


class Solution:
    def reversePairs(self, nums: List[int]) -> int:
        vals = sorted(set(nums))
        tree = [0] * (len(vals) + 1)  # Fenwick over ranks 1..len(vals)

        def add(i: int) -> None:
            while i < len(tree):
                tree[i] += 1
                i += i & -i

        def prefix(i: int) -> int:
            total = 0
            while i > 0:
                total += tree[i]
                i -= i & -i
            return total

        pairs = 0
        for seen, x in enumerate(nums):
            not_bigger = prefix(bisect_right(vals, 2 * x))  # earlier values <= 2x
            pairs += seen - not_bigger
            add(bisect_left(vals, x) + 1)
        return pairs
```
