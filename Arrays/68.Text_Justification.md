# 🔹 Problem Name: 68. Text Justification (String Simulation, Hard)

**🔗 Link:** [LeetCode 68](https://leetcode.com/problems/text-justification/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given a list of words and a line width, lay the words out in lines that are each exactly `maxWidth` characters. Pack words greedily (as many per line as fit) and pad with spaces so the line is fully justified: gaps as even as possible, extra spaces going to the leftmost gaps. The last line, and any line with a single word, is left-justified with padding on the right.

* **Example:** `words = ["This", "is", "an", "example", "of", "text", "justification."], maxWidth = 16` → `["This    is    an", "example  of text", "justification.  "]`
* **Constraints:** `1 ≤ words.length ≤ 300`, `1 ≤ words[i].length ≤ 20`, `1 ≤ maxWidth ≤ 100`, `words[i].length ≤ maxWidth`

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Greedy line packing + `divmod` spacing.** Take words while `letters + next word + (one space per gap) ≤ maxWidth`. For a full line with `g` gaps and `spare = maxWidth − letters` spaces, every gap gets `spare // g` spaces and the leftmost `spare % g` gaps get one more. The last line, and any line with a single word, is left-justified and padded with spaces on the right.
* **Core Concept:** the problem is pure bookkeeping — the difficulty is getting the three line types (full, single-word, last) right
* **When to Use This Pattern?** Formatting / layout simulations: word wrap, splitting messages into fixed-width parts (2468), distributing `x` units as evenly as possible over `g` slots with the extra going left (1592).
* **Mistakes to Avoid:**
  * Division by zero on a one-word line (`g = 0`) — it must be left-justified.
  * Fully justifying the last line — it uses single spaces plus right padding.
  * Giving the extra spaces to the right gaps — the rule is leftmost first.
  * Off-by-one in the fit test: adding word `w` to a line that already has `c` words needs `c` spaces, not `c − 1`.

## 🔹 Optimization Path

* **Brute Force:** re-join the whole candidate line for every word to test the width, then hand out the padding one space at a time round-robin — O(n · W) for `n` words and width `W`.
* **Optimized Solution:** running letter count for the fit test, one `divmod` per line — O(S + L · W) where `S` = total characters of the input and `L · W` = output size.
* **Further Improvements Possible?** No; producing the output already costs `L · W`.

## 🔹 Solution Breakdown

* **Optimal Approach:** `start`, grow `end` while the next word fits; then emit the line by type and continue from `start = end`.
* **Why This Works?** Greedy packing is required by the statement ("as many words as you can"). Within a line, `spare = q·g + r` with `q = spare // g`, `r = spare % g`; giving `q + 1` to the first `r` gaps and `q` to the rest is the only distribution that is as even as possible with the larger gaps on the left.
* **Edge Cases Considered:**
  * A word exactly `maxWidth` long → a line on its own, no padding.
  * Last line with several words → single spaces, then `ljust(maxWidth)`.
  * A single word in total → it is the last line.

## 🔹 Tricks & Patterns Used

* **Even split with leftover to the left:** `q, r = divmod(spare, g)`; gap `k` gets `q + (1 if k < r else 0)`.
* **Running counters instead of rebuilding strings** for the fit test.

## 🔹 Alternative Data Structures

* Build each line as a list of parts and `"".join` it once — avoids quadratic string concatenation.
* Minimum-raggedness (Knuth–Plass) line breaking is a DP — a different objective from this problem's greedy rule.

## 🔹 Complexity Analysis

* **Time Complexity:** O(S + L · W), linear in input plus output
* **Space Complexity:** O(L · W) for the output

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def fullJustify(self, words: List[str], maxWidth: int) -> List[str]:
        lines, line = [], []
        for word in words:
            if len(" ".join(line + [word])) > maxWidth:
                lines.append(line)
                line = []
            line.append(word)
        lines.append(line)

        result = []
        for index, line in enumerate(lines):
            if index == len(lines) - 1 or len(line) == 1:
                result.append(" ".join(line).ljust(maxWidth))
                continue
            gaps = [""] * (len(line) - 1)
            spare = maxWidth - sum(len(word) for word in line)
            for k in range(spare):
                gaps[k % len(gaps)] += " "
            result.append("".join(word + gap for word, gap in zip(line, gaps + [""])))
        return result
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def fullJustify(self, words: List[str], maxWidth: int) -> List[str]:
        result, start, n = [], 0, len(words)
        while start < n:
            end, letters = start + 1, len(words[start])
            # words[start:end] already need end - start - 1 spaces; one more joins words[end]
            while end < n and letters + len(words[end]) + (end - start) <= maxWidth:
                letters += len(words[end])
                end += 1
            gaps = end - start - 1
            if end == n or gaps == 0:
                result.append(" ".join(words[start:end]).ljust(maxWidth))
            else:
                width, extra = divmod(maxWidth - letters, gaps)
                parts = [words[start + k] + " " * (width + (1 if k < extra else 0)) for k in range(gaps)]
                result.append("".join(parts) + words[end - 1])
            start = end
        return result
```
