# 🔹 Problem Name: 863. All Nodes Distance K in Binary Tree (Tree to Graph BFS, Medium)

**🔗 Link:** [LeetCode 863](https://leetcode.com/problems/all-nodes-distance-k-in-binary-tree/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Add parent pointers, then BFS.** A tree only lets you walk down, but distance-`k` nodes can be above or in a sibling subtree. Record every node's parent in one traversal; now each node has up to three neighbours (`left`, `right`, `parent`) and a plain BFS from `target` for `k` rounds lands exactly on the answer.
* **Core Concept:** turn the rooted tree into an undirected graph, then shortest distance = BFS layers
* **When to Use This Pattern?** "Distance from a given node (not the root)", "spread / infection from a node", "nodes within `k` of X" in a binary tree.
* **Mistakes to Avoid:**
  * Searching only the target's subtree: answers above the target or in its siblings' subtrees are missed.
  * No visited set: with parent edges the walk goes back and forth forever (or double-counts).
  * Comparing node values to find the target instead of using the given node — fine here (values are unique), but node identity is the safer habit.

## 🔹 Optimization Path

* **Brute Force:** store every node's root path; `dist(u, target) = |path(u)| + |path(target)| − 2·|shared prefix|` — O(n·h).
* **Optimized Solution:** parent map + BFS — O(n).
* **Further Improvements Possible?** A single DFS returning "distance to target found in this subtree" avoids the map, still O(n); fine for interviews but harder to get right.

## 🔹 Solution Breakdown

* **Optimal Approach:** DFS with a stack to fill `parent`; then `frontier = [target]` and `k` times replace it with all unseen neighbours of its nodes.
* **Why This Works?** After `r` rounds the frontier holds exactly the nodes whose shortest path to `target` has `r` edges — standard BFS layering. In a tree there is one path between any two nodes, so a node is never reached twice in the same round and checking `seen` is enough.
* **Edge Cases Considered:**
  * `k = 0` → `[target.val]`.
  * `k` larger than any distance (up to 1000 with ≤ 500 nodes) → the frontier empties → `[]`.
  * Target is the root → only downward neighbours exist.

## 🔹 Tricks & Patterns Used

* **Parent dictionary keyed by node:** adds the missing upward edge without modifying the tree.
* **Frontier list per round:** the BFS level number is the loop counter, no distances stored.

## 🔹 Alternative Data Structures

* Adjacency list keyed by value (values are unique, 0..500) — same BFS, works without node identity.
* Recursive "distance-from-target" DFS that, on the way back up, launches a downward collection into the other subtree.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n) for the parent map and the visited set

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def distanceK(self, root: TreeNode, target: TreeNode, k: int) -> List[int]:
        paths, stack = {}, [(root, [root])]
        while stack:
            node, path = stack.pop()
            paths[node] = path
            for child in (node.left, node.right):
                if child:
                    stack.append((child, path + [child]))
        to_target = paths[target]
        answer = []
        for node, path in paths.items():
            shared = 0
            while shared < min(len(path), len(to_target)) and path[shared] is to_target[shared]:
                shared += 1
            # both climb to their lowest common ancestor: the last node the two paths share
            if len(path) + len(to_target) - 2 * shared == k:
                answer.append(node.val)
        return answer
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def distanceK(self, root: TreeNode, target: TreeNode, k: int) -> List[int]:
        parent, stack = {root: None}, [root]
        while stack:
            node = stack.pop()
            for child in (node.left, node.right):
                if child:
                    parent[child] = node
                    stack.append(child)
        seen, frontier = {target}, [target]
        for _ in range(k):
            # one path between two tree nodes, so no node can enter the same frontier twice
            frontier = [nb for node in frontier for nb in (node.left, node.right, parent[node])
                        if nb and nb not in seen]
            seen.update(frontier)
        return [node.val for node in frontier]
```
