# 🔹 Problem Name: 207. Course Schedule (Topological Sort, Medium)

**🔗 Link:** [LeetCode 207](https://leetcode.com/problems/course-schedule/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Kahn's algorithm: repeatedly take courses with no remaining prerequisites (in-degree 0). If every course gets taken, there is no cycle.
* **Core Concept:** Topological sort / cycle detection in a directed graph
* **When to Use This Pattern?** Dependencies (build order, task scheduling, prerequisite chains); "is there a valid order?"
* **Mistakes to Avoid:**
  * Edge direction: `[a, b]` means `b → a` (take `b` before `a`).
  * Undirected-style cycle detection (visited set only) — directed graphs need in-degrees or 3-colour DFS.

## 🔹 Optimization Path

* **Brute Force:** Try permutations of courses — O(n!).
* **Optimized Solution:** Kahn's BFS — O(V + E).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Build adjacency + in-degree; queue all in-degree-0 nodes; pop, count, decrement neighbours, enqueue those reaching 0. Answer: `count == numCourses`.
* **Why This Works?** A DAG always has a node with in-degree 0, and removing it leaves a DAG. Nodes on a cycle never reach in-degree 0, so they are never counted.
* **Edge Cases Considered:**
  * No prerequisites → True.
  * Self-loop or 2-cycle → False.
  * Disconnected components.

## 🔹 Alternative Data Structures

* **DFS with 3 colours** (white/grey/black): a grey → grey edge is a cycle.

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        adj = [[] for _ in range(numCourses)]
        indeg = [0] * numCourses
        for course, pre in prerequisites:  # pre -> course
            adj[pre].append(course)
            indeg[course] += 1

        q = deque(c for c in range(numCourses) if indeg[c] == 0)
        taken = 0
        while q:
            c = q.popleft()
            taken += 1
            for nxt in adj[c]:
                indeg[nxt] -= 1
                if indeg[nxt] == 0:
                    q.append(nxt)
        return taken == numCourses  # leftovers sit on a cycle
```
