# 🔹 Problem Name: 1649. Create Sorted Array through Instructions (Fenwick Tree, Hard)

**🔗 Link:** [LeetCode 1649](https://leetcode.com/problems/create-sorted-array-through-instructions/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Insert the numbers of `instructions` one by one, left to right, into a container that is kept sorted. Inserting `x` costs the smaller of two counts: how many stored elements are strictly less than `x`, and how many are strictly greater. Return the total cost of all insertions modulo `10^9 + 7`.

* **Example:** `instructions = [1,5,6,2]` → `1`
* **Constraints:** `1 ≤ instructions.length ≤ 10^5`, `1 ≤ instructions[i] ≤ 10^5`

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** Inserting `x` costs `min(#elements < x, #elements > x)`. A Fenwick tree over values (≤ 10⁵) gives both counts in O(log M).
* **Core Concept:** Fenwick tree as a dynamic frequency table + modulo
* **When to Use This Pattern?** Online insertions with rank queries ("how many so far are smaller/larger?").
* **Mistakes to Avoid:**
  * Actually inserting into a list (`insort`) — O(n) per insert, O(n²) total.
  * `#greater = inserted - prefix(x)`, **not** `inserted - prefix(x - 1)` (that would count equal values as greater).
  * Forgetting `% (10**9 + 7)`.

## 🔹 Optimization Path

* **Brute Force:** O(n²) — keep a sorted list.
* **Optimized Solution:** O(n log M).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** For the `i`-th insertion (`i` elements already in): `less = prefix(x - 1)`, `greater = i - prefix(x)`; add `min(less, greater)`; then `add(x, 1)`.
* **Why This Works?** The tree stores the count of every value inserted so far, so prefix sums are exactly rank counts.
* **Edge Cases Considered:**
  * Many duplicates (equal values count as neither less nor greater, so they never add to the cost).
  * Strictly increasing input → cost 0.

## 🔹 Code Snippet (Brute Force)

```python
from bisect import bisect_left, bisect_right, insort
from typing import List

MOD = 10**9 + 7


class Solution:
    def createSortedArray(self, instructions: List[int]) -> int:
        arr = []  # sorted list of everything inserted so far
        cost = 0
        for x in instructions:
            less = bisect_left(arr, x)
            greater = len(arr) - bisect_right(arr, x)
            cost += min(less, greater)
            insort(arr, x)  # O(n) shift per insert
        return cost % MOD
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List

MOD = 10**9 + 7


class Solution:
    def createSortedArray(self, instructions: List[int]) -> int:
        size = max(instructions)
        tree = [0] * (size + 1)

        def add(i: int) -> None:
            while i <= size:
                tree[i] += 1
                i += i & -i

        def prefix(i: int) -> int:  # how many inserted values are <= i
            total = 0
            while i > 0:
                total += tree[i]
                i -= i & -i
            return total

        cost = 0
        for inserted, x in enumerate(instructions):
            less = prefix(x - 1)
            greater = inserted - prefix(x)
            cost += min(less, greater)
            add(x)
        return cost % MOD
```
