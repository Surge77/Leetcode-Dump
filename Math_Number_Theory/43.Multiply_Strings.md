# 🔹 Problem Name: 43. Multiply Strings (Digit Arithmetic, Medium)

**🔗 Link:** [LeetCode 43](https://leetcode.com/problems/multiply-strings/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Positional product array.** Digit `num1[i]` times digit `num2[j]` always lands in columns `i + j` (carry) and `i + j + 1` (units) of a result of length `len1 + len2`. Accumulate every digit product into its column, then sweep right-to-left once to push carries.
* **Core Concept:** long multiplication without materialising the partial-product rows
* **When to Use This Pattern?** Big-number arithmetic on strings or digit arrays when built-in big integers are disallowed — add, multiply, compare.
* **Mistakes to Avoid:**
  * Converting with `int(num1)` — the statement forbids it (and the numbers have up to 200 digits).
  * Forgetting the `"0"` case: the result array is all zeros and stripping leading zeros leaves an empty string.
  * Result length is at most `len1 + len2` digits, never more.

## 🔹 Optimization Path

* **Brute Force:** grade-school rows — multiply `num1` by each digit of `num2`, append `k` zeros for the shift, and add the row to a running string sum. O(m·(n + m)) with a new string per row.
* **Optimized Solution:** one integer array of size `n + m`, every `d1·d2` added into place, carries resolved at the end — O(n·m) time, O(n + m) space.
* **Further Improvements Possible?** Karatsuba (O(n^1.585)) or FFT multiplication — pointless for 200 digits.

## 🔹 Solution Breakdown

* **Optimal Approach:** `res = [0] * (n + m)`; for `i` from the right of `num1`, `j` from the right of `num2`: `total = d1 * d2 + res[i + j + 1]`, `res[i + j + 1] = total % 10`, `res[i + j] += total // 10`. Strip leading zeros and join.
* **Why This Works?** Digit `i` of an `n`-digit number has place value `10^(n−1−i)`; the product of digits `i` and `j` has place value `10^(n+m−2−i−j)`, which is index `i + j + 1` in an array of length `n + m` read left-to-right. Doing the carry immediately keeps every cell below 10 except `res[i + j]`, which is fixed when its own column is processed later (smaller `i + j` is processed after larger).
* **Edge Cases Considered:**
  * Either input is `"0"` → `"0"`.
  * `"9" * "9"` = `"81"` uses both columns; `"2" * "3"` leaves a leading zero to strip.

## 🔹 Tricks & Patterns Used

* **Index `i + j + 1` for the units digit:** removes all shifting/padding logic from long multiplication.
* **Lazy carry:** sum many products into a column and normalise once.

## 🔹 Alternative Data Structures

* Reversed digit lists (least significant first) — indexes become `i + j` and appends grow the number naturally.
* Base-10⁴ limbs instead of single digits to cut the work by 16× (common in competitive big-int code).

## 🔹 Complexity Analysis

* **Time Complexity:** O(n · m)
* **Space Complexity:** O(n + m)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def multiply(self, num1: str, num2: str) -> str:
        def add(a: str, b: str) -> str:
            i, j, carry, out = len(a) - 1, len(b) - 1, 0, []
            while i >= 0 or j >= 0 or carry:
                total = carry + (ord(a[i]) - 48 if i >= 0 else 0) + (ord(b[j]) - 48 if j >= 0 else 0)
                out.append(chr(total % 10 + 48))
                carry = total // 10
                i, j = i - 1, j - 1
            return "".join(reversed(out))

        def times_digit(a: str, d: int) -> str:
            carry, out = 0, []
            for ch in reversed(a):
                total = (ord(ch) - 48) * d + carry
                out.append(chr(total % 10 + 48))
                carry = total // 10
            if carry:
                out.append(chr(carry + 48))
            return "".join(reversed(out))

        if num1 == "0" or num2 == "0":
            return "0"
        result = "0"
        for shift, ch in enumerate(reversed(num2)):
            result = add(result, times_digit(num1, ord(ch) - 48) + "0" * shift)
        return result
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def multiply(self, num1: str, num2: str) -> str:
        if num1 == "0" or num2 == "0":
            return "0"
        n, m = len(num1), len(num2)
        res = [0] * (n + m)
        for i in range(n - 1, -1, -1):
            d1 = ord(num1[i]) - 48
            for j in range(m - 1, -1, -1):
                total = d1 * (ord(num2[j]) - 48) + res[i + j + 1]
                res[i + j + 1] = total % 10
                # res[i + j] may briefly exceed 9; it is normalised when column i + j is processed
                res[i + j] += total // 10
        start = 0 if res[0] else 1  # product of n- and m-digit numbers has n+m or n+m-1 digits
        return "".join(map(str, res[start:]))
```
