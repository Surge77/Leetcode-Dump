# 🔹 Problem Name: 1732. Find the Highest Altitude (Prefix Sum, Easy)

**🔗 Link:** [LeetCode 1732](https://leetcode.com/problems/find-the-highest-altitude/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

A biker starts at altitude `0` and rides through `n` segments; `gain[i]` is the net altitude change of segment `i`. Return the highest altitude reached at any of the `n + 1` points, the starting point included.

* **Example:** `gain = [-5,1,5,0,-7]` → `1`
* **Constraints:** `1 ≤ n ≤ 100`, `-100 ≤ gain[i] ≤ 100`

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Running sum, tracking the maximum.** Start at altitude `0`, add each `gain[i]`, and keep the highest value seen — including the starting `0`.
* **Core Concept:** altitudes are the prefix sums of the gains
* **When to Use This Pattern?** A sequence of deltas whose cumulative value you need to inspect (balances, elevations, scores after each step).
* **Mistakes to Avoid:**
  * Starting the maximum at `-inf` or at the first gain: the start point (altitude `0`) counts, so an all-downhill route returns `0`.
  * Building the whole altitude array when only the maximum is needed.

## 🔹 Optimization Path

* **Brute Force:** for every point `i`, recompute `sum(gain[:i])` and take the maximum — O(n²).
* **Optimized Solution:** keep a single running altitude — O(n).
* **Further Improvements Possible?** No; each gain must be read once.

## 🔹 Solution Breakdown

* **Optimal Approach:** `altitude = best = 0`; for each `g`: `altitude += g`; `best = max(best, altitude)`.
* **Why This Works?** After processing `gain[:i]`, `altitude` equals `sum(gain[:i])`, which is exactly the altitude of point `i`, so the running maximum covers all `n + 1` points.
* **Edge Cases Considered:**
  * All gains negative → answer stays `0`.
  * A single gain → compare `0` with that gain.
  * Gains may be zero; the maximum can be a plateau.

## 🔹 Tricks & Patterns Used

* **`itertools.accumulate`** gives the prefix sums directly: `max(0, *accumulate(gain))`.
* **Initial value `0`** represents the starting point.

## 🔹 Alternative Data Structures

* An explicit `altitudes = [0] + list(accumulate(gain))` array — clearer, O(n) extra space.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def largestAltitude(self, gain: List[int]) -> int:
        return max(sum(gain[:i]) for i in range(len(gain) + 1))
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def largestAltitude(self, gain: List[int]) -> int:
        altitude = best = 0  # the starting point counts as a candidate
        for step in gain:
            altitude += step
            best = max(best, altitude)
        return best
```
