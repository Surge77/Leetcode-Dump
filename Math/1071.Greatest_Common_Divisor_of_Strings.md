# 1071. Greatest Common Divisor of Strings

**🔗 Link:** [LeetCode 1071](https://leetcode.com/problems/greatest-common-divisor-of-strings/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

A string `t` divides `s` when `s` is `t` repeated one or more times. Given `str1` and `str2`, return the longest string that divides both, or the empty string if no such string exists.

* **Example:** `str1 = "ABCABC", str2 = "ABC"` → `"ABC"`
* **Constraints:** `1 ≤ str1.length, str2.length ≤ 1000`; both strings are uppercase English letters.

## 🔹 Quick Breakdown

* **Difficulty Level:** Easy
* **Main Approach:** **Concatenation test, then a numeric GCD.** If a common divisor string exists, `str1 + str2 == str2 + str1`. When that holds, the answer is the prefix of `str1` whose length is `gcd(len(str1), len(str2))`.
* **Core Concept:** strings built from the same repeating unit commute under concatenation
* **When to Use This Pattern?** "Largest repeating unit shared by two strings" and other problems where divisibility of lengths and periodicity interact.
* **Mistakes to Avoid:**
  * Taking `gcd` of the lengths without the concatenation check — `"LEET"` and `"CODE"` have `gcd = 4` but share no unit.
  * Trying prefixes of every length and testing each — correct, but O(n · m) at the limits.

## 🔹 Optimization Path

* **Brute Force:** for each length from `min(len1, len2)` down to 1, if it divides both lengths, test whether repeating that prefix rebuilds both strings — O(min(n, m) · (n + m)).
* **Optimized Solution:** one concatenation comparison and one `gcd` — O(n + m).
* **Further Improvements Possible?** No; the strings must be read once.

## 🔹 Solution Breakdown

* **Optimal Approach:** if `str1 + str2 != str2 + str1`, return `""`; otherwise return `str1[:gcd(len(str1), len(str2))]`.
* **Why This Works?** If both strings are powers of a unit `t` (`str1 = t^a`, `str2 = t^b`) then both concatenations equal `t^(a+b)`. Conversely, if they commute they share a primitive root. The *largest* common unit has length equal to the largest length dividing both, which is the GCD.
* **Edge Cases Considered:**
  * One string is a multiple of the other (`"ABABAB"`, `"ABAB"` → `"AB"`).
  * Equal strings → the string itself.
  * No common unit → `""`.

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def gcdOfStrings(self, str1: str, str2: str) -> str:
        for length in range(min(len(str1), len(str2)), 0, -1):
            if len(str1) % length or len(str2) % length:
                continue
            unit = str1[:length]
            if unit * (len(str1) // length) == str1 and unit * (len(str2) // length) == str2:
                return unit
        return ""
```
