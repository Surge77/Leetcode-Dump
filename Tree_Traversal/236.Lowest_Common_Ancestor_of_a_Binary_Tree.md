# 🔹 Problem Name: 236. Lowest Common Ancestor of a Binary Tree (Tree Traversal, Medium)

**🔗 Link:** [LeetCode 236](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given a binary tree (not necessarily a search tree) and two of its nodes `p` and `q`, return their lowest common ancestor: the deepest node that has both of them in its subtree. A node counts as a descendant of itself.

* **Example:** `root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1` → `3`
* **Constraints:** `2 ≤ nodes ≤ 10^5`, `-10^9 ≤ Node.val ≤ 10^9`, all values unique, `p != q`, both exist in the tree

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Record each node's parent with an iterative traversal until both `p` and `q` are found. Collect all ancestors of `p`; walk up from `q` until hitting one of them.
* **Core Concept:** Parent pointers + ancestor set
* **When to Use This Pattern?** LCA in a plain binary tree (no BST ordering), distance between two nodes (`depth(p) + depth(q) - 2·depth(lca)`).
* **Mistakes to Avoid:**
  * Using the BST trick (compare values) — this is not a BST.
  * Forgetting a node can be its own ancestor (`p` may be the LCA).

## 🔹 Optimization Path

* **Brute Force:** Root-to-node paths for both, compare — two O(n) searches, but the code's `[node] + rest` recopies the path at every level, so it is O(n + h²) (O(n²) on a chain) and the recursion is bounded by Python's recursion limit.
* **Optimized Solution:** O(n) single traversal with early stop.
* **Further Improvements Possible?** Many queries → binary lifting or Euler tour + sparse table (O(log n) / O(1) per query).

## 🔹 Solution Breakdown

* **Optimal Approach:** Stack traversal filling `parent`; stop once `p` and `q` are both in it. `ancestors = {p, parent[p], …}`; climb from `q` until in `ancestors`.
* **Why This Works?** The LCA is the first node on `q`'s path to the root that also lies on `p`'s path to the root.
* **Edge Cases Considered:**
  * `p` is an ancestor of `q`.
  * `p == q` (excluded by the constraints, but the code still returns that node).
  * Deep skewed tree (iterative — no recursion limit).

## 🔹 Tricks & Patterns Used

* **Parent map** turns a tree into something you can climb.
* **Early termination** when both targets are found.

## 🔹 Alternative Data Structures

* Classic recursion: return the node if it is `p`/`q`; if both sides return non-null, the current node is the LCA.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
class Solution:
    def lowestCommonAncestor(self, root: "TreeNode", p: "TreeNode", q: "TreeNode") -> "TreeNode":
        def path_to(node, target):
            if node is None:
                return None
            if node is target:
                return [node]
            for child in (node.left, node.right):
                rest = path_to(child, target)
                if rest is not None:
                    return [node] + rest
            return None

        path_p, path_q = path_to(root, p), path_to(root, q)
        lca = root
        for a, b in zip(path_p, path_q):
            if a is not b:
                break
            lca = a
        return lca
```

## 🔹 Code Snippet (Optimized)

```python
class Solution:
    def lowestCommonAncestor(self, root: "TreeNode", p: "TreeNode", q: "TreeNode") -> "TreeNode":
        parent = {root: None}
        stack = [root]
        while p not in parent or q not in parent:
            node = stack.pop()
            for child in (node.left, node.right):
                if child:
                    parent[child] = node
                    stack.append(child)

        ancestors = set()
        while p:  # p and all its ancestors
            ancestors.add(p)
            p = parent[p]
        while q not in ancestors:
            q = parent[q]
        return q
```
