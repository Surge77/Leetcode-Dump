# 🔹 Problem Name: 875. Koko Eating Bananas (Binary Search on Answer, Medium)

**🔗 Link:** [LeetCode 875](https://leetcode.com/problems/koko-eating-bananas/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** The speed `k` is monotone: if `k` works, every faster speed works. Binary search the smallest `k` in `[1, max(piles)]` whose total hours `Σ ceil(p / k)` is `≤ h`.
* **Core Concept:** Binary search on the answer space
* **When to Use This Pattern?** "Minimum X such that it is possible…" / "maximum X such that…", where checking a given X is easy and feasibility is monotone.
* **Mistakes to Avoid:**
  * Float `ceil(p / k)` — use integer `(p + k - 1) // k`.
  * Lower bound 0 → division by zero.
  * Mixing `lo < hi` with `hi = mid - 1` (infinite loops / off-by-one).

## 🔹 Optimization Path

* **Brute Force:** O(max(p) · n) — try every speed.
* **Optimized Solution:** O(n log max(p)).
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `lo = 1, hi = max(piles)`; while `lo < hi`: if `hours(mid) <= h` then `hi = mid` else `lo = mid + 1`.
* **Why This Works?** `hours(k)` is non-increasing in `k`, so the feasible speeds form a suffix `[k*, ∞)`; the loop keeps the invariant "`k*` is in `[lo, hi]`".
* **Edge Cases Considered:**
  * `h == len(piles)` → answer is `max(piles)`.
  * Very large `h` → answer 1.

## 🔹 Tricks & Patterns Used

* **Template:** `while lo < hi: mid = (lo + hi) // 2; if ok(mid): hi = mid else lo = mid + 1` → returns the first feasible value.
* **Integer ceiling:** `-(-p // k)` or `(p + k - 1) // k`.

* None — the "array" being searched is the range of possible answers.

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def minEatingSpeed(self, piles: List[int], h: int) -> int:
        def hours(k: int) -> int:
            return sum((p + k - 1) // k for p in piles)  # integer ceil(p / k)

        lo, hi = 1, max(piles)
        while lo < hi:  # invariant: answer in [lo, hi]
            mid = (lo + hi) // 2
            if hours(mid) <= h:
                hi = mid  # mid works; maybe something slower works too
            else:
                lo = mid + 1
        return lo
```
