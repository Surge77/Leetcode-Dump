# 🔹 Problem Name: 117. Populating Next Right Pointers in Each Node II (Tree BFS, Medium)

**🔗 Link:** [LeetCode 117](https://leetcode.com/problems/populating-next-right-pointers-in-each-node-ii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Walk each level through the `next` links already built.** Once level `k` is linked it *is* a linked list: walk it left to right and append every child you meet to a fresh list for level `k + 1` (a dummy head plus a `tail` pointer). That list's first node is where the next round starts. No queue — O(1) extra space.
* **Core Concept:** the output being built (the `next` pointers) doubles as the BFS queue for the level below
* **When to Use This Pattern?** Level-by-level work on a tree when an O(width) queue is not allowed, or any "link / thread the nodes of each level" task. The dummy-head + tail trick also builds any list while scanning another.
* **Mistakes to Avoid:**
  * Reusing the 116 solution (`node.left.next = node.right`, `node.right.next = node.next.left`): it assumes a perfect tree. Here children can be missing, so `node.next.left` may be `None` while a farther cousin exists.
  * Starting the next round at `level.left`: the first node of the next level is the **first child found** in the walk, which may hang several nodes to the right.

## 🔹 Optimization Path

* **Brute Force:** BFS with a queue, one level at a time; link each node to the one dequeued after it — O(n) time, O(w) space (`w` = widest level, about n/2 for a full tree).
* **Optimized Solution:** level walk over existing `next` links + dummy head — O(n) time, O(1) extra space.
* **Further Improvements Possible?** No: every node must be touched, and the extra space is already constant.

## 🔹 Solution Breakdown

* **Optimal Approach:** `level = root`. While `level`: `dummy = tail = Node()`; walk `node` from `level` along `next`, appending `node.left` then `node.right` (when present) after `tail`; then `level = dummy.next`.
* **Why This Works?** Walking level `k` left to right and appending children left-then-right produces level `k + 1` in left-to-right order, so each `tail.next = child` links a node to its true right neighbour. The last node of a level keeps `next = None` (all pointers start as `NULL`) because nothing is appended after it. By induction every level is fully linked before it is walked.
* **Edge Cases Considered:**
  * Empty tree → return `None`.
  * A childless node between two parents — the walk skips it and links the cousins across the gap.
  * A 6000-deep path — fully iterative, so no recursion limit.

## 🔹 Tricks & Patterns Used

* **Dummy head + tail:** appending to an empty list needs no special case; `dummy.next` is the head at the end.
* **Reuse the output as the iteration structure:** level `k`'s `next` chain replaces the queue for building level `k + 1`.

## 🔹 Alternative Data Structures

* `deque` BFS (the brute force) — simplest; O(w) memory.
* DFS visiting left before right with a per-depth "last node seen" list (`last[d].next = node; last[d] = node`) — O(h) memory, but recursion up to 6000 deep.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n)
* **Space Complexity:** O(1) extra

## 🔹 Code Snippet (Brute Force)

```python
from collections import deque


class Node:
    def __init__(self, val: int = 0, left: 'Node' = None, right: 'Node' = None, next: 'Node' = None):
        self.val = val
        self.left = left
        self.right = right
        self.next = next


class Solution:
    def connect(self, root: 'Node') -> 'Node':
        queue = deque([root] if root else [])
        while queue:
            prev = None
            for _ in range(len(queue)):  # only the nodes of the current level
                node = queue.popleft()
                if prev:
                    prev.next = node
                prev = node
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        return root
```

## 🔹 Code Snippet (Optimized)

```python
class Node:
    def __init__(self, val: int = 0, left: 'Node' = None, right: 'Node' = None, next: 'Node' = None):
        self.val = val
        self.left = left
        self.right = right
        self.next = next


class Solution:
    def connect(self, root: 'Node') -> 'Node':
        level = root
        while level:
            dummy = tail = Node()
            node = level
            while node:  # this level was linked in the previous round, so `next` walks it
                for child in (node.left, node.right):
                    if child:
                        tail.next = child
                        tail = child
                node = node.next
            level = dummy.next
        return root
```
