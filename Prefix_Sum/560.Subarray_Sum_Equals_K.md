# 560. Subarray Sum Equals K

**🔗 Link:** [LeetCode 560](https://leetcode.com/problems/subarray-sum-equals-k/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Given an integer array `nums` and an integer `k`, return how many contiguous, non-empty subarrays have a sum equal to `k`. Values may be negative.

* **Example:** `nums = [1,1,1]`, `k = 2` → `2`
* **Constraints:** `1 ≤ nums.length ≤ 2 * 10^4`, `-1000 ≤ nums[i] ≤ 1000`, `-10^7 ≤ k ≤ 10^7`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** A subarray ending at `j` sums to `k` iff some earlier prefix equals `prefix_j - k`. Keep a hashmap of how many times each prefix sum has occurred.
* **Core Concept:** Prefix sum + frequency hashmap
* **When to Use This Pattern?** Counting subarrays with an exact sum / sum divisible by k / equal number of 0s and 1s — especially when negatives rule out sliding window.
* **Mistakes to Avoid:**
  * Sliding window — breaks with negative numbers.
  * Forgetting `seen[0] = 1` (subarrays starting at index 0).
  * Updating the map before counting (would match a prefix with itself when `k = 0`).

## 🔹 Optimization Path

* **Brute Force:** O(n²) — all subarrays with a running sum.
* **Optimized Solution:** O(n) time, O(n) space.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** Running `prefix`; `count += seen[prefix - k]`; then `seen[prefix] += 1`.
* **Why This Works?** `sum(i+1..j) = prefix_j - prefix_i`; setting it to `k` means `prefix_i = prefix_j - k`, and the map counts those `i` in O(1).
* **Edge Cases Considered:**
  * `k = 0` with zeros in the array.
  * Negative numbers.

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        count = 0
        for i in range(len(nums)):
            total = 0
            for j in range(i, len(nums)):
                total += nums[j]
                if total == k:
                    count += 1
        return count
```

## 🔹 Code Snippet (Optimized)

```python
from collections import defaultdict
from typing import List


class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        seen = defaultdict(int)
        seen[0] = 1  # empty prefix
        prefix = count = 0
        for x in nums:
            prefix += x
            count += seen[prefix - k]  # earlier prefixes that leave sum k
            seen[prefix] += 1
        return count
```
