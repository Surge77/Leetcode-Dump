# 134. Gas Station

**🔗 Link:** [LeetCode 134](https://leetcode.com/problems/gas-station/)
**🟢 Status:** 🔄 Need Review


## 🔹 Problem Statement

Gas stations sit on a circular road. Station `i` gives `gas[i]` fuel and the leg to the next station costs `cost[i]`. Starting with an empty tank at some station, return the index from which you can drive the full circle clockwise, or -1 if no start works. The valid start is unique when it exists.

* **Example:** `gas = [1,2,3,4,5], cost = [3,4,5,1,2]` → `3`
* **Constraints:** `n == gas.length == cost.length`, `1 ≤ n ≤ 10^5`, `0 ≤ gas[i], cost[i] ≤ 10^4`, the answer is unique.

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** If total gas < total cost → `-1`. Otherwise scan once; whenever the tank goes negative, no station from the current start up to here can work, so restart at the next station.
* **Core Concept:** Greedy with a prefix-sum argument
* **When to Use This Pattern?** Circular tours, "find a starting point so the running sum never goes negative".
* **Mistakes to Avoid:**
  * Simulating from every start — O(n²).
  * Restarting at `start + 1` instead of `i + 1`.

## 🔹 Optimization Path

* **Brute Force:** Try every start — O(n²).
* **Optimized Solution:** O(n) single pass.
* **Further Improvements Possible?** No.

## 🔹 Solution Breakdown

* **Optimal Approach:** `tank += gas[i] - cost[i]`; if `tank < 0`: `start = i + 1`, `tank = 0`. Return `start` if the total is non-negative.
* **Why This Works?** If you run dry at `i` starting from `s`, every station between `s` and `i` arrives with a tank ≥ 0 from `s`, so starting there instead cannot help. A non-negative total guarantees the final `start` can wrap around.
* **Edge Cases Considered:**
  * Single station.
  * Total exactly equal (tank ends at 0).

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        n = len(gas)
        for start in range(n):  # simulate the full loop from every station
            tank = 0
            for k in range(n):
                i = (start + k) % n
                tank += gas[i] - cost[i]
                if tank < 0:
                    break
            else:
                return start
        return -1
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        if sum(gas) < sum(cost):
            return -1
        start = tank = 0
        for i in range(len(gas)):
            tank += gas[i] - cost[i]
            if tank < 0:  # no station in [start, i] can be the answer
                start, tank = i + 1, 0
        return start
```
