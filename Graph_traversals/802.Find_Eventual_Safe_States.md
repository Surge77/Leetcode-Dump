# 🔹 Problem Name: 802. Find Eventual Safe States (Topological Sort, Medium)

**🔗 Link:** [LeetCode 802](https://leetcode.com/problems/find-eventual-safe-states/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** **Kahn's algorithm on the reversed graph.** A node is safe iff **every** outgoing edge leads to a safe node; terminal nodes (out-degree 0) are safe. Keep `out_left[v]` = edges of `v` not yet known to end at a safe node. Start a queue with the terminals; when a node becomes safe, decrement `out_left` of each of its predecessors and enqueue those that hit 0.
* **Core Concept:** unsafe ⇔ some path reaches a cycle; peeling nodes whose successors are all safe is a topological sort that stops at cycles
* **When to Use This Pattern?** "Which nodes can't reach a cycle", "which states always terminate", dependency resolution where a node is ready only when all of its children are.
* **Mistakes to Avoid:**
  * Using in-degree on the original graph — safety depends on **out**-going edges, so reverse the graph and count out-degrees.
  * Recursive three-colour DFS on a 10⁴-node chain → recursion error in Python; the BFS version needs no recursion.
  * Returning nodes in discovery order — the answer must be sorted.

## 🔹 Optimization Path

* **Brute Force:** fixed-point iteration — repeatedly scan all nodes and mark `v` safe when all of `graph[v]` are safe, until a full scan changes nothing — O(n · (n + e)).
* **Optimized Solution:** reverse-graph Kahn — O(n + e).
* **Further Improvements Possible?** No; every edge must be inspected.

## 🔹 Solution Breakdown

* **Optimal Approach:** build `parents[w]` (reverse edges) and `out_left[v] = len(graph[v])`; BFS from all terminals; output `v` in increasing order where `safe[v]`.
* **Why This Works?** By induction, a node is dequeued only after each of its successors was proven safe, so it is safe. Conversely a node on a cycle can never reach `out_left == 0` (its cycle successor is never dequeued first), and neither can any node with an edge into a cycle — exactly the unsafe ones.
* **Edge Cases Considered:**
  * Self-loop `i → i` → never safe.
  * All nodes terminal → all safe.
  * A node whose edges all point into a cycle → unsafe.

## 🔹 Tricks & Patterns Used

* **Reverse the edges to propagate "done" backwards:** the queue carries safe nodes to the nodes that depend on them.
* **`graph[i]` is strictly increasing** → no duplicate edges, so `len(graph[v])` is the exact out-degree.

## 🔹 Alternative Data Structures

* Three-colour DFS (white / grey / black): a grey node revisited means a cycle; black-and-acyclic nodes are safe. Same O(n + e), but needs an explicit stack in Python.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n + e), `n ≤ 10⁴`, `e ≤ 4·10⁴`
* **Space Complexity:** O(n + e) for the reversed graph

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def eventualSafeNodes(self, graph: List[List[int]]) -> List[int]:
        n = len(graph)
        safe = [False] * n
        changed = True
        while changed:  # a node can only turn safe after its successors did, so iterate to a fixed point
            changed = False
            for v in range(n):
                if not safe[v] and all(safe[w] for w in graph[v]):
                    safe[v] = changed = True
        return [v for v in range(n) if safe[v]]
```

## 🔹 Code Snippet (Optimized)

```python
from collections import deque
from typing import List


class Solution:
    def eventualSafeNodes(self, graph: List[List[int]]) -> List[int]:
        n = len(graph)
        parents = [[] for _ in range(n)]
        out_left = [len(succ) for succ in graph]
        for v, succ in enumerate(graph):
            for w in succ:
                parents[w].append(v)

        queue = deque(v for v in range(n) if out_left[v] == 0)
        safe = [False] * n
        while queue:
            w = queue.popleft()
            safe[w] = True
            for v in parents[w]:
                out_left[v] -= 1
                if out_left[v] == 0:  # every edge out of v now ends at a safe node
                    queue.append(v)
        return [v for v in range(n) if safe[v]]
```
