# 🔹 Problem Name: 1631. Path With Minimum Effort (Dijkstra — minimax, Medium)

**🔗 Link:** [LeetCode 1631](https://leetcode.com/problems/path-with-minimum-effort/)
**🟢 Status:** 🔄 Need Review

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** A path's cost is its **largest** step `|h1 - h2|`. Dijkstra still works if "distance + w" is replaced by `max(distance, w)`.
* **Core Concept:** Minimax path (bottleneck shortest path)
* **When to Use This Pattern?** Minimise the worst edge on a path (safest route, lowest required capacity, minimum water level to swim).
* **Mistakes to Avoid:**
  * Summing efforts — the cost is the maximum, not the sum.
  * DFS/DP with only right/down moves — the path may go in all four directions.

## 🔹 Optimization Path

* **Brute Force:** Enumerate paths — exponential.
* **Alternative:** Binary search the effort + BFS feasibility — O(mn log H).
* **Optimized Solution:** Dijkstra — O(mn log(mn)).

## 🔹 Solution Breakdown

* **Optimal Approach:** `effort[0][0] = 0`; pop the cell with the smallest effort; for neighbours, `cand = max(e, |h - h'|)`; push if better. Return when the target is popped.
* **Why This Works?** `max` is monotone (a path's cost never decreases when extended), which is the only property Dijkstra needs.
* **Edge Cases Considered:**
  * 1×1 grid → 0.
  * Flat grid → 0.

## 🔹 Pattern Recognition

* **Belongs To:** Graph — Shortest Path (minimax Dijkstra)

## 🔹 Tricks & Patterns Used

* **Generalised Dijkstra:** any monotone path cost works (`max`, `+`, `*` of probabilities ≤ 1 with max-heap).
* **Early exit** when the destination is popped.

## 🔹 Alternative Data Structures

* **Union-Find:** sort all edges by effort, union until start and end connect — Kruskal-style, O(E log E).

## 🔹 Complexity Analysis

* **Time Complexity:** O(m · n · log(m · n))
* **Space Complexity:** O(m · n)

## 🔹 Code Snippet (Optimized)

```python
import heapq
from typing import List


class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        m, n = len(heights), len(heights[0])
        best = [[float("inf")] * n for _ in range(m)]
        best[0][0] = 0
        pq = [(0, 0, 0)]  # (effort so far, row, col)
        while pq:
            e, i, j = heapq.heappop(pq)
            if (i, j) == (m - 1, n - 1):
                return e
            if e > best[i][j]:
                continue
            for x, y in ((i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1)):
                if 0 <= x < m and 0 <= y < n:
                    cand = max(e, abs(heights[x][y] - heights[i][j]))
                    if cand < best[x][y]:
                        best[x][y] = cand
                        heapq.heappush(pq, (cand, x, y))
        return 0
```
