# 🔹 Problem Name: 2381. Shifting Letters II (Difference Array, Medium)

**🔗 Link:** [LeetCode 2381](https://leetcode.com/problems/shifting-letters-ii/)
**🟢 Status:** 🔄 Need Review

## 🔹 Problem Statement

Given a lowercase string `s` and a list of shifts `[start, end, direction]`, move every letter in `s[start..end]` one step forward (`direction = 1`) or backward (`direction = 0`) in the alphabet, wrapping `z` ↔ `a`. Return the string after all shifts are applied.

* **Example:** `s = "abc"`, `shifts = [[0,1,0],[1,2,1],[0,2,1]]` → `"ace"`
* **Constraints:** `1 ≤ s.length, shifts.length ≤ 5 * 10^4`, `0 ≤ start ≤ end < s.length`, `direction ∈ {0, 1}`

## 🔹 Quick Breakdown

* **Difficulty Level:** Medium
* **Main Approach:** Each shift `[start, end, direction]` adds `+1` (forward) or `−1` (backward) to every index in `[start, end]`. Record it in a difference array (`diff[start] += d`, `diff[end + 1] -= d`), prefix-sum to get each index's net shift, and apply it mod 26.
* **Core Concept:** range updates via a difference array; wrap-around with `% 26`
* **When to Use This Pattern?** Many range updates, all applied before any read.
* **Mistakes to Avoid:**
  * Applying every shift letter by letter: O(n · q) = 2.5·10⁹ in the worst case.
  * Negative net shifts: Python's `%` already returns 0..25; in Java/C++ add 26 before `%`.

## 🔹 Optimization Path

* **Brute Force:** apply each shift to its range — O(n · q).
* **Optimized Solution:** difference array — O(n + q).

## 🔹 Solution Breakdown

* **Optimal Approach:** build `diff` of length `n + 1`, then walk the string with a running `shift`.
* **Why This Works?** Shifts commute (they are additions mod 26), so only the net shift per index matters, and the difference array delivers the net sum per index in one pass.
* **Edge Cases Considered:**
  * Shifts that cancel out (forward and backward on the same range).
  * Large net shifts (up to 5·10⁴) — reduced by `% 26`.

## 🔹 Tricks & Patterns Used

* **Closed range update:** `diff[l] += x; diff[r + 1] -= x` (array of length `n + 1`).
* **Cyclic alphabet:** `chr((ord(c) - 97 + shift) % 26 + 97)`.

## 🔹 Alternative Data Structures

* A Fenwick tree supports the same updates **interleaved** with reads (O(log n) each) — not needed when all updates come first.

## 🔹 Complexity Analysis

* **Time Complexity:** O(n + q)
* **Space Complexity:** O(n)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Solution:
    def shiftingLetters(self, s: str, shifts: List[List[int]]) -> str:
        codes = [ord(c) - 97 for c in s]
        for start, end, direction in shifts:
            for i in range(start, end + 1):
                codes[i] = (codes[i] + (1 if direction else -1)) % 26
        return "".join(chr(c + 97) for c in codes)
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Solution:
    def shiftingLetters(self, s: str, shifts: List[List[int]]) -> str:
        diff = [0] * (len(s) + 1)
        for start, end, direction in shifts:
            delta = 1 if direction else -1
            diff[start] += delta
            diff[end + 1] -= delta
        out, shift = [], 0
        for i, ch in enumerate(s):
            shift += diff[i]
            out.append(chr((ord(ch) - 97 + shift) % 26 + 97))
        return "".join(out)
```
