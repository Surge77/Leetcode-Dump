# 759. Employee Free Time

## 🔹 Problem Statement

Each employee has a schedule: a sorted list of non-overlapping busy `Interval` objects (`start`, `end`). Return the finite stretches of time when all employees are free at once, as a sorted list of intervals. Time before the earliest start or after the latest end is unbounded and not reported. *(premium — paraphrased from memory, not checked against the official page)*

* **Example:** `schedule = [[[1,2],[5,6]],[[1,3]],[[4,10]]]` → `[[3,4]]`
* **Constraints:** `1 ≤ schedule.length, schedule[i].length ≤ 50`; `0 ≤ start < end ≤ 10^8`.

## 🔹 Quick Breakdown

* **Difficulty Level:** Hard
* **Main Approach:** **Merge all busy intervals, report the holes.** Flatten every employee's intervals into one list, sort by start, and sweep while tracking the furthest `end` seen so far. When the next interval starts after that `end`, nobody is working in between — that gap is common free time.
* **Core Concept:** the union of the busy intervals' complement, restricted to the span between the earliest start and the latest end
* **When to Use This Pattern?** "When is *everyone* free / *no one* busy / *no* meeting scheduled" — merge-intervals thinking where the answer is the gaps, not the merged blocks.
* **Mistakes to Avoid:**
  * Comparing with the *previous interval's* end instead of the **maximum** end so far — a long early interval can cover several short later ones.
  * Using `>=`: a gap needs positive length, so touching intervals (`[1, 2]` and `[2, 3]`) produce nothing.
  * Reporting time before the first start or after the last end — it is infinite free time and not asked for.

## 🔹 Optimization Path

* **Brute Force:** mark every busy unit slot on a timeline between the minimum start and maximum end, then read off the runs of unmarked slots — O(span + total busy length), up to 10⁸ slots.
* **Optimized Solution:** sort all intervals by start, sweep with `reach = max end` — O(N log N), N = total number of intervals.
* **Further Improvements Possible?** Each employee's list is already sorted and non-overlapping, so a min-heap over the heads of the `k` lists merges them in O(N log k).

## 🔹 Solution Breakdown

* **Optimal Approach:** `reach = end of the first interval`. For each next interval: if `start > reach`, append `Interval(reach, start)`; then `reach = max(reach, end)`.
* **Why This Works?** After sorting, `reach` is the right edge of the union of everything started so far. An interval that starts beyond it leaves a window no earlier interval can cover, and no later interval starts before this one, so the window is free for every employee.
* **Edge Cases Considered:**
  * One employee with one interval → no gap, return `[]`.
  * Intervals nested inside a longer one — `max` keeps `reach` from moving backwards.
  * The input holds `Interval` objects (`.start` / `.end`), not lists.

## 🔹 Tricks & Patterns Used

* **Gaps from a running maximum:** `reach` only grows, so one pass finds every hole.
* **Flatten then sort:** the per-employee grouping is irrelevant for the answer.

## 🔹 Alternative Data Structures

* Min-heap of `(start, employee, index)` — merges the pre-sorted lists lazily, O(N log k).
* Event list `(time, +1/-1)`: free time is where the active count is `0`.

## 🔹 Complexity Analysis

* **Time Complexity:** O(N log N) for the sort
* **Space Complexity:** O(N) for the flattened list (output is smaller)

## 🔹 Code Snippet (Brute Force)

```python
from typing import List


class Interval:
    def __init__(self, start: int = None, end: int = None):
        self.start = start
        self.end = end


class Solution:
    def employeeFreeTime(self, schedule: '[[Interval]]') -> '[Interval]':
        busy = set()
        low, high = float("inf"), float("-inf")
        for employee in schedule:
            for iv in employee:
                busy.update(range(iv.start, iv.end))
                low, high = min(low, iv.start), max(high, iv.end)
        free = []
        slot = low
        while slot < high:
            if slot in busy:
                slot += 1
                continue
            begin = slot
            while slot < high and slot not in busy:
                slot += 1
            free.append(Interval(begin, slot))
        return free
```

## 🔹 Code Snippet (Optimized)

```python
from typing import List


class Interval:
    def __init__(self, start: int = None, end: int = None):
        self.start = start
        self.end = end


class Solution:
    def employeeFreeTime(self, schedule: '[[Interval]]') -> '[Interval]':
        busy = sorted((iv for employee in schedule for iv in employee), key=lambda iv: iv.start)
        free = []
        reach = busy[0].end
        for iv in busy[1:]:
            if iv.start > reach:
                free.append(Interval(reach, iv.start))
            reach = max(reach, iv.end)  # an early long interval may swallow later ones
        return free
```
